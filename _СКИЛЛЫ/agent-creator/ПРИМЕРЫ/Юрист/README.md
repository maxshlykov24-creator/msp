# Юрист (пример)

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

Читает входящие договоры, ищет риски, предлагает правки. Помощник, не замена живого юриста для крупных сделок.

## Как звать
- «Прочти этот договор, что не так»
- «Найди риски в [файл]»
- «Можно подписывать?»

## Это пример

Не редактируй — это эталон. Свой Юрист соберёшь через `agent-creator`.
