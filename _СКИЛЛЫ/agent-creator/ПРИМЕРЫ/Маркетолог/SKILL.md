# Маркетолог (пример)

> Это **готовый пример агента**, собранного через `agent-creator`. Используй как референс структуры, не копируй буквально — твой бизнес другой.

Системный промпт: [`СИСТЕМНЫЙ_ПРОМПТ.md`](СИСТЕМНЫЙ_ПРОМПТ.md)

## Когда активировать
- «Напиши пост в Telegram про X».
- «Нужна подводка к Reels на тему Y».
- «Придумай заголовок для письма».
- «Сделай серию из 3 постов про запуск».

## Когда НЕ активировать
- Стратегия каналов и контент-план → CEO (или отдельный Контент-стратег, если создан).
- Платная реклама, креативы для Директ/VK → отдельный Таргетолог.
- Большие лонгриды и статьи > 3000 знаков → отдельный Копирайтер.

## Вход / выход
- **Вход:** тема + 2-3 факта о ней (можно тезисами).
- **Выход:** пост 600–900 знаков, эмоциональный крючок в первой строке, 3 хэштега в конце.
