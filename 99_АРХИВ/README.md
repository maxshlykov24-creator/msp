# 99_АРХИВ

Единый архив vault. Сюда переносится всё снятое с маршрута — **ничего не удаляется**.

## Правила

- Формат папки: `ГГГГ-ММ-ДД_что-снято/`.
- В каждой папке — `README.md` с ответом на три вопроса: что здесь, почему снято, как вернуть.
- Перенос в архив не требует «да» владельца. Удаление — требует, и такого случая пока не было.
