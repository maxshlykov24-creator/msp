# МАСТЕР АГЕНТОВ

**Команда:** `@мастер`  
**Правило:** `.cursor/rules/мастер.mdc`

## Что делает

Создаёт новых агентов для Cursor по шаблону, без ошибок:
1. Интервью → 5 вопросов о задачах агента
2. Черновик → заполняет шаблон реальным содержимым
3. Валидация → чеклист 12 пунктов
4. Запись → `.cursor/rules/[имя].mdc` + папка `3. АГЕНТЫ/`
5. Регистрация → вносит агента в команду CEO (`сео.mdc`)

## Вызов

```
@мастер создай агента для [задача]
@мастер аудит @[агент]
@мастер /fast создай @[имя]: [полное ТЗ]
```

## Структура папки

```
3. АГЕНТЫ/МАСТЕР/
├── README.md
├── _КОНТЕКСТ/
│   └── примеры/      ← удачные созданные агенты
└── _ЛОГИ/            ← лог созданных агентов
```
