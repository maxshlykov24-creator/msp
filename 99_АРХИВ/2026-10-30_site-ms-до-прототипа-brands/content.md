# Контент сайта — черновик для правок

> Этот файл — рабочая шпаргалка. Все правки вносятся в `index.html` по маркерам `<!-- EDIT: ... -->`.
> Говори в Cursor: «поменяй [имя маркера] на [новый текст]» — и правка займёт 30 секунд.

---

## Маркеры и что там сейчас

### Навигация
- `nav-name` — имя в шапке: **Максим**
- `nav-cta` — кнопка: **Написать** → ссылка на Telegram

### Hero
- `hero-badge` — подпись над заголовком: **Архитектор систем · MS Product**
- `hero-title` — заголовок: **Строю системы, которые работают без вас**
- `hero-subtitle` — подзаголовок: краткое описание услуг + фиксированный чек
- `hero-cta-primary` — кнопка **Написать в Telegram** → `t.me/USERNAME`
- `hero-cta-secondary` — кнопка **Смотреть кейсы** → `#cases`

### Клиенты
- `clients-label` — подпись: **Работали вместе**
- `clients-list` — список: MANSBAND, MartaChe, DK Academy, Detensor

### Услуги
- `service-card-1` — **amoCRM**: воронки, автоматизация, интеграция с мессенджерами
- `service-card-2` — **МойСклад**: миграция, синхронизация, учёт
- `service-card-3` — **Боты и интеграции**: Telegram-боты, webhook, API

### Кейсы
- `case-1` — **MANSBAND**: Talk.me + amoCRM → 0 потерянных обращений, −3 ч/день
- `case-2` — **MartaChe**: RetailCRM → МойСклад → 100% данных, авто-бонусы
- `case-3` — **DK Academy**: бот + LiveInform + amoCRM → 24/7, −5 ч/день, 3 системы

### О себе
- `about-heading` — заголовок: **О себе**
- `about-text` — три абзаца о специализации, стеке, принципе работы
- `about-principles` — три принципа: Твёрдое слово / Системность / Код вместо человека
- `about-stats` — 4 карточки цифр: **10+ внедрений / 3+ года / Фикс чек / B2B**

### Контакты
- `contact-heading` — **Есть задача? Давайте разберём её.**
- `contact-subtitle` — подзаголовок
- `contact-cta` — кнопка **Написать в Telegram**
- `contact-links` — email + @USERNAME

### Футер
- `footer-copy` — копирайт
- `footer-links` — ссылка на Telegram
