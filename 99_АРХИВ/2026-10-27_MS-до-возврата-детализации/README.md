# MS Product · финальный комплект

Утверждённая геометрия MS, палитра бургунди, матовая фактура по образцу фона. Тёмная и светлая атмосфера. Регистр названия: **MS Product**.

- [Форматы и ограничения разрешения](web-kit/ИНСТРУКЦИЯ.txt)

Контуры и надпись векторные; фактура растровая. Материал восстановлен по утверждённому образцу отдельным изображением 1216×1293 и используется целиком. Крупные обложки экспортированы из SVG шириной 3840 пикселей, фон сохраняет исходное растровое разрешение.

Старые варианты и история сохранены в `99_АРХИВ/2026-10-27_MS-перед-финалом-качества` и предыдущих архивах MS. Для новых материалов использовать этот комплект.
