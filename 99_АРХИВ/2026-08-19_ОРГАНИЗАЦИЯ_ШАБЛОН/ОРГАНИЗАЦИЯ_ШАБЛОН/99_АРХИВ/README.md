# 99_АРХИВ/

**Сюда переезжает всё устаревшее.** Не удаляется — лежит как бэкап.

Префикс `99_` нужен чтобы папка валилась в самый низ списка в Finder/Проводнике и не отвлекала.

## Что сюда попадает

- **`StartPack_v1_оригинал_{дата}/`** — оригинал StartPack ученика после установки М2.
- **`_контекст_starpack_{дата}/`** — копия StartPack из `_ВХОДЯЩЕЕ/` после полной обработки.
- **`{отдел}_archived_{дата}/`** — отделы, которые ученик удалил командой `/убери отдел X`.
- **`M2_отменено_{дата}/`** — если ученик откатил установку М2.

## Восстановление

| Что | Команда |
|---|---|
| Откатить установку М2 | `/откати установку М2` |
| Вернуть удалённый отдел | `/восстанови отдел X` |
| Восстановить файл из старого StartPack | `/найди файл X в архиве` |

## Что НЕ удалять

Ничего из этой папки не удаляй вручную — Архивариус ведёт каталог восстановления.
