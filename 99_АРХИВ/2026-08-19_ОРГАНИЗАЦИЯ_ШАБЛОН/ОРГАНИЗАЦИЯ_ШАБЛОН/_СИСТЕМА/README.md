# _СИСТЕМА/

Служебная часть. **Ученик сюда обычно не лезет** — здесь живут агенты, скиллы, правила, логи.

## Структура

| Папка | Что внутри |
|---|---|
| `_АГЕНТЫ/` | 4 системных агента: CEO, Архивариус, Аудитор, Архитектор |
| `_СКИЛЛЫ/` | Скиллы агентов: inbox-classifier, department-builder и унаследованные из StartPack v1 |
| `_ПРАВИЛА/` | `.mdc`-правила: 10-источники, 11-верификация, 15-границы (новые в М2) |
| `_ЛОГИ/` | Журнал работы агентов: что сделали, какой результат |
| `_ПРОФИЛЬ/` | `PROFILE.md` владельца (имя, бизнес, роль, MBTI) |
| `_ПОДДЕРЖКА/` | FAQ, TROUBLESHOOTING, инструкции по платформам |

## Главные файлы (создаются Архитектором при установке М2)

- **`РЕЕСТР_КОМАНДЫ.md`** — иерархия и список всех агентов с зонами ответственности. CEO читает первым.
- **`ОБЩАЯ_БАЗА_СМЫСЛОВ.md`** — главный смысловой файл компании (миссия, обещания, ценности).
- **`КАРТА_СМЫСЛОВ.md`** — оглавление со ссылками в отделы (унаследовано из M1).
- **`LICENSE.md`** — полная лицензия и условия использования.
- **`ВЕРСИЯ.md`** — текущая версия системы.

## Когда заглядывать сюда

- Хочешь посмотреть что и как настроено у агентов.
- Дописать своё `.mdc`-правило (продвинутый режим).
- Заглянуть в `_ЛОГИ/` чтобы понять «что вчера делал агент X».
- Прочитать `LICENSE.md` если есть вопросы по условиям.

## Когда НЕ трогать руками

- Системные промпты агентов — лучше через Архитектора (`/архитектор обнови промпт X`).
- Реестр команды — только Архитектор через верификацию.
- `_ПРАВИЛА/*.mdc` — только если очень понимаешь что делаешь.
