# _АГЕНТЫ/

Здесь живут **4 системных агента** цифровой организации. Это не руководители отделов (те живут в самих отделах) — это служебные агенты, которые работают на всю систему.

## Команда

| Агент | Роль | Триггеры активации |
|---|---|---|
| **CEO** | Маршрутизатор задач + стратегия | «привет», «помоги начать», «что делать», или первое сообщение в чате |
| **Архивариус** | Файлы, индексы, классификация входящего | «разложи», «обнови индекс», «куда это», новый файл в `_ВХОДЯЩЕЕ/` |
| **Аудитор** | Светофоры полноты карты + готовность отделов | «проверь карту», «как с контекстом», `/проверь готовность М2` |
| **Архитектор** | Структура папки (создание/изменение отделов) | `/архитектор добавь/убери/объедини отдел`, или Протокол 3 для М2 |

## Принципы

1. **Все подчинены CEO** — на любую задачу первым отвечает CEO, он решает кому передать.
2. **Никто не общается с владельцем напрямую**, кроме CEO. Остальные — через CEO.
3. **Архитектор спит** после установки — просыпается только командами `/архитектор`.
4. **Аудитор не правит** — только считает и подсвечивает.

## Структура папки агента

Каждый агент — отдельная папка со стандартным составом:

```
{Имя_агента}/
├── СИСТЕМНЫЙ_ПРОМПТ.md     ≤300 слов под любую модель Cursor
├── SKILL.md                  что умеет (короткое описание)
└── ЛОГИ/                     что делал (опционально)
```

## Что НЕ трогать руками

- `СИСТЕМНЫЙ_ПРОМПТ.md` — обновляется только Архитектором или с явного согласия владельца.
- Изменение поведения агента — через **Адаптацию**: скажи CEO «не нравится как X отвечает, сделай так-то» — он добавит правило в `АДАПТАЦИЯ.md`.
