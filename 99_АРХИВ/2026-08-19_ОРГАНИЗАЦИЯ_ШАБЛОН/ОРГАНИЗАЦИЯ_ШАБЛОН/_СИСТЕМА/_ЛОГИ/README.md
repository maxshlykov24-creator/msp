# _ЛОГИ/

Сюда агенты пишут что делали. **Это память системы между сессиями.**

## Структура

```
_ЛОГИ/
├── посл_сессия.md           ← всегда самая свежая, читается агентами первой
├── 2026-05-05.md            ← ежедневный архив
├── 2026-05-06.md
└── ...
```

## Формат строки

```
- {время HH:MM} · {агент} · {что сделал} · {результат: OK / ошибка / спросил} · [→ {ссылка}]
```

Пример:
```
- 14:32 · Архивариус · разложил KP_СберAI.pdf в 02_ПРОДАЖИ · OK · → _ДЕЛЬТЫ/2026-05-05#0042
- 15:01 · CEO · передал задачу Руководителю Маркетинга · OK
- 15:14 · Аудитор · светофоры 17/21 🟢, 4 жёлтых · OK · → ЛОГИ_АУДИТА/
```

## Правило 13-логи (М2)

Каждый агент **до действия** читает `посл_сессия.md`, **после** — допишет строку. Это даёт контекст между активациями.

## Rollover

В полночь Архивариус переносит вчерашний `посл_сессия.md` в архив `{вчера}.md`. Очищает текущий, оставляет только шапку. Это техническая операция, ученик её не замечает.
