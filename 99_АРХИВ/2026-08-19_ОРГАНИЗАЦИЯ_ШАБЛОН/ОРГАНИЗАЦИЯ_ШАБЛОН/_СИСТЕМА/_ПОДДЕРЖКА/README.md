# _ПОДДЕРЖКА/

Справочные материалы для ученика. **Унаследовано из StartPack v1.**

## Файлы

| Файл | Что внутри |
|---|---|
| `FAQ.md` | Часто задаваемые вопросы |
| `TROUBLESHOOTING.md` | Что делать если: модель не отвечает, файл потерялся, агент глючит, и т.д. |
| `WINDOWS_SETUP.md` | Настройка для Windows-пользователей (UTF-8, пути, кириллица) |
| `MBTI_АДАПТАЦИЯ.md` | Справочник MBTI-стилей для команды агентов (как подстраиваться под владельца) |

## Когда заглядывать

- Что-то не работает → `TROUBLESHOOTING.md`.
- Не знаешь как сделать X → `FAQ.md`.
- Только настраиваешь систему → `WINDOWS_SETUP.md` если на Windows.
