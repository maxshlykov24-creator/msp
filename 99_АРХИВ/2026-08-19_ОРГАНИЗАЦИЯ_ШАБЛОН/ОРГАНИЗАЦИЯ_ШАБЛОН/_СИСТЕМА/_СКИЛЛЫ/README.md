# _СКИЛЛЫ/

Скилл = **переиспользуемый навык**, который один или несколько агентов могут вызывать.

## Скиллы из StartPack v1 (унаследованы)

| Скилл | Кто использует | Что делает |
|---|---|---|
| `auto-context-pull` | CEO | Полуавтоматический сбор контекста из 5 источников (сайт, соцсети, облако, ZIP, голосовые) → карта смыслов |
| `agent-creator` | CEO | Фабрика новых агентов из 4 вопросов (роль, задача, вход, выход) |
| `business-discovery` | CEO (fallback) | Чек-лист на 9 категорий для бизнесов без сайта/облака |

## Скиллы М2 (новые)

| Скилл | Кто использует | Что делает |
|---|---|---|
| `inbox-classifier` | Архивариус | Расщепляет входящий файл на смыслы, классифицирует в отдел, готовит карточку верификации |
| `department-builder` | Архитектор | Создаёт отдел за один проход: папка + 3 файла + регистрация в реестре |

## Структура скилла

Каждый скилл — отдельная папка:

```
{имя-скилла}/
├── SKILL.md            короткое описание (что делает, кто использует)
├── ИНСТРУКЦИЯ.md       детальный протокол (вход → шаги → выход)
└── ШАБЛОНЫ/            опциональные шаблоны для генерации артефактов
```

## Принцип «один скилл = один навык»

Не швейцарский нож. Если скилл начинает делать «и то и это» — разбиваем на два.
