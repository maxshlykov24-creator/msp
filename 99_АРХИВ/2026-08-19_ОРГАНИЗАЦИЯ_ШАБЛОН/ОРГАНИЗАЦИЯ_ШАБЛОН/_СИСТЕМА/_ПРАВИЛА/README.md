# _ПРАВИЛА/

Здесь лежат **`.mdc`-правила Cursor**, которые задают поведение всей команды агентов.

## Правила М2 (3 новых, в дополнение к 9 из StartPack v1)

| Файл | Что задаёт |
|---|---|
| `10-источники.mdc` | **Anti-галлюцинация.** Агент отвечает только из своих файлов + ОБЩАЯ_БАЗА_СМЫСЛОВ. Если данных нет — говорит «не знаю», не выдумывает. |
| `11-верификация.mdc` | **Изменения требуют «да».** Файл из `_ВХОДЯЩЕЕ/`, обновление БАЗА_СМЫСЛОВ или РУКОВОДИТЕЛЬ.md, создание/удаление отделов — каждое требует подтверждения ученика. |
| `15-границы.mdc` | **Изоляция отделов.** Руководитель отдела отвечает только по своему отделу. Прямые обращения между руководителями запрещены — координация только через CEO. |

## Правила из StartPack v1 (унаследованы)

`00-ядро`, `01-ceo`, `02-архивариус`, `03-аудитор`, `95-attribution`, `96-mbti`, `97-auto-context-pull`, `98-business-discovery`, `99-agent-creator` — лежат в `.cursor/rules/` корня.

## Где живут .mdc

Cursor требует чтобы `.mdc`-правила лежали в `.cursor/rules/` в корне проекта. Поэтому **физически** все правила (и М1, и М2) — в `.cursor/rules/`. Эта папка `_СИСТЕМА/_ПРАВИЛА/` — **зеркало для удобства чтения и редактирования** (с навигацией, README, версиями).

Архивариус синхронизирует две папки автоматически.

## Что НЕ делать

- Не редактировать `.mdc` вручную, если не понимаешь как они влияют на агентов.
- Не отключать правила `10-источники` и `11-верификация` — они защищают от галлюцинаций и потери контекста.
