# _ПРОФИЛЬ/

Здесь живёт **`PROFILE.md`** владельца — один из ключевых файлов системы. Все агенты читают его при старте через правило `00-ядро.mdc`.

## Содержание PROFILE.md

```markdown
## Лицензиат
- Имя:
- Email:
- Версия системы:

## Кто я
- Имя, город:
- Возраст / роль:
- MBTI (заполняется командой через наблюдение):

## Бизнес
- Название:
- Ниша:
- География:
- Выручка / стадия:
- Команда (количество людей):
- Каналы продаж:

## Боли на 90 дней (3 главные)
1.
2.
3.

## 3 KPI
1.
2.
3.

## Стек инструментов
- ...
```

## Дополнительные файлы

- `СТИЛЬ_РАБОТЫ.md` — как с владельцем общаться (длина ответов, формальность, что любит / не любит).
- `ОТКРЫТЫЕ_ВОПРОСЫ.md` — пробелы в карте смыслов и противоречия для разбора.

## Что переезжает в `_ПРОФИЛЬ/` при установке М2

Из StartPack v1: `_ПРОФИЛЬ/PROFILE.md`, `_ПРОФИЛЬ/СТИЛЬ_РАБОТЫ.md` (если есть).
