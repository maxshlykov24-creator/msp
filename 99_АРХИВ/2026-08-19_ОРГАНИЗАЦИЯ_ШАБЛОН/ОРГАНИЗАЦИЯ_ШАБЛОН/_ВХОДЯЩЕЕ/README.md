# _ВХОДЯЩЕЕ/

**Это главная точка взаимодействия с системой.** Сюда ученик кидает любые файлы — Архивариус разложит через верификацию.

## Подпапки

| Папка | Что внутри |
|---|---|
| `новое/` | Сюда кидаешь файлы. Архивариус читает их в течение минуты. |
| `_к_проверке/` | Карточки от Архивариуса с предложением «положить в отдел X?». Открой и ответь. |
| `_обработано/` | Файлы которые уже разложены по отделам. Архив для истории. |

## Как пользоваться

1. Положи файл в `новое/`.
2. Через ~30 секунд в `_к_проверке/` появится карточка. Открой её.
3. Ответь в чате CEO: «да», «в другой отдел», «не сохранять».
4. После «да» — Архивариус разложит файл и переместит исходный в `_обработано/`.

## Что сюда можно

- Документы (PDF, MD, TXT, DOCX)
- Таблицы (CSV, XLSX)
- Транскрибации (TXT, JSON)
- Голосовые расшифровки (TXT)
- Скриншоты с пояснением (PNG + MD)

## Что НЕ кидать сюда

- Личные файлы не про бизнес (фото детей, чеки за продукты).
- Файлы которые ты точно знаешь куда (клади сразу в нужный отдел в его локальное `ВХОДЯЩЕЕ/`).
- Огромные архивы > 500 МБ — Архивариус не справится.
