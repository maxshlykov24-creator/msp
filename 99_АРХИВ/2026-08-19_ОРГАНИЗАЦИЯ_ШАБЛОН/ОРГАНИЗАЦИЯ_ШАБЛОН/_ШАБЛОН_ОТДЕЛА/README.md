# _ШАБЛОН_ОТДЕЛА/

Это **образец**, по которому Архитектор создаёт отдел при установке М2 или командой `/архитектор добавь отдел Y`.

## Что внутри отдела

```
0X_ИМЯ_ОТДЕЛА/
├── РУКОВОДИТЕЛЬ.md       системный промпт + зона ответственности + примеры + чек-лист
├── БАЗА_СМЫСЛОВ.md        накопительная (растёт от каждого входящего)
└── ВХОДЯЩЕЕ/              локальное входящее (если ученик кладёт сразу сюда)
```

3 элемента — минимум. Тематические подпапки (`скрипты/`, `звонки/`, etc.) появляются естественно когда Архивариус кладёт файл подходящей категории. Не создаются заранее.

## Как Архитектор использует шаблон

1. Берёт `_ШАБЛОН_ОТДЕЛА/РУКОВОДИТЕЛЬ.md`.
2. Подставляет в плейсхолдеры данные из карты смыслов конкретного ученика:
   - Имя отдела
   - Зона ответственности (3–5 задач из №11 «Процессы»)
   - Что НЕ делает (3 типичных не-моих)
   - Эталонные диалоги (под ToV и продукт ученика)
   - Чек-лист первого дня (адаптированный)
3. Кладёт результат в новый отдел `0X_ИМЯ/РУКОВОДИТЕЛЬ.md`.
4. То же самое с `БАЗА_СМЫСЛОВ.md` (короткая шапка с тематическими разделами).

## Принципы наполнения

- **Готовность из коробки 60–70%** — ученик дорабатывает 5 шагов чек-листа за 10 минут.
- **Под любую модель** — длина РУКОВОДИТЕЛЬ.md ≤300 слов в активной части (без чек-листа).
- **Из контекста ученика** — никаких пресетов, только то что есть в его карте смыслов.
