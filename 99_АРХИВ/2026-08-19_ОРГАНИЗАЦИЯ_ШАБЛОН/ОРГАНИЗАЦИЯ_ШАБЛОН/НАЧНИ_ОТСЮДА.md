# 🎱 Привет. Это твоя цифровая организация.

> Ты только что закончил **Модуль 2** курса «Внедрение ИИ в бизнес». У тебя на диске — твоя цифровая организация с первыми ИИ-сотрудниками. Открывай Cursor, начинаем.

## Быстрый старт (1 минута)

| Что хочешь | Что делать |
|---|---|
| Что-то спросить | Открой чат Cursor (`Cmd+L` или `Ctrl+L`), напиши **«привет»**. CEO маршрутизирует. |
| Кинуть файл | В `_ВХОДЯЩЕЕ/новое/`. Архивариус разложит через карточку верификации. |
| Найти что-то | `/найди X` или CEO в чате |
| Прочитать инструкцию | Открой [`ИНСТРУКЦИЯ.md`](ИНСТРУКЦИЯ.md) или скажи `/помощь` |

## Твоя команда

После установки М2 в `_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md` — полный список ИИ-сотрудников твоей компании. Для быстрой ориентации:

- **CEO** — общается с тобой, маршрутизирует задачи.
- **Архивариус** — работает с файлами, разбирает входящее.
- **Аудитор** — считает светофоры готовности.
- **Архитектор** — структура папки. Спит до запроса.
- **Руководители твоих отделов** — первые ИИ-сотрудники в твоей компании. По одному на отдел. Имена и состав — индивидуально под твой бизнес.

## Если что-то не так

| Симптом | Команда |
|---|---|
| Агент отвечает «средне» | Скажи «нет, поправь так-то» — он обновит свой КОНТЕКСТ |
| Агент придумывает | «Не выдумывай, только из моих файлов» |
| Что-то сломалось | `/откати установку М2` — вернёт StartPack v1 |
| Не помню как делать X | `/помощь` |
| Хочу видеть всю команду | `/команда` |

## Структура папки

```
{твой_бизнес}/
├── _ВХОДЯЩЕЕ/         главная точка ученика
├── 0X_ОТДЕЛ_А/         (количество и имена — твои)
├── 0Y_ОТДЕЛ_Б/
├── ...
├── 99_АРХИВ/           устаревшее, восстановимое
└── _СИСТЕМА/           служебка (агенты, скиллы, правила, логи)
```

Подробности — в `ИНСТРУКЦИЯ.md` раздел 5 (Карта файлов).

## Что НЕ трогать руками

- Содержимое `_СИСТЕМА/_АГЕНТЫ/*/СИСТЕМНЫЙ_ПРОМПТ.md` — обновляется командой.
- `_СИСТЕМА/_ПРАВИЛА/*.mdc` — Cursor Rules, ломаются при ручной правке.
- `_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md` — Архитектор ведёт.
- Файлы в `99_АРХИВ/` — не удалять (нужны для отката).

## Что дальше — Модуль 3

После М2 у тебя есть структура и руководители-агенты, но они **не работают 24/7** — живут в твоём Cursor. В М3 — даём им тело: VPS + Clawbot. Тогда они смогут принимать звонки, отвечать в Telegram, обрабатывать почту.

Подготовка к М3 — `/проверь готовность М2`. Получишь 3 светофора. Все зелёные → М3 откроется.
