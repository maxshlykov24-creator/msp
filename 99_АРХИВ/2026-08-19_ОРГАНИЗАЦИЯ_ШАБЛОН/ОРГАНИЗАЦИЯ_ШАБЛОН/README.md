# ОРГАНИЗАЦИЯ_ШАБЛОН

Это **мастер-шаблон цифровой организации** Модуля 2 курса «Внедрение ИИ в бизнес. Второй поток».

## Что здесь

Эта папка — образец, по которому **Архитектор** разворачивает цифровую организацию для конкретного ученика после М1. Сама по себе папка не работает — она шаблонная.

В реальной работе ученика папка получает имя его бизнеса (`PLEADA/`, `Krylov_Consulting/`, etc.) и наполняется индивидуальным контентом из его карты смыслов.

## Структура

```
ОРГАНИЗАЦИЯ_ШАБЛОН/
├── _ВХОДЯЩЕЕ/                 главная точка ученика
├── 99_АРХИВ/                   неактивное (с префиксом 99 → внизу списка)
├── _СИСТЕМА/                   служебная часть (ученик сюда не лезет)
│   ├── _АГЕНТЫ/                CEO, Архивариус, Аудитор, Архитектор
│   ├── _СКИЛЛЫ/                inbox-classifier, department-builder
│   ├── _ПРАВИЛА/               .mdc-правила
│   ├── _ЛОГИ/                  что делали агенты
│   ├── _ПРОФИЛЬ/               PROFILE.md
│   └── _ПОДДЕРЖКА/             FAQ, TROUBLESHOOTING
├── _ШАБЛОН_ОТДЕЛА/             образец отдела (используется Архитектором)
├── НАЧНИ_ОТСЮДА.md             entry point для ученика
└── ИНСТРУКЦИЯ.md               полная инструкция пользования
```

## Что заполнится при развёртывании на бизнес ученика

- В корне появятся **отделы 0X_ИМЯ** (3–8 штук, зависит от карты смыслов).
- В каждом отделе — РУКОВОДИТЕЛЬ.md с заполненной зоной ответственности.
- `_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md` отразит реальную иерархию.
- `_СИСТЕМА/ОБЩАЯ_БАЗА_СМЫСЛОВ.md` соберёт смыслы уровня компании.
- `ИНСТРУКЦИЯ.md` адаптируется под состав отделов ученика.

## Принципы

1. **Простота.** ≤300 слов в любом промпте, под любую модель Cursor.
2. **Готовые решения через диалог.** Архитектор предлагает структуру из карты смыслов, ученик верифицирует.
3. **StartPack нетронут.** Копия в `_ВХОДЯЩЕЕ/`, оригинал → `99_АРХИВ/` в финале.
4. **Откат тривиален.** Команда `/откати установку М2` возвращает StartPack v1.
