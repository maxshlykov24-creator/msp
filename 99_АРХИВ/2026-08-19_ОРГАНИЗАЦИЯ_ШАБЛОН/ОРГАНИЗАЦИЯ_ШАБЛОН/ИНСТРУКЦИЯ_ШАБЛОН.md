# 🎱 ИНСТРУКЦИЯ — Цифровая организация {{ИМЯ_БИЗНЕСА}}

> Полное руководство по работе с твоей цифровой организацией.
> Команда `/помощь` в любом чате открывает этот файл.

---

## 1. Что у тебя есть

После Модуля 2 у тебя на диске:

- **{{N}} отделов** твоей компании (зеркало реальной структуры).
- **{{N}} ИИ-сотрудников** — руководителей отделов, готовых к работе на 60–70% сразу.
- **CEO** — общается с тобой и маршрутизирует задачи.
- **Архивариус, Аудитор, Архитектор** — служебные агенты.
- **Конвейер `_ВХОДЯЩЕЕ/`** с верификацией — кидаешь файл, разбирается, раскладывается по «да».
- **Реестр команды** — `_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md` (список всех ИИ-сотрудников).

## 2. Первый день (≤30 минут)

- [ ] **Шаг 1:** Открой Cursor, нажми `Cmd+L` / `Ctrl+L`, напиши `привет`.
- [ ] **Шаг 2:** CEO представит команду. Скажи `/команда` — увидишь полный реестр.
- [ ] **Шаг 3:** Выбери один отдел и пройди `ЧЕК-ЛИСТ_ПЕРВОГО_ДНЯ` в его `РУКОВОДИТЕЛЬ.md` (~10 минут).
- [ ] **Шаг 4:** Кинь один реальный документ в `_ВХОДЯЩЕЕ/новое/`. Через ~30 секунд в `_ВХОДЯЩЕЕ/_к_проверке/` появится карточка. Ответь «да».
- [ ] **Шаг 5:** Спроси одного руководителя отдела что-нибудь по его теме. Если ответ слабый — скажи «нет, поправь так-то».

## 3. Ежедневная работа

| Когда | Что делать |
|---|---|
| Утром | `что у меня в _ВХОДЯЩЕЕ/_к_проверке/` — разобрать карточки |
| Днём | Кидать новые файлы в `_ВХОДЯЩЕЕ/новое/` по мере появления |
| Вечером | `руководитель X, что было сегодня` — сводка по отделу |
| Раз в неделю | `/проверь готовность` — Аудитор покажет светофоры и баллы |
| Раз в месяц | Открыть `_СИСТЕМА/_ДЕЛЬТЫ/` — что менялось в контексте |
| Раз в квартал | Обновить `КАРТА_СМЫСЛОВ.md` (новые цели, продукты) |

## 4. Команды

### Прямое обращение к агенту через @ (нативно в Cursor)

Каждый ИИ-сотрудник = `.mdc`-правило в `.cursor/rules/`. Cursor сам распознаёт `@имя_файла` в чате — **autocomplete показывает доступных при наборе `@`**.

| Обращение | Кому |
|---|---|
| `@ceo` | CEO (универсальный, всегда работает) |
| `@archive` | Архивариус |
| `@audit` | Аудитор Контекста |
| `@architect` | Архитектор |
| `@dept-{отдел}` | Руководитель этого отдела (например `@dept-продажи`) |
| `@{имя}` | Руководитель по своему имени (если ты его задал — например `@маша`) |

> **Совет:** в чате наберите `@` — Cursor покажет всех доступных. Не нужно помнить имена.

Полный список — `_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md` или команда `/команда`.

### Активация и навигация
| Команда | Что делает |
|---|---|
| `привет` / `помоги начать` | CEO маршрутизирует |
| `/команда` | Реестр всех ИИ-сотрудников с именами и алиасами |
| `/помощь` | Открыть эту инструкцию |
| `/найди X` | Поиск файла по системе |

### Управление структурой
| Команда | Что делает |
|---|---|
| `/архитектор объедини отделы X и Y` | Слияние двух отделов |
| `/архитектор раздели отдел X` | Разделение |
| `/архитектор убери отдел X` | Удаление (в `99_АРХИВ/`) |
| `/архитектор добавь отдел Y` | Создание нового |
| `/архитектор переименуй X в Y` | Только имя, код в реестре остаётся |

### Работа с файлами
| Команда | Что делает |
|---|---|
| `/разложи` | Архивариус разбирает все файлы из `_ВХОДЯЩЕЕ/новое/` |
| `/откати дельту YYYY-MM-DD#NN` | Откат конкретного изменения |

### Контроль и аудит
| Команда | Что делает |
|---|---|
| `/проверь готовность М2` | Аудитор → 3 светофора + балл |
| `/отчёт по отделам` | Состояние всех отделов |
| `/как дела у X` | Отчёт по конкретному руководителю |

### Кризис
| Команда | Что делает |
|---|---|
| `/откати установку М2` | Возврат к StartPack v1 |

## 5. Карта файлов — что куда класть

| Тип документа | Куда класть | Кто разложит |
|---|---|---|
| КП, прайс, скрипт продаж | `_ВХОДЯЩЕЕ/новое/` | Архивариус → отдел продаж |
| Резюме, оценка, регламент найма | `_ВХОДЯЩЕЕ/новое/` | Архивариус → персонал |
| Счёт, накладная, отчёт | `_ВХОДЯЩЕЕ/новое/` | Архивариус → финансы |
| Жалоба клиента | `_ВХОДЯЩЕЕ/новое/` | Архивариус → качество |
| Креатив, пост, идея рекламы | `_ВХОДЯЩЕЕ/новое/` | Архивариус → маркетинг |
| Стратегическое решение | `00_РУКОВОДСТВО/решения-собственника/` (вручную) | сам |
| Не знаешь куда | `_ВХОДЯЩЕЕ/новое/` | Архивариус через карточку |

## 6. Конвейер `_ВХОДЯЩЕЕ/` — пошагово

```
1. Кладёшь файл в _ВХОДЯЩЕЕ/новое/
2. Через ~30 секунд в _ВХОДЯЩЕЕ/_к_проверке/ — карточка:
   "Файл X. Смыслы: 1/2/3. Положу в отдел Y. Применить?"
3. Ответ:
   • "да" — раскладывает + обновляет БАЗА_СМЫСЛОВ.md
   • "в Z" — переразметка в другой отдел
   • "не сохраняй" — в _обработано/_отклонено/
4. Файл переезжает в отдел.
5. Запись в _СИСТЕМА/_ДЕЛЬТЫ/ — для отката.
```

## 7. Работа с руководителями

### Активация
`руководитель {название}, ...` — например:
- «руководитель продаж, что ответить клиенту X»
- «руководитель маркетинга, идея для поста про новый продукт»

### Если ответ слабый
Скажи **«нет, поправь так-то»** — руководитель обновит свой контекст. Следующий ответ будет лучше.

### Когда передать другому
- Запрос требует двух+ отделов → `передай CEO`.
- Стратегический вопрос → передай в `00_РУКОВОДСТВО`.
- Вопрос про статистику всей компании → ждёт Аналитика (М7).

## 8. Изменение системы под себя

Любое изменение — через Архитектора с верификацией:

| Хочу | Команда |
|---|---|
| Объединить два отдела (например, продажи и маркетинг) | `/архитектор объедини 02 и 06` |
| Разделить большой отдел | `/архитектор раздели X` |
| Убрать ненужный | `/архитектор убери X` |
| Добавить новый (юр.отдел, R&D) | `/архитектор добавь {{ИМЯ}}` |
| Сменить режим руководителя (нанял человека) | `/руководитель X режим усиливаю` |

## 9. Что делать если что-то не так

| Симптом | Решение |
|---|---|
| Агент отвечает «средне» | Дозаполни КОНТЕКСТ.md его отдела + кинь 3–5 примеров твоей работы в его `ВХОДЯЩЕЕ/` |
| Агент придумывает | Проверь правило `_ПРАВИЛА/10-источники.mdc` — оно должно быть активно. Скажи «не выдумывай, только из моих файлов» |
| Не находишь файл | `/найди X` или CEO в чате |
| Что-то сломалось | `/откати установку М2` — вернёт StartPack v1 |
| Нужно вернуть случайно изменённое | `/откати дельту YYYY-MM-DD#NN` — список в `_СИСТЕМА/_ДЕЛЬТЫ/` |
| Завис конвейер | Открой карточку в `_ВХОДЯЩЕЕ/_к_проверке/` руками, ответь |

## 10. Поддержание контекста (раз в неделю/месяц)

- **Раз в неделю:** `/проверь готовность` — Аудитор пробежит светофоры и выдаст балл.
- **Раз в месяц:** посмотри `_СИСТЕМА/_ДЕЛЬТЫ/` — что менялось.
- **Раз в квартал:** обнови `КАРТА_СМЫСЛОВ.md` (новые цели, продукты).
- **Когда нанял человека:** `/руководитель X режим усиливаю` — агент перейдёт в режим помощника.

## 11. Готовность к Модулю 3

Перед М3 проверь:
- [ ] 3 светофора Аудитора 🟢
- [ ] Хотя бы один файл прошёл через конвейер
- [ ] Чек-лист первого дня выполнен в одном отделе
- [ ] `_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md` отражает реальный состав

Все ✅ → М3 откроется автоматически.
