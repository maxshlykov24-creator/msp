# Medusa Store Studio

Заготовка лежит здесь:

`2. БИЗНЕС/08_Системное/_код/medusa-store-studio/`

Это не живой магазин. Это скиллы и ранбук. Движок появляется только после `store-setup`.

## Перед работой

1. Прочитай `КАК_НАЧАТЬ.md` в той папке. Банки и прочие интеграции — `GORGO.md` плюс живые доки https://docs.gorgojs.ru, не память.
2. Скажи владельцу открыть **эту папку отдельным окном Cursor**, не корень vault. Иначе скиллы `.agents/` / `.claude/` / `.kimi-code/` не подхватятся.
3. Дальше работай по `RUNBOOK.md`. Порядок скиллов не менять: setup → architecture → design → payments-ru → shipping-ru → manage → deploy.
4. Не клади секреты в git. Не обещай «оплата работает» без тестового платежа. Чеки 54-ФЗ обязательны до продаж.

Не касса MANSBAND. Не коробка в `07_Продукт/`. Не сайт `site-ms`.
