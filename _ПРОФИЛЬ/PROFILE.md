## Главное на горизонте 90 дней

Источник правды: [`КАРТА_СМЫСЛОВ.md`](../2. БИЗНЕС/08_Системное/_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md) §17 (цели, боли, горизонты бэклога) и §10 (финансы).

- **Боль №1 (дословно):** закрыть **500 000 ₽** долгов (полный долг **1 722 294 ₽** на 2026-08-11)
- **Боль №2:** просадка фокуса (несистемное обучение/задачи → прокрастинация, апатия) + новый долг
- **Цель 90 дней:** −500к долгов через дожим конвейера (Триумф → MANSBAND → Берёза → Keris → Billboardoff → DIVO)
- **Касса май–июль 2026:** 216 / 314 / 331 тыс. ₽ (среднее 287; без подписок 238)
- **Модель:** фикс-проекты (от 70к, ощущение среднего ~150к) + сопровождение **4 000 ₽/ч** (было 3к; МАРТАче на 4к)

## 3 KPI на квартал

1. Закрыть 500 000 ₽ долгов
2. Дожать/закрыть деньги по конвейеру клиентов (см. карту §6)
3. Вернуть системность: задачи + обучение + ритм (зал / жена / Бог по утрам) — без этого эффективность падает. Сейчас **97%** времени в операционке.
