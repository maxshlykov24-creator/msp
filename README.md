**Точка входа:** Ио, исполнительный директор (`@ceo`, `@сео`, `@иос`). Отвечает по умолчанию, отдельного обращения не требует — достаточно описать задачу.

**Команда:** службы Ио · Архивариус · Аудитор · Архитектор, плюс 12 руководителей отделов. Бизнес: `@dept-стратегия` (Соломон), `@dept-продажи`, `@dept-производство`, `@dept-продукт`, `@dept-финансы`. Личное: `@dept-ритм`, `@dept-дух`, `@dept-обучение`, `@dept-люди`, `@dept-семья`, `@dept-устойчивость`, `@dept-тело` (Анатолий). Новый сотрудник — скиллом `agent-creator`, новый отдел — Архитектором, не руками.
