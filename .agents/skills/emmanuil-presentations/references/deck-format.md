# Формат содержания

Все значения — обычный текст. HTML экранируется: перенос задаётся как `\n`.
Каждая новая презентация хранит содержание в своём `deck.json`, не внутри навыка.
Контрольный пример — `assets/example.json`.

## Верхний уровень

```json
{
  "title": "Название выступления",
  "speaker": "Имя и фамилия спикера",
  "slides": [
    {"kind": "cover", "title": "Основной заголовок", "subtitle": "курсивная строка"},
    {
      "kind": "quote",
      "chapter": "РАЗДЕЛ",
      "title": "Заголовок слайда",
      "text": "Полный проверенный текст цитаты без внешних кавычек",
      "reference": "Название книги 1:1",
      "context": "Краткая проверенная подпись при необходимости",
      "image": "images/scene.png"
    },
    {"kind": "closing", "eyebrow": "ФИНАЛЬНЫЙ ВОПРОС", "title": "Первая строка", "subtitle": "главная мысль"}
  ]
}
```

Фрагмент показывает поля; это не разрешение выдумывать цитаты.
`image` ищется относительно JSON, затем в `assets/` навыка; абсолютный путь тоже допустим.
Не добавляй `image` в `cover`, `rows`, `columns`, `definition`: они изображения не выводят.
Новые изображения храни в папке задачи, не только в generated_images.

## Композиции

- `cover`: `title`, необязательный `subtitle`. Имя берётся из общего `speaker`.
- `definition`: `title`, `text`, необязательный `eyebrow`.
- `rows`: `title`, `items` из 1–3 объектов `{"title":"…","text":"…"}`.
- `columns`: те же `items`, необязательные `eyebrow`, `scope_title`, `scope_text`.
  Длинные классификации дели. При меньшем числе пунктов оцени свободное место визуально.
- `quote`: `title`, `text`, `reference`; необязательны `context`, `image`, `image_alt`, `dense`.
  Без картинки — крупный текст; с картинкой — текст слева и сцена справа.
  `dense: true` воспроизводит плотную композицию Авигеи. Если она переполняется,
  раздели цитату; не изобретай ещё более мелкую разновидность.
- `closing`: `title`, необязательны `subtitle`, `eyebrow`, `image`, `image_alt`.
  Авторскую мысль не оформляй под библейский стих без источника.

`chapter` — короткая подпись в шапке. Нумерация пересчитывается по числу slides.

## Редактура

Писание сверяй по выбранному переводу. Частичный стих допускается при согласовании
сокращения с владельцем. Перенос не меняет слов. Контекст отделён от блока цитаты.
При разделении длинного стиха сохраняй весь текст без потерь, обозначай продолжение;
не выдавай каждую половину за полный стих.

Проверка PDF удостоверяет, что JSON дошёл до нужной страницы, но не доказывает
корректность самого JSON. Вручную сверь его с вводными.

`assets/example.json` содержит утверждённую последовательность Оксаны Пуршаги.
Не переносить её имя и текст в новые выступления по умолчанию.
Иллюстрации `assets/illustrations/` можно применять к соответствующим историям.
