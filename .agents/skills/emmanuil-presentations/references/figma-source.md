# Источник Figma

Файл: https://www.figma.com/design/8EH2K6A3EVAt1aND3D44E2/

Проверенные узлы:

- `1:2` — страница Эммануил: инст, ютуб, тг и тд.
- `8791:8901` — широкий макет «за детей» из скриншота владельца, 3200×1216.
- `8791:8897` — «тв эмм», тот же стиль в 1920×1080.
- `8791:8898` — фоновая группа 16:9, экспортирована в `assets/brand/background.png`.
- `8791:8899` — цветы; `8791:8900` — текстура.
- `8800:1614` — группа «лого» в соседнем макете серии.
  `8800:1616` — надпись, `8800:1627` — внешний знак, `8800:1632` — внутренний.
- `8800:2327` — смешанный Playfair Display SemiBold и SemiBold Italic.
- `8800:2325`, `8800:2326` — Manrope Bold.

Основание `#F4DFA4`, текст `#3E4D23`. Фотография обесцвечена, стоит screen с opacity
слоя .8 и заливки .9; текстура повёрнута на 90° и наложена hard-light с фильтрами.
Сохранённый экспорт группы уже включает композицию. Не накладывай эффекты второй раз.

## Тот же утверждённый стиль

Используй локальные ресурсы: они получены из Figma и проверены. Повторный сетевой запрос
не требуется только ради подтверждения происхождения. Скриншот владельца не является ресурсом.

## Другой фон или актуальная версия

1. Обнаружь инструменты Figma `create_session`, `use_figma`, `get_design_context`, `download_assets`.
   Прочитай обязательные навыки Figma перед вызовами; не копируй API-схемы по памяти.
2. Создай сессию задачи, передавай точный возвращённый `sessionId`.
3. Найди нужный узел чтением страницы. Mixed-font текст проверяй через
   `getStyledTextSegments(['fontName'])`, а не общий `fontName`.
4. Получи design context со screenshot и сопоставь с ориентиром владельца:
   текст «молитва за детей» встречается в десятках разных макетов.
5. Получи экспорт фоновой группы без текста/людей и SVG логотипа. Сначала проверь
   версии «тв»: это готовые 16:9. Временные ссылки скачай сразу способом из ответа инструмента.
6. Проверь тип, размеры, ненулевой размер и вид каждого файла.
   Пустой raw-download не считается оригиналом.
7. Новые ресурсы сохраняй в папку задачи. Запиши fileKey, nodeId, начертания,
   размеры, цвета и SHA-256. Временные access-bearing URL не сохраняй в навык или git.
8. Встрой локальные файлы в HTML/PDF. SVG сохраняй с исходными пропорциями;
   внутренний знак имеет собственные размеры и отступы.

Для новой темы адаптируй копию оформления в папке задачи. Утверждённый навык меняй
только по просьбе обновить его. Чужой Figma-файл для экспорта менять не нужно.

## Основание выбора

Владелец выбрал светлый цветочный фон из Figma вместо промежуточного тёмно-зелёного,
попросил оригинальный логотип и совпадение шрифтов. 01.11.2026 подтвердил результат:
«Все получилось супер», попросил сохранить процесс навыком для менее сильной модели.
Выбор этого стиля не означает разрешение применять его к любым клиентским презентациям.
