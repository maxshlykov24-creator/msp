# Инсайты (недельная сводка — по желанию)

**Опционально:** если хочешь **сам** собирать краткую сводку по неделе — используй эту папку. Полный текст дня остаётся в файлах [`../`](../) по датам.

Ассистент **не** дописывает сюда инсайты из закрывашки по умолчанию; распределение — в дневном файле или смысловой ветке профиля; сильные доработки ассистент **предлагает** в чате. Регламент — [`СИНХРОН_С_АССИСТЕНТОМ.md`](../../../../СИНХРОН_С_АССИСТЕНТОМ.md) (корень репозитория).

## Если ведёшь сводку вручную

- **Один календарный файл = одна неделя** (понедельник — воскресенье).
- Имя файла: **`Инсайты DD.MM.YY - DD.MM.YY.md`** (пн–вс, год двузначный).
- Внутри: по желанию подзаголовок на день и буллеты; полный дубль закрывашки не обязателен.
