# Именование файлов и папок

## Заметки

Формат: `YYYY-MM-DD_Название.md`

- Дата — когда событие произошло или заметка создана, не когда правилась.
- Название — по-русски, слова через `_`, без лишних предлогов.
- Пример: `2026-08-13_Созвон_Билбордофф_итоги.md`

Применяется в `1. ЛИЧНОЕ/`, `2. БИЗНЕС/` и `_ВХОДЯЩЕЕ/`.

## Постоянные документы

Регламенты, реестры, профили и шаблоны — БЕЗ даты, заглавными с `_`: `РЕЕСТР_ПРОЕКТОВ.md`, `КАРТА_СМЫСЛОВ.md`, `ГРАНИЦЫ_И_ИСТОЧНИКИ.md`.

Логика простая: если файл живёт и обновляется — имя без даты. Если это срез момента — с датой.

## Папки

- Зоны верхнего уровня — с номером: `_ВХОДЯЩЕЕ`, `1. ЛИЧНОЕ`, `2. БИЗНЕС`, `3. АГЕНТЫ`.
- Системные — с префиксом `_`: `_СИСТЕМА`, `_ПРОФИЛЬ`, `_ЗНАНИЯ`, `_КОНТЕКСТ`, `_ЛОГИ`, `_ДАННЫЕ`.
- Внутри зон — по нумерации своего регламента (`1.3. Планирование`, `08_Системное`).
- Клиентские папки — по имени клиента как в реестре проектов: `Keris_Club`, `MANSBAND`, `LicenseBridge_USA`.
- Внутри папки клиента производства — двузначные разделы как в `08_Системное`: `01_Договорённости` · `02_Знание` · `03_Проекты` · `04_Встречи` · `05_Материалы` · `06_Доступы`. В каждой папке — `README.md`. Карточка, задачи и деньги — `КЛИЕНТ.md`, `ЗАДАЧИ.md`, `ДЕНЬГИ.md` в корне папки клиента.
- Код клиента — в `2. БИЗНЕС/08_Системное/_код/`, не внутри папки клиента. Эталон раскладки: `04_Производство/Активные/Keris_Club/`.

## Код

- Файлы и переменные — `snake_case` для Python, `camelCase` для JS/TS.
- Репозитории сервисов — латиницей через дефис: `dkacademy-bot`, `talkme-amojo-bridge`.
- Пути с кириллицей и пробелами в командах — всегда в двойных кавычках.

## Логи агентов

`3. АГЕНТЫ/<ИМЯ>/_ЛОГИ/YYYY-MM.md` — один файл на месяц, дописывается сверху вниз.
Ретро CEO — `3. АГЕНТЫ/CEO/_ЛОГИ/РЕТРО/YYYY-MM-DD_ретро.md`.

## Архив

`99_АРХИВ/YYYY-MM-DD_что-снято/` — папка по дате переноса с коротким пояснением причины в имени, внутри файлы как были, без переименования. Запись об архивации — в `99_АРХИВ/README.md`.

Внутри `2. БИЗНЕС/08_Системное/` до 2026-08-13 использовалась своя ветка `Архив/YYYY-MM-DD/` — она осталась как есть (консолидация в единый `99_АРХИВ/` отложена сознательно, не потерянная задача).

## Чего не делать

- Не переименовывать существующие файлы «для порядка» без запроса — ломаются ссылки в правилах.
- Не плодить синонимы папок (`inbox`, `Входящие`, `Входящее` — только `_ВХОДЯЩЕЕ`).
- Не менять формат даты. Смена правила — правка этого файла плюс `1. ЛИЧНОЕ/СТРУКТУРА_И_ПРИНЦИПЫ.md`.
