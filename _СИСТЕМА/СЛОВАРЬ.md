# Словарь терминов vault

> Если встретил незнакомый термин в правилах или заметках — смотри сюда, не угадывай.
> Термин добавляется, когда он реально используется в правилах или в общении с владельцем.

## Методология работы

| Термин | Значение |
|---|---|
| **BOOP** | Схема разбора задачи: Goal (цель как DoD) → Obstacles (что мешает) → Plan (шаги) → Logic (безопасность в лимитах). Команда `/boop`. Развёрнуто — `_ПРОФИЛЬ/СТИЛЬ_РАБОТЫ.md` |
| **DoD** | Definition of Done — измеримые критерии приёмки. Без DoD задача не считается поставленной |
| **Кайдзен-вопросы** | Три вопроса до предложения решения: строит систему или тушит пожар; приближает ли к 1 млн/мес; не крадёт ли время у критичного |
| **КИНЖАЛ** | Блок 09:00–12:00. Только стратегические задачи, без суеты и мелких дёрганий |
| **Хвосты** | Незакрытые старые обязательства перед клиентами. Верхний приоритет бэклога. Реестр — `2. БИЗНЕС/01_Стратегия/ХВОСТЫ.md` |
| **Последние 10%** | Узкое место владельца: проект доведён до 90%, но не поставлен «на рельсы». Лечится обязательным DoD и приёмкой |
| **Протокол 0** | Обязательное молчаливое чтение контекста в начале нетривиальной сессии. См. `.cursorrules` §2 |

## Ритуалы и файлы

| Термин | Значение |
|---|---|
| **Открывашка** | Утренний разбор дня. `1. ЛИЧНОЕ/1. Повторки/1.1. Открывашка/` |
| **Закрывашка** | Вечерний разбор дня. Инсайты остаются в дневном файле, в `Инсайты/` автоматически не переносятся |
| **Карта смыслов** | SSOT бизнеса, 21 раздел. `2. БИЗНЕС/08_Системное/_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md` |
| **Светофор** | Оценка полноты карты: 🟢 ≥80% и подтверждено · 🟡 40–79% · 🔴 <40%. Считает `@аудитор` |
| **Синхрон** | Журнал договорённостей с ИИ. Не стартовый контекст; правила оттуда поднимаются в `.cursorrules` по Протоколу 8 |
| **Главный регламент раскладки** | `1. ЛИЧНОЕ/СТРУКТУРА_И_ПРИНЦИПЫ.md`. Не называть это «каноном» |

## Бизнес и продукт

| Термин | Значение |
|---|---|
| **Коробка** | Типовое воспроизводимое решение с фиксированным составом и ценой. Противоположность разовому «пожару» |
| **Фикс-чек** | Цена за результат/этап, а не за часы. Целевая модель против почасовки |
| **Техсопровождение** | Второй контур дохода, почасовка. Целевая ставка 4 000 ₽/ч |
| **SPOF** | Single point of failure — всё завязано на владельце. Главный риск, §18 карты |
| **Конвейер** | Очередь клиентов на дожим денег. Порядок — §17 карты |
