# Логика дерева — почему структура такая

> Верхний уровень vault. Детали внутри зон — в их собственных регламентах, здесь их не дублируем.

## Верхний уровень

| Папка | Что внутри | Кто меняет |
|---|---|---|
| `_ВХОДЯЩЕЕ/` | Единый инбокс: сырьё и черновики до разноса | Владелец, агенты |
| `1. ЛИЧНОЕ/` | Личный профиль: дух, разум, тело, повторки, финансы | Владелец, личные агенты |
| `2. БИЗНЕС/` | MS Product: клиенты, проекты, финансы, системное ядро, код | Владелец, бизнес-агенты |
| `3. АГЕНТЫ/` | ИИ-команда: контекст и логи каждого агента | CEO и агенты |
| `_ПРОФИЛЬ/` | Кто владелец и как с ним работать | CEO |
| `_СИСТЕМА/` | Устройство системы: словарь, логика, именование, версия, якорь inbox | CEO, Архивариус |
| `.cursor/rules/` | Правила агентов для Cursor | CEO, скилл `agent-creator` |

Системные папки с префиксом `_` сортируются наверх — системное всегда на виду, рабочие зоны с цифрами идут своим порядком ниже.

## Принципы

**Зона определяет место, а не похожее название.** Тренировки и журнал весов — в `1. ЛИЧНОЕ/4. Тело/`, а не в `3. Разум/` только потому, что там есть слово «развитие». Спорные случаи разбирает таблица граничных случаев в главном регламенте раскладки.

**Глубина по возможности до 3 уровней.** Длинные пути съедают контекст агента и путают навигацию. Исключения есть (`3. АГЕНТЫ/CEO/_ЛОГИ/РЕТРО/`), но их немного.

**Один файл — одна сущность.** Дробим, только когда файл реально не читается за раз.

**Не создавать папки «на всякий случай».** Новая папка — только с `README.md` и с явным сообщением владельцу, что она появилась на диске.

**Лучше добавлять, чем переделывать.** Перестройка дерева дороже, чем кажется, и ломает ссылки в правилах.

## Что отвергли

**Один большой файл памяти.** Так был устроен `РАСШИРЕННЫЙ_КОНТЕКСТ.md` — снят 2026-08-13. Проблема: превращается в простыню, факты дублируют карту смыслов и расходятся с ней, агент не понимает, что здесь источник правды, а что копия. Заменён слоями: профиль, стиль, инсайты, карта смыслов.

**Синхрон как стартовый контекст.** 56 КБ журнала в начале каждого чата съедали окно. Синхрон остался журналом; устойчивые правила поднимаются в `.cursorrules` по Протоколу 8.

**Отдельный воркспейс только для `2. БИЗНЕС/`.** Требовал копий правил, копии разъезжались (правило `@тиктик` про TikTok при папке про TickTick, два экземпляра `модель.mdc`). Оставлен один воркспейс — корень vault.
