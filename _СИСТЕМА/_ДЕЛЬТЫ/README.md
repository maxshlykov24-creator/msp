# Дельты — журнал изменений с возможностью отката

Каждое применённое изменение структуры или смыслов пишется сюда файлом `ГГГГ-ММ-ДД.md` (или отдельным файлом на крупную операцию, например `M2_install_2026-08-19.md`).

## Формат записи

```
## #NN · ЧЧ:ММ · агент

**Действие:** что сделано
**Файлы:** список путей
**Откат:** конкретные шаги, как вернуть как было
```

## Откат

Команда владельца `/откати дельту ГГГГ-ММ-ДД#NN` — агент читает запись и выполняет её блок «Откат».

Дельта пишется **после** применения изменения, не до. Без «да» владельца изменение не применяется, значит и дельты нет (правило `11-верификация`).
