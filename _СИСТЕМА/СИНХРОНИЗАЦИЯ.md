# Синхронизация vault с GitHub

> **Статус на 2026-08-13:** синхронизация **отключена**. Vault живёт локально, репозиторий `msp` замирает на последнем коммите.

---

## Что было отключено

Два launchd-агента:

| Label | Что делал | Интервал |
|---|---|---|
| `com.msp.vault-sync` | `vault-sync-auto.sh` — коммит и push | каждые 120 сек |
| `com.msp.vault-sync-wake` | `vault-sync-pull-wake.sh` — pull после пробуждения | каждые 300 сек и при логине |

Команда отключения:

```sh
launchctl bootout gui/$(id -u)/com.msp.vault-sync
launchctl bootout gui/$(id -u)/com.msp.vault-sync-wake
```

`plist`-файлы перенесены из `~/Library/LaunchAgents/` в `99_АРХИВ/launchagents/`. **Не удалены.** Исходники остались на месте: `2. БИЗНЕС/08_Системное/Скрипты_vault/git/`.

---

## Важное следствие

`post-commit`-хук **не установлен** (`core.hooksPath` не настроен). Значит launchd был единственным механизмом, который пушил vault на GitHub. После отключения:

- локальные коммиты остаются локальными;
- Cursor на телефоне видит состояние на последнем коммите до 2026-08-13;
- ручной `git push` работает как обычно.

## Как вернуть

### Вариант A — по факту коммита (рекомендуется)

Пуш происходит только когда ты реально закоммитил. Нет холостых коммитов каждые 2 минуты, нет мусора в истории.

```sh
cd /Users/max/CURSOR
bash "2. БИЗНЕС/08_Системное/Скрипты_vault/git/install-git-hooks.sh"
```

Проверка: `git config core.hooksPath` должен вернуть путь к `githooks`.

Откат: `git config --unset core.hooksPath`.

### Вариант B — фоном каждые 2 минуты

Прежнее поведение: автокоммит и push без твоего участия. Нужен, если хочешь править vault с телефона и видеть изменения на Mac без ручных действий.

```sh
cd /Users/max/CURSOR
bash "2. БИЗНЕС/08_Системное/Скрипты_vault/git/install-launchagents.sh"
```

Скрипт сам скопирует `plist` в `~/Library/LaunchAgents/` из папки `git/` и загрузит агентов. Копии в `99_АРХИВ/launchagents/` для этого не нужны — они лежат как страховка.

Проверка: `launchctl list | grep msp` — две строки.

Пауза без удаления: создать файл `.vault-sync-off` в корне vault. `vault-sync-auto.sh` его проверяет и выходит.

### Вариант C — вручную

```sh
cd /Users/max/CURSOR && git add -A && git commit -m "sync" && git push
```

2. Доступ по SSH или токену не протух.
