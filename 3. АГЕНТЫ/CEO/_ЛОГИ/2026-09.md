## 2026-09-07 · MartaChe — диагностика «не подтягивается наличие» на сайте
**Запрос:** почему по товару «Бомбер Бити розовый кварц» на martache.ru не подтягивается наличие.
**Результат:** причина вне нашего контура. Наличие на сайте проверяет кастомный скрипт в Tilda, дёргая `neurosell-tilda-ms-order-hook-5f6f.twc1.net/get_quantity/` (сервер 91.210.170.221, подрядчик Neurosell). По этой карточке сервис отдаёт `Product not found (404)` → сайт пишет «Не удалось проверить наличие товара». МойСклад чист: остаток 30/доступно 28, ОСНОВНОЙ СКЛАД 28, цена 13500, артикул Bom_Bt/940, externalCode уникален и находится фильтром. Tilda чиста: карточка в каталоге, структура идентична рабочей чёрной.
**Масштаб (скан всех 207 карточек каталога):** 198 работают, 2 всегда 404 (оба «розовый кварц»), 7 плавающих `Failed to process API Request for MS` — сервис получает от МойСклад HTML вместо JSON (похоже на лимит запросов).
**Зацепка:** `clear_cache/?key=update` стабильно отвечает «Список товаров уже в процессе обновления» и кэш не дособирается — новые карточки в него не попадают.
**На нашем VPS (marta-vps):** интеграции остатков нет, только loyalty-сервис. Домен `martachepl.neurosell-...` в nginx — наследство от старого приложения.
**Оценка:** ✅ причина локализована, чинить на стороне подрядчика.
