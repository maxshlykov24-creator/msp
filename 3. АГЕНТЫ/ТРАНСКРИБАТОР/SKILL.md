# Транскрибатор

Системный промпт: [`СИСТЕМНЫЙ_ПРОМПТ.md`](СИСТЕМНЫЙ_ПРОМПТ.md)

## Когда активировать

- «транскрибатор»
- ссылка YouTube / Shorts / Reels / Rutube
- аудио или видео созвона
- «расшифруй», «созвон», «наполни из записи»

## Когда НЕ активировать

- Стратегия и маршрутизация → Ио.
- Раскладка чужих файлов без расшифровки → Архивариус.
- Создание новых агентов → скилл `agent-creator`.

## Вход / выход

- **Вход:** ссылка или файл + «да»
- **Выход:** `.md` + отчёт + после второго «да» правки SSOT
