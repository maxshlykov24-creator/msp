## Одна формула

```
Список     = КУДА принадлежит (сфера / клиент)
Колонка    = КОГДА примерно (горизонт внимания)
Календарь  = КОГДА именно займу слот (обязательство)
Сегодня    = ЧТО делаю сейчас (1 + ≤3), не весь бэклог
```

### Куда «вставлять» задачу

| Вопрос | Действие |
|--------|----------|
| Это мысль/инсайт, не дело? | `Инсайты` или `Мысли` как **Note**, не TEXT; в vault при ценности |
| Есть клиент/проект? | Список клиента (MANSBAND, DK…) или `Бизнес` |
| Сфера жизни без клиента? | Дух / Разум / Тело / Семья / Церковь / Порядок… |
| Нужно сделать на этой неделе? | Колонка **Неделя** (+ желательно дата дня, даже без часа) |
| Просто «когда-нибудь / цель»? | Колонка **Горизонт** — **без** даты в календаре |
| Фиксированное время (зал, созвон, дорога)? | Дата **и время** → видно в Календаре (`Прочее` или список сферы) |
| Поймал на лету, не разобрал? | Колонка **Входящее** → разбор в планировании (вечер/утро) |

### Как использовать календарь

- Календарь = **занятость**, не склад желаний.
- В календарь попадает только то, под что реально выделяешь слот (≥15–30 мин) или якорь (созвон, церковь, дорога).
- «Неделя» без даты = бэклог недели; при планировании (вечер «Планирование завтра» / раз в неделю) **3–7 дел** получают дату → появляются в календаре/Today.
- Не тащить Горизонт в календарь «чтобы не забыть» — для этого колонка + еженедельный обзор.

### План на день (связка с @фокус)

1. Утро: открыть **Today / календарь** + список «Прочее» (ритм).  
2. Выбрать **1 СЕЙЧАС** + до **2** слотов (всего ≤3 исполняемых).  
3. Всё остальное из «Неделя» — хвост, не экран.  
4. Вечер: «Планирование завтра» — перенести 1–3 дела с датой на завтра; закрыть/сдвинуть несделанное.

Правило уже есть в Фокусе: не добавлять 4-й слот без вытеснения.

## WIP по сферам (предложение)

На одну календарную неделю в работе (колонка Неделя + дата):

- Клиентские/деньги: ≤3 активных «главных»  
- Дух/тело/семья: через повторки и якоря, не через раздувание Недели
