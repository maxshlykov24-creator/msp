## 1. Что я увидел (главное наблюдение)

TickTick у тебя — **не таск-менеджер, а внешняя кора головного мозга и доска идентичности**.  
Три функции в одном инструменте:
- очередь дел (437 TEXT)
- духовный дневник (732 в Инсайтах — проповеди, теология, рефлексия)
- черновик «подумать вслух» (Мысли, Желания, Игра, Нейросеть-идеи)

Это не плохо. Это объясняет, почему «хаотично»: ты смотришь в список, чтобы выбрать дело, а попадаешь в **поток смыслов и амбиций** — и хватаешь то, что эмоционально «горит», а не то, что в слоте.

## 2. Корень — не инструмент

90% без даты → календарь никогда не заполняется → **ничего не заставляет выбирать**.  
«Неделя» без даты = не обязательство, а пожелание.  
Инсайты/Мысли/Желания раздули счёт → визуальный шум → экран = весь бэклог, а не день.

## 3. Ты уже сам поставил себе диагноз (в Инсайтах)

- «1 Кор 14:40 … благопристойно и чинно. **А у меня сейчас перемешано**»
- «Новые проекты = ясный старт. Старые = **размытая ответственность**»
- «Ты не безответственный. Ты **гиперответственный без границ**»
- «Без меры всегда будет цикл. **Границы — избавление от реакции и переход к стратегии**»
- «Упростить рутину до минимума … привязать ко времени/месту … **не оставлять себе выбор**»
- «Время на месяц вперед должно рассчитываться из целей … мозг по Паркинсону сделает быстрее»
- «Если 9:00, то я начинаю» (if–then)
- «Черновик не должен быть крутым, он должен быть каким-нибудь»
- «Распределить по 12 ячейкам в % загруженности»

Это и есть метод. Я только собираю его в систему.

## 4. Что уже хорошо (не ломать)

- Списки по сферам + клиентские — структура верная.
- Kanban: Входящее → Неделя → Горизонт — верный каркас.
- Ритуал дня в `Прочее` (Бог, зал, открывашка, планирование завтра, Настя, церковь, дорога) — живой.
- Духовные повторки с RRULE — держатся.
- Шаблон `ГЛАВНОЕ ДЕЙСТВИЕ / ПОВТОРКИ / ЗАДАЧКИ` в клиентских — правильный инстинкт (= 1·3·∞).
- Колонка `Оплаты` с датами — самая дисциплинированная часть (МойСклад, СДЭК, amo, WA, TG).
- В vault уже есть `@фокус` с экраном 1 СЕЙЧАС · ≤3 сегодня · ∞ хвост.

## 5. Вердикт

**Не меняй инструмент и не пересоздавай списки. Раздели 4 типа объектов и включи календарь только для дел.**

Формула:
```
Список   = куда принадлежит (сфера/клиент)
Колонка  = горизонт внимания (Входящее/Неделя/Горизонт)
Календарь= реальный слот (дата ± время) — ТОЛЬКО дела и якоря
Сегодня  = 1 СЕЙЧАС + ≤3, не весь бэклог
```

## 6. Минимальная модель (внедрять за 1 неделю)

1. **4 типа, 4 судьбы:**
   - Дело → список + колонка + (если на неделе) дата.
   - Якорь/ритм → `Прочее` с временем (уже есть).
   - Цель/горизонт → колонка Горизонт, **без даты**, не в календарь.
   - Инсайт/мысль → Note (не TEXT), живёт ≤7 дней → разбор.

2. **Правило «Неделя = дата»:** что в колонке Неделя на этой неделе → получает дату дня (без часа ок). Нет даты — значит это Горизонт, не Неделя.

3. **WIP недели:** ≤3 «главных действия» по клиентам/деньгам одновременно (твоё «ГЛАВНОЕ ДЕЙСТВИЕ» уже это).

4. **День = `@фокус`:** утром Today + Прочее → 1 СЕЙЧАС + ≤2 слота. Вечер «Планирование завтра» → 1–3 дела с датой на завтра.

5. **Еженедельный обзор (30 мин, воскресенье/понедельник):**
   - Инсайты старше 7 дней → удалить / в vault / свернуть в 1 задачу Горизонта.
   - «Входящее» по сферам → разобрать: дата / Горизонт / удалить.
   - Проверить `Оплаты` на неделю.

6. **Календарь не склад желаний:** Горизонт и Инсайты туда не тащим.

## 7. Инсайты (732)

Не удалять массово. Это твой духовный дневник — материал для проповедей и слова.  
Решение: список закрыть для новых TEXT (только Note); норма «>7 дней → разбор» уже у тебя в задачах.  
Ценное → в `1. ЛИЧНОЕ/2. Дух/2.2. Проповеди/` или `2.3. Служение/2.3.1. Мое слово/` (по смыслу).  
Объём 732 — визуально давит; скрыть список из Today, держать как архив.

## 8. Связь с компанией (MS Product)

В `Бизнес` лежат продуктовые беты: «свой квиз», «бот планирования масштаба», «регламент внедрения», «сайт для сотрудничества», «сервис авто-внедрения amoCRM».  
Сейчас они в Входящем/Горизонте без дат → всегда проигрывают клиентским пожарам.  
→ Вынести **одну** продуктовую бету в «главное действие недели» раз в 2 недели, со слотом в КИНЖАЛ. Иначе коробка не родится.

## 9. Пилот (предложение)

1 неделя по этой модели, без массовой правки:
- проставить даты текущей «Неделе» (разово, ~15 дел);
- скрыть Инсайты из Today;
- 1 еженедельный обзор;
- каждое утро `@фокус`, каждый вечер «планирование завтра».

Через неделю — калибровка: что держится, что нет.
