## Экран фокуса (СДВГ / исполнение)

| Слой | Лимит | Зачем |
|------|-------|-------|
| **СЕЙЧАС** | 1 задача + DoD + таймер | Initiation + time blindness (Barkley) |
| **Сегодня** | ≤ **3** слота (WIP) | Kanban WIP; не раздувать параллель |
| **Хвост** | ∞, **свёрнут** | Внешняя память без шума на экране |

**Микростарт:** первый шаг ≤2 мин. **If–Then** на экране. **Счёт закрытий** = игра/дофамин.  
Не добавлять 4-й слот в «сегодня» без явного вытеснения одного из трёх.

## Лестница приоритетов

| Уровень | Когда | Примеры |
|---------|--------|---------|
| **critical** | Крупные деньги + жёсткий дедлайн / штраф | Keris, Mansband |
| **high** | Клиент ждёт, обещание с датой, репутационный риг | ДК Академия, Rus бренд |
| **medium** | Поддержка, быстро закрыть, без дедлайна | Divomotors |
| **close** | Выход / мало денег, но закрыть обязательства | VanPak, Позвоночник |

**Порядок решений:** critical → high (дедлайн) → high (ожидание) → close (обязательства) → medium → close (без долга).

---

## Алгоритм при любой правке расписания

1. **Прочитать** все задачи в дашборде + `penalty` + `timeline`.
2. **Якоря** (созвоны, обещанные слоты) — не двигать без явной просьбы.
3. **Проверить конфликт:** два блока >1 ч в одном слоте = ошибка.
4. **Проверить перегруз дня:** >6 ч глубокой работы подряд = предупредить.
5. **Проверить приоритет:** задача `close`/`medium` не вытесняет `critical`/`high` с дедлайном.
6. **Если пользователь просит день X:** не соглашаться автоматически — сказать *почему* этот день ок или *куда* лучше (с альтернативой).
7. **После переноса:** одной строкой — что якорится, что сдвинулось, риск если есть.

## Слоты по умолчанию

| Время | Правило |
|-------|---------|
| 09:00–12:00 | **КИНЖАЛ** — только critical, стратегия |
| 12:00–17:00 | Основной блок — critical production (режется якорями) |
| 17:00–20:00 | high / подготовка к созвону / хвосты с дедлайном |
| «по ходу» / «промежуток» | close, medium, ≤30 мин |
| **Личные якоря** | ЭЦП, церковь, дорога — выезд заранее; work не поверх |
| Блок 3 ч | Одна задача; не в день с 2+ якорями утром без паузы |

## Типовые ошибки (не повторять)

- Перенести задачу куда сказали пользователь, **не проверив** занятость утра/якоря.
- Поставить `close` в КИНЖАЛ или вместо critical-блока.
- Обещать «сегодня» high-задачу, когда день уже забит critical (без явного сдвига critical).
- Не объяснять, **почему** вторник лучше среды (или наоборот).
