## ЧТО ЭТО

**Агент фокуса** — из списка задач выдаёт одно главное сейчас, честную картину дня, реалистичное время и со временем учит точно оценивать задачи.

Работает в двух режимах:
- **Сейчас:** задачи в чате **или** файл [`_КОНТЕКСТ/ПОВЕСТКА.md`](_КОНТЕКСТ/ПОВЕСТКА.md) — минималистичная доска
- **Будущее:** агент сам читает файлы vault и составляет повестку без ручного ввода

```

```

```
- Задача 2 (2ч)

@фокус сверься с @ПОВЕСТКА.md (или приложи агенты/ФОКУС/_КОНТЕКСТ/ПОВЕСТКА.md)

@фокус закрыл [задача], ушло [время]

@фокус что на неделе

@фокус калибровка
```

## ЧТО УМЕЕТ

### Приоритизация:
1. Парсит список задач, определяет проект
2. Маркирует тип: `[система]` / `[пожар]` / `[хвост]`
3. Расставляет по приоритету: Хвосты → Клиентские дедлайны → Системное → Операционка
4. Выдаёт **одно главное сейчас** + DoD + минимальный шаг на плохой день

### Коррекция времени:
- Умножает твою оценку ×2 (стартовый коэффициент)
- Явно показывает обе цифры: твоя / реальная
- При перегрузе дня сигналит: «не влезет, выбери»

### Блокер-детектор:
- Если задача появляется повторно без закрытия → спрашивает «что мешает»
- Декомпозирует задачу если блокер — неясность «с чего начать»
- При 3+ циклах без движения → предлагает разобрать через `@психолог`

### Трекинг и калибровка:
- Фиксирует факт времени при закрытии задачи
- Ведёт лог план/факт в `_ЛОГИ/YYYY-MM.md`
- По команде `@фокус калибровка` — статистика по типам задач и персональный коэффициент

## ИСТОЧНИКИ ПРИОРИТЕТОВ

Агент ориентируется на:
- `Бизнес/99_Системное/РЕЕСТР_ПРОЕКТОВ.md` — клиенты, проекты, привязка кода в vault (канон)
- `Бизнес/01_Стратегия_и_управление/ХВОСТЫ.md` — хвосты (высший приоритет)
- `Бизнес/04_Производство_внедрений/Активные/MANSBAND/СТАТУС_ЗАДАЧ.md` — задачи MANSBAND
- `РАСШИРЕННЫЙ_КОНТЕКСТ.md` — стратегия и бэклог

При ручном вводе задач подключать через `@` для сверки контекста.
