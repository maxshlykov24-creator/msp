# Входящее (инбокс)

Всё **сырьёвое** без готового места: заметки, мысли, настроение, созвоны, транскрипты, скрины, PDF — краткосрочно лежит здесь, потом разносится в [`1. Профиль`](../1. Профиль) по правилам [`СТРУКТУРА_И_ПРИНЦИПЫ.md`](../1. Профиль/СТРУКТУРА_И_ПРИНЦИПЫ.md).

**Сроки:** в идеале разбирать **каждый день**; не держать дольше **3 дней** без переноса (иначе инбокс превращается в свалку).

**Не путать с [`6. Прочее/`](../1. Профиль/6. Прочее):** там — редкие единичные темы без своей ветки на долгий срок; сюда — поток «сначала сюда, потом по местам».

## Работа с ассистентом

- Триггеры: «разбери Входящее», `@0. Входящее`, вложения из этой папки.
- После разбора ассистент **переносит** файлы по профилю и **дописывает** мета-идеи в [`ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md`](../1. Профиль/1. Повторки/1.3. Планирование/1.3.1. Неделя/ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md) (дата, куда положили, что можно улучшить в структуре vault). Тебе не обязательно сразу оценивать мета в чате — ревью предложений отдельным слотом (например раз в неделю).
- **Канон** (`СТРУКТУРА_И_ПРИНЦИПЫ`, деревья, реестры) меняется **только** после твоего явного решения по итогам ревью.

## Перед массовым переносом

Если открыты вкладки с файлами, куда идёт перенос, Cursor может спросить про конфликт версий — закрой или синхронизируй вкладки с диском.
