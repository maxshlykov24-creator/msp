# 1. Профиль

Личный профиль, цели и контекст для ассистента. Учебные материалы курса (модуль 2, Cursor) — [`3. Разум/3.1. Изучение/3.1.4. Курсы/1. Учебные материалы/README.md`](3. Разум/3.1. Изучение/3.1.4. Курсы/1. Учебные материалы/README.md). Сырьё без места — [`../0. Входящее`](../0. Входящее). Канон раскладки и очередь идей — см. цепочку ниже.

## Порядок работы со структурой (цепочка)

О **личном vault и дереве профиля**, не о бизнес-стратегии (исключение — в конце блока).

1. **`Личное/0. Входящее/`** — единый сырой вход; разнос по профилю в идеале каждый день, максимум до нескольких дней (`0. Входящее/README.md`).
2. **`СТРУКТУРА_И_ПРИНЦИПЫ.md`** — главный регламент «куда что класть»; при сомнении в зоне открываю в первую очередь.
3. **`КАРТА_ЦЕЛЕЙ_И_РЕГЛАМЕНТОВ.md`** — какой файл `Цели_и_регламент` открыть для зоны.
4. **`ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md`** (`1. Повторки/1.3. Планирование/1.3.1. Неделя/`) — черновая очередь идей по дереву после разборов Входящего; в `СТРУКТУРА_И_ПРИНЦИПЫ.md` переносится **только после твоего решения**.
5. **`СИНХРОН_С_АССИСТЕНТОМ.md`** (корень репозитория `CURSOR`) — договорённости с ИИ; **не** подменяет главный регламент раскладки и **не** подменяет предложения по папкам.

**Вне этой цепочки:** [`РАСШИРЕННЫЙ_КОНТЕКСТ.md`](../../РАСШИРЕННЫЙ_КОНТЕКСТ.md) — стратегия и контекст MS Product; к порядку личных папок здесь не привязан.

**Структура личных дел** (модуль 2, шаблон в `3. Разум/3.1. Изучение/3.1.4. Курсы/1. Учебные материалы/`): папки ниже — разделы жизни. Новое без места — в **`0. Входящее`**, затем разносить по веткам профиля.

## Верхний уровень

- `1. Повторки/` — открывашка, закрывашка, планирование по горизонтам; цели/регламент блока — `1. Повторки/Цели_и_регламент.md`
- `2. Дух/` — духовная жизнь, изучение Писания, проповеди, служение (в т.ч. церковь — см. `2. Дух/README.md`)
- `3. Разум/` — интеллект и кругозор: обучение, семья (жена и дети), `Люди/` (друзья, родственники, подарки), финансы (смыслы + `Финансы/Цели_и_регламент.md`), хотелки, путешествия, рестораны, кино (подробнее — `3. Разум/README.md`); светские инсайты — в `1. Повторки/1.2. Закрывашка/`
- `4. Тело/` — здоровье и спорт (`Здоровье/`, `Спорт/`); цели/регламент — `4. Тело/Цели_и_регламент.md`
- `5. Документы/` — паспорта, договоры, медицина (официальные выписки и бумаги), налоги
- `6. Прочее/` — крайний резерв для единичных тем без своей ветки; периодически разбирать (см. `6. Прочее/README.md`)

**Разграничение:** `5. Документы/5.2. Медицина` — официальные документы и выписки. `4. Тело/4.1. Здоровье/` — смыслы по здоровью, анализы как файл для себя, план питания, сон, лёд, добавки; тренировки — в `4. Тело/4.2. Спорт/`.

Обучение светских тем — в `3. Разум/3.1. Изучение/` (темы: `3.1.1. Бизнес/` … `3.1.5. Развитие/`; материалы курса — `3.1.4. Курсы/1. Учебные материалы/`); обзор тем, если заведёшь файл — `3. Разум/3.1. Изучение/Обзор.md`.
