## 🤖 АГЕНТ @модель

**Автоматический выбор оптимальной AI-модели**

### Что это:
Агент помогает выбрать лучшую модель для любой задачи за < 1 сек

### Как установить:
Рабочая установка агента — в **корне vault Cursor** (`агенты/МОДЕЛЬ/`, `.cursor/rules/модель.mdc`). Переустановка из архива курса:
```bash
cd агент_модель/
python3 install_agent.py --path "/путь/к/корню/workspace"
```

### Как использовать:
```
@модель какая модель для [твоя задача]
```

**Примеры:**
- `@модель какая модель для написания поста`
- `@модель оцени задачу: Python скрипт`
- `@модель создай план --detail`
