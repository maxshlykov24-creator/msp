# 2.4. Личные записи

Датированные **личные** духовные записи: молитва, признание перед Богом, выбор верности, короткие порывы сердца.

**Сюда не кладём:** конспекты чужих проповедей (`2.2. Проповеди/`), домашки и системный разбор Писания (`2.1. Изучение/`), буфер материалов «разнести по темам» (`2.1.4. Прочее/`).

**Имена файлов:** `YYYY-MM-DD_кратко.md` (как в профиле).

**Из [`0. Входящее`](../../../0.%20Входящее/):** сюда при разборе, если это личный дневник/молитва, а не сырьё под перенос в `2.1.1.`–`2.1.3.`.

Родитель — [README выше](../README.md). Канон — [`СТРУКТУРА_И_ПРИНЦИПЫ.md`](../../СТРУКТУРА_И_ПРИНЦИПЫ.md).
