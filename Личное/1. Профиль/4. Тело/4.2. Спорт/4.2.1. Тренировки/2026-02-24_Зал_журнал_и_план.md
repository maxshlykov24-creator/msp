# Зал: журнал и план (цикл с 24.02.2026)

## Контекст

- **Рост / вес:** 182 см, ~77 кг (на момент фиксации в чате).
- **Возобновление:** с **24.02.2026** после паузы ~3 месяца; до того ~месяц зала/дома.
- **Интервал:** целевой ритм **3 раза в неделю**, **до ~50 минут** за раз; при хорошем восстановлении — рассмотреть **4-й день** (лёгкий/слабое звено), не форсировать.
- **Учёт веса в записях:** для **жима гантелей лёжа** — **кг на одну гантель** (в каждой руке своя). В ранних строках марта, если отличался снаряд, смотри пометки в дне.
- **Мотивация:** рост массы и формы **через стабильность**, без рывков; нравятся футбол, серф, зал (когда нет травм).

## Биография спорта (кратко)

- С ~7 лет **футбол серьёзно**, ~11 лет; ежедневные тренировки, еженедельные игры.
- Последние 3 года в юности — **капитан**, **3 чемпионства** первенства.
- Затем перерыв; в последний год до периода журнала — **футбол 5×5** с любителями (нравится).

## Колено и футбол (на контроле)

- Симптоматика (из описания): дискомфорт при **максимальном сгибе** колена; неприятно **сидеть на стопу** с согнутым коленом; при **долгом сидении** с согнутой ногой — побаливает; остальные углы терпимы. «Покой» несколько недель **полностью** проблему не снял; к моменту уточнения в чате стало **чуть лучше**, полный сгиб всё ещё чувствуется.
- **Футбол:** пауза **~3 недели** из-за колена (на момент чата).
- **Не диагноз:** при сохранении симптомов имеет смысл **очередь к специалисту** (ортопед / МСК, при необходимости УЗИ/МРТ) — решение за тобой.
- **В зале:** без глубокого **приседа/выпада** под нагрузкой, пока нет ясности; гиперэкстензия и осторожная **задняя цепь** (например румынская с мягким коленом) — только **без усиления боли**.

## Актуальный шаблон недели (3 дня, ≤50 мин)

**День 1 — толчок: грудь + трицепс**


| Блок | Упражнение                | Подходы × повторы |
| ---- | ------------------------- | ----------------- |
|      | Жим гантелей лёжа         | 3×8–12            |
|      | Наклонная (гантели)       | 3×8–12            |
|      | Разводка / бабочка        | 3×10–15           |
|      | Трицепс (блок или аналог) | 3×10–12           |


**День 2 — тяги + бицепс + задняя цепь**


| Блок | Упражнение                        | Подходы × повторы           |
| ---- | --------------------------------- | --------------------------- |
|      | Вертикальная тяга (блок)          | 3×8–12                      |
|      | Горизонтальная тяга               | 3×8–12                      |
|      | Гиперэкстензия / разгибание спины | 3×12–20 (без боли в колене) |
|      | Бицепс — **одно** упражнение      | 3×8–12                      |


**День 3 — плечи + коротко руки + кор**


| Блок | Упражнение                                                    | Подходы × повторы |
| ---- | ------------------------------------------------------------- | ----------------- |
|      | Жим гантелей сидя                                             | 3×8–12            |
|      | Подъёмы в стороны                                             | 3×10–15           |
|      | Задняя дельта (наклон)                                        | 3×12–15           |
|      | **Либо** блок на трицепс, **либо** молоток на бицепс (не оба) | 2×10–12           |
|      | Планка                                                        | 2–3×40–60 с       |


**Пресс:** подъём ног лёжа — только если **колено не ухудшается**; иначе планка + «мёртвый жук» без агрессивного сгиба.

**Прогрессия:** раз в 1–2 недели — малый шаг (**+1 повтор** в рабочем сете или **+2,5 кг** там, где безопасно). Раз в **4–6 недель** — **микроразгрузка** (−30–40% веса или минус подход).

**Четвёртый день (по готовности):** лёгкий повтор паттерна с −30% веса **или** только задняя цепь + кор + лёгкие руки (~40 мин).

**Контрольная метрика раз в неделю (по желанию):** топ-сет жима гантелей лёжа (кг × повторы) + одно тяговое на блоке (кг × повторы).
