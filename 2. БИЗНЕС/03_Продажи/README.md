# 03_Продажи

> Воронка, сделки, скрипты и процесс продаж — мои собственные, не клиентские внедрения.

---

## О папке

Всё, что относится к **притоку денег до старта проекта**: лиды, квалификация, этапы воронки, шаблоны писем, регламенты. Работа в amoCRM по своим сделкам — здесь. Технические интеграции CRM в рамках доставки клиенту — это [`04_Производство`](../04_Производство/README.md).

## Содержимое

- Скрипты и сценарии диалогов.
- [`2026-08-19_AI-менеджер_презентация_клиенту.html`](2026-08-19_AI-менеджер_презентация_клиенту.html) — клиентская дека «AI-менеджер первой линии».
- [`БОЛИ_И_ВОЗРАЖЕНИЯ.md`](БОЛИ_И_ВОЗРАЖЕНИЯ.md) — боли, возражения, позиционирование; **якорь-питч для собственников** (CRM / стандарты / ОК / менеджеры «дерутся за заявки»).
- [`ВОПРОС_КРИТЕРИЯ_УСПЕХА_ПРОЕКТА.md`](ВОПРОС_КРИТЕРИЯ_УСПЕХА_ПРОЕКТА.md) — ретроспективный вопрос при согласовании проекта (критерий успеха с точки зрения клиента).
- [`БРИФ_КВАЛИФИКАЦИЯ_v2.md`](БРИФ_КВАЛИФИКАЦИЯ_v2.md) — первый контакт, если продаём CRM.
- [`БРИФ_СВОЯ_СИСТЕМА.md`](БРИФ_СВОЯ_СИСТЕМА.md) — семь вопросов ЛПР, если CRM и таск-трекер не сели и нужна система под процесс. Эталон: HIDE, 2026-09-01.
- Описание воронки и статусов (в т.ч. экспорт/снимок из amoCRM для контекста).
- Шаблоны коммерческих предложений, привязанных к этапу продажи (не продуктовая «упаковка» — та в [`06_`](../07_Продукт/README.md)).

## Как использовать

- Выгрузки и временные файлы из CRM сначала в [`_ВХОДЯЩЕЕ`](../../_ВХОДЯЩЕЕ), потом — сюда в осмысленную подпапку (например `Воронка/`, `Шаблоны/`).
- Не храни персональные данные клиентов без необходимости; маскируй в общих документах.
