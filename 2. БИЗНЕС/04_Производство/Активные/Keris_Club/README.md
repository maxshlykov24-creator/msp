# Keris Club

> Единая CRM-система на amoCRM для экосистемы Keris Club: питомник, груминг и общая клиентская база.

Карточка и живое состояние — [`КЛИЕНТ.md`](КЛИЕНТ.md). Задачи — [`ЗАДАЧИ.md`](ЗАДАЧИ.md). Деньги — [`ДЕНЬГИ.md`](ДЕНЬГИ.md).

## Разделы

| Папка | Что внутри |
|-------|------------|
| [`01_Договорённости/`](01_Договорённости/README.md) | КП, коммерция, юрдокументы |
| [`02_Знание/`](02_Знание/README.md) | контекст, архитектура, анализы, прайс, чаты |
| [`03_Проекты/`](03_Проекты/README.md) | Питомник, Груминг, Дашборд |
| [`04_Встречи/`](04_Встречи/README.md) | транскрипты и решения по дате |
| [`05_Материалы/`](05_Материалы/README.md) | презентации, HTML-инструкции, регламенты |
| [`06_Доступы/`](06_Доступы/README.md) | секреты, вне git |

Код — в `2. БИЗНЕС/08_Системное/_код/keris-*`, ссылки в карточке.

## Как использовать

- Новый артефакт кладётся в свой раздел, не в корень.
- Сырые материалы — сначала в [`_ВХОДЯЩЕЕ`](../../../../_ВХОДЯЩЕЕ/README.md), потом сюда.
- Эталон КП: [`08_Системное/Шаблоны/ЭТАЛОН_КП_И_ПРЕЗЕНТАЦИИ.md`](../../../08_Системное/Шаблоны/ЭТАЛОН_КП_И_ПРЕЗЕНТАЦИИ.md).
