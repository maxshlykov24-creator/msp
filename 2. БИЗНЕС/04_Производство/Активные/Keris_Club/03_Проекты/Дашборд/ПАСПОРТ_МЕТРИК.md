# Паспорт метрик — пульс Keris Club

Короткий допуск только тех цифр, что на экране. Учёт в amoCRM и записи ведётся актуально: цифры строим как рабочий пульс, а не как защиту от пустых полей.

Часовой пояс — Москва. Тестовые сделки (`[ТЕСТ]` в названии) в счёт не входят.

## Питомник — воронка «Продажи» `11036674`

| На экране | Формула | Скрываем если |
|---|---|---|
| Новые заявки (hero) | сделки, **созданные** за 7 / 30 дней | пустой срез → `.empty` |
| Бронь за период | из этих заявок сейчас на «Щенок забронирован» `86718354`, «Документы оформлены» `86718358` или «Уехал в семью» `142` | не скрываем: 0 — тоже ответ |
| Продали за период | сделки статуса `142`, у которых `closed_at` попал в период; рубли = сумма `price` | не скрываем: 0 — тоже ответ |
| Средний чек | рубли продаж / число продаж за период | продаж 0 — подписи нет |
| Ждут помёт · сейчас | запас: открытые на «Ожидает помета» `86717274` | 0 сделок — плитки нет |
| Воронка в «Как дошли» | заявка → бронь → продано **по когорте созданных** за период, штуки; процент мелкой подписью только при ≥ 20 заявок | — |
| «Больше всего с …» | поле «Источник» `1820835` у заявок периода | не заполнено ни у одной заявки периода |

Плитка «продали» и третья ступень воронки могут разойтись: воронка показывает, куда дошли заявки, созданные за период; плитка — какие продажи **закрыли** в эти дни, даже если заявка старше.

SLA и время первого ответа на пульс не выносим. Карточка «без ответа больше суток» в режиме Сегодня — задача, не KPI.

Витрина «Щенки» `11036834` на пульс не идёт: там тестовые карточки.

## Груминг — таблица `bookings` + `master_shifts`

Визит как `amocrm_metrics.is_visit`: статус не `cancelled`/`no_show`, `starts_at` ≤ сейчас. Naive-время салона.

| На экране | Формула | Скрываем если |
|---|---|---|
| Выручка (hero) | сумма `price` визитов за период | визитов 0 и загрузки нет → `.empty` |
| Средний чек | выручка / число визитов | визитов 0 — подписи нет |
| Визитов | штуки визитов за период | — |
| Загрузка за период | занятые минуты записей (не `cancelled`) / доступные минуты смен `master_shifts` за тот же отрезок; на экране часы, не проценты | смен в срезе нет |
| На неделю вперёд | та же формула на `[сейчас … +7 дней]` | смен вперёд нет |
| Не пришли | `status = no_show` за период | в БД ни разу не было `no_show` |
| Снова пришли | телефоны с 2+ визитами за период | режим Неделя, или повторных нет |
| Не были 60+ дней | клиент с хотя бы одним визитом, без будущей записи, последний визит ≥ 60 дней назад | 0 |
| Кто стрижёт | визиты, сумма и часы загрузки по `master_id` | один мастер и без загрузки — чипов нет |

Чек может быть ниже прайса: визит по абонементу даёт мало рублей в `price`. Это не ошибка.

Не берём воронку amoCRM «Груминг»: источник истины — Postgres записи. Смены без `starts_at`/`ends_at` и дни из `salon_closures` в доступные часы не входят.

## Сегодня

| Карточка | Формула | Скрываем если |
|---|---|---|
| Заявки без движения > 24 ч | открытые «Новая заявка» / «Взято в работу», `updated_at` старше суток; одна сводка, не список | 0 |
| Платёж рассрочки на 7 дней | воронка «Рассрочка» `11036838`, поле `1820847` в ближайшие 7 дней, без `[ТЕСТ]` | нет таких сделок |
| Завтра без подтверждения | `bookings.status = pending` на завтра | 0 |
| Клиенты салона 60+ дней | то же, что плитка «не были 60+ дней» | 0 |
| Питомник сейчас | заявки, созданные сегодня | строка остаётся: «новых нет» |
| Салон сейчас | визиты сегодня + ближайший `starts_at` | строка остаётся: «визитов нет» |

Режим Сегодня не прячем, даже если карточек нет.

## Фильтр «Всё»

Одна сумма сверху: продажи щенков за период (`sold_sum`) + выручка салона (`revenue`). Нет ни того ни другого — героя нет, остаются главы.

## Что сознательно не на экране

Cross-sell «щенок → груминг», рассылки, LTV отдельной цифрой, 6-этапная воронка, дни недели, таблица источников, календарь дат, проценты как главные цифры, загрузка мастеров в %, план/факт, статус напоминаний, SLA как KPI.
