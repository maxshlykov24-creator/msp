# Чеклист — цикл склада (Береза Групп)

**Полная инструкция с визуалом:** [`инструкция/Склад_МойСклад_цикл.html`](инструкция/Склад_МойСклад_цикл.html) — открыть в браузере, можно PDF (`Cmd+P`).

**Система:** МойСклад + таблица «Береза групп склад»  
**Обновлён:** 2026-08-12

---

## Приёмка (товар приехал)

- [ ] **Закупки → Заказы поставщику** → нужный заказ (или создай новый: + Заказ → позиции по заявке поставщика)
- [ ] Пересчитать факт на месте
- [ ] **Создать документ → Приёмка** → фактическое кол-во → **Сохранить**
- [ ] Статус **Найдено расхождение** → Дима
- [ ] Проверить **Склад → Остатки**

---

## Запустить отгрузки

- [ ] Таблица **Береза групп склад** → обязательные поля + **U — коробов**
- [ ] Флаг **I — Отгрузить** → 5–10 сек → появились ID
- [ ] Нет → лист **errors** → общий чат → Макс

---

## Раздать и провести

- [ ] Отгрузки → закладка **Распределить** / фильтр **Новое**
- [ ] Фильтр по артикулу → выделить → **Изменить** → **Сборщик**
- [ ] Статусы: **В сборке** → **На проверке** → **Проверено** → **Отправлена**
- [ ] Менеджеру для отправки: фильтр **Проверено** (не «весь остаток склада»)

---

## Если что-то не так

| Ситуация | Действие |
|----------|----------|
| Нет отгрузки после флага | errors → проверить **U** |
| Расхождение приёмки | Дима |
| Непонятная ошибка | Скрин → общий чат → Макс |
| Случайно удалил | **Показатели → Корзина** |

---

> **Макс** — система, errors, учётки. **Дима** — товар, план, артикулы.
