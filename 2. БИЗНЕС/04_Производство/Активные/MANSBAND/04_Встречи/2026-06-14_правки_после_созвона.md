## Что сделано

### A. Шапка, адреса, навигация
- Из селектора магазина в шапке убран «Онлайн-магазин» (тип `Store` сохранён — нужен для доставки).
- Адреса магазинов:
  - На Бауманской → `г. Москва, Спартаковская пл., д. 14, стр. 2`
  - На Пятницкой → `г. Москва, ул. Пятницкая, д. 8`
  - Адрес отправителя в Доставке обновлён на новый адрес.
- Левое меню переупорядочено: **Новая заявка → Заявки → Сары → Очередь Эдвина → Закрытие смены → Статистика**.
- В «Заявках» добавлены подразделы по виду (Все · Продажи · Аренда · Сертификаты · Продажи компании · Доставки · Дефекты) и фильтр статуса **открытые / завершённые / просроченные** (просрочка считается по сроку отложки/актуальности/аренды).
- Новый раздел **«Сары»** (реферальные выплаты за совет): ведомость отправлено / не отправлено, отметка скриншота, авто-текст сообщения (копирование). Моки + store.

### B. Суммы и скидки (во всех денежных формах)
- Раздел «Позиции в чеке» переименован в **«Товары, стоимость и скидка»**; оплата вынесена в отдельную карточку **«Оплата»**.
- Скидка на чек перенесена внутрь блока товаров; три суммы в ряд: **Общая стоимость · Скидка (₽) · Итого**.
- При скидке в % сумма скидки показывается в ₽ (в плитке «Скидка»).
- Поштучная скидка показывает сумму скидки на позицию в ₽.
- Зафиксированная нижняя строка (sticky): **Сумма · Оплачено · Остаток**.

### C. Оплата и чаевые
- Способы оплаты без привязки к магазину: «Наличные (Бауманская/Пятницкая)» → одна «Наличные».
- Чаевые: «Сдача» остаётся фиксированной, фактически к возврату клиенту уменьшается на чаевые (показывается явно).
- Перевод чаевых через Эдвина = выбор консультанта (по умолчанию ответственный), без ввода реквизитов.
- Частичная оплата: «Успех» недоступен без полной оплаты (оставлено как было).
- Кнопка авто-подстановки в оплате переименована «остаток» → «доплата».

### D. Правки по видам
- **Продажа:** блоки B/C; направивший/источник не перезаписываются после авто-подстановки; плашка «Из обещания/слива №…».
- **Продажа компании:** убраны описания-шум; порядок телефон→имя клиента, телефон→имя руководителя, **название компании** (отдельное поле); «контактное лицо» убрано; источник — нормальный «источник рекламы»; блоки B/C.
- **Сертификат:** чистка подписей-шума; блоки B/C; баланс в карточке оплаты.
- **Аренда:** услуга-позиция со стоимостью; состав комплекта — обязателен (контроль движения, без цены); дата конца = авто (начало + 2 дня), редактируемая; выдача/возврат — факт без дефолта; «Фото паспорта / прав» без лишних подписей; блоки B/C.
- **Отложка:** срок действия = авто следующий день (редактируемый); блоки B/C; селектор этапа доступен, сохранение блокируется без обязательных полей.
- **Обещание / Не слив / Слив:** чистка описаний; в Сливе — корректная пометка логики конверсии (слив убирает клиента из знаменателя, капают бонусы).
- **Дефекты:** позиции без стоимости; чистка описаний.
- **Доставка / Обмен / Возврат:** блоки B/C (Доставка), сквозная чистка описаний.

### Сквозной принцип «заголовок без шума»
Убраны подсказки-дубли: «авто из amoCRM», «ручной/авто из сессии», «сплит 30%», «свободный ввод не обязателен», «(обязательно)» в подписях фото и т.п. Обязательность обозначается только звёздочкой `*`.

### Этап стал доступен из селектора
Селектор этапа в формах больше не блокируется при незаполненных полях — блокируется только кнопка сохранения (как просил Миша на примере отложки).
