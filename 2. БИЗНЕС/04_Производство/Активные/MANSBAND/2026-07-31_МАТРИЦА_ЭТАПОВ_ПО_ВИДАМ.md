# Матрица этапов по видам заявок — утверждённый черновик

**Дата:** 2026-07-31 · **Кому:** Миша (MANSBAND) · **Статус:** ответы Миши учтены  
**Источник:** созвон 29.07.2026 (п.10, п.16) + ответы на вопросы матрицы

Воронка в amoCRM одна — «Продажи» (pipeline 9601214). Скрыты везде: «Новая заявка», «Взято в работу», «Неразобранное».

---

## Решения (ответы Миши)

1. У продажи добавляется «Ждет товар» (вариант 29.07).
2. «Товар отложен» в продаже оставляем.
3. Имя этапа аренды — «В аренде» (как в amoCRM).
4. «Товар в магазине» из селектов при создании убираем: при создании ставят только «Ждет товар», дальше этапы проставляют по процессу.
5. У продажи «Провал» при создании не вариант — это либо слив, либо не слив.

---

## Этапы при создании заявки

| Вид заявки | Что можно выбрать при создании |
|---|---|
| Продажа | Хочет прийти · Ждет товар · Товар отложен · Встреча назначена · Успех |
| Продажа компании | Счет выставлен · Ждет товар |
| Аренда | Аренда оплачена · Ждет товар |
| Отложка | Ждет товар · Товар отложен |
| Обещание | Дано обещание · Хочет прийти · Ждет товар |
| Сертификат пластиковый | Сертификат оплачен · Успех |
| Сертификат электронный | Сертификат оплачен · Успех |
| Доставка | Передан на сборку |
| Слив | Провал · Встреча назначена (если есть дата) |
| Не слив | Провал |
| Возврат / Обмен | Успех · Провал |
| Дефект / Химчистка / Перешив / Не тот размер | Успех · Провал |

---

## Жизненный цикл после создания (смена этапа в карточке)

Эти этапы не выбирают при создании — появляются по ходу работы (Эдвин / Миша / консультант / логист).

| Вид | Позже по процессу |
|---|---|
| Продажа | Хочет прийти · Ждет товар · Товар отложен · Встреча назначена · Успех |
| Продажа компании | Счет выставлен → Оплачено → Ждет товар → Документы готовы → Документы переданы → Успех · Провал |
| Аренда | Аренда оплачена · Ждет товар · В аренде · Успех · Провал |
| Отложка / Обещание | + Успех · Провал |
| Доставка | Собран · Отправлен · Доставлен · Успех · Провал |

**Аренда / «Возвращена».** При создании заявки этапа «Возвращена» нет — только «Аренда оплачена» и «Ждет товар». Возврат комплекта — отдельное событие позже (факт возврата в карточке / смена этапа), не кнопка при создании.

**«Товар в магазине».** Не в селекте создания. Когда товар реально приехал на точку — этап ставят уже в процессе (карточка / задача перемещения), не при заведении заявки.

## Слив vs не слив (созвон 29.07, Миша)

| | Слив | Не слив |
|---|---|---|
| Смысл | Не продали, но ещё можно дожать | Целевой шанс закрыт / «позондировали и ушли» |
| Когда | 1) «Похожу по магазинам и приду» — взять телефон. 2) Перевод в другой шоурум — назначить встречу + телефон | Нет смысла тащить дальше |
| Аннуляция | Только если есть телефон и встреча назначена; если потом купили — слив аннулируют | Не аннулируется «в продажу» тем же путём |
| Этапы | «Провал» (телефон необязателен) или «Встреча назначена» (телефон обязателен) | Только «Провал» |

**Соответствие коду сейчас:** да.
- `SlivForm` — без даты → «Провал», телефон необязателен; с датой → «Встреча назначена», телефон обязателен; комментарий обязателен.
- `NoSlivForm` — только «Провал».
- У продажи «Провал» при создании убран (см. таблицу выше).

## Конвейер продажи компании (п.9)

Этапы воронки: `Счет выставлен → Оплачено → Документы готовы → Документы переданы → Успех`.

Параллельно — **статусы** (не этапы):

| Статус | Кто | Где |
|---|---|---|
| Номер и дата счета | Эдвин | очередь Эдвина |
| Оплачено / не оплачено | Эдвин | очередь Эдвина |
| Документы готовы / не готовы | Миша | очередь Миши |
| Ателье оплатить / оплачено | Миша | очередь Миши, если есть сумма ателье |

## Что меняется в amoCRM

Новые этапы до релиза: «Счет выставлен», «Оплачено», «Документы готовы», «Документы переданы» в pipeline 9601214.

Переименование «Сертификат продан» → «Сертификат оплачен» уже учтено в коде (работают оба имени).
