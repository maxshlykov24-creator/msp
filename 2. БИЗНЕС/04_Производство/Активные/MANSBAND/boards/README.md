# Доски воронок MANSBAND

**Ссылка (публичная, у кого есть ссылка):** https://mansband-kassa.ru/boards/
Прямые ссылки: `#offline`, `#online`, `#complaints`.

## Что внутри

| Файл | Роль |
|---|---|
| `boards-data.js` | **единственный источник правды**: этапы (порядок = колонки слева направо) и переходы |
| `boards.js` | раскладка и маршрутизация связей, режим фокуса, масштаб |
| `boards.css` | оформление |
| `index.html` | шапка, вкладки, легенда, панель этапа |
| `deploy.sh` | выкладка на VPS (`/var/www/mansband-boards`), nginx `location /boards/` |
| `структура_продажи.csv` | выгрузка регламента, на VPS не выкладывается |

## Логика картинки

- Этапы стоят **в одну линию слева направо** — это основной ход сделки.
- Переходы «через этап» вперёд идут **по каналам сверху**, возвраты назад — **по каналам снизу**, провалы — **по нижней шине** к карточке «Провал».
- Каналы распределяются автоматически, поэтому линии не проходят сквозь карточки и не наслаиваются.
- Цвета: синий — основной ход, оранжевый — товар/перемещение, оранжевый пунктир — возврат назад, зелёный — в Успех, серый пунктир — в Провал.
- **Клик по этапу** — остаются только его связи, слева внизу список «откуда приходит / куда уходит». Esc или клик по пустому месту — сброс.
- Кнопка «Вписать» — вся доска целиком; по умолчанию 100% с горизонтальным скроллом.

## Как менять

Сказать в Cursor, что поправить (например: «из Товар отложен добавь переход в Дано обещание»).
Правится только `boards-data.js`, дальше `bash deploy.sh` — раскладка пересчитается сама.
