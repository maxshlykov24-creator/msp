# MANSBAND (активный проект)

> Ритейл костюмов: мультиканал, amoCRM, МойСклад, кассы, лояльность (фаза 2). Документация в vault — для контекста ИИ и команды.

## О папке

Рабочая база по клиенту: контекст ниши, дорожная карта, статус задач, воронки, касса, подписки. Не дублирует переписку в мессенджерах — только структурированные артефакты.
