# Скрипт коллтрекинга на сайт Mansband

Скрипт нужно установить; он молчит, пока на сервере `CT_LIVE=false`. По подтверждению владельца 21.10 Roistat уже не работает из-за неоплаты. Проверка только со ссылки с `?ct=1`. Roistat снимается после контрольных звонков, не раньше.

## Куда вставить

Одна строка в TapTop, в конец `<head>` или перед `</body>`, на всех страницах, где есть телефон. Отдельно то же самое на квиз `zamer.mansband.ru`.

```html
<script src="https://ai-msp.ru/ct.js" async></script>
```

Скрипт Roistat пока не удалять.

## Как проверить до переключения

Открыть `https://mansband.ru/?ct=1`. После прокрутки или клика номер `+7 931 009-02-51` должен смениться на номер из пула, если в адресе есть UTM или `yclid`. Прямой заход показывает статичный номер органики. Вторая страница того же визита держит тот же номер.

`?ct=0` выключает тест в этом браузере.

## Что заполнить в `.env` на сервере

Файл на сервере: `/root/talkme-amojo-bridge/.env`. В git его нет.

- `CT_POOL_NUMBERS`: 10 подключённых номеров пула, 10 цифр через запятую
- `CT_ORGANIC_NUMBER`: подтверждённый основной номер сайта, используется также как резерв и не входит в динамический пул. Для звонков на него точный источник не назначаем.
- `CT_CHANNEL_NUMBERS`: `9310000000=2ГИС;9310000001=Авито`. Значение строго как в списке поля «Источник (техническое)»
- `CT_UTM_SOURCE_MAP`: `yandex=Яндекс Директ`. Пустое значение не пишет источник, UTM при этом пишутся
- `TELPHIN_WEBHOOK_SECRET`: секрет в пути вебхука
- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`

`CT_LIVE` остаётся `false`, пока контрольные звонки не записаны в сделки.

Вебхук Телфин, второй адрес, существующий адрес интеграции amoCRM не менять:

```text
https://ai-msp.ru/webhooks/telphin/СЕКРЕТ
```

Секрет уже записан на сервере в `TELPHIN_WEBHOOK_SECRET`. Старый адрес `mansband-chat-bridge.twc1.net` для скрипта не использовать: сертификат на это имя не выпускался, рабочий адрес моста `https://ai-msp.ru`.

Первый боевой звонок может прийти в незнакомом формате. Он сохранится в базе, в лог попадут имена полей без телефона клиента. После этого в `parse_telphin` добавляются подтверждённые имена, не раньше.

## Переключение

1. Удалить скрипт Roistat в TapTop.
2. Если номер в HTML принадлежит Roistat, заменить его на `CT_ORGANIC_NUMBER`.
3. На сервере `CT_LIVE=true` и `docker compose up -d --build api`.
4. Открыть сайт без `?ct=1` и убедиться, что номер подменился.

Номера Roistat не отключать 7 дней: у части посетителей страница останется открытой или в кэше.


## Контроль после настройки

- `https://ai-msp.ru/ct/health` должен вернуть HTTP 200. HTTP 503 означает проблему БД либо отсутствие свежей фоновой сверки. Нужна отдельная внешняя проверка этого адреса, пока она не подключена.
- Контрольная перегрузка в тестовой среде: все номера заняты, следующему посетителю выдаётся основной, ранее выданные номера не меняются.
- После настройки Telegram проверить получение сигнала, повтор при ошибке доставки и сообщение о восстановлении.
- Ключи и список номеров только на сервере, не в git. До контрольных сделок `CT_LIVE=false`.
