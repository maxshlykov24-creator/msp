## Что должен получить продавец

В поиске, подборе в заявку, составе продажи, возврате и перемещении у подтверждённого товара есть миниатюра. Наведение показывает увеличенный кадр. Нажатие открывает его на компьютере и телефоне. Размер, рост, цена, складской остаток и выбор товара продолжают работать по обычным правилам кассы.

Миниатюра костюма находится в основной строке. Если у вариации несколько снимков, расцветка переключается внутри просмотра. Если для расцветки из заголовка кадра нет, миниатюра показывает тот кадр, который откроется по нажатию. Подпись называет расцветку и узор этого кадра. На рабочей кассе 19 ноября 2026 проверены `CM90/90H`, переключение четырёх расцветок `YI8863` и фото пиджака `M03/642MB3` в заявке.

Единица обработки — одна пронумерованная группа **внутри конкретного столбца** листа «Фотосессия». У группы может быть несколько кодов МоегоСклада. Разные размеры одного изделия и одной расцветки получают общий снимок.

**У костюма фото показывается на пиджаке и в общей строке комплекта. Карточки костюмных брюк и жилетов остаются без фото**, включая детали смокинга. Совпадение вариации, размера и цвета с пиджаком этого правила не меняет. Самостоятельные брюки или жилет из раздела одежды можно включить со своим подтверждённым кадром.

### Что проверено после публикации 19 ноября 2026

Пилот опубликован в разделе [«Поиск товара» рабочей кассы](https://mansband-kassa.ru/#products). Удобный пример для продавца — `BAZ3070MTTBE`. Раскрой строку тренча, затем наведи указатель на миниатюру или нажми на неё.

- После исправления в авторизованной сессии рабочей кассы открыты все десять увеличенных фотографий. В продаже для `M03/642MB3` проверены десять пиджаков с фото, десять брюк и десять жилетов без фото. Для `M03/642B3+` проверено по девять карточек каждого вида с тем же результатом. У `M23/33-120` девять пиджаков показали фото, все строки брюк в выдаче остались без изображения. Общая строка костюма-тройки в каталоге открыла кадр пиджака.
- Для быстрой приёмки введи в подборе продажи `M03/642MB3 48`. Одновременно видны три изделия одного размера. Миниатюра есть только у пиджака.
- В работающем сервисе проверены каталог и подбор в продажу для всех десяти групп. По короткому коду `501` первые 12 результатов подбора — сафари, по шесть коричневых и чёрных. Фото P2 есть только у чёрных.
- Браузерная проверка на сохранённых ответах рабочего API прошла для всех десяти групп в обоих экранах. Тренч дал один адрес миниатюры на 16 сочетаний размера и роста. У `YI8863` подтвердились пять коричневых карточек из двадцати. Проверены наведение, клик, закрытие клавишей Escape и касание на мобильном экране. При открытии фото состав продажи сохранился.
- Рабочий адрес вернул HTTP 200 для состояния кассы, PostgreSQL доступен. В контейнере рабочей кассы совпали контрольные суммы всех 20 WebP. По публичному адресу без сессии запрос к фото вернул HTTP 401. В отдельном запуске того же веб-образа с тестовой сессией все 20 файлов прошли через nginx с HTTP 200, правильными байтами и приватным кэшированием.
- На рабочем сервере материалы выпуска лежат в `/opt/mansband-kassa/backups/catalog-photos-20261119-OHnuDU`. В `images.json` записаны предыдущие образы, в `source-before.tar.gz` сохранены исходные версии изменённых файлов. `files.json` содержит контрольные суммы, `live-search.json` содержит выдачу каталога, `release.log` и `exact-code/release.log` содержат результаты выкладки. Выпуск интерфейса — `photos-20261119-111733`, итоговый образ поиска — `mansband-kassa-api:photos-exact-501`.
- Исправленный веб-образ — `mansband-kassa-web:suit-photo-20261119-120425`. Папка этого обновления — `/opt/mansband-kassa/backups/catalog-suit-photos-20261119-HKuEq6`. В ней сохранены предыдущий и новый индексы, имена обоих образов в `images.json` и журнал `release.log`. Обновление затронуло только веб-интерфейс. Если касса уже открыта до выкладки, обнови вкладку после завершения текущей операции.

## 2. Выбрать следующую партию

1. Открой `inventory.json`. В `groups` найди группу по первой ячейке столбца артикулов, например `Z2`. Посмотри `category`, `number`, `entries`, `sources` и `catalog`. Пропусти ячейки, уже находящиеся в `selection.json`.
2. Начни с небольшого набора групп со статусом `один исходник`. Открой каждый кадр. Сверь вид изделия, цвет и узор с таблицей и кандидатами каталога. Для группы с несколькими артикулами проверь каждый артикул. Соседний номер или такой же номер в другой колонке — отдельная группа.
3. Допиши объект в конец `selection.json`, используя существующую запись как образец. В `source` укажи имя ARW без расширения, в `variations` точные значения поля «Вариация» из кассы, в `models` полные названия сфотографированных видов изделия до скобки. Цвет и узор скопируй из каталога. Пустой узор передаётся пустой строкой. Для костюма включи в `models` только вид пиджака с `suit_part=jacket` и укажи `suit: true` для общей строки комплекта. Брюки и жилет этой вариации в список не добавляй.
4. Сохрани в рабочем отчёте ячейку, исходник, проверенные коды, цвет и решение по каждому спорному случаю. Для повтора из другого столбца сначала проверь, покрыты ли те же карточки принятой группой. Повторную привязку одной карточки скрипт остановит.
5. После каждой партии отмечай обработанные ячейки. При итоговой сверке укажи для каждой группы из свежего `inventory.json` одно из трёх решений. Для опубликованной группы отметь выпуск. Для уже покрытой группы укажи другую ячейку. Для отложенной запиши причину и вопрос клиенту. Отдельно перечисли исходники вне таблицы. Итоговое количество групп сверяй со свежим отчётом `scan`.

**Как разбирать исключения**

| Ситуация | Действие исполнителя |
|---|---|
| У пиджака, брюк и жилета общий код | По полям `suit_part`, `category` и названию проверь, входит ли изделие в костюм. В костюмной группе отбирай только пиджаки. Сборка остановится, если включить в подборку костюмные брюки или жилет, в том числе без флага `suit: true`. Для отдельно снятых брюк из раздела одежды нужен собственный вид изделия и подтверждённый исходник. |
| В имени фотографии дефис, в МоемСкладе косая черта | Используй кандидата из отчёта. В отбор впиши фактический код кассы со всеми разделителями и знаками `+`. |
| Кандидат появился только после замены латинской `m` на кириллическую `м` | Сверь полный код, вид и цвет с карточкой. После документированной сверки добавь `"confirmed_m": true`. При нескольких кандидатах оставь вопрос открытым. |
| Один код встречается в нескольких цветах | Публикуй только подтверждённую расцветку. Пример N2 показывает, как привязать коричневый `YI8863` и оставить другие цвета отдельно. |
| По одной записи Excel у одного вида нашлись разные сочетания цвета, кроя или узора | Отложи группу. При наличии решения клиента впиши источник и содержание решения в `appearance_evidence`. Выбери точный цвет и узор. Для нескольких вариантов кроя у того же цвета и узора укажи допустимые значения, например `"fits": ["slim fit"]`. |
| Более одного исходника, например B2, либо нет файла, например B85 | Зафиксируй ячейку и имена файлов. Когда клиент выберет основной кадр, укажи его точное имя в `source`, а источник решения в `source_evidence`. Для группы с несколькими файлами выбор ограничен её собственными кадрами. Для пустой группы нужен явно подтверждённый файл, который реально есть в папке. |
| Файл вне таблицы, например `501-черный-2.ARW` | Оставь исходник в папке. В таблице для P2 указан кадр `501-черный-1`. Остальные ракурсы ждут самостоятельного решения. |
| Нет соответствия, совпало только начало кода или расходится вид изделия | Запиши ячейку и расхождение, переходи к следующей группе. После решения клиента допустим `confirmed_codes` со структурой `{"запись из Excel":{"variation":"точный код из кассы","evidence":"источник и решение"}}`. Код должен существовать в свежем каталоге. Подстрока или визуально похожий артикул не подтверждают связь. |
| У части артикулов в группе подтверждены товар и снимок | Запиши только подтверждённые вариации. В `excluded_entries` укажи точную строку Excel и причину пропуска для каждой оставшейся позиции. Например, `{"артикул из Excel":"Нужен узор по карточке"}`. Сборка запрещает пропуск всех записей группы. |
