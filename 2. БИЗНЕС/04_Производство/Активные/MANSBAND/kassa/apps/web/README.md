# MANSBAND — Касса (прототип)

Кликабельный прототип кассы для MANSBAND: быстрый UI поверх amoCRM (сделка = заявка) + каталог МойСклад. Десктоп-first, адаптив под телефон. Демо-данные построены на реальных воронках/полях `mansband.amocrm.ru`.

## Запуск

> Node нужен с npm. Если в системе нет — автономный Node лежит в `~/.local/node-dist/` (см. `env.sh`).

```bash
# при необходимости активировать локальный node:
source ~/.local/node-dist/env.sh

npm install      # один раз
npm run dev      # http://localhost:5173  (или указанный порт)
npm run build    # прод-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Что внутри (кликабельно)

- **Заявки** — список/доска, поиск, фильтры, карточка заявки.
- **Новая заявка** — конструктор Тип → Вид. Рабочие формы: Продажа, Сертификат, Аренда, Слив. Остальные виды — экраны-заглушки в дизайне.
- **Продажа** — товары, скидки/подарок, мульти-оплата, авто-сдача, «Успех».
- **Сертификаты** — реестр с балансом, списание, авто-гашение.
- **Очередь Эдвина** — сдача/возврат «не выдано» → «отправил».
- **Закрытие смены** — сверка факт/система по способам оплаты.
- **Статистика** — конверсия по консультантам/магазинам, магазин vs call-менеджер.

Deep-links: `#board`, `#new`, `#new/sale`, `#certificates`, `#queue`, `#shift`, `#dashboard`.

## Структура

```
src/
  data/        типы + мок (форма ~ amoCRM/МойСклад)
  components/  ui, Layout, PaymentBlock, ProductPicker
  views/       экраны + forms/
  store.tsx    общий стейт (заявки, сертификаты, очередь)
presentation/  продающий слайд-деск (index.html, открыть в браузере)
```
