Система ведёт менеджера по следующему шагу — старый клиент не зависит от памяти нового.

Определение

«Следующий шаг»

У каждой активной сделки продления в любой момент есть ровно одна открытая задача с датой. Проверяет не человек — сторожевой процесс на сервере.

Доказательство

Переход по факту

Счёт → оплата (авто-статус Точка Банк) → макет утверждён → печать → монтаж → фотоотчёт → УПД → новый цикл. Каждый переход — по факту, не по проставленному флажку в чек-листе.
