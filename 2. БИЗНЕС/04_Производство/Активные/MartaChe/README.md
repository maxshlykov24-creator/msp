## Telegram-рассылка «Честная пятница», 12.11.2026

Отправка через Wazzup API, бот `@MARTAcheBot_bot`: фотография, затем отдельный текст; искусственных пауз между ними нет. Жирные выделения и UTM: `utm_source=telegram`, `utm_medium=messenger`, `utm_campaign=chestnaya_pyatnitsa`.

- Основная база API: 105 уникальных адресатов, обе части приняты API для всех.
- Тест по архиву вне основной базы: 3 успешные пары, 2 отказа на первом фото.
- Остальная база: 1 067 адресатов после исключений; 1 065 новых попыток, 78 успешных пар и 987 отказов на фото. Два ранее подтверждённых отказа повторно не отправлялись. Завершено 12.11.2026 в 15:18 МСК.
- Итого без личного теста владельца: 186 уникальных клиентов с принятыми фото и текстом, 372 уникальных сообщения; повторных принятых частей нет. 989 адресатов остались без рассылки: `MESSAGES_NOT_TEXT_FIRST_FROM_TELEGRAM_BOT`. Этот код не доказывает блокировку бота клиентом.
- Источник: ответы `POST /v3/message`. HTTP 201 подтверждает успешный ответ API, а не прочтение. Для Telegram Bot Wazzup показывает только статус «Отправлено».
- Закрытый журнал отправок и исключений: `retailcrm_chat_export/data/campaign_2026-11-12_receipts.json` (gitignored, содержит идентификаторы; не коммитить). Перед любым продолжением прочитать журнал и исключить уже принятые части. Личный тест владельца тоже исключать. Не менять порядок на «текст → фото» без согласования.
