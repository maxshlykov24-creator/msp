# LicenseBridge USA — созвон по аудиту Этапа 0 (транскрипт)

**Дата:** 2026-06-18
**Тип:** демонстрация результатов Этапа 0 (аудит) клиенту (Павел)
**Артефакт показан:** `presentation/Этап0_Аудит.html` + прототип дашборда

## Ключевые решения и корректировки фокуса

1. **Приоритет Этапа 1 переставлен:** № 1 — мессенджеры (официальная/белая интеграция WhatsApp и Telegram), затем телефония/звонки, распределение, доходимость лидов, дубли. Клиент: «проблема номер один — мессенджеры… звонки-то работают». Передача записей звонков — боль РОПа, не первостепенная.
2. **Белая интеграция WhatsApp/Telegram:** текущая серая через e-chat завязана на телефон Павла (вход по QR, одно устройство). При отвале VPN/интернета в РФ менеджеры весь день не могут отправлять КП/файлы. Официальная интеграция снимает эту зависимость.
3. **Facebook через сервис-агрегатор**, а не прямая интеграция: чтобы лить заявки с нескольких рекламных аккаунтов; если один забанят/уйдёт на проверку — второй работает. Сейчас прямая интеграция с одним рекламным аккаунтом; аккаунт на проверке, доступов нет, выгружают файлом и обзванивают вручную через новый лид. Агрегатор может завязать все источники.
4. **SMS RingCentral нестабильны:** нельзя много сообщений подряд и много текста в одном — иначе не доставляется. Проверить на стороне RingCentral.
5. **Дашборд = две вкладки с переключателем РОП ↔ Маркетинг.** Маркетингу: сквозная аналитика (рекламная кампания → лид qual/non-qual → продажа/отказ). РОПу: скорость ответа менеджера (в Kommo не реализовано), приход, конверсия, открытые сделки, конверсия по этапам (где теряют клиентов), просроченные задачи. Сделать базовый минимум (2 страницы), расширять потом. Клиент пришлёт список нужных метрик. Разграничение доступа по желанию — пока достаточно переключателя.
6. **Контроль застоя сделок через уведомления в Telegram-чат:** бот тегает ответственного + ссылка на сделку, не только автозадачи.
7. **Серверные решения вместо платных виджетов:** дубли-объединение, триггеры и расчёты выносить на свой сервер — экономия на помесячных подписках виджетов Kommo.
8. **SLA по этапам:** у клиента уже есть памятки к каждому этапу в настройках воронки (автоматизация) — заберём оттуда. Время/нормы по этапам клиент пришлёт текстом/голосом, отдельный созвон не нужен.

## Уточнения по системе

- **Алина — 0 звонков в CRM:** Павел подключил её и в RingCentral (с записью), и в Kommo (сопоставил по имени), но звонков нет — проблема глубже в интеграции; часть звонков вообще не доходит.
- **SIP-оборудование:** звонки шли, иногда отваливалась регистрация SIM, обновили прошивку — стало лучше. Нужен прямой доступ к оборудованию через роутер (не через компьютер) для перезагрузки в любой момент; товарищ в США даст удалённый доступ. RingCentral оставить резервом на пару месяцев.
- **New Bot Leads — на паузе:** новое направление, нужен отдельный сотрудник. В активный объём сейчас не входит → работаем по трём воронкам.
- **Сборка:** путь несколько месяцев; оплата 50% + вторая часть (до месяца после первой). Была одна автозадача (когда начинать сбор); клиентский менеджер теперь ставит задачу следующего шага на каждую сделку. Фокус сейчас не на сборке, а на продажах.
- **Передача сделки между менеджерами:** только в случае дубля; иначе закреплено за одним менеджером (пока не придумали, как делить при оплате).
- **Часовые пояса:** менеджеры работают день/ночь/вечер, покрывают Нью-Йорк и Калифорнию (с утра до вечера) — учитывать в правиле распределения.
- **Мусор для чистки:** тестовые сделки; задачи на холодный прозвон (≈40 контактов), не привязанные к сделкам.
- **Сделки без задач:** всего 7, на этапе «Первичный контакт» + тесты — допустимо.
- **Возвращаемость:** редкая, но идут рекомендации (сарафан), ~5 обращений в личку.
