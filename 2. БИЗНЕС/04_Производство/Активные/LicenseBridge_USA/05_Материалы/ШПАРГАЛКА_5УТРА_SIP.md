## ШАГ 1. TeamViewer на Mac — САМОЕ ВАЖНОЕ (делать первым)
Без этого потеряем доступ, когда человек уедет. Компьютер в США — **Apple (macOS)**.

1. Установить/открыть TeamViewer на Mac.
2. **Выдать системные разрешения** (без них будет чёрный экран, управлять нельзя):
   Системные настройки → **Конфиденциальность и безопасность (Privacy & Security)** → включить TeamViewer в:
   - **Запись экрана (Screen Recording)** ✅
   - **Универсальный доступ (Accessibility)** ✅
   - (если предложит) **Доступ к диску (Full Disk Access)** ✅
   После включения — **перезапустить TeamViewer**.
3. Настройки TeamViewer → **Неконтролируемый доступ (Unattended access)**:
   - включить **«Запускать TeamViewer при запуске системы»**;
   - задать **постоянный пароль** (записать!).
4. Электропитание macOS: Системные настройки → **Экономия энергии / Аккумулятор → Адаптер питания**:
   - **«Препятствовать автоматическому переходу в режим сна…»** — включить;
   - **«Запускать автоматически после сбоя питания»** — включить (если есть).
   - На заметку: экран может гаснуть — это ок, главное чтобы Mac **не засыпал**.
5. Оставить Mac: **включён, в розетке, кабель интернета воткнут**, на 3 дня. Крышку ноутбука (если это MacBook) — либо не закрывать, либо подключить внешний монитор/питание (иначе уснёт).
6. Записать и прислать мне: **TeamViewer ID + пароль**.

> Проверка: с другого устройства зайти по этому ID+паролю — должно пустить и **дать управлять** (курсор двигается). Если видно экран, но курсор не слушается — не выданы разрешения из п.2.

## ШАГ 3. Достучаться до шлюза (у него другая подсеть)
Шлюз на `192.168.5.150`, а роутер даёт `192.168.1.x` — напрямую не откроется. Один раз заходим так:

1. Кабелем соединить шлюз TG400 **напрямую с ноутбуком** помощника (если Mac без Ethernet — нужен переходник USB‑C→Ethernet).
2. Задать ноутбуку статический IP **`192.168.5.10`**, маска `255.255.255.0`:
   - **macOS:** Системные настройки → **Сеть** → выбрать Ethernet‑адаптер → **Детали (Details)** → **TCP/IP** → «Конфигурация IPv4» = **Вручную (Manually)** → IP `192.168.5.10`, маска `255.255.255.0` → OK.
   - **Windows:** Параметры адаптера → свойства IPv4 → тот же IP/маску.
3. В браузере открыть **`http://192.168.5.150`**, войти `Admin` / `password`.
