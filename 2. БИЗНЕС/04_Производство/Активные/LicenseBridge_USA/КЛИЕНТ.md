# LicenseBridge USA — карточка клиента

> SSOT папки. Детали — в разделах, не дублировать объёмом.

| Поле | Значение |
|---|---|
| Стадия | активный: живой прод плюс сопровождение |
| Суть | консалтинг по получению лицензий подрядчиков в США, B2B и B2C. Задача: стабилизировать приём лидов, связь и распределение заявок в Kommo, затем снизить ручную работу и построить аналитику |
| Контакты | Павел — владелец · Александра — РОП |
| Команда клиента | 4 sales плюс 1 клиентский менеджер |
| Стек | Kommo · Asterisk и TG400 · Pleep · Telnyx · WhatsApp Cloud API · Make · Facebook и Tilda как источники лидов |
| Прод | дашборд `lb.mspod24.ru`, хаб и Asterisk на своём сервере |
| Обновлено | 2026-09-07 |
