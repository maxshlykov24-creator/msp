## Важно про «восстановление»

1. NOVA делает **настоящий merge**: чаты/история уезжают в выжившую карточку. Через API **нельзя** гарантированно «разлепить» чаты обратно.
2. Что можно быстро восстановить из этого дампа:
   - пересоздать **пропавший контакт/сделку** с полями из `*.jsonl`;
   - вернуть связи контакт↔сделка по `contact_ids` / `lead_ids` из индексов;
   - сверить, что пропало: сравнить текущий API с `contacts_index.json` / `leads_index.json`.
3. Перед массовым откатом — **не удалять** уже склеенные карточки вручную; сначала сверка id.
