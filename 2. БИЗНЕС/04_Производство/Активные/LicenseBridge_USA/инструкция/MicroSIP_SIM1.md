## Чеклист

1. Скачать MicroSIP (полная версия): https://www.microsip.org/downloads  
2. Меню (стрелка справа сверху) → **Add Account**  
3. Поля: SIP Server / Domain = `159.65.97.156`, Username / Login = `101`, пароль из ДОСТУПЫ, Transport = **UDP**, Media Encryption = **Off**, Proxy/STUN пусто  
4. Save → статус **Online**  
5. Тест: исходящий `+1…` → входящий на линию → звук в обе стороны  
6. Отчёт: «Online»

## Важно

- Только Windows (на Mac — Linphone).
- Аккаунт `101` — только на одном ПК одновременно.
- Не класть пароль в общие чаты без необходимости.
- Закрытый MicroSIP не задерживает звонок: линия сразу уходит на 103. Держать
  программу открытой вне смены не нужно.
- Набор в 11 цифр без плюса (`18187911783`). Звонить клиенту можно 08:00–21:00
  **по его местному времени** — требование TCPA, считается по его штату.
