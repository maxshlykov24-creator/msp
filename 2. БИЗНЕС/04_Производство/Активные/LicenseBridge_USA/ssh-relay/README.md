# LicenseBridge SSH relay

Изолированный SSH-relay на `72.56.123.137:2222`. Он принимает исходящий туннель со старого Mac mini и не публикует VNC/TG400 напрямую в интернет.

Полный актуальный handoff: [`../2026-07-17_УДАЛЕННЫЙ_ДОСТУП_И_TG400.md`](../02_Знание/2026-07-17_УДАЛЕННЫЙ_ДОСТУП_И_TG400.md).

## Штатное подключение

На Mac администратора дважды нажать `~/Desktop/LicenseBridge Mac.app`. Приложение:

1. запускает локальный SSH-туннель по ключу;
2. открывает Screen Sharing;
3. после закрытия Screen Sharing останавливает локальный туннель.

TG400 во время сеанса доступен по `http://127.0.0.1:8080`.

## Первый запуск на Mac mini

```bash
ssh -p 2222 -N \
  -o ServerAliveInterval=30 \
  -o ServerAliveCountMax=3 \
  -o ExitOnForwardFailure=yes \
  -R 127.0.0.1:15900:127.0.0.1:5900 \
  -R 127.0.0.1:10022:127.0.0.1:22 \
  -R 127.0.0.1:18080:192.168.5.150:80 \
  -R 127.0.0.1:18443:192.168.5.150:443 \
  relay@72.56.123.137
```

При первом подключении проверить fingerprint RSA:

```text
SHA256:HClAWMrXtx2XHFVPPl4PS1y2xt/LCJefkDIT5ufkQbs
```

Временный пароль хранится локально в `~/.ssh/licensebridge_relay_password` и не коммитится.

## Подключение администратора

```bash
ssh -p 2222 -N \
  -L 127.0.0.1:5901:127.0.0.1:15900 \
  -L 127.0.0.1:10023:127.0.0.1:10022 \
  -L 127.0.0.1:8080:127.0.0.1:18080 \
  -L 127.0.0.1:8443:127.0.0.1:18443 \
  relay@72.56.123.137
```

После подключения:

- экран Mac: `vnc://127.0.0.1:5901`;
- SSH Mac: `ssh -p 10023 pavelkhlopenko@127.0.0.1`;
- TG400 HTTP: `http://127.0.0.1:8080`;
- TG400 HTTPS: `https://127.0.0.1:8443`.

Фактическая сеть после исправления 2026-07-17:

- TG400: `192.168.5.150/24`, шлюз `192.168.5.1`, MAC `f4:b5:49:ff:0b:7f`;
- Ethernet Mac mini: `192.168.5.1/24`, без шлюза;
- Wi-Fi Mac mini сохраняет основной маршрут в интернет через `192.168.1.254`.
- Mac mini выполняет NAT `192.168.5.0/24 → en1` через отдельный PF-anchor `com.apple/licensebridge-tg400`.
- Сетевой watchdog `/usr/local/sbin/licensebridge-tg400-network` восстанавливает IP, forwarding и NAT раз в 30 секунд.

## Ограничения

- разрешены только порты `15900`, `10022`, `18080`, `18443` на loopback внутри relay;
- наружу открыт только SSH `2222`;
- поддержка старых SSH-алгоритмов изолирована в контейнере и не меняет основной SSH VPS;
- после первого входа пароль нужно заменить RSA-ключом Mac и отключить `PasswordAuthentication`.
