Маркировка Честный знак

Ревизия по API МойСклад. КриптоПро на компьютеры клиента из этого контура не ставил.

Товаров 370. Штрихкод EAN есть у всех. Тип учёта Честный знак LP_CLOTHES у 169, не маркируются 201 (материалы, услуги и т.п.). КриптоПро на компьютеры клиента из этого контура не ставил.

Коды маркировки при отгрузке смотрите в документе отгрузки: Честный знак → коды. Если отгрузка ругается на токен или КриптоПро — обновить КриптоПро CSP на кассе/офисе по инструкции КриптоПро, не в облаке МС.

  1. МойСклад → Настройки → Честный знак: проверить, что токен живой.
  2. Карточка товара: штрихкод / GTIN совпадает с честным знаком.
  3. При отгрузке коды списываются. Если код не проклёвывается — не проводить отгрузку «в минус».
  4. Остатки кизов сверять с НАЦИУМ, не с ощущением.
