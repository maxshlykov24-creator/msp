## Утверждённая загрузка, 15.10.2026

Владелец разрешил загрузку файла `2026_10_08_Товары_сайта_для_утверждения.xlsx` (SHA256 `aade5bc6127b01e71f54f2db7df098cbed5f5c74647144e1cb022229c3e16c68`), использование подтверждённых архивных карточек и создание оплат только по успешным заказам, на полную сумму заказа покупателя. Возвраты проверяются отдельно.

Предварительная сверка: 207 заказов и 265 товарных строк, 134 позиции. Из 83 строк «Добавить отдельно» 11 совпали с архивными карточками; две строки нового товара различаются только регистром цвета, поэтому нужны 71 новая карточка. 51 исходное сопоставление существующим товарам сохранено; неоднозначность кардигана Maria Kalashnikova разрешена по настоящему `wooms_id` карточки сайта, без выбора наугад.

Заказ №6896 (24 900 ₽) владелец подтвердил как тестовый и разрешил не переносить. Прочих явных тестовых имён, примечаний и телефонов-заглушек в выбранных 207 заказах не найдено. №6895 и №10000 без телефона, сами по себе тестовыми не признаны. К загрузке 206 заказов: 179 успешных на 2 414 530,45 ₽ и 27 в обработке на 625 816,23 ₽. Для статуса «В обработке» платежи не создаются, даже если на сайте есть `date_paid`. Возвратов в выбранных заказах WooCommerce нет.

`WS-232733` — отображаемый номер сайта, реальный ID `232730`; совпадение подтверждено датой, суммой и всеми строками. Внутренний ID `232733` принадлежит другому отменённому заказу и не импортируется. Сопоставление по одному похожему номеру запрещено.

Загрузка выполняется небольшими последовательными пакетами с `X-Lognex-WebHook-Disable: true`, без резервов и отгрузок. Для всех новых сущностей заданы постоянные `syncId`, которые по документации API возвращают ранее созданную сущность при повторе. Существующие товары и контрагенты не переписываются, карточки не объединяются. Заказ и позиции повторно читаются до оплаты, после оплаты проверяется `payedSum`. Успешный пилот: №5308, документ 12 175 ₽, связанный входящий платёж на ту же сумму, дата оплаты сайта сохранена. МойСклад округляет время документа до минуты; календарная дата сохраняется.
