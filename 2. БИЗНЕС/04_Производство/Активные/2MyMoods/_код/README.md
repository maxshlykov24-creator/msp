По [ограничениям amoCRM](https://www.amocrm.ru/developers/content/api/recommendations), ответ 429 означает превышение частоты; повторные превышения или подозрительная активность могут привести к 403. Сам 403 также встречается при недостатке прав, поэтому один код не доказывает причину.

В сборщик дашборда добавлен межзапускный предохранитель: первый HTTP 429 останавливает запросы amo на 30 минут, HTTP 403 на 6 часов; срок хранится в закрытом локальном файле и переживает очередной запуск таймера.
