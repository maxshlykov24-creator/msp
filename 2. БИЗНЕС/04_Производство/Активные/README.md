# Активные

> Клиенты со сделкой в работе: внедрение или сопровождение. Стадия читается из `КЛИЕНТ.md`, не из имени этой папки.

Лиды до подписания — в [`../Лиды/`](../Лиды/README.md). Сданные — в [`../Архив/`](../Архив/README.md).

---

## О папке

Каждый клиент — отдельная подпапка по имени из реестра проектов: `Keris_Club`, `MANSBAND`. Внутри — единый шаблон. Код клиента в эту папку не кладём: он живёт в `08_Системное/_код/`.

## Структура папки клиента

```
Клиент/
├── README.md              — навигатор
├── КЛИЕНТ.md              — карточка-SSOT: контакты, стадия, стек, ссылки на код
├── ЗАДАЧИ.md              — доска задач (статусы: ожидание / в работе / на проверке / готово / отложено)
├── ДЕНЬГИ.md              — этапы оплат, подписки клиента, часы поддержки
├── 01_Договорённости/     — КП, коммерция, договоры
├── 02_Знание/             — контекст, архитектура, анализы, чаты
├── 03_Проекты/<Проект>/   — одно внедрение: ТЗ, план, DoD
├── 04_Встречи/            — транскрипты, имя с датой
├── 05_Материалы/          — презентации, HTML-инструкции, регламенты
└── 06_Доступы/            — секреты, вне git
```

В **каждой** папке — `README.md`. Имена файлов — по `_СИСТЕМА/ИМЕНОВАНИЕ.md`.

Эталон раскладки: [`Keris_Club/`](Keris_Club/README.md). Все клиенты переведены на него 2026-09-07: документы разложены по разделам, README есть в каждой папке. Обязательные файлы корня (`КЛИЕНТ.md`, `ЗАДАЧИ.md`, `ДЕНЬГИ.md`) пока заполнены только у Keris, Берёзы и MANSBAND.

## Как использовать

- Новый клиент со сделкой — папка здесь по шаблону.
- Лид без подписи — в `Лиды/`, тот же шаблон внутри.
- После сдачи — в `Архив/`.
- Сырьё — через [`_ВХОДЯЩЕЕ`](../../../_ВХОДЯЩЕЕ/README.md).
