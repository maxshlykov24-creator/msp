# Архив

> Завершённые внедрения — источник шаблонов и постмортемов.

---

## О папке

Сюда переносятся проекты из `Активные/` после сдачи. Хранить обезличено там, где есть ПДн клиента. Главная ценность архива — переиспользование: готовые схемы, рабочие конфиги, поведение edge-кейсов.

## Как использовать

- При переносе из `Активные/`: убери лишнее, добавь постмортем (что сработало, что нет).
- При старте нового похожего проекта — ищи здесь прецеденты.
