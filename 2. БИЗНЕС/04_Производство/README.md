# 04_Производство

> Реализация проектов: интеграции n8n, amoCRM, МойСклад, кастомный код, миграции, сдача.

---

## О папке

**Операционное ядро доставки**: ТЗ, схемы потоков, конфиги (без секретов), чек-листы внедрения, постмортемы, заметки по клиентским окружениям. Стек в профиле — JS/TS, Python, REST, SQL, JSON.

## Содержимое

- [`Активные/`](Активные/README.md) — клиенты со сделкой (внедрение или сопровождение).
- [`Лиды/`](Лиды/README.md) — клиенты до подписанной сделки.
- [`Архив/`](Архив/README.md) — завершённые внедрения; обезличенная документация для переиспользования.
- [`Шаблоны_ТЗ/`](Шаблоны_ТЗ/README.md) — заготовки ТЗ, чек-листы, типовые структуры проектов.

## Как использовать

- Новый клиент со сделкой → папка в `Активные/` по шаблону из `Активные/README.md`.
- Лид без подписи → `Лиды/`. После сдачи → `Архив/`.
- Сырые логи и дампы — через [`_ВХОДЯЩЕЕ`](../../_ВХОДЯЩЕЕ), затем выжимка сюда.
- Секреты и ключи не коммить в заметки; указывай только место хранения (vault, env).
