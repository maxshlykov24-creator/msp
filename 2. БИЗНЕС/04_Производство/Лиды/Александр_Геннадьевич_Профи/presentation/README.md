## Календарь

Неделя, три условных направления, проекты А, Б, В. Карточки содержат исполнителя, дату, направление, план, факт и статус. Реализованы перенос мышкой, перенос через редактор на телефоне, редактирование, отборы, локальное сохранение и сброс с подтверждением. При недоступности localStorage данные живут в текущем сеансе. Введённые значения экранируются, некорректный объём не сохраняется.

Печать даты означает работы, запланированные на выбранный день, в их текущем состоянии. Исторические версии плана не восстанавливаются. Фильтры общие с календарём. Печать отдельного дня изолирована от печати презентации.

Файл содержит исходное статичное заполнение календаря и отчёта для просмотрщиков без JavaScript. Интерактив требует браузера с JavaScript. Публичной публикации, серверного сохранения, многопользовательской работы и соединений с рабочими системами нет.
