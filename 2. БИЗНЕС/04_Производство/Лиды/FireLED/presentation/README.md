# Презентация FireLED

Исходный редактируемый файл: `Предложение_FireLED.html`. PDF является экспортом того же HTML. Контекст и расчётные допущения: [README клиента](../README.md).

## Оформление и источники изображений

Использован существующий `ПРЕЗЕНТАЦИЯ_ПРОДАЖИ_MS/TEMPLATE.html` и актуальный бренд MS Product: бургунди, пыльно-розовые акценты, Inter, аура, лучи, шёлк, пыль и навигация. Для PDF сохранена A4 landscape. На узком экране все разделы отображаются последовательно.

- MS: `08_Системное/БРЕНД/logo-ms-transparent.png`.
- FireLED: https://fireled.ru/wp-content/themes/fireled/assets/images/fireled_logo.svg . Временный путь присланного снимка логотипа оказался недоступен, поэтому использован оригинал того же бренда с сайта, без перерисовки и перекрашивания.
- Фото Пан Чемодан: https://fireled.ru/wp-content/uploads/2026/07/photo-01-31-1024x768.jpg . Это изображение из портфолио клиента, не кейс MS Product.

`assets` нужны для редактирования; для просмотра и передачи достаточно HTML или PDF. Выполнен embed_presentation.py, внешних загрузок для отображения HTML нет. Источники доступны обычными ссылками на последнем слайде.

## Проверка 16.11.2026

- Chromium: 19 слайдов, изображения и встроенные шрифты загружены; ошибок JavaScript и сетевых загрузок при просмотре нет.
- 1440×1000, 1366×768, 1024×768: основной контент всех слайдов внутри доступной области.
- 375, 390, 768 пикселей: все 19 разделов доступны скроллом; ширина документа совпадает с шириной окна.
- Проверены кнопки вперёд и назад, Home и End, создание и очистка печатных слоёв.
- HTML просмотрен визуально; PDF экспортирован из того же HTML. Итоговая проверка PDF фиксируется ниже.
- Физический телефон, Safari и открытие вложения в Telegram не проверены. Эмуляция узкой ширины не заменяет эти проверки.

Внедрение в клиентские сервисы не выполнялось. Презентация описывает предложенный результат, а не демонстрирует готовую систему FireLED.

## Итог PDF

PDF повторно открыт: 19 страниц A4 landscape (841,92 × 594,96 pt). Все страницы отрендерены Poppler и визуально просмотрены. Текст, логотипы, фото и таблицы не обрезаны; цена и источники присутствуют, шаблонные заглушки отсутствуют. Poppler сообщил предупреждения о bounding box отдельных Type 3 glyph; визуальных дефектов при просмотре страниц не обнаружено. Подготовлены именно презентационные материалы; работоспособность будущей интеграции этими проверками не подтверждается.
