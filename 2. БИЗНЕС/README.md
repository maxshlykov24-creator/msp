# Бизнес

> Зона **компании** в vault: финансы, продажи, производство, маркетинг, продукт и системные описания для людей и ИИ. Ведётся так, чтобы сюда можно было подключать сотрудников и партнёров без смены структуры папок.

---

## О папке

`2. БИЗНЕС/` — артефакты и процессы **компании MS Product** (клиенты, деньги компании, офферы, внедрения, ИИ-агенты). Все функции по сути закрывает **владелец**; папки `01_`…`08_` наполняются ролями, агентами и регламентами, а не новой «отдельной папкой под команду». Каждая операционная зона содержит `_ai/` для артефактов, генерируемых ИИ-агентами.

С 2026-08-19 (Модуль 2) папка отдела содержит `РУКОВОДИТЕЛЬ.md` — системный промпт ИИ-руководителя, `БАЗА_СМЫСЛОВ.md` — накопленные тезисы, `ВХОДЯЩЕЕ/` — материалы на разбор, `ЛОГИ/`. Состав команды и алиасы вызова — [`_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md`](../_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md).

Не заменяет `1. ЛИЧНОЕ/`: сырьё для быта и духа — в [`_ВХОДЯЩЕЕ`](../_ВХОДЯЩЕЕ) (корень vault) и ветках профиля по [`СТРУКТУРА_И_ПРИНЦИПЫ.md`](../1. ЛИЧНОЕ/СТРУКТУРА_И_ПРИНЦИПЫ.md). Профиль владельца и его стиль — в [`_ПРОФИЛЬ/`](../_ПРОФИЛЬ/PROFILE.md); дублировать сюда объёмом не нужно — здесь то, что относится к **деятельности компании** и может жить в общем доступе (с учётом конфиденциальности по клиентам).

**Инбокс:** единый для всего vault — [`_ВХОДЯЩЕЕ`](../_ВХОДЯЩЕЕ) в корне репозитория (не `2. БИЗНЕС/00_Inbox`, не `1. ЛИЧНОЕ/Входящее`).

SSOT бизнеса (стратегия, стек, цели): [`08_Системное/_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md`](08_Системное/_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md). Слепок **компании** под эту зону: [`08_Системное/ПРОФИЛЬ_ПРОЕКТА.md`](08_Системное/ПРОФИЛЬ_ПРОЕКТА.md).

**Правила ведения папок (README, Inbox, проекты, ICQ):** [`08_Системное/РЕГЛАМЕНТ_ЗОНЫ_БИЗНЕС.md`](08_Системное/РЕГЛАМЕНТ_ЗОНЫ_БИЗНЕС.md) — в том числе карта **«офисное здание»** (вход → этажи → кабинеты → при необходимости шкафы).

## Как использовать

1. Новые файлы по бизнесу не по адресу — сначала в [`_ВХОДЯЩЕЕ`](../_ВХОДЯЩЕЕ) (корень vault).
2. Для задач ИИ по работе: `@2. БИЗНЕС` или конкретная папка + [`ПРОФИЛЬ_ПРОЕКТА.md`](08_Системное/ПРОФИЛЬ_ПРОЕКТА.md) (контекст компании; стиль работы — [`_ПРОФИЛЬ/СТИЛЬ_РАБОТЫ.md`](../_ПРОФИЛЬ/СТИЛЬ_РАБОТЫ.md)).
3. После наполнения Inbox — прогоняй раскладку: список файлов → целевая зона → перенос.
4. **Отдельное окно Cursor только на эту папку** (`Файл → Открыть папку → 2. БИЗНЕС/`): действует [`.cursorrules`](.cursorrules) в корне `2. БИЗНЕС/` — контекст MS Product без личного vault; удобно для сотрудников и ИИ только по компании.
