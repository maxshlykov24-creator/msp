# Печать для МойСклад (ИП Афанасьева)

## Файл

**`печать_МойСклад.png`** — загрузить в **Настройки → Организации → Печать**.

Скрипт: `process_stamp.py` → `python3 process_stamp.py`

## Принятый метод (2026-05-26, «идеально»)

**Цель:** белый фон, читаемый оттиск как на фото, без ручки в углу.

**Делать:**
1. Найти круг печати по синей маске HSV → кроп + круговая маска (обрезает ручку).
2. Маска чернил — **мягкий порог** (B−R, B−G, S>20, V>26), не Otsu и не morphology close/open.
3. Пиксели чернил — **оригинальные цвета с фото**, не перекраска в один синий.
4. Внутри круга серый ореол бумаги (S<45, V>100) → белый.
5. Квадрат **без апскейла** (нативное разрешение кропа).

**Не делать** (ломает читаемость, особенно кольцо ИНН):
- бинаризация Otsu, раздувание morphology;
- заливка одним цветом по density;
- резкость / UnsharpMask / bilateral на всём кадре;
- апскейл до 800–1200 px.

## Подпись

**`подпись_МойСклад.png`** → **Настройки → Организации → Подпись руководителя**.

Скрипт: `python3 process_signature.py` (исходник: `подпись_исходник.png` или `~/Downloads/подпись.png`).

Рецепт подписи (отличается от печати): цвет ручки с фото, **нажим** — с плотности штриха (не копируем серый ореол). Все контуры чернил, включая галочку сверху справа.
