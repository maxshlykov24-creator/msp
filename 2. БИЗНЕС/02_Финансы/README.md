# 02_Финансы

> Деньги бизнеса: цели по выручке, долги, подушка, юнит-экономика — на уровне документов и расчётов.

---

## О папке

Финансовый контур **предпринимательской** деятельности: планы прибыли, контроль обязательств (в т.ч. «хвосты» — детали в [`01_`](../01_Стратегия/ХВОСТЫ.md)), модели перехода на фиксированные чеки. Личные траты и семейный бюджет — только если явно разграничиваешь подпапкой и не смешиваешь с операционкой компании.

## Содержимое

- [`РЕКВИЗИТЫ_ИП.md`](РЕКВИЗИТЫ_ИП.md) — ИНН, ОГРНИП, адрес, расчётный счёт, банк и контакты (для счетов, договоров, политики конфиденциальности).
- [`2026-08-07_ИП_Шлыков_Максим_Александрович_реквизиты.pdf`](2026-08-07_ИП_Шлыков_Максим_Александрович_реквизиты.pdf) — исходный PDF реквизитов (сверка 2026-08-07).
- [`2026-08-13_доходы_май-август.csv`](2026-08-13_доходы_май-август.csv) — кассовые поступления по клиентам, май–август 2026 (сводка в карте §10).
- [`ГРАНИЦЫ_И_ИСТОЧНИКИ.md`](ГРАНИЦЫ_И_ИСТОЧНИКИ.md) — что лежит в `02_`, что в карте смыслов; источник правды по таблицам.
- Таблицы целей и фактов (или ссылки на учётные системы).
- Списки долгов/кредиторов в обезличенном виде при необходимости.
- Заметки по рискам (зависимость от одного клиента, сезонность и т.д.).

## Как использовать

- Сверяй цели из [`01_Стратегия`](../01_Стратегия/README.md) с фактом: план → факт → дельта.
- Обновляй при изменении модели ценообразования (связь с [`07_Продукт`](../07_Продукт/README.md)).
- Чувствительные цифры — по правилам безопасности проекта; в README зон достаточно логики, без полных ПДн.

## Связи

- [`01_Стратегия`](../01_Стратегия/README.md) — цели, к которым подводят цифры.
- [`07_Продукт`](../07_Продукт/README.md) — влияние ценообразования на юнит-экономику.
