# Правила Cursor для workspace `2. Бизнес/`

Эта папка нужна, когда в Cursor открыт **только** каталог `2. Бизнес/` (без `1. Личное/` и корневых агентов).

## Зачем зеркало

| Файл | Полный vault (корень) | Только `2. Бизнес/` |
|------|----------------------|------------------|
| `@архитектор` | `.cursor/rules/архитектор.mdc` | `2. Бизнес/.cursor/rules/архитектор.mdc` |
| `@сео`, `@уборщик`, `@модель` | `.cursor/rules/*.mdc` | `2. Бизнес/.cursor/rules/*.mdc` (пути с `../1. Личное/`) |

В зеркалах пути **относительны к `2. Бизнес/`** — иначе агенты не найдут `1. Личное/` и `0. Входящее/` при изолированном workspace.

## Канон

При работе в **полном vault** приоритет у корневых `.cursor/rules/`.  
Дубли в `2. Бизнес/.cursor/rules/` **не удалять** — они обслуживают отдельное окно MS Product.

## Инбокс

Единый инбокс vault — **`0. Входящее/`** в корне репозитория (не `2. Бизнес/00_Inbox`).
