# kroy-sync

Учёт кроя JB.CO поверх папки YUJI в Моём Складе. Обмен с Wildberries и Ozon собран и выключен: `SYNC_ENABLED=0`. Штатную синхронизацию Моего Склада этот проход не гасит.

## Что уже есть в кабинете

Каталог цеха не пересобираем. Товар YUJI это модель и цвет, размер это модификация, штрихкод на модификации. Рулонов не было: их карточки добавляет `catalog.py`, количество не ставим.

## Команды

```
python3 -m unittest tests.test_core
python3 exchange.py
python3 catalog.py
python3 catalog.py --apply
python3 cut.py --date 2026-09-26 --product "Футболка сердце — Чёрный" --color "Чёрный" --s 42 --m 42 --rolls 2
```

`--apply` у кроя пишет списание рулона и приход размеров. Без флага только говорит, можно ли провести. Повтор той же строки находит внешний код и не удваивает. Если рулонов меньше, чем в факте, документ не создаётся.

## Таблица

Рабочая таблица приёмки читается с сервера, не из браузера закройщика. `python3 sheet_sync.py --setup` пишет шапку, список изделий и формулы цвета. `python3 sheet_sync.py` каждые 15 секунд смотрит новые строки. Заполненная строка один раз создаёт оприходование размеров и списание рулона того же цвета. Повтор и правка проведённой строки второй документ не делают. На Wildberries и Ozon этот процесс не пишет.

Наблюдатель запущен отдельно: сервер 194.87.226.234, каталог `/opt/kroy-sync`, служба `kroy-watch`. Сайт и соседние боты на этой машине не используются.

`sheet/Факт.gs` оставлен как запасной скрипт внутри таблицы. Живой контур его не использует.

## Включение позже

После чек-листа в `CHECKLIST.md` и явного да: дата в `CUTOVER_DATE`, затем `SYNC_ENABLED=1`. История до даты не читается. Ozon молчит, пока пуст `OZON_API_KEY`. Штатный обмен сам не выключается: `exchange.disable_native` даже с двумя флагами в этот проход отказывается писать.
