# DKAcademy Analytics — как перепроверить цифры

Короткий чек-лист для сверки данных дашборда с amoCRM. Можно показывать руководителю.

- **Дашборд:** https://dkacademy-analytics.ru
- **Логин / пароль:** `maxim` / `Maxim123`
- **Период для проверки:** поставь вверху «Июнь» (или даты «от/до»).
- **Обновление:** автоматически каждые 10 мин с 7:00 до 22:00 МСК.

---

## 1. Что это за метрики (определения)

| Метрика | Что значит |
|---|---|
| **Новые обращения** | Новые лиды (сделки), созданные за период **в воронке «Продажи»**. Повторные продажи не входят. |
| **Конверсия лид → сделка** | **Только воронка «Продажи».** Из новых обращений периода — какой % дошёл до статуса «Успех» (этапы «Не обработан» → «Успех»). Формула: сделки в Успех из лидов периода ÷ все новые лиды периода. |
| **Приход (оплачено)** | Сумма оплаченных (Успех) сделок за период, **только воронка «Продажи»**. Повторные продажи считаются отдельно. |
| **Конверсия повторных** | Отдельно по воронке «Повторные продажи»: какой % повторных обращений дошёл до Успеха. |
| **Мин. в разговоре** | Суммарная длительность телефонных звонков за период. Чаты сюда **не** входят. |
| **Скорость ответа** | Среднее время от входящего сообщения клиента до первого ответа менеджера (мин). Приближённо: один ответ ограничен сверху 8 часами, чтобы ночь/выходные не ломали среднее. |
| **Контактов по часу дня** | **Среднее за день** за выбранный период (звонки + сообщения в данный час), а не сумма. При выборе квартала показывает типичную нагрузку часа. |
| **Пропущено диалогов** | Входящие диалоги/звонки, помеченные amoCRM как непринятые: клиент обратился, ответа в диалоге не было. |
| **Постоянные клиенты** | Уникальные клиенты с успешной сделкой (за всё доступное в CRM время), по контакту, без дублей. |

> **Важно (с 19.06.2026):** все ключевые метрики дашборда (новые обращения, конверсия, счета, приход) считаются **только по воронке «Продажи»** — повторные продажи больше не завышают конверсию. Повторные показываются отдельно («Конверсия повторных», воронка «Повторные продажи»).

> В дашборде у этих метрик стоит значок «i» — наведи курсор, всплывёт то же определение.

## 2. Сверка с amoCRM (по шагам)

Открой amoCRM → раздел **Сделки**, выстави тот же период, что и в дашборде.

1. **Новые обращения** — фильтр «Дата создания» = период → число сделок внизу списка = «Новые обращения» в дашборде.
2. **Оплачено / приход** — фильтр «Этап» = «Успех» + «Дата закрытия» = период → количество = «Оплачено сделок», сумма бюджета = «Приход».
3. **Конверсия лид → сделка** — из тех же новых лидов периода посмотри, сколько в «Успех». Доля = конверсия в дашборде.
4. **По конкретному менеджеру** — добавь фильтр «Ответственный» = нужный менеджер и повтори п.1–3. Сверь с его строкой во вкладке «По менеджерам».
5. **Минуты / звонки** — amoCRM → «Аналитика» → отчёт по звонкам за период → сумма минут = «Мин. в разговоре».
6. **Пропущенные** — списки диалогов / отчёт по непринятым за период.

Допустимо небольшое расхождение в 1–2 единицы — данные подтягиваются раз в 10 минут.

## 3. Что отвечать руководителю (коротко)

- **«Алина С. — уволена»** — убрана из аналитики везде (таблица, графики, фильтры). Если появится ещё кто-то лишний — скажи, добавлю за минуту.
- **«Что за конверсия»** — их две, обе подписаны: «лид → сделка» (новые) и «повторные». У каждой значок «i» с расшифровкой.
- **«Минуты в разговоре»** — это телефония (длительность звонков), не чаты.
- **«Скорость ответа»** — среднее время до ответа менеджера; считается приближённо, выбросы (ночь/выходные) ограничены, чтобы не задирать цифру.
- **«Что такое пропущенный диалог»** — непринятое входящее обращение (клиент написал/позвонил — ответа в диалоге нет).

## 4. Как задать/изменить план (раздел «Таблица»)

Планы теперь хранятся в системе и задаются руководителем прямо в дашборде.

1. Открой вкладку **«Таблица»**, режим **«Отдел продаж»**.
2. Вверху выбери **один месяц** (кнопка «Месяц» или даты в пределах одного месяца) — в шапке столбца «План» загорится метка **«правка»**, ячейки станут редактируемыми.
3. Впиши план на месяц в нужной строке → **Enter** (или клик вне поля). Появится «План сохранён».
4. Столбцы **«Факт»** и **«% плана»** пересчитаются сразу; KPI-карточки и верхние плашки тоже подхватят новый план.

Как считается план под период:
- Числовые метрики (звонки, лиды, приход и т.д.) — **пропорционально дням**: за полный месяц = план месяца, за часть месяца = доля, за квартал = сумма месяцев.
- Проценты и средний чек (конверсии, ср. чек) — план остаётся целевым значением и не суммируется.
- Изменить план можно только когда выбран **один месяц**. При «Квартале»/произвольном диапазоне план показывается, но не редактируется (метка «выберите месяц»).

### План «оплачено (сумма)» по менеджерам
- Во вкладке **«По менеджерам»** при выбранном **одном месяце** в колонке «План, ₽» можно вписать план прихода каждому менеджеру (Enter — сохранится).
- **План отдела по приходу = сумма планов менеджеров** (пересчитывается автоматически и подставляется в карточку «Приход» и таблицу «Отдел продаж»).
- Остальные метрики (звонки, счета и т.д.) планируются только на уровне отдела.

## 5. Важная оговорка про историю

История в этом аккаунте amoCRM доступна примерно **с 16.03.2026** (события — глубина ~3 мес). Поэтому очень старые периоды будут пустыми — это ограничение CRM, а не ошибка аналитики.
