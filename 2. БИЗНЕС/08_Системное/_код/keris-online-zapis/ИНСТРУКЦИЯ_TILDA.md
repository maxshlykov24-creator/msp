# Онлайн-запись на kerisclub.ru (Tilda)

Форма с VPN идёт через тот же Cloudflare-туннель, что Mini App. Кнопки «Записаться» остаются `#keris-book`, адрес страницы не меняется. `sslip.io` для вебхуков YCLIENTS не трогаем.

На сайт **не ставим свою кнопку** — только код окна. Кнопки «Записаться» остаются ваши (шапка, обложка и т.д.).

Сниппет: [`tilda-embed.html`](tilda-embed.html)  
Копия на сервере: [https://194.87.118.214.sslip.io/tilda-embed.html](https://194.87.118.214.sslip.io/tilda-embed.html)

---

## Что сделать (один раз + ссылки на кнопках)

### 1. Вставить код окна

1. Открыть [`tilda-embed.html`](tilda-embed.html) → **выделить всё** → скопировать.
2. Tilda → **Настройки сайта** → **Ещё** → **HTML-код для всех страниц** (или блок **T123 HTML** в **общем футере** сайта).
3. Вставить скопированный код.
4. Сохранить. Ссылку кнопок не менять: `#keris-book`. URL внутри окна сниппет берёт сам.

Предпочтительно: код в **HTML для всех страниц** / футере — тогда «Записаться» в шапке работает везде.

### 2. Привязать ваши кнопки

У **каждой** кнопки «Записаться» (и любой другой, что должна открывать запись):

1. Открыть настройки кнопки / пункта меню.
2. В поле **Ссылка** указать ровно: `#keris-book`
3. Не ставить URL формы и не делать «открыть в новой вкладке» на внешний адрес.

Пример: зелёная «Записаться» справа сверху → ссылка `#keris-book`.

### 3. Опубликовать

**Опубликовать** сайт (или все затронутые страницы).

### 4. Проверить

- Клик по «Записаться» → окно **поверх** сайта, адрес страницы не меняется.
- Крестик / клик по затемнению закрывают окно.
- На телефоне окно на весь экран.
- (По желанию) тестовая запись → уведомление в админ-бот.

## Если не открывается

1. С включённым VPN открыть [груминг](https://kerisclub.ru/gruming) → «Записаться» — окно с формой, не пустой iframe.
2. Код окна реально на странице (футер / HTML для всех страниц) и сайт **опубликован**.
3. У кнопки ссылка именно `#keris-book`, не `https://…`.
4. В Zero Block не подменять на «ссылка на URL» внешней страницы.
