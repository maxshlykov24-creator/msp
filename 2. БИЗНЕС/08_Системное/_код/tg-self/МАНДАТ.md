# Мандат: личный Telegram

Владелец 2026-08-20 дал Cursor доступ к своему Telegram. Это не бот: сессии Telethon от аккаунтов Максима.

CLI: `2. БИЗНЕС/08_Системное/_код/tg-self/`
Сессии: `tg_self.session` (личный, `@maxim_shlykov`) и `tg_work.session` (рабочий). Не коммитить. Ключи: `.env` (не коммитить, не читать в чат). Идентификаторы без секретов — `accounts.json`.

Оба self id считаются «мой голос»: в общей группе неважно, с какого аккаунта написано.

## Рамки: как телефон, не как бот

Это user-сессия MTProto. Почти всё, что Максим делает в облачном Telegram с телефона, можно сделать отсюда: читать, писать, опросы, файлы, правки, пересылки, реакции, закрепы, прочитано, участники, админка если есть права.

Это не «любая кнопка телефона без оговорок»:

- Секретные чаты недоступны.
- Удалённые сообщения недоступны.
- Личный 1:1 звонок в Telethon нет. Групповой созвон есть (`CreateGroupCallRequest`) — не вызывать: это колокольчик на всю группу.
- Нельзя то, чего не может сам аккаунт: нет прав админа — не кикнешь, опрос закрыт — не переголосуешь.
- Номер, облачный пароль, `api_hash`, файл сессии — не повторять в ответах и не класть в git.

Нет готовой команды в `tg.py` — не отказ. Пиши одноразовый скрипт через Telethon в том же venv. Не оставляй секреты в файле.

## Когда брать

Если для ответа не хватает файлов vault, или задача про живое:

- переписки с клиентами и подрядчиками
- переписка с женой (чат «Моя любовь»)
- семья, церковь, рабочие группы
- непрочитанные
- договорённости, обещания, дедлайны, «кто что сказал»
- любой контекст, который обычно лежит в Telegram, а не в заметке

Не ждать фразы «открой телегу». Сначала файлы. Дыра в файлах — читать Telegram.

## Как

```bash
cd "2. БИЗНЕС/08_Системное/_код/tg-self"
source .venv/bin/activate
python3 tg.py whoami
python3 tg.py whoami --account work
python3 tg.py dialogs --limit 30
```

Историю и непрочитанные — через Telethon в том же venv (`iter_dialogs`, `iter_messages`, `unread_count`). Готовой команды `history` в CLI может не быть: писать короткий одноразовый скрипт, не оставлять секреты в файле.

Папки чатов (Dialog Filters): «Без ответа», «ЭММ», «MSP», «Группы». Рабочие клиентские чаты чаще в MSP.

Личные группы вроде «Мачо Дача Хата Хаус» — аккаунт `self`. Рабочие клиенты — чаще `work`.

Если `tg_self.session` занят другим скриптом (`database is locked`) — подождать и повторить. Не копировать сессию в `/tmp`: второй вход с тем же ключом Telegram отзывает. Не убивать чужой прогон без нужды.

## Опросы

Прогон 2026-08-20: чат «Мачо Дача Хата Хаус», опрос «Арена», голос «Думаю» → «Нет не смогу или не хочу». Сообщение не писали.

`message.click(text=...)` для опросов не использовать: `answer.text` теперь `TextWithEntities`, сравнение ломается. Брать `.text` из объекта или CLI ниже.

```bash
# найти опросы
python3 tg.py polls --chat "Мачо Дача" --limit 200

# сменить / поставить голос, без сообщения в чат
python3 tg.py vote --chat "Мачо Дача" --option "нет"

# конкретный опрос
python3 tg.py vote --chat "Мачо Дача" --msg 26310 --option "нет"

# создать опрос
python3 tg.py poll --chat "Мачо Дача" --question "Арена 29.08" --answers "Да" "Нет" "Думаю"
```

`--option` — подстрока варианта, регистр не важен: `нет` попадёт в «Нет не смогу или не хочу».

Сырой Telethon, если CLI не подходит:

```python
import random
from telethon.tl.functions.messages import SendVoteRequest
from telethon.tl.types import Poll, PollAnswer, TextWithEntities

def label(value):
    return value.text if hasattr(value, "text") else str(value)

# голос
target = next(
    ans.option
    for ans in msg.media.poll.answers
    if "нет" in label(ans.text).lower()
)
await client(SendVoteRequest(peer=entity, msg_id=msg.id, options=[target]))
# снять голос: options=[]

# создать
poll = Poll(
    id=random.getrandbits(63),
    question=TextWithEntities("Вопрос", []),
    answers=[
        PollAnswer(TextWithEntities("Да", []), b"0"),
        PollAnswer(TextWithEntities("Нет", []), b"1"),
    ],
    hash=0,
)
await client.send_file(entity, poll)
```
