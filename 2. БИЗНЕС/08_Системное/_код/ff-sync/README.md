# ff-sync

Фулфилмент Берёза Групп. Источник правды по клиентам — МойСклад, рабочее место Глеба — своя панель на сервере. Google Таблицы сняты с маршрута 2026-09-03, код в `_архив/`.

Прод: VPS `72.56.8.43`, каталог `/opt/ff-sync`. Панель: `http://72.56.8.43:8787`. Организация всегда ООО БЕРЁЗА ГРУПП, склад Фулфилмент.

## Как работает Глеб

1. В МойСклад заводит контрагента: группа `Фулфилмент`, реквизиты по ИНН, в доп.полях токены WB/Ozon и три тарифа.
2. Сервер раз в 10 минут забирает карточку, прячет токены маской, пингует кабинеты и тянет каталог. Кнопка «Обновить клиентов» в панели делает то же вручную.
3. Панель, раздел **Приёмка**: контрагент, штрихкод, количество, литраж, тип продукции. Артикул, наименование, маркетплейс и GTIN подставляются из каталога кабинетов. Не хватило литража или GTIN — строка помечается жёлтым и в МойСклад не уходит.
4. Кнопка **Создать товары и заказ поставщика**: товар создаётся с поставщиком-клиентом и типом маркировки, затем один заказ поставщика на клиента с номером от МойСклад. Приёмку сотрудники делают вручную по этому заказу.
5. Заказы FBS/FBO сами падают в МойСклад как заказы покупателя с проектом `WB ФБС` / `WB ФБО` / `Ozon ФБС` / `Ozon ФБО` и списывают остаток по FIFO.
6. Раздел **Учёт**: партии FIFO, дни на складе, литры и деньги по тарифам контрагента. Фильтр по контрагенту и поиск по артикулу, штрихкоду, GTIN.
7. Отметил позиции — кнопка **Выставить счёт**. В МойСклад уходит счёт покупателю тремя строками: хранение, приёмка, отгрузка. Выставленное запоминается, второй раз те же дни не считаются.
8. Кнопка **Выгрузить в Excel** отдаёт текущий срез учёта с фильтром и итогами.

Токены из карточки после приёма затираются на `wb_****a7f1 принят 03.09 14:20`. Поле **Синхронизация** показывает, всё ли чисто.

## Доступ в панель

`FF_USERS` в `.env` — пары `логин:пароль` через запятую. `FF_SECRET` подписывает сессию, живёт 30 дней.

## Команды

```
ssh root@72.56.8.43
cd /opt/ff-sync
docker compose up -d --build
docker compose exec worker python ping.py
docker compose exec worker python cli.py list
docker compose exec worker python cli.py ensure-attrs
docker compose exec worker python cli.py sync-agents
```

Образ: `docker.io/library/python:3.12-slim`. В Dockerfile нет `apt-get`.
