Задеплой магазин. В отличие от дева, в проде **Redis обязателен** и бэкенд запускается **двумя процессами**.

## 1. Сервер
RU VPS ~**650–950 ₽/мес** (Timeweb, Selectel, Beget). Минимум **2 ГБ RAM**, лучше 4 (сборка Next.js прожорлива).
Поставить: Node 20–24, PostgreSQL, Redis, nginx (или Caddy), git.

## 2. Переменные окружения (прод)
```
DATABASE_URL=postgres://user:pass@localhost:5432/store
REDIS_URL=redis://localhost:6379
JWT_SECRET=<длинная случайная строка>
COOKIE_SECRET=<другая длинная случайная строка>
STORE_CORS=https://<домен-витрины>
ADMIN_CORS=https://<домен-админки>
AUTH_CORS=https://<домен-витрины>,https://<домен-админки>
MEDUSA_BACKEND_URL=https://<домен-бэкенда>
PORT=9000
```
🔒 Секреты только на сервере, **не в git**. Дефолтные `supersecret` — заменить.

## 3. Сборка и миграции
```bash
npm ci
npx medusa db:migrate        # ДО старта
npm run build                # результат в .medusa/server
```

## 4. Два процесса
```bash
# server — API + админка
MEDUSA_WORKER_MODE=server DISABLE_MEDUSA_ADMIN=false npm run start

# worker — фоновые и отложенные задачи
MEDUSA_WORKER_MODE=worker DISABLE_MEDUSA_ADMIN=true npm run start
```
Держать под systemd или pm2 (автостарт и перезапуск после падения).

## 5. Витрина
Вариант А — **Vercel** (просто и бесплатно на старте): подключить репозиторий, задать `NEXT_PUBLIC_MEDUSA_BACKEND_URL` и `NEXT_PUBLIC_MEDUSA_PUBLISHABLE_KEY`, деплой.
Вариант Б — **на том же VPS**: `npm run build && npm run start` под pm2, nginx проксирует.
⚠️ Для РФ-аудитории учитывать доступность выбранного хостинга.

## 6. Домен и HTTPS
nginx/Caddy: витрина → `:8000`, бэкенд и админка → `:9000`. Сертификат — Let's Encrypt (у Caddy автоматом).
Домены прописать в `*_CORS` и в `MEDUSA_BACKEND_URL`, иначе админка и витрина упрутся в CORS.

## 7. После деплоя — обязательно
- `https://<бэкенд>/health` → `OK`
- Админка открывается, логин работает
- Витрина показывает товары и цены в рублях
- **Перерегистрировать вебхуки платёжки на боевой домен** (в кабинете ЮKassa/Т-Кассы) — частая забытая деталь
- Провести **тестовый платёж на боевом** и проверить, что пришёл чек
- Настроить **бэкапы БД** (магазин без бэкапа = потеря заказов)
- Прогнать сабагента `store-qa`

## Экономика (честно)
Сервер ~650–950 ₽/мес + эквайринг ~3.5% с оборота (столько же берут любые платформы, включая конструкторы) + домен. Движок и админка — бесплатно. Экономия против конструктора не в подписке (она сопоставима), а в **отсутствии потолка по дизайну и функциям** и в том, что магазин твой.
