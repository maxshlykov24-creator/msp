# 🛒 Medusa Store Studio — агентная среда для интернет-магазинов

Готовая среда, чтобы **ИИ-агент собирал вам интернет-магазины** под российский рынок: каталог, корзина, чекаут, оплата картами и СБП, фискальные чеки 54-ФЗ, доставка, админка на русском. Магазином можно управлять прямо из агента.

**Стек:** Medusa v2 (бэкенд + админка) + Next.js 15 (витрина) + ЮKassa/Т-Касса + ApiShip.
**Цена вопроса:** движок бесплатный (MIT), платите только за сервер (~650–950 ₽/мес) и эквайринг.

## Установка
1. Поставь агентную среду (Codex, Kimi Code или Claude Code) и открой в ней эту папку.
2. Проверь, что скиллы подхватились: попроси агента перечислить доступные скиллы — должны быть `store-setup`, `payments-ru`, `shipping-ru`, `store-design`, `store-manage`, `deploy-store`.
3. Скажи агенту, какой магазин нужен — и вперёд.

## Быстрый старт
👉 **Первый раз — иди по [`RUNBOOK.md`](RUNBOOK.md)**: пошаговый прогон с готовыми промптами, контрольными точками и известными граблями. Полный магазин за ~1.5 часа.

Или сразу командами:
```
скилл store-setup магазин кроссовок
скилл store-architecture магазин кроссовок, рынок Россия
скилл store-design минимализм, тёмная тема, товар — герой
скилл payments-ru юкасса
скилл store-manage заведи 20 товаров из этого прайса
скилл deploy-store
```

## Чем это отличается от конструктора
Конструктор даёт быстрый старт, но упирается в потолок: чужие блоки, чужие правила, ежемесячная подписка и невозможность выйти за рамки шаблона. Здесь наоборот — **вся коммерция бесплатно из коробки, а дизайн и логика ограничены только тем, что вы попросите у агента**. Взамен нужен сервер и минимальная техническая гигиена.

**Честно, где конструктор выигрывает:** запуск за вечер без разработчика, всё в комплекте (хостинг, SSL, обновления, поддержка), десятки готовых интеграций в один клик. Если нужно «просто начать продавать завтра» — конструктор проще. Эта среда — про свой магазин без потолка.

## ⚠️ Что проверить самому
- **Тестовый платёж обязателен** перед запуском продаж. Не верьте «должно работать».
- **54-ФЗ:** чеки настраиваются в платёжном плагине (`useReceipt`), отдельная касса не нужна — но без настроенных чеков торговать нельзя.
- **Секреты** (ключи ЮKassa, пароли) — только в `.env` на сервере, никогда в git.
- **Русская админка** переведена примерно на 78% — часть пунктов останется на английском.
- Плагин **1С пока умеет только импорт товаров** — не обещайте клиенту полную синхронизацию.
- Плагины ЮKassa/Т-Кассы — community (Gorgo, MIT), не официальные. Перед боевым запуском стоит посмотреть код.
