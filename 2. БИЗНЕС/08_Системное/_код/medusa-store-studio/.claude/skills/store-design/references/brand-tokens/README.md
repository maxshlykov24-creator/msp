# Брендовые токены — референсы для дизайна магазина

Реальные дизайн-системы живых DTC-брендов: палитра (точные hex), типографическая шкала, отступы, компоненты + описание философии бренда. Используй как **отправную точку и эталон уровня**, а не для копирования один-в-один.

| Файл | Характер | Когда брать за основу |
|---|---|---|
| `aesop.md` | Аптекарский минимализм, почти монохром (#313131 на белом), ноль градиентов | Премиум, косметика, «тихая роскошь» |
| `diptyque.md` | Парфюмерная классика, editorial | Парфюм, свечи, подарочное |
| `glossier.md` | Мягкий потребительский бьюти, пилюли-кнопки | Молодёжная косметика, дружелюбный тон |
| `ordinary.md` | Клинический минимализм, стерильно + один резкий акцент | Уход, «наука», честный прайс |
| `hardgraft.md` | Кожа/ремесло, тёплая палитра, фактура | Аксессуары, ручная работа, крафт |
| `patagonia.md` | Аутдор, естественные цвета, крупная съёмка | Спорт, экипировка, устойчивость |
| `dyson.md` | Техника, инженерная подача, контраст | Электроника, гаджеты, «технологии» |
| `casper.md` | Дом/уют, спокойная палитра | Мебель, текстиль, товары для дома |

## Как применять
1. Выбери бренд, ближайший по **характеру товара** (не по отрасли буквально).
2. Вытащи структуру: палитра (база + один акцент), пары шрифтов, шкала кеглей, шаг отступов.
3. **Адаптируй под свой бренд** — поменяй акцент, шрифты, тон. Копировать чужую палитру целиком нельзя (это чужая айдентика).
4. Сверься с правилами в `SKILL.md` — пропорции карточек, галерея PDP, чекаут, доступность.
