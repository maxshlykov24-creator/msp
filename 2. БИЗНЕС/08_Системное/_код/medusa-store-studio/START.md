# 🚀 С чего начать

> В vault MS Product точка входа — [`КАК_НАЧАТЬ.md`](КАК_НАЧАТЬ.md). Эту папку открывай отдельным окном Cursor, не из корня vault.

Это среда для сборки интернет-магазинов с ИИ-агентом. Внутри — скиллы, сабагенты и правила, по которым агент разворачивает магазин, достраивает страницы, делает дизайн, подключает российские платёжки и наполняет каталог.

## Что нужно на старте

| Что | Зачем |
|---|---|
| **Codex**, **Kimi Code** или **Claude Code** | сам агент; среда работает во всех трёх| сам агент; среда работает в обоих |
| **Node 20–24** | Medusa не запустится на других версиях |
| **PostgreSQL 15+** | база магазина |
| **VS Code / Cursor / Antigravity** | любая IDE, куда ставится агент |

Проверить одной командой:
```bash
node -v && psql --version && pg_isready
```

## Три шага

**1.** Открой эту папку в агенте.
**2.** Набери `скилл ` — должны появиться `store-setup`, `store-architecture`, `store-design`, `payments-ru`, `shipping-ru`, `store-manage`, `deploy-store`. Если появились — среда подхватилась.
**3.** Открой [`RUNBOOK.md`](RUNBOOK.md) и иди по нему сверху вниз. Там пошаговый прогон с готовыми промптами, контрольными точками и известными граблями.

Первый магазин — примерно 2.5 часа, из них минут пятнадцать просто ждёшь установку.

## Что важно знать заранее

**Движок бесплатный, но магазин не бесплатный.** Medusa под MIT, платить за неё не нужно. Платить придётся за сервер (~650–950 ₽/мес) и за эквайринг (~3.5% с оборота — столько же берут любые платформы). Экономия против конструктора не в подписке, а в отсутствии потолка.

**Тестовый платёж перед запуском обязателен.** Не верь «должно работать» — проведи реальную оплату на тестовом магазине платёжного сервиса.

**Про чеки 54-ФЗ.** Отдельную кассу покупать не надо — чеки формирует сам платёжный сервис. Но без настроенных чеков торговать нельзя, это не формальность.

**Юридические страницы** (оферта, политика данных) агент генерирует черновиками. Перед реальными продажами их должен посмотреть юрист.

**Плагины платёжек — community**, не официальные продукты банков. Код открыт (MIT), но ответственность на тебе.

## Если что-то пошло не так

Почти все типичные затыки уже описаны в `RUNBOOK.md` и внутри скиллов: постгрес не стартует на macOS, `.env` без перевода строки, цены в неверном масштабе, привязка платёжки, которая выглядит несработавшей. Сначала загляни туда — скорее всего, ответ уже есть.
