# Дорожный режим

Фраза для ассистента: **включи дорожный режим**.

Команда встроена в `.cursor/rules/ceo.mdc` и раздел «Дорожный режим Mac»
`3. АГЕНТЫ/CEO/СИСТЕМНЫЙ_ПРОМПТ.md`. Cursor и Codex читают одну реализацию.

## Установка

Исходник хранится здесь, локальная команда и LaunchAgent ссылаются на него.
На Mac владельца выполнить:

```bash
/usr/bin/python3 "/Users/max/CURSOR/2. БИЗНЕС/08_Системное/Скрипты_vault/road-mode/road_mode.py" install
```

Это устанавливает `/Users/max/.local/bin/road-mode`, обработчик
`~/Library/LaunchAgents/com.msp.road-mode.plist` и четыре точных разрешения
pmset. При первой установке подтвердить системное окно macOS. Согласие
в чате не заменяет авторизацию администратора. Не запускать на VPS или
в облачном контейнере. Установка сама режим не включает.

## Использование

Выполнить `/Users/max/.local/bin/road-mode start`, затем проверить
`/Users/max/.local/bin/road-mode status`. Команда завершает Telegram без выхода
из аккаунта, включает Low Power Mode для батареи и зарядки, запрещает сон,
выключает вывод звука и отправляет дисплей в сон. Другие приложения не меняет.

После фактического закрытия и открытия крышки пользовательский LaunchAgent
`com.msp.road-mode` отключает Low Power Mode и запрет сна, включает звук
на существующей громкости и будит дисплей. Telegram не запускается.
Если команда дана уже при закрытой крышке, достаточно открыть её.
Проверка датчика происходит раз в две секунды только в активном режиме.

Ручной возврат: `/Users/max/.local/bin/road-mode stop`.
Проверка: `/Users/max/.local/bin/road-mode status`.
Состояние и ошибки: `/Users/max/.local/share/road-mode/state.json` и
`/Users/max/.local/share/road-mode/events.log` (локально, вне git).

Для восстановления без пароля `/etc/sudoers.d/msp-road-mode` разрешает только
четыре точных вызова pmset: `-a disablesleep 0`, `-a disablesleep 1`,
`-a lowpowermode 0`, `-a lowpowermode 1`. Скрипт работает от пользователя,
не от root. Датчик: AppleClamshellState из IORegistry. Обработчик запускается
при входе пользователя и перезапускается launchd при аварийном завершении.

Обычный возврат означает lowpowermode=0, disablesleep=0, звук включён.
Предыдущие ручные настройки из этого чата (постоянный запрет сна и mute)
специально не восстанавливаются. Яркость и громкость не меняются.
Уже существующий com.local.keepawake с caffeinate -i не изменён: он может
по-прежнему предотвращать автоматический сон при открытой крышке.

Не использовать принудительное завершение Telegram или выход из аккаунта.
Не закрывать Cursor, ChatGPT, терминалы, Wi-Fi и VPN.
