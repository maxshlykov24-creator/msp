# Скрипты_vault

> Python-утилиты для управления структурой папок vault: переименование, перемещение, нормализация путей.

---

## О папке

Скрипты перенесены из корня репозитория (`Распределение/`). Применяются при реструктуризации vault — массовые операции над файлами и папками, которые вручную делать долго или ошибочно.

## Git-синхронизация (vault → GitHub → Cursor Cloud)

См. [`git/README.md`](git/README.md) — auto-sync, launchd, Cursor Web, DoD.

## Содержимое (Python)

- `apply_profile_nested_codes.py` — применение вложенных кодов к профилю.
- `bulk_profile_nested_paths.py` — массовое обновление вложенных путей профиля.
- `bulk_replace_paths.py` — замена путей в файлах.
- `bulk_strip_zero_path_segments.py` — удаление нулевых сегментов из путей.
- `move_inbox_dukh_to_profile.py` — перемещение файлов духа из Inbox в профиль.
- `move_inbox_sermons_to_2_2.py` — перемещение проповедей в `2.2`.
- `rename_profile_numbered.py` — переименование нумерованных файлов профиля.
- `rename_razum_dd_dot.py` — нормализация имён в ветке Разум.
- `rename_vault_r3_razum0.py` — обработка раздела Разум.
- `strip_leading_zeros_profile_dirs.py` — удаление ведущих нулей из имён папок профиля.

## Как использовать

- Запускать из корня репозитория: `python 2. БИЗНЕС/08_Системное/Скрипты_vault/<script>.py`.
- Перед запуском — сделай резервную копию или убедись, что в git нет несохранённых изменений.
- Скрипты написаны под конкретные задачи реструктуризации; перед повторным применением проверь актуальность логики.
