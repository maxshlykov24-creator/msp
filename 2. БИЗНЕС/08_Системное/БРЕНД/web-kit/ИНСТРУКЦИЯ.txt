MS PRODUCT · КОМПЛЕКТ ДЛЯ САЙТА

Основной логотип для светлой темы: svg/logo-horizontal-gradient-dark.svg
Основной логотип для тёмной темы: svg/logo-horizontal-gradient-light.svg
Белый: svg/logo-horizontal-white.svg
Чёрный: svg/logo-horizontal-black.svg
Одноцветный фиолетовый: svg/logo-horizontal-violet.svg
Полностью градиентный: svg/logo-horizontal-full-gradient.svg
Отдельный знак: svg/mark-gradient-dark.svg (цветной), mark-white.svg, mark-black.svg.

Форматы
SVG: основной формат логотипа для сайта, масштабируется без потери качества.
Буквы переведены в контуры, загрузка шрифта не требуется.
PNG: прозрачные логотипы, горизонтальные шириной 1074 px; отдельные знаки 512 px.
WebP: те же варианты с прозрачностью для веба.
JPG: обложки с фоном, без прозрачности.

Фоновые версии
cover-aura: атмосферная обложка 1200×630 для превью ссылки.
hero-aura: широкая фоновая композиция 1920×1080.
social-square: квадратная обложка 1080×1080.
cover-dark, cover-light, cover-violet: однотонные обложки 1200×630.
backgrounds/aura.webp: фон отдельно, без логотипа.
Фон создан встроенным image_gen. Промпт и источники в source/design-notes.txt.
SVG фоновых обложек содержит встроенную растровую картинку; сам знак и надпись векторные.

Иконки
icons/favicon.svg: векторная иконка вкладки.
icons/favicon.ico: 16, 32, 48 px в одном файле.
icons/apple-touch-icon.png: 180×180.
icons/icon-192.png и icon-512.png: иконки веб-приложения.
icons/site.webmanifest: стартовый манифест. Пути рассчитаны на /assets/ms-product/.
Перед подключением манифеста согласовать его с существующим манифестом сайта.

Применение
Рекомендуемая ширина горизонтального логотипа от 180 CSS px.
Для узкого мобильного меню использовать отдельный знак от 32 CSS px.
Сохранять пропорции. Не добавлять тени, обводку и свечение на сам знак.
Белую версию ставить на тёмный фон; чёрную на светлый.
Фоновую обложку не использовать вместо прозрачного логотипа в меню.
Для светлой темы выбирать gradient-dark, для тёмной gradient-light.
В шапке задавать width и height по пропорции 537:120 и alt="MS Product".

Проверка
PNG, WebP, JPG открыты декодером; прозрачность логотипов проверена.
Обложки и увеличенные favicon просмотрены визуально.
На действующий сайт файлы не установлены. Исходные логотипы сохранены.

Обновление фона: 26 октября 2026. По уточнению владельца убраны пересечения и заломы; вместо них одна плавная тёмная дуга с мягким ореолом по референсу. Зернистая текстура сохранена.
