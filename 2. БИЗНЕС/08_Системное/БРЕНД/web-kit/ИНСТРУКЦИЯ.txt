MS Product — финальный комплект, 27.10.2026

Галерея: index.html
Мастер знака: source/master-mark.svg
Материал знака: source/mark-material.png, ранний эталон 1730×909. В SVG используется фрагмент 600×300 с отражённым продолжением.
Геометрия утверждена: равные стойки M, симметричная S, просвет 64 единицы, общий правый край x=800.
Текст: MS Product, Helvetica Neue Medium, переведён в кривые.

SVG — точные векторные контуры, встроенная растровая фактура. Светлый и тёмный знаки также содержат фактуру; надпись остаётся гладкой.
PNG — прозрачные логотипы и крупные обложки (3840 пикселей по ширине).
WebP — облегчённые файлы для сайта.
JPG — непрозрачные обложки.
icons — favicon.ico, SVG, PNG и webmanifest.
backgrounds — тёмный и светлый фон отдельно.

Новая генерация материала отменена. Используется исходный микрорисунок ранней обложки. Масштабирование не добавляет новых деталей. SVG растеризуются сразу в конечном разрешении.
Большие обложки: знак и текст отрисованы из вектора; атмосферный фон масштабируется из исходника 1730×909. Экспорт 3840 не означает, что исходный фон стал нативным 4K.

Имена gradient-light означают светлую надпись для тёмной поверхности; gradient-dark — тёмную надпись для светлой поверхности. Имена violet сохранены для совместимости; цвет внутри — бургунди.
Сборка: python3 source/build.py, затем node source/export.cjs (нужны fontTools и sharp).
