**Каноническое место** логотипов компании для презентаций, HTML-инструкций, дашбордов и КП.

## Файлы

| Файл | Формат | Когда использовать |
|------|--------|-------------------|
| [`logo-ms-transparent.png`](logo-ms-transparent.png) | PNG, RGBA | **По умолчанию** — светлый фон, инструкции, эталонные КП (Keris, Rusbrend). Без чёрного квадрата. |
| [`logo-ms.png`](logo-ms.png) | PNG, RGB | Тёмные презентации (шаблон `ПРЕЗЕНТАЦИЯ_ПРОДАЖИ_MS`) — лого в «иконке» на чёрном |

---

## Быстро скопировать в проект

```bash
# прозрачный (рекомендуется)
cp "2. БИЗНЕС/08_Системное/БРЕНД/logo-ms-transparent.png" "04_Производство/Активные/{Клиент}/presentation/"

# для тёмного шаблона продаж
cp "2. БИЗНЕС/08_Системное/БРЕНД/logo-ms.png" "04_Производство/Активные/{Клиент}/presentation/"
```

В HTML рядом с файлом: `<img src="logo-ms-transparent.png" alt="MS Product">`  
Для локального открытия файла — клади PNG **в ту же папку**, что и `.html`.

## Основной визуальный вариант · утверждён 26 октября 2026

Владелец выбрал именно [мягкую фактуру внутри исходного знака MS](web-kit/png/cover-aura-approved.png), ранее показанную как `logo-tests/cover-aura-material.png`. Знак слева цветной с мягкой фактурой фонового материала; надпись MS Product справа гладкая белая. Это основной визуальный эталон для будущего сайта.

Фон без логотипа: [aura.webp](web-kit/backgrounds/aura.webp), исходник [aura-source.png](web-kit/backgrounds/aura-source.png). Точное описание и ограничения: [design-notes.txt](web-kit/source/design-notes.txt).

Поздние эксперименты с микробуквами M S P и новыми градиентами не заменяют основной вариант. Владелец разрешил не переделывать весь комплект: старые SVG, размеры и иконки сохранены как технические варианты; выбранная фактурная композиция пока растровая. Не выдавать старые SVG за точное воспроизведение утверждённой фактуры. На сайт ничего не установлено.

Белый знак на фоне был предыдущим утверждённым вариантом; теперь приоритет у фактурного цветного знака. Исходная форма MS сохранена, новые монограммы отклонены. [История проб](logo-tests/index.html).
