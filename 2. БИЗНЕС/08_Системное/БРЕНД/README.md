# MS Product · финальный комплект

Утверждённая геометрия MS, палитра бургунди, детальная фактура из раннего эталона фона. Тёмная и светлая атмосфера. Регистр названия: **MS Product**.

- [Галерея и файлы](web-kit/index.html)
- Полный ZIP `MS-Product-web-kit.zip` хранится только локально и не отправляется в GitHub из-за размера. Отслеживаемые файлы комплекта находятся в [web-kit](web-kit/index.html). ZIP сохраняется отдельно; его резервирование через Git не выполняется.
- [Мастер SVG](web-kit/source/master-mark.svg)
- [Знак на прозрачном фоне](logo-ms-transparent.png)
- [Тёмная обложка](web-kit/png/cover-aura.png)

- [Форматы и ограничения разрешения](web-kit/ИНСТРУКЦИЯ.txt)

Контуры и надпись векторные; фактура растровая. Материал взят непосредственно из ранней обложки: участок 600×300, продолженный отражением внутри векторной маски. Все варианты знака фактурные, включая светлый и тёмный. Крупные обложки экспортированы из SVG шириной 3840 пикселей, фон сохраняет исходное растровое разрешение.

Старые варианты и история сохранены в `99_АРХИВ/2026-10-27_MS-перед-финалом-качества` и предыдущих архивах MS. Для новых материалов использовать этот комплект.
