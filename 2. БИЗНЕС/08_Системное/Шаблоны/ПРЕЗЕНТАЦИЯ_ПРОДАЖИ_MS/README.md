# Шаблон: HTML-презентация для продажи внедрения

> **Живой визуальный эталон (тёмный MS):** [`04_Производство/Активные/2MyMoods/presentation/Предложение_2MyMoods.html`](../../04_Производство/Активные/2MyMoods/presentation/Предложение_2MyMoods.html)  
> **Эталон CRM/интеграции (полный пакет, светлый):** Keris Club — [`ЭТАЛОН_КП_И_ПРЕЗЕНТАЦИИ.md`](../ЭТАЛОН_КП_И_ПРЕЗЕНТАЦИИ.md)  
> **Шаблон:** [`TEMPLATE.html`](TEMPLATE.html) · лого [`assets/logo-ms-transparent.png`](assets/logo-ms-transparent.png) · канон [`../../БРЕНД/`](../../БРЕНД/)

Один HTML-файл.

- **Компьютер:** слайды, стрелки / пробел, кнопка «Печать в PDF».
- **Телефон и Telegram:** одна длинная страница, скролл вниз. `@media (max-width: 900px)` плюс `isPhone()` в JS — не выкидывать.

**Новая короткая продающая презентация** — всегда этот шаблон, не собирать с нуля. Перед отправкой клиенту — `embed_presentation.py`, чтобы на чужом компьютере и в Telegram ничего не отвалилось.

---

## Когда использовать

- Встреча с собственником / ЛПР **до** старта
- Есть прототип — показываем «можно потрогать»
- Боль → решение → демо → цена → «стартуем?»
- **Не** для внутренней техдокументации и онбординга команды

Полный пакет amoCRM + МойСклад на 12 слайдах в палитре клиента — Keris, этот README не подменяет.

## Структура (7 слайдов — не раздувать)

| № | Слайд | Задача |
|---|--------|--------|
| 1 | **Обложка** | Лого клиента × MS + одна фраза ценности |
| 2 | **Что болит** | 4 карточки из разговора |
| 3 | **Что входит** | 4 результата, без цены в кикере |
| 4 | **Демо** | Реальный скрин прототипа, не иконки |
| 5 | **Почему так** / что не входит | 4 якоря |
| 6 | **Сроки и оплата** | Сумма, срок от дня после старта, платежи |
| 7 | **Финал** | Можно убрать, если слайд 6 закрывает старт |

### Что не класть

- Слайд «архитектура» без запроса клиента-технаря
- Теги MVP / Phase 2 / таблицы на месяцы вперёд
- Жаргон без объяснения
- Презентацию только-слайдами без ветки телефона: клиент откроет в Telegram и застрянет

## Как сделать под нового клиента

1. Скопировать `TEMPLATE.html` + `assets/logo-ms-transparent.png` в  
   `04_Производство/Активные/{Клиент}/presentation/`
2. Переименовать в `Предложение_{Клиент}.html`
3. Положить `assets/logo-client.png` и скрины прототипа
4. Заменить блоки `<!-- EDIT -->` и `data-title`
5. Цифры слайда 6 = текстовое КП
6. Проверить Chrome (слайды + PDF) и узкое окно ~390px или телефон: все блоки в одном скролле, без стрелок
7. Перед отправкой:

```bash
python3 "2. БИЗНЕС/08_Системное/Шаблоны/embed_presentation.py" \
  "2. БИЗНЕС/04_Производство/Активные/{Клиент}/presentation/Предложение_{Клиент}.html"
```

Клиенту уходит **только этот HTML**. Папку `assets` не слать.
