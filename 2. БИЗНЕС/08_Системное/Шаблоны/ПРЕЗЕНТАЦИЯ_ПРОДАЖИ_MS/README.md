Один HTML-файл. Свет, лучи и печать — как в HIDE. Не собирать с нуля и не откатывать слои «для простоты».

- **Компьютер:** слайды, стрелки / пробел, крутящиеся лучи, пыль за курсором, блик на смене слайда, кнопка «Печать в PDF».
- **Телефон и Telegram:** одна длинная страница, скролл вниз. `@media screen and (max-width: 900px)` плюс `isPhone()` в JS — не выкидывать. Пыль и блик на узком экране выключены.

**Новая короткая продающая презентация** — всегда этот шаблон. Перед отправкой клиенту — `embed_presentation.py`, чтобы на чужом компьютере и в Telegram ничего не отвалилось.

## Когда использовать

- Встреча с собственником / ЛПР **до** старта

- Боль → решение → демо → цена → «стартуем?»

## Обязательный хром (не выкидывать)

Это и есть «как в HIDE». Цвета клиента **не** подменяют чёрный фон MS. Акцент меняется токенами `--a1`, `--a2` и их RGB-парами `--a1-rgb`, `--a2-rgb` — лучи, пыль и аура перекрасятся сами.

| Элемент | Как |
|---|---|
| Фон | Чёрный `#000` + три радиальных пятна из `--a1-rgb` |
| Аура | Два слоя `.aura` с дрейфом 24 с / 33 с |
| Лучи | `.rays` — конический градиент, полный оборот за 120 с. Слой больше диагонали экрана, край не вылезает в кадр |
| Шёлк | `.silk` — тонкая диагональная нить, ткань вместо плоской заливки |
| Пыль | `canvas#dust` — частицы в цвете акцента, параллакс от курсора |
| Свет за курсором | `#spot` — мягкое пятно, двигается через `transform` |
| Виньетка | `.vign` — взгляд в центр слайда |
| Блик | `#flare` — вспышка при смене слайда, в ту же сторону, что и уезжает экран |
| Лого MS | Справа сверху, `assets/logo-ms-transparent.png`, рядом полупрозрачная подпись Inter «MS Product» |
| Обложка | Лого клиента × лого MS |
| Прогресс | Тонкая полоса сверху |
| Счётчик | Слева снизу `1 / N · Название` |
| PDF | Кнопка «Печать в PDF». Один слайд = один лист **A4 landscape**. `preparePrint()` копирует ауру, лучи, виньетку и бейдж на каждый слайд. Мобильные стили не должны срабатывать на печати: только `@media screen and (max-width: 900px)` |
| Телефон / Telegram | Одна страница, скролл вниз. Карточки в одну колонку. Стрелки, счётчик, PDF, пыль и блик скрыты. Лого MS остаётся справа сверху |
| Один файл | Перед отправкой прогон `embed_presentation.py` |

Палитра по умолчанию (MS). Под клиента меняются четыре токена, не разметка.

| Токен | Значение |
|---|---|
| Фон | `#000000` |
| Карточка | `#1C1C1E` |
| Акцент 1 | `#5B7CDE` · `--a1-rgb: 91,124,222` |
| Акцент 2 | `#8AA4F0` · `--a2-rgb: 138,164,240` |
| Шрифт | Inter + JetBrains Mono |

Живой HIDE держит тёплое золото (`#C8A45C` / `#E9DCB8`). Для такого клиента переписать `--a1`, `--a2` и обе RGB-пары.

## Печать в PDF — как должно быть с первого раза

Не возвращать `@page { size: 1280px 720px }`. Chrome игнорирует пиксельный размер, сажает слайд на A4 и режет низ, а хвост следующего слайда вылезает в белый зазор.

| Правило | Зачем |
|---|---|
| `@page { size: A4 landscape; margin: 0 }` | Браузер всегда понимает A4, лист совпадает со слайдом |
| Слайд `297mm × 210mm`, `overflow: hidden` | Один экран = одна страница, ничего не вылезает |
| `.deck { display: block }` | `break-after` на flex-детях в Chrome не работает |
| Мобильный `@media` только `screen and` | Иначе на узкой ширине листа карточки встают столбиком и слайд не влезает |
| `isPhone()` молчит при `body.printing` | Печать не переключает колоду в телефонный режим |
| `preparePrint()` копирует `.aura`, `.rays`, `.vign` и бейдж | В PDF остаётся свет, не плоский чёрный прямоугольник |
| Пыль, курсорный свет и блик в печати скрыты | Это живой слой, в PDF он только мешает |

Проверка: «Печать в PDF» → число страниц = числу слайдов, ориентация альбомная, примечание внизу слайда не обрезано.

## Структура (7 слайдов — не раздувать)

| № | Слайд | Задача |
|---|--------|--------|
| 1 | **Обложка** | Лого клиента × MS + одна фраза ценности |
| 2 | **Что болит** | 4 карточки из разговора |
| 3 | **Что входит** | 4 результата, без цены в кикере |
| 4 | **Демо** | Реальный скрин прототипа, не иконки. Если нужно раскрыть прототип — `.shot-solo` или `.shot-grid`, как в HIDE |
| 5 | **Почему так** / что не входит | 4 якоря |
| 6 | **Сроки и оплата** | Сумма, срок от дня после старта, платежи |
| 7 | **Финал** | Можно убрать, если слайд 6 закрывает старт |

### Что не класть

- Слайд «архитектура» без запроса клиента-технаря
- Теги MVP / Phase 2 / таблицы на месяцы вперёд
- Жаргон без объяснения
- Презентацию только-слайдами без ветки телефона: клиент откроет в Telegram и застрянет
- Плоский чёрный фон без лучей «чтобы быстрее»

## Как сделать под нового клиента

1. Скопировать `TEMPLATE.html` + `assets/logo-ms-transparent.png` в  
   `04_Производство/Активные/{Клиент}/presentation/`
2. Переименовать в `Предложение_{Клиент}.html`
3. Положить `assets/logo-client.png` и скрины прототипа
4. Заменить блоки `<!-- EDIT -->` и `data-title`
5. Если акцент не синий MS — поменять `--a1`, `--a2`, `--a1-rgb`, `--a2-rgb`
6. Цифры слайда 6 = текстовое КП
7. Проверить Chrome (слайды + PDF: A4 альбом, по странице на слайд) и узкое окно ~390px или телефон: все блоки в одном скролле, без стрелок
8. Перед отправкой:

```bash
python3 "2. БИЗНЕС/08_Системное/Шаблоны/embed_presentation.py" \
  "2. БИЗНЕС/04_Производство/Активные/{Клиент}/presentation/Предложение_{Клиент}.html"
```

Клиенту уходит **только этот HTML**. Папку `assets` не слать.
