# Эталон премиального дашборда (glassmorphism / monochrome luxury)

> **Источник:** `2. БИЗНЕС/04_Производство/Активные/DIVO_Motors/дашборд/DIVO_дашборд_прототип.html`
> **Статус:** утверждено владельцем (2026-07-07) — использовать как базовый стиль для новых аналитических дашбордов (следующий похожий кейс — не пересобирать с нуля, копировать блок `<style>` + JS-паттерны и менять только данные/метрики).

## Когда применять

Клиентский аналитический дашборд (amoCRM / МойСклад / любой источник), одностраничный HTML-прототип, премиальная подача метрик. Не для служебных внутренних инструкций (там — `ЭТАЛОН_HTML_ИНСТРУКЦИИ.md`).

## Ключевые визуальные принципы (порядок важности)

1. **Тёмный монохром + один акцент.** Фон почти чёрный (`#060607`→`#030304`), текст белый/светло-серый, единственный акцент — приглушённая бронза `#c8a45c` (только для «успеха»/лидера/важного статуса). Никаких ярких зелёных/красных/синих — только приглушённые оттенки (`--green:#9fc9ac; --red:#c98680`).
2. **Стекло, а не пластик.** `background: rgba(255,255,255,.02–.05)` + `backdrop-filter: blur(24px) saturate(150%)` + тонкая рамка `border:1px solid rgba(255,255,255,.08)` + **inset**-тени сверху/слева для блика стекла (не обычные drop-shadow).
3. **Крупные тонкие цифры.** Метрики — `font-weight:300`, крупный размер (28–40px), обязательно `font-variant-numeric:tabular-nums`, лёгкий градиент текста (`linear-gradient(160deg,#fff 30%,#b8bcc6 100%)` + `background-clip:text`).
4. **Много воздуха.** Паддинги карточек 26–32px (не 16–18px), gap между карточками 14–16px.
5. **3D-tilt + glow при наведении** (только десктоп/мышь): JS считает угол по позиции курсора внутри карточки, крутит `perspective(900px) rotateX/rotateY`, добавляет `radial-gradient` блик под курсором. Обязательно отключать через `@media(hover:none)` на мобильных (тач не умеет hover — трансформации превращаются в мусор).
6. **Никаких советов/инсайтов от системы.** Только цифры, факты, честные пометки об ограничениях данных если есть. Без блоков-подсказок «узкое место», «рекомендуем».
7. **Донат-чарт для долей** (`conic-gradient`) — компактнее и «дороже» смотрится, чем горизонтальный список каналов.
8. **Футер — только бренд.** Лого MS Product + подпись + техническая ссылка на источник данных, без пояснительного текста.

## 3D-tilt hover (JS, event delegation — работает и на динамически перерисованных карточках)

```js
(function(){
  let active = null;
  function reset(el){ el.style.setProperty('--rx','0deg'); el.style.setProperty('--ry','0deg'); el.style.setProperty('--ty','0px'); el.classList.remove('tilt-active'); }
  document.addEventListener('pointermove', e=>{
    const card = e.target.closest('.tilt');
    if(!card){ if(active){ reset(active); active=null; } return; }
    if(card !== active){ if(active) reset(active); active=card; card.classList.add('tilt-active'); }
    const r = card.getBoundingClientRect();
    const px=(e.clientX-r.left)/r.width, py=(e.clientY-r.top)/r.height;
    card.style.setProperty('--rx', ((px-0.5)*9).toFixed(2)+'deg');
    card.style.setProperty('--ry', ((0.5-py)*9).toFixed(2)+'deg');
    card.style.setProperty('--ty','-3px');
    card.style.setProperty('--mx',(px*100).toFixed(1)+'%');
    card.style.setProperty('--my',(py*100).toFixed(1)+'%');
  });
  document.addEventListener('pointerleave', ()=>{ if(active){ reset(active); active=null; } });
})();
```

CSS для `.tilt` — см. полностью в исходном файле (секция `/* ── premium interactive tilt/glow (hover) ── */`).

## Мобильная адаптация (обязательно, не опционально)

- `@media(hover:none)` — принудительно `transform:none` на всех `.tilt`-элементах и скрыть `::after`-блик (иначе на тач-устройствах эффект «залипает»).
- Ниже ~760px: шапка (`.topbar-in`) переходит на wrap, переключатель периода и диапазон дат — каждый на всю ширину строкой (`flex:1 1 100%`), а не пытаться уместить в одну линию.
- Сетки метрик (`kpi-grid`, `fin-grid`, `status-strip`, `mgr-grid`) — на мобильном схлопывать в 1–2 колонки, не в 3–5.
- Паддинги карточек уменьшать примерно вдвое (28px→18px), шрифт метрик — примерно на 30% меньше.
- Второстепенные подписи (`.sec-title span`, `.live`, `.updated`) — скрывать на мобильном, чтобы не переполнять шапку.

Полный пример media-запроса — секция `/* ── mobile adaptation ── */` в конце `<style>` файла-источника.

## Данные и честность (не про визуал, но обязательное правило)

- Тянуть только реальные данные источника (amoCRM/МС), не выдумывать метрики.
- Если поле в CRM не заполняется/не используется — либо не выводить метрику, либо явно пометить ограничение в подписи (`.kpi-sub`/`.fin-sub`), не в отдельном «советующем» блоке.
- Управляемая клиентская агрегация (JSON по дням → JS считает нужный диапазон) — предпочтительнее пережатия тяжёлых сырых данных в HTML, если объём большой.

## Как использовать в новом проекте

1. Скопировать `<style>` блок целиком из `DIVO_дашборд_прототип.html` (токены + `.glass`, `.tilt`, `.kpi*`, media-запросы).
2. Заменить логотип, цвета акцента (если бренд клиента требует другой акцент вместо бронзы — менять **только** `--amber`/`--bronze`, не архитектуру стиля).
3. Пересобрать разметку блоков под метрики конкретного клиента, сохраняя структуру: KPI-грид → каналы (донат) → статусы → доп.метрики → менеджеры → футер.
4. Прогнать чек мобильной адаптации (390px) и десктопа (1440px) через headless-скриншот перед показом клиенту.
