# 08_Системное

> Мета-уровень зоны `2. БИЗНЕС/`: профиль **компании** для ИИ, скрипты vault, шаблоны промптов.

---

## О папке

Артефакты, которые обслуживают систему папок и помогают ИИ ориентироваться: согласованный профиль компании, утилиты для vault, шаблоны промптов под работу в `2. БИЗНЕС/`.

## Содержимое

- Профиль владельца переехал в корень vault: [`_ПРОФИЛЬ/`](../../_ПРОФИЛЬ/README.md). Здесь остаётся только бизнес-слой.
- [`_ЗНАНИЯ/`](_ЗНАНИЯ/README.md) — `КАРТА_СМЫСЛОВ.md` (SSOT бизнеса для ИИ-команды).
- [`РЕГЛАМЕНТ_ЗОНЫ_БИЗНЕС.md`](РЕГЛАМЕНТ_ЗОНЫ_БИЗНЕС.md) — правила `2. БИЗНЕС/`: Inbox, README в новых папках, проекты, ICQ.
- [`ПРОФИЛЬ_ПРОЕКТА.md`](ПРОФИЛЬ_ПРОЕКТА.md) — слепок компании для автоматизации и внедрений (и онбординга людей).
- [`РЕЕСТР_ПРОЕКТОВ.md`](РЕЕСТР_ПРОЕКТОВ.md) — активные клиенты и внедрения, привязка репозиториев в полном vault к проектам (в т.ч. папки вне `2. БИЗНЕС/`).
- [`ДОСТУПЫ.md`](ДОСТУПЫ.md) — учётные записи MS Product и клиентов (**секретно**; не тянуть в контекст ИИ без нужды).
- [`МАТЕРИАЛЫ_MS_PRODUCT.md`](МАТЕРИАЛЫ_MS_PRODUCT.md) — база знаний: курсы, видео, шаблоны (без паролей).
- [`МЕТОДОЛОГИЯ_ГРЕБЕНЮК.md`](МЕТОДОЛОГИЯ_ГРЕБЕНЮК.md) — принципы «Реальный миллион» для ориентира ИИ при задачах масштабирования.
- [`СПРАВОЧНИК_YCLIENTS_API.md`](СПРАВОЧНИК_YCLIENTS_API.md) — практический справочник по API YCLIENTS (авторизация, права, эндпоинты, известные баги/нюансы), собран на проекте Keris Club, для повторного использования в любых будущих интеграциях.
- [`Обучение_MAC/`](Обучение_MAC/README.md) — материалы модуля 3 (система папок, workbook, промпт проверки ICQ).
- [`Скрипты_vault/`](Скрипты_vault/README.md) — Python-скрипты для управления структурой папок.
- При необходимости: подпапки `Промпты/`, `Чеклисты_ИИ/` и т.п.

## Как использовать

- Обновляй профиль, когда меняется ниша, стек или модель монетизации **компании**.
- Скрипты из `Скрипты_vault/` — для операций над vault (переименование, перемещение, нормализация).

### Контроль качества контекста (ICQ)

Раз в 4–8 недель или после крупного пополнения `2. БИЗНЕС/`: открой [`Обучение_MAC/ПРОМПТ_ПРОВЕРКИ_ДЗ.md`](Обучение_MAC/ПРОМПТ_ПРОВЕРКИ_ДЗ.md), добавь в контекст чата папку `2. БИЗНЕС/` и этот файл — прогон по чеклисту **Index Context Quality** (цель ≥ 80%). Если ниже — добей недостающие README, артефакты и «Профиль» по сценарию промпта.
