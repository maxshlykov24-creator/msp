# Агент @архитектор — бизнес-аналитик и проектировщик

**Команда:** `@архитектор`  
**Правило:** [`.cursor/rules/архитектор.mdc`](../../../.cursor/rules/архитектор.mdc)  
**Папка данных:** `3. АГЕНТЫ/АРХИТЕКТОР/` (от корня workspace `2. БИЗНЕС/`)

---

## Назначение

По данным, которые приносит владелец (ответы клиента, брифы), агент готовит:

- карточку клиента;
- списки вопросов для discovery;
- AS-IS / TO-BE;
- интеграционную карту (mermaid);
- детальное ТЗ с фазами MVP и последующими этапами;
- краткое резюме для клиента (без технички).

Реализацию (код, n8n, прод-настройки) агент **не выполняет** — артефакты передаются исполнителю.

## Команды

| Команда | Результат |
|---------|-----------|
| `@архитектор карточка [ид]` | `_КОНТЕКСТ/клиенты/[ид]/карточка.md` |
| `@архитектор дискавери [ид]` | Вопросы из `банк_вопросов.md` под контекст |
| `@архитектор as-is [ид]` | `_КОНТЕКСТ/клиенты/[ид]/AS-IS.md` |
| `@архитектор to-be [ид]` | `_КОНТЕКСТ/клиенты/[ид]/TO-BE.md` |
| `@архитектор карта [ид]` | Интеграционная схема (одна страница) |
| `@архитектор тз [ид]` | `_КОНТЕКСТ/клиенты/[ид]/ТЗ.md` по шаблону |
| `@архитектор резюме [ид]` | Краткое резюме для клиента |

`[ид]` — латиница, цифры, подчёркивание (например `demo_retail`).
