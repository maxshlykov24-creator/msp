# AS-IS amoCRM — 3 воронки (факт)

**Аккаунт:** billboardof.amocrm.ru (из карточки)  
**Поля:** в **сделке** доп. поля по сути не ведут (ответственный — авто). В **контакте:** бюджет, рабочий телефон, компания, доп. «ссылка на таблицу размещения», доп. «адрес»; в **компании** — email. Подробно: [`../2026-07-10_amoCRM_поля.md`](../2026-07-10_amoCRM_поля.md).  
**Логика сделки:** этапы + задачи + виджет F5.  
**Скрины:** `01_НОВЫЕ_ЗАЯВКИ.png` · `02_СОПРОВОЖДЕНИЕ.png` · `03_ОТВАЛ.png`

Паттерн почти на каждом этапе (кроме части финалов):  
1) закрыть текущие задачи → 2) чек-лист «Команда F5» → 3) создать задачу (+1 мин).

---

## 1. НОВЫЕ ЗАЯВКИ

| Этап | Автоматизации (как на скрине) |
|------|-------------------------------|
| Неразобранное | Задача «Связаться»: собрать инфо для составления… · Чек-лист F5 |
| Адресная программа | Закрыть задачи · Задача «Связаться»: получить предварительное согл… (+1 мин) · F5 |
| Резерв (поставщик/клиент) | Закрыть задачи · F5 · Задача «Связаться»: поставить в резерв у поставщик… (+1 мин) |
| Подготовка документов | Закрыть задачи · Задача «Документы»: подготовить документы и перед… (+1 мин) · F5 |
| Документы на подписи | Закрыть задачи · Задача «проверка»: прикрепить в описание ссылку… (+1 мин) · Задача «Документы»: получить подтверждение оплат… (+1 мин) · F5 |
| Оплата подтверждена | Закрыть задачи · **Через 5 мин: смена статуса → Сопровождение / проверка сделки** |
| Выполнено | Создать покупателя (прикреплять к существующему) |
| Закрыто и не реализовано | Причины отказа (настроить) · **Через 5 мин: смена статуса → отказ / Первичный контакт** |

**Смысл:** первичная продажа → после оплаты сделка уезжает в **Сопровождение** на этап «проверка сделки». Отказ уезжает в воронку/статус **«отказ»**.

---

## 2. СОПРОВОЖДЕНИЕ (продление / операционка)

| Этап | Автоматизации |
|------|----------------|
| Новое продление | Закрыть задачи · F5 · Задача «проверка»: выставить счет клиенту |
| Выставлен счёт | Закрыть задачи · F5 · Задача «проверка»: получить деньги от клиента (+1 мин) |
| Проверка сделки | Закрыть задачи · F5 · Задача «проверка»: убедиться, что сделка выполнена… (+1 мин) |
| Макет | Закрыть задачи · Задача «Связаться»: получить утверждение… (+1 мин) · F5 |
| Запуск в печать | Закрыть задачи · Задача: отправить разбивку поставщику (+1 мин) · F5 · Задача: получить подтверждение на… (+1 мин) |
| Монтаж/ФО | Закрыть задачи · **Создать сделку → «новое продление»** · F5 · Задача: отправить фотоотчёт клиенту (+1 мин) |
| УПД (закрывающие) | Закрыть задачи · Задача «Документы»: добиться подписания УПД… (+1 мин) |
| Успешно реализовано | Создать покупателя (прикреплять к существующему) |
| Закрыто и не реализовано | Причины отказа · **Через 1 мин: смена статуса → Потерянный контакт** · Задача «Связаться» |

**Смысл:** месячный цикл продления. На **Монтаж/ФО** автосоздаётся следующая сделка в «Новое продление» (петля LTV). Оплата = ручная задача «получить деньги», без банка/1С в триггерах.

---

## 3. ОТВАЛ

| Этап | Автоматизации |
|------|----------------|
| Неразобранное | Источник «Неразобранное» **вкл** · Контроль дублей **выкл** · триггеров нет |
| Первичный контакт | Пусто |
| Переговоры | Пусто |
| Принимают решение | Пусто |
| Успешно реализовано | Создать покупателя |
| Закрыто и не реализовано | Причины отказа — **не настроены** |

**Смысл:** упрощённая воронка без F5/задач. Имя «ОТВАЛ» + живые этапы — по факту дожим/реанимация или склад «отвалившихся» (уточнять у Сергея не обязательно для скоупа этапа 1, если фокус = Сопровождение).

## Выводы под боль (контроль)

1. **Каркас воронок уже есть** и совпадает с их рукописными схемами + календарём месяца. Проблема не в отсутствии этапов.
2. **Дисциплина = F5-чек-листы + задачи «проверка/связаться»** — ровно то, что Сергей описал как «тыкали вперёд» / каша. Доказательств (оплата, файл, письмо поставщику) в DP нет — только задачи и галочки виджета.
3. **Петля продления** на Монтаж/ФО опасна, если CRM не ведут: автосделки будут плодиться или игнорироваться.
4. **Оплата** в CRM не связана с Точкой/1С — только задача и ручной этап «Оплата подтверждена» / «получить деньги».
5. **Причины отказа** нигде не настроены (согласуется с «будут позже»).
6. **Контроль дублей выкл** (видно на ОТВАЛ).
7. Для скоупа этапа 1 достаточно этой карты воронок + уже собранного `от_клиента/` — **доступ админа amo не обязателен**, чтобы зафиксировать «что есть». Доступ нужен только на внедрение.
