# Каркас пакетов (шаблон тиров)

> Логика 3 тиров проверена на практике. Содержимое — под актуальный продукт, не из прошлой презентации.
> Заполнять по мере упаковки коробки. Сейчас — скелет.

---

## Принцип тиров

| Тир | Логика | Аудитория |
|-----|--------|-----------|
| **Базовый** | Минимально достаточный результат. Только настройка, без «руки держать». | Клиент, который хочет сам вникнуть. |
| **Стандарт** | Базовый + автоматизация + обучение команды. Снимает необходимость разбираться самому. | Основной пакет, наибольший объём продаж. |
| **Премиум** | Стандарт + сопровождение + личный менеджер/контроль. Полный аутсорс результата. | Клиент, для которого время дороже денег. |
