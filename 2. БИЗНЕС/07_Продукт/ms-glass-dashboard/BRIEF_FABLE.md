## 2. Структура: ОДИН экран-командный центр

Никаких вкладок-экранов. Один скролл + модалки/дровер. Сверху вниз:

1. **HERO-лента (sticky):** якорь с Богом / стих дня → **КИНЖАЛ** (главная задача дня) + фокус-таймер → 1–3 задачи фокуса → мини-прогресс целей + ближайший флажок.
2. **Фокус дня:** 1–3 задачи (soft-cap 3), «Сейчас» = активная с таймером, блок **«Дожать»**.
3. **Поток задач:** Хвосты / Инбокс / Очередь + быстрый захват + контроль по проектам.
4. **Пульс жизни:** 8 направлений (кольца цель/факт часов), скор недели, стрики, чекин дня.

Детали — **дровер справа / модалки**: «Год 2026» (долг, доход, флажки, weekly/monthly review), разбор задачи, редактор привычек/направлений. **Sticky «Сейчас»**: активная задача с таймером видна при любом скролле. **cmd+K** — палитра: мгновенный захват в инбокс + переход к секции (как Spotlight, без визуального шума).

## 5. Направления жизни (8) — ядро «Пульса»

Вместо мёртвого бюджета времени: у каждого направления **редактируемая цель часов/нед**, факт копится **автоматически** — фокус-таймер и чекины тегируются направлением, часы капают в кольцо.

| Направление | Цель ч/нед | Внутри |
|---|---|---|
| Дух | 12 | молитва ~10ч/нед (под-цель), Библия, изучение |
| Тело | 3 | Лёд (5×/нед), Зал (3×/нед) |
| Семья (жена) | 5 | привычка «Настя» (3×/нед) |
| Разум | 8 | развитие, система |
| Церковь | 4 | дьякон, служения, семейное служение |
| Порядок | 2 | инсайты, разбор, распределение |
| Бизнес | 30 | клиенты, хвосты |

Итого ~64ч/нед. Направления редактируемы (цель/вес/вкл-выкл). По клику — дровер направления: цель, факт-часы, свои задачи/привычки, заметки. Скор недели: вклад = min(факт/цель, 1) × вес; **Дух — приоритетный вес**. Старые привычки мигрируют под направления: Бог→Дух, Лёд/Зал→Тело, Настя→Семья, Изучение→Дух/Разум — историю не терять.

## 6. Флажки — путь в точку Б

- У каждой крупной цели (долг→0, доход→400к, хвосты→0, часы направлений) — набор **флажков-вех**. Прошёл веху → визуальный «салют» + «ты реально стал ближе».
- Hero показывает **ближайший флажок и % пути**. Флажок = честный факт: «−100к долга», «доход 250к», «неделя ≥ цели по Духу», «хвост MANSBAND закрыт».
- История флажков = дорожка достижений: откаты не обнуляют пройденный путь.

## 7. Постановка целей — лёгкий слой (не мастер на 6 шагов)

У цели/флажка три поля:
- **Формулировка 110%** — не «доход 400к», а с поджигающей деталью (показывать крупно).
- **Микро-шаг ≤48ч** — обязательное поле (цель без действия за 48ч мозг обесценивает).
- **Будущий Я** — короткая заметка-идентичность в дровере «Год 2026» (тихий якорь).

При создании крупной цели — опционально 2–3 вопроса-подсказки («если бы деньги были не важны?», «главный риск?»). Не форсировать.

## 8. Правила таск-менеджера (вшить в механику)

- **DoD «Готово»:** физически завершено · нет хвостов на уточнение · инсайт внедрён/сохранён. 3-точечное подтверждение — только при закрытии важной/красной задачи; мелочь — просто «✓».
- **3 переноса:** счётчик переносов на задаче; на 4-й — модалка-развилка: **удалить / делегировать (кому) / упростить**.
- **Главное действие первым:** утром до старта Кинжала очередь мелочей приглушена (мягкий замок + подсказка), не жёсткий запрет.
- **Блокпост (форс-мажор):** Кинжал не сделан → флоу: без вины → зафиксировать причину → авто-перенос завтра пунктом №1 → если перенос системный, предложить упростить до шага, который нельзя не сделать.
- **Дожать:** отдельная линза — задачи «почти готово / залипли» (переносилась ≥1 или помечена «80%»). Дожим = закрыть до конца, а не начать новое.
- **Ритуалы:** Пятница = стратегический компас (А→Б, долги, хвосты, life-скор, флажки). Суббота = «Большая зачистка»: инбокс→0, архив недели, метрика «сколько красных закрыто; 0 = неделя вхолостую».

Не раздувать: DoD-чеклист только на важные; ритуалы — в дровере «Год/Ритмы», без отдельных экранов.

## 11. Критерий «зашло»

Открываю утром → вижу Бога, Кинжал и ближайший флажок за 2 секунды. Весь день живу в sticky «Сейчас» с таймером. Вечером закрывашка за 60 секунд. В субботу зачистка показывает, была ли неделя настоящей. И выглядит так, что хочется показать клиентам как витрину моего уровня.
