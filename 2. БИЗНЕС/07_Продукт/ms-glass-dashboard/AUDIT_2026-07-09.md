# Аудит MS Command · 2026-07-09

**Объект:** `_ВХОДЯЩЕЕ/ms-glass-dashboard/index.html`  
**Критерий:** помогает ли закрыть долги, выйти на 300–400к, закрыть хвосты, держать жизнь, стать «уровнем выше» через систему (ISTJ + Гребенюк + реестр приоритетов).

---

## Вердикт

Продукт красивый и уже ближе к профилю, чем Excel. Но **половина экранов — декоративные заглушки**, а рабочий контур (хвосты → кинжал → 1–3 фокуса → долги) размыт ритуалами и статичными карточками. Системность есть в идее; трение — в объёме UI без действия.

---

## 1. Сегодня

### Уязвимости / баги / UX
- Нет лимита фокуса: «на сегодня» можно накидать сколько угодно — ломает «1–3».
- Кинжал не связан с задачей в очереди (отдельный textarea) → два источника правды.
- Открывашка + закрывашка + чекин + кинжал + очередь на одном экране = перегруз для 60-сек старта.
- `lifeRev`/`lifeDebt` только на `change` — при уходе без blur данные могут не сохраниться.
- Экспорт только в clipboard; нет подсказки пути под открывашку/закрывашку vault.
- Badge «Сегодня» считает due=сегодня даже без `today` — ок, но нет предупреждения «>3 фокусов».

### Логические дыры vs цели
- Долг >1M не виден как прогресс — только поле «отдано сегодня».
- Нет правила ≥30% входящих на долги.
- Нет «важное / срочное» и поля «кто, не как».
- Anti-hero / плащ супергероя не измеряется.
- Хвосты в KPI — число, но нет CTA «заполнить ХВОСТЫ.md».

### Системность vs трение
- **+** Чекин привычек, кинжал 09–12, сортировка pri, DoD в `next`.
- **−** Двойной ритуал (открывашка/закрывашка) конкурирует с действием; легко «заполнить формы» вместо закрыть хвост.

### Усилить
- Порядок: 60с жизнь → кинжал (=1 задача) → макс 3 фокуса → мини-долг.
- Soft-cap фокусов; кинжал = задача pri≤2.
- Свернуть открывашку/закрывашку в аккордеон.

## 2. Жизнь

### Уязвимости / UX
- Бюджет времени (86/105ч) — статичная декорация, не редактируется, не влияет на день.
- Стрики считают назад от сегодня; пропуск вчера = 0 даже при сильной неделе (жёстко, но честно — ок).
- Seed Excel до июня с дырами — скор «провал» при пустой текущей неделе может демотивировать без контекста.

### Логические дыры
- Нет явной связи «выручка недели → ≥30% на долги».
- Недельные цели есть; нет weekly review как ритуала (пятница).

### Системность vs трение
- **+** Отказ от Excel план/накоп/% — правильно под профиль.
- **+** Скор + стрики + тепло — метрика, которая у него работает.
- **−** Бюджет времени = шум.

### Усилить
- Убрать/спрятать бюджет; добавить «долг-норма недели» (цель ₽ + % от выручки).
- Пятничный weekly review → флажки.

## 3. Очередь

### Уязвимости / UX
- Нет редактирования задачи после создания (только done / на сегодня).
- Фильтр «Система» = только pri5; поддержка (pri4) и внедрение (pri3) размазаны.
- Lane Гребенюка как тег на каждой карточке — канбан ради канбана, не меняет поведение.
- Нет поля `who`; `next` подписан как DoD, но это скорее «следующий шаг».
- Кайдзен в модалке — одна строка-намёк, не гейт.

### Логические дыры
- Приоритет реестра есть в sort, но UI не объясняет «хвост всегда выше».
- Нет отдельного inbox хвостов / стартеров для `ХВОСТЫ.md` (файл пустой).

### Системность vs трение
- **+** Жёсткий pri 1→6.
- **−** Модалка перегружена (lane + P + today + client) без кайдзен-гейта.

### Усилить
- Модель: **режим** Пустота/Газ/Золото (не 5 lanes); поля who, important, urgent, DoD.
- Кайдзен: 3 коротких чекбокса перед Save.
- Раздел/фильтр «Хвосты» first-class + стартеры.

## 4. Клиенты

### Уязвимости / UX
- Карточки статичны, не связаны с `tasks[]`.
- Нет клика → очередь / следующий шаг из живых задач.
- Техподдержка — текст без SLA-таймера и без задач.

### Логические дыры
- Реестр (MANSBAND касса=хвост, Keris, Billboardoff…) отражён слабо; Van Pak / Дима отсутствуют в seed (допустимо), но DIVO/DKAcademy без живой связи.

### Системность vs трение
- **−** Экран «посмотреть и уйти» — заброс.

### Усилить
- Клиент = агрегация открытых задач + один next; хвост-бейдж.

## 5. Газ / 400к

### Уязвимости / UX
- Воронка с `?` и ширинами-заглушками — имитация данных.
- «Золотые шаги» — статичный HTML, не задачи, не редактируются.
- KPI «выручка нед.» дублирует жизнь, но без цели 400к progress bar.

### Логические дыры
- Газ до единичек противоречит диагностике («сначала пустота + единички»).
- Нет прогресса А→Б (200→400) и долга.

### Системность vs трение
- **−** Декор создаёт ложное чувство «труба под контролем».

### Усилить
- Слить с «Год 2026»: долг↓, доход↑, хвосты→0, единички, этап. Газ — только после честного статуса единичек.

### Логические дыры
- Недельный разбор 15.07 захардкожен; нет повторяющейся пятницы.

### Системность vs трение
- **−** Чистый календарь без игры/метрики — по профилю исполнения «ломает».

### Усилить
- Убрать отдельный раздел; due задач + пятничный review на Сегодня/Год.

## 7. Стратегия

### Уязвимости / UX
- Этапы Гребенюка статичны (hardcoded «Пустота сейчас»).
- Единички сохраняются — хорошо; нет DoD/следующего шага на единичку.
- Кайдзен — текст, не гейт на создание задач.

### Логические дыры
- Нет экрана «Год 2026» как единого компаса.
- Плащ супергероя упомянут в диагностике, в UI нет.

### Системность vs трение
- **+** 5 единичек — правильный артефакт.
- **−** Экран редко открывается → единички не живут в ежедневном контуре.

### Усилить
- Единички на экране Год + напоминание на Сегодня если пустые.
- Weekly review: А→Б, долги, хвосты, единички, life-скор.

## Решение по модели (после аудита)

**Не канбан из 5 lanes.** Рабочая модель:

1. **Реестр pri 1–6** — жёсткая сортировка (закон).
2. **Режим:** Пустота | Газ | Золото — зачем эта задача сейчас.
3. **Важное × Срочное** — к цели vs к ухудшению.
4. **Кто** — делегирование/авто вместо «как».
5. **DoD + следующий шаг** — короткий цикл.

Календарь и декоративная труба — **убрать**. Газ+Стратегия → **Год 2026**. Хвосты — **отдельный экран**.
