# Референсы

> Прошлые версии упаковки, офферы, презентации — не текущий продукт, а исторический контекст и база для создания нового.

---

## О папке

Здесь хранятся артефакты прошлых попыток упаковки продукта. Они не являются целью и не определяют текущее направление, но дают:
- Понимание, как уже формулировали ценность для клиента.
- Готовые элементы (методология доставки, структура пакетов), которые можно переработать.
- Кейсы и клиентские имена — для новых офферов.

## Содержимое

- [`2024_Презентация_fashion.md`](2024_Презентация_fashion.md) — презентация под fashion-нишу (amoCRM + МойСклад); составлена ~год назад. Не текущий оффер, но показывает рабочую методологию 5 шагов и структуру 3 пакетов.
