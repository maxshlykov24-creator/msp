| **Автор** | Phenomenon Studio |

### Что передают рендеры / блоки

| Блок | Смысл |
|------|-------|
| **Hero + Showreel** | «Мы — студия уровня, который доверяют VC-backed команды». Движение = живой продукт, не статичная визитка. |
| **IN NUMBERS** (500M+ raised, 5.0 Clutch, x2 repeat) | Доверие через **измеримый результат**, не через «мы креативные». |
| **Featured client wins** | Каждый кейс = история успеха клиента (раунд, партнёрство, награда) — **продаём исход**, не процесс. |
| **Problem → CTA** (Extend / Redesign / Launch MVP) | Сегментация аудитории по боли; один экран — один сценарий входа. |
| **Services tabs** (Launch / Evolve / Rebrand / Extend) | Полный lifecycle продукта — позиция **долгосрочного партнёра**. |
| **Featured cases** | Tech stack + timeline + **Results** — прозрачность и техническая зрелость. |
| **Industries** (SaaS, Healthcare, FinTech, EdTech) | Challenges → How we solve — **говорим языком клиента**, не списком услуг. |
| **Why choose us + Awards + Testimonials** | Тройной слой доверия: экспертиза, регуляторика, отзывы, награды. |

### Что нравится (для переноса)

- Плотность **social proof** без шума.
- Кейсы с **конкретными метриками** (+35% conversion, $1.3M raised).
- Чёткий hero + два CTA (talk / cases).
- Структура «боль → решение → действие» по сегментам.

## 4. KaultAI — Autonomous AI Workflow Landing

| | |
|---|---|
| **URL** | https://dribbble.com/shots/27249429-KaultAI-Landing-Page-Autonomous-AI-Workflow |
| **Тип** | Dribbble / UI concept |
| **Автор** | [Kris Anfalova](https://dribbble.com/Kris_anfalova) |
| **Case с текстом** | [Contra — KaultAI Landing Page Design](https://contra.com/p/OsQo6ALr-kault-ai-landing-page-design) |

### Что передают рендеры / описание автора

> SaaS для elite developers: **сложные AI-implementation → seamless autonomous workflows**. Technical depth + premium aesthetics.

| Блок | Смысл |
|------|-------|
| **Dark mode + chrome 3D** | Скорость, поток данных, «velocity» — **без клише AI-robot stock**. |
| **Hero → AI workspace preview** | Маркeting плавно переходит в **функциональный UI** продукта. |
| **Micro-copy** ([VELOCITY_X], [FLOW_LOCKED]) | Developer-centric атмосфера — **terminal-grade premium**. |
| **Quick-action presets** | Автomation / workflow — сразу видно **как работает**, не только «что обещаем». |
| **Minimal nav** | Фокус на одном workflow, без отвлечений. |

### Challenge → Solution (из case)

- **Challenge:** визуализировать «autonomous workflows» без штампов.
- **Solution:** dark + high-contrast 3D + чёткая иерархия hero → workspace.

### Что нравится (для переноса)

- **3D / motion** как метафора потока автоматизации (n8n, webhooks, интеграции).
- Premium dark UI — сочетается с **liquid glass** (§9 регламента).
- «Дорогой» SaaS для технической аудитории — близко к позиционированию MS Product.

## 5. Traffic Masters — живой сайт агентства (2026-08-20)

| | |
|---|---|
| **URL** | https://traffic-masters.ru/ |
| **Тип** | Живой сайт маркетингового агентства (Next.js) |
| **Как попал** | Ссылка владельца из VK (`utm_source=vkontakte`) |
| **Слова владельца** | «нравится как выглядит» — для корректировок и доработки своего сайта (`ms-p.ru` / `site-ms`) |
| **Что именно нравится** | не названо; ниже — что видно в вёрстке на 2026-08-20 |

Источник токенов: CSS `:root` и разметка главной на дату фиксации. Не копировать тексты, цены и оффер — только вид и каркас.

### Палитра и тип (факт с сайта)

| Токен | Значение |
|-------|----------|
| Фон / текст | `#fff` / `#111` |
| Primary | `#0080ff` · ink `#0069d9` |
| Primary-deep (hero) | `#181d3b` |
| Accent | `#ef7e32` · ink `#b04f0f` · градиент цифр до `#ffb37a` |
| Secondary / muted | `#f5f6fa` · muted-text `#6e6e6e` |
| Border | `#c9c9c9` |
| Шрифт | **Cygre** (Regular / Medium / SemiBold / Bold), `font-heading` = sans |
| Контейнер | `max-w-[1200px]` |

Это **светлая** агентская страница. Прод MS Product сейчас тёмный (магента → фиолет → циан, liquid silk). Палитру Traffic Masters на `ms-p.ru` не переносить без отдельного «да».

### Что видно в блоках

| Блок | Приём |
|------|-------|
| **Шапка** | Плавающая пилюля: `rounded-full`, `backdrop-blur`, полупрозрачный фон, отступ от краёв (`top-6` / `top-8`), не на всю ширину экрана. Справа CTA «Перезвоните мне» — капсула + круг со стрелкой. |
| **Навигация** | Hover-слайд текста вверх (`translate-y`), не просто смена цвета. |
| **Hero** | Не на весь экран: скруглённая карточка `32px` с фото-фоном (`/brand/hero/hero-bg.jpg`), поверх тёмный navy и два blur-пятна. По центру: badge с live-dot → заголовок 64px → подзаголовок → два CTA → три цифры через разделители. |
| **CTA** | Капсула uppercase + кружок со стрелкой, которая едет вправо; на primary — shine. Второй CTA инверсный (белая заливка). |
| **О нас** | Клеймо-пилюля с оранжевой точкой. Заголовок с одним акцентым словом. Дальше **фото-bento**: две высокие карточки + цифра 120+ + коммуникация, текст поверх фото, `rounded-3xl`. |
| **Клиенты** | Бегущая строка логотипов, маска по краям, пауза на hover. |
| **Услуги** | Две колонки: иконка площадки в стеклянной плитке, заголовок, абзац, мини-капсула «Подробнее». Hover: синяя тень и градиентная заливка. |
| **Ниши / кейсы / тарифы / квиз / команда / FAQ / форма** | Полная продающая лестница: цифры в кейсах, 4 тарифа, квиз на 5 шагов, люди с «+ / −», FAQ, форма внизу. |

### Что брать на правки ms-p.ru (гипотеза, пока владелец не уточнил)

Брать каркас и микродвижение, не светлую схему и не чужой оффер.

| Приём | Зачем на ms-p.ru |
|-------|------------------|
| Шапка-пилюля с отступом от края | Сейчас шапка на всю ширину, липкая полоса |
| Hero как скруглённая сцена, не на весь viewport | Сильнее «карточка продукта», чем растянутый шёлк |
| CTA-капсула + круг со стрелкой | Понятнее, чем одна градиентная кнопка |
| Клеймо секции (точка + uppercase) | Ритм между блоками |
| Цифры сразу под hero | Доверие до скролла к кейсам |
| Фото- или продукт-bento в «о нас» / результатах | Сейчас карточки однотипные, без иерархии |
| Hover-слайд подписи | Дешёвая «дороговизна» без нового шейдера |

**Не брать без отдельного решения:** светлый фон, синий `#0080ff`, оранжевый акцент, чужие фото, квиз, витрина тарифов, бегущая строка чужих логотипов.

Чужие тексты, цены, оффер Ozon и бренд не копировать. Палитру с главной не выписывал: без отдельного «да» на `ms-p.ru` не переносить.

### Что видно в блоках

| Блок | Приём |
|------|-------|
| **Hero** | Цифра доверия сразу (`4929+`), заголовок «с одного экрана», два CTA: начать / смотреть демо. Рядом скрин продукта, не сток. |
| **Боль** | «Видите только половину картины» — кабинет даёт выручку, не прибыль. |
| **Сравнение** | Таблица «как сейчас / как с нами» по строкам: выручка, ДРР, unit, финансы, поставки. |
| **Фичи** | Семь модулей как одна система. У каждого — скрин своего экрана, не иконка. |
| **Склейка** | «Одни данные из API во всех модулях» — от сводки к SKU без ручной сверки. |
| **Доказательство** | Блок «как это выглядит внутри» на живом магазине. |
| **Тарифы** | Три карточки от оборота; одна помечена «популярный». |
| **Онбординг** | Три шага с временем: 30 секунд → ключ Read Only → данные через 35 минут. |
| **Персоны** | Три входа: новичок / растущий / менеджер чужих магазинов. |
| **Основатель** | «Сам пользуюсь каждый день» — не абстрактный отзыв. |
| **Ресурсы** | Справка, дорожная карта, номер версии — продукт живой. |
| **FAQ** | Шесть вопросов, якорь `#faq`. |
| **Финал** | Повтор CTA + снятие страха: пробный период, без карты, настройка за 5 минут. |

### Что брать, когда будем делать сайт (гипотеза)

Каркас лестницы и плотность, не чужой оффер и не светлую схему.

| Приём | Зачем нам |
|-------|-----------|
| Цифра + скрин продукта в hero | Доверие до скролла, продукт реален |
| Таблица «было / стало» | Сложный оффер читается за 10 секунд |
| Фичи со скринами своих экранов | Не список обещаний |
| Три шага с конкретным временем | Снимает «это долго внедрять» |
| Три персоны | Разные входы без отдельного лендинга |
| FAQ на якоре | Закрывает типовые страхи (доступ, цена, срок) |

**Не брать:** тексты и цены Yoolip, нишу Ozon, чужой бренд, расширение-виджет, клуб, дорожную карту WB.
