# Cursor для проектировщика

Переход из браузерного чата в рабочее место. Читать на третьей неделе, не раньше — сначала привыкни к самой работе с ИИ.

---

## 1. Зачем это, если чат в браузере уже работает

В браузере ты копируешь. Каждый раз: открыл ТУ, выделил, скопировал, вставил в чат, дописал вопрос. Потом то же самое с заданием. Потом ответ копируешь обратно в документ.

Пока задача одна, это терпимо. Когда задач десять в день, ты бросаешь.

**Cursor работает иначе: ты открываешь папку объекта, и ИИ может сам находить и читать файлы внутри неё.** Пишешь «сверь спецификацию из этого файла с выгрузкой из того» — и он читает оба сам. Ничего копировать не надо.

Важная оговорка сразу: «может читать» не равно «всё сразу видит». Он ищет по папке и подтягивает то, что счёл нужным, а объём текста за один раз ограничен. Поэтому нужные файлы лучше называть явно через `@`.

Разница на практике:

| | Браузерный чат | Cursor |
|---|---|---|
| Дать ИИ документ | Скопировать текст | Написать `@имя_файла` |
| Работать с 5 файлами сразу | Практически невозможно | Обычное дело |
| Сохранить результат | Скопировать обратно | Пишет в файл сам, ты подтверждаешь |
| Настроить под себя один раз | Нет, объясняешь в каждом чате | Файл правил, работает всегда |
| Свои помощники под задачи | Нет | Да, правила-помощники |

Cursor — это редактор кода по происхождению, и первое впечатление может быть «это не для меня». Не пугайся. **Для тебя это умный блокнот, который читает твои рабочие файлы.** Программировать не придётся.

---

## 2. Установка

1. Скачай с [cursor.com](https://cursor.com), поставь как обычную программу
2. При первом запуске зарегистрируйся. Есть бесплатный режим с ограничениями и платная подписка — для реальной работы понадобится платная
3. При вопросе про импорт настроек из других редакторов — пропускай, тебе не нужно
4. Язык интерфейса можно оставить английским, кнопок ты будешь использовать три штуки

**Панель чата открывается сочетанием Cmd+I (Mac) или Ctrl+I (Windows).** Это единственное сочетание, которое надо запомнить. Если версия окажется другой, панель всегда есть в правой части окна и в меню View.

Отдельно про конфиденциальность: в настройках включи Privacy Mode. Он запрещает обучение на твоих данных, но не делает работу локальной — запросы всё равно уходят на серверы. Стоп-лист из правила 4 продолжает действовать.

## 3. Как открыть свой проект

`File → Open Folder` и выбираешь папку объекта. Например `Объекты/Жилой_квартал_Северный/`.

Слева появится дерево файлов, справа — чат. Файлы из этой папки ИИ может прочитать по твоей команде. Исключение — то, что ты сам закроешь: имена файлов и папок, записанные в файл `.cursorignore` в корне, ИИ не читает. Это удобный способ спрятать чувствительное.

**Что имеет смысл держать в папке объекта:**

- ТУ и задание (лучше в текстовом виде или PDF)
- Пояснительные записки
- Расчёты и выгрузки из таблиц
- Переписка, протоколы
- Замечания экспертизы

**С чем будут проблемы.** Чертёж DWG — бинарный файл, читать его не надо и рассчитывать на это нельзя. Работай с тем, что из чертежа выгружается: спецификации, ведомости, таблицы координат и отметок, экспорт данных сети.

Word и Excel (`.docx`, `.xlsx`) — тоже не текстовые файлы, и результат непредсказуем: иногда читается, иногда нет. Не борись с этим. Самый надёжный путь для рабочих документов такой:

- `.docx` → «Сохранить как» в обычный текст `.txt`, либо просто скопировать текст в чат
- `.xlsx` → «Сохранить как» в `.csv`
- PDF → обычно читается, кроме сканов без текстового слоя. Скан сначала прогони через распознавание

Одна минута на пересохранение снимает половину будущих затыков.

## 4. Три режима

В чате есть переключатель режима. Разница принципиальная.

### Ask — спросить

ИИ читает файлы и отвечает. **Твои файлы он не меняет.** Это не про конфиденциальность (текст всё равно уходит на сервер), а про то, что документы останутся нетронутыми.

Здесь ты живёшь первые две недели. Разбор ТУ, вопросы по нормам, проверка расчёта, поиск противоречий — всё это Ask.

### Plan — сначала покажи, что собираешься сделать

ИИ изучает файлы, задаёт вопросы и составляет план работы. Ты читаешь план и правишь его.

**Важно: сам по себе Plan файлы не меняет.** Чтобы он начал работать, надо нажать кнопку **Build**. Пока ты её не нажал, ничего не произойдёт. Через этот режим работает [`СБОРКА_СИСТЕМЫ.md`](СБОРКА_СИСТЕМЫ.md).

### Agent — делай

ИИ работает сам: создаёт файлы, правит, запускает команды. Быстро и удобно, но требует привычки.

**Правило для новичка: две недели живёшь в Ask, потом добавляешь Plan, Agent — когда перестанешь удивляться результатам.**

Изменения показываются как «было / стало», их можно отклонить, а состояние откатить через Restore Checkpoint. Но не считай, что обратимо вообще всё: контрольные точки живут локально, а команды в терминале и внешние действия назад не отматываются. Настоящая страховка от потери работы — копия папки или git, а не кнопка отмены.

## 5. Символ @ — как показать ИИ нужный файл

Пишешь в чате `@` и начинаешь набирать имя файла, Cursor подставит.

**Один файл:**

```
@ТУ_водоканал.pdf разбери эти технические условия по схеме: требования таблицей, точки подключения, чего не хватает
```

**Несколько файлов сразу:**

```
Сверь @спецификация.xlsx и @выгрузка_из_модели.csv, найди расхождения по количеству и диаметрам
```

**Вся папка:**

```
@Жилой_квартал_Северный/ найди все места, где отметки в записке расходятся с отметками в таблице колодцев
```

Последнее — то, ради чего всё затевалось. В браузере такое просто невозможно.

## 6. Файл правил: настроить один раз

Главная неприятность браузерного чата — каждый новый чат начинается с нуля. Ты снова объясняешь, кто ты, чем занимаешься, что нужны цитаты норм.

В Cursor это решается файлом правил, который читается автоматически в каждом чате.

**Что делать:**

1. Возьми из комплекта [`ПАСПОРТ.mdc`](ПАСПОРТ.mdc)
2. В корне своей рабочей папки создай папку `.cursor`, внутри неё папку `rules` и положи файл туда: `.cursor/rules/ПАСПОРТ.mdc`
3. Заполни места в квадратных скобках своими данными
4. Проверь: задай вопрос про норму и посмотри, потребует ли ИИ цитату сам, без напоминания

После этого каждый чат начинается с того, что ИИ уже знает: ты инженер-проектировщик наружных сетей, объяснять надо без ИТ-жаргона, номера пунктов выдумывать нельзя, числа не сочинять.

*Если встретишь в интернете совет положить файл `.cursorrules` в корень — это старый формат. Он пока работает, но постепенно выводится из употребления, поэтому сразу делай через `.cursor/rules/`.*

## 7. Помощники под задачи

Следующий уровень. Паспорт — общие правила для всего, помощник — инструкция под конкретную работу.

Вместо длинного промпта на пятнадцать строк ты пишешь:

```
@ту разбери @ТУ_водоканал.pdf
```

и получаешь тот же результат, потому что вся инструкция лежит в файле помощника.

Технически это такие же файлы правил, просто узкие и вызываются вручную по имени. В комплекте три готовых: `@ту`, `@нормоконтроль`, `@записка`. Установка — [`АГЕНТЫ/README.md`](АГЕНТЫ/README.md), это две минуты копирования файлов.

## 8. Выбор модели

Внизу окна чата есть переключатель модели. Разные модели — разное качество, скорость и цена.

Что выбирать под твои задачи, разобрано в [`ВЫБОР_МОДЕЛИ.md`](ВЫБОР_МОДЕЛИ.md). Коротко: для разбора норм и сложного анализа бери самую сильную из доступных, для писем и черновиков хватит быстрой.

## 9. Первые пять действий

По шагам, с ожидаемым результатом. Час времени.

**Шаг 1.** Установи Cursor, открой папку с любым закрытым объектом.
*Результат:* видишь дерево файлов слева.

**Шаг 2.** Открой чат (Cmd+I или Ctrl+I), убедись, что стоит режим Ask. Напиши:

```
@ТУ.pdf прочитай эти технические условия и назови точку подключения, требуемые параметры и срок действия ТУ
```

*Результат:* ИИ отвечает по твоему файлу, который ты никуда не копировал. Это тот самый момент, ради которого стоило ставить программу.

**Шаг 3.** Задай сквозной вопрос по нескольким документам:

```
@папка_объекта/ найди расхождения между данными в задании и в технических условиях
```

*Результат:* ответ, для которого ИИ прочитал несколько файлов.

**Шаг 4.** Положи `ПАСПОРТ.mdc` в `.cursor/rules/` своей рабочей папки, заполни своими данными. Задай вопрос про норму.
*Результат:* ИИ сам приводит пункт и цитату, ты об этом не просил.

**Шаг 5.** Установи помощника `@ту` по инструкции из `АГЕНТЫ/README.md`. Напиши `@ту разбери @ТУ.pdf`.
*Результат:* полный структурированный разбор одной строкой запроса.

## 10. Частые затыки

**«Не понимаю, куда писать».** Чат справа. Если его нет — Cmd+I или Ctrl+I.

**«ИИ не видит файл».** Сошлись на него явно через `@`. Если не помогло, проверь, что файл лежит внутри открытой папки и не попал в `.cursorignore`.

**«Не читает PDF, Word или Excel».** Для PDF частая причина — скан без текстового слоя, прогони через распознавание. Word и Excel надёжнее пересохранить в `.txt` и `.csv`, см. раздел 3.

**«Он что-то поменял в моём файле, я не просил».** Значит был включён режим Agent (или ты нажал Build в Plan). Изменения показываются как «было / стало», отклони кнопкой. Переключись на Ask.

**«Ответы стали хуже, чем в начале чата».** Диалог слишком длинный, модель тонет в старом контексте. Новая задача — новый чат. Правило простое: сменилась тема, открывай чистый.

**«Просит доплатить».** Мощные модели расходуют лимит подписки. Для тяжёлых задач бери сильную модель, для мелочи — быструю. Подробности в `ВЫБОР_МОДЕЛИ.md`.

**«Всё равно сложно».** Открой папку комплекта в Cursor, переключись в Plan, напиши `@СБОРКА_СИСТЕМЫ.md сделай`. Cursor задаст вопросы и покажет план. Проверь план и нажми **Build** — дальше он всё настроит сам. Это способ пропустить ручную настройку.
