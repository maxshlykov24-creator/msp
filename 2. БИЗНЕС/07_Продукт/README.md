# 06_Продукт_и_упаковка

> Что продаём, как описано для клиента и для команды: услуги, коробки, границы внедрения.

---

## О папке

Материалы про **продуктовую линейку**: типовые решения, описания модулей, прайс-логика (фикс vs почас), шаблоны КП и скопов «что входит / не входит». Цель — чтобы ИИ и люди одинаково понимали предложение.

## Содержимое

- [`ПОЗИЦИОНИРОВАНИЕ.md`](ПОЗИЦИОНИРОВАНИЕ.md) — кому, чем отличаемся, границы (якорь для КП и ИИ).
- Описания продуктов и пакетов внедрения.
- Методички «как мы доставляем» (сырые чаты клиентов — сначала в [`Входящее`](../../Входящее) или [`04_`](../04_Производство_внедрений/README.md), не сюда).
- Артефакты упаковки: презентации продуктов, one-pager.

## Как использовать

- Новые черновики офферов — в [`Входящее`](../../Входящее), затем переносить сюда в аккуратный файл.
- При изменении продукта обновляй README соседних зон, если меняется воронка или производство.
- Эта папка живёт под «Важно»-приоритетом backlog; наполняй её по мере стандартизации.
