# Входящее (инбокс vault)

Единый **корневой** инбокс всего vault: личное, бизнес, транскрипты, скрины, PDF — всё сырьё без готового места **сначала сюда**, потом разнос по зонам.

**Не внутри** `Личное/` и **не внутри** `Бизнес/` — отдельная папка на уровне корня репозитория.

## Сроки

В идеале разбирать **каждый день**; не держать дольше **3 дней** без переноса.

## Куда разносить

| Тип сырья | Куда |
|-----------|------|
| Личное (профиль, дух, тело, путешествия) | `Личное/…` по [`СТРУКТУРА_И_ПРИНЦИПЫ.md`](../Личное/СТРУКТУРА_И_ПРИНЦИПЫ.md) |
| Клиенты, внедрения, код | `Бизнес/04_Производство_внедрений/…` |
| Лиды, продажи | `Бизнес/03_Продажи/…` |
| Техподдержка | `Бизнес/08_Поддержка/…` |
| YouTube / контент MS Product | `Бизнес/05_Маркетинг_и_контент/_ai/` |
| Договоры, печати ИП | `Бизнес/02_Финансы_и_риски/…` |

**Не путать с** `Личное/6. Прочее/` — там редкое без ветки на долгий срок.

## Работа с ассистентом

- Триггеры: «разбери Входящее», `@Входящее`, вложения из этой папки.
- После разбора — перенос файлов и допись в [`ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md`](../Личное/1.%20Повторки/1.3.%20Планирование/1.3.1.%20Неделя/ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md).
- Правки `СТРУКТУРА_И_ПРИНЦИПЫ.md` и деревьев — только после твоего решения.

## Учебные материалы курса

Шаблоны — в `Личное/3. Разум/3.1. Изучение/3.1.4. Курсы/1. Учебные материалы/`; не смешивать с сырьём.
