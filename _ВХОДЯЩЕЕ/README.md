# Входящее (инбокс vault)

Единый **корневой** инбокс всего vault: личное, бизнес, транскрипты, скрины, PDF — всё сырьё без готового места **сначала сюда**, потом разнос по зонам.

**Не внутри** `1. ЛИЧНОЕ/` и **не внутри** `2. БИЗНЕС/` — отдельная папка на уровне корня репозитория.

## Конвейер

```
новое/         сюда падает всё непонятое
_к_проверке/   разложено Архивариусом, ждёт «да» владельца
_обработано/   подтверждено, можно разносить по зонам
```

Файл не уезжает из `_к_проверке/` в зону, пока не подтвердил владелец.

## Сроки

В идеале разбирать **каждый день**; не держать дольше **3 дней** без переноса.

## Куда разносить

| Тип сырья | Куда |
|-----------|------|
| Личное (профиль, дух, тело, путешествия) | `1. ЛИЧНОЕ/…` по [`СТРУКТУРА_И_ПРИНЦИПЫ.md`](../1.%20ЛИЧНОЕ/СТРУКТУРА_И_ПРИНЦИПЫ.md) |
| Клиенты, внедрения, код | `2. БИЗНЕС/04_Производство/…` |
| Лиды, продажи | `2. БИЗНЕС/03_Продажи/…` |
| Техподдержка | `2. БИЗНЕС/05_Поддержка/…` |
| YouTube / контент MS Product | `2. БИЗНЕС/06_Маркетинг/_ai/` |
| Договоры, печати ИП | `2. БИЗНЕС/02_Финансы/…` |

**Не путать с** `1. ЛИЧНОЕ/6. Прочее/` — там редкое без ветки на долгий срок.

## Работа с ассистентом

- Отвечает Архивариус. Триггеры: «разложи входящее», «куда это положить», «наведи порядок».
- После разбора — перенос файлов и допись в [`ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md`](../1.%20ЛИЧНОЕ/1.%20Повторки/1.3.%20Планирование/1.3.1.%20Неделя/ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md).
- Правки `СТРУКТУРА_И_ПРИНЦИПЫ.md` и деревьев — только после твоего решения.

## Учебные материалы курса

Шаблоны — в `1. ЛИЧНОЕ/3. Разум/3.1. Изучение/3.1.4. Курсы/1. Учебные материалы/`; не смешивать с сырьём.
