## Загрузка. Два шага

### Шаг 1. Скилл

В чате с нужным Grok Bot напиши:

```
Сохрани это как скилл maxim-voice.
Черновик ответа в моём тоне. Три круга: рабочий, близкий, личный.
По умолчанию не отправляй. Отправка только если я сказал отправь.
```

Дальше прикрепи всю папку или по очереди `SKILL.md` и четыре файла из `references/`.

Если скилл не появился в меню `/`:

Settings → Plugins → Yours → включить `maxim-voice` для этого бота.

Документация: https://docs.x.ai/grok-bot/skills-routines-and-automations

### Шаг 2. Проверка на живом

Кинь боту одно реальное входящее, без подсказки круга, и фразу:

```
бесшумный режим
```

Готово, если:

- пришёл текст сообщения, не эссе
- нет точки в конце последней строки
- нет длинного тире, слэша, двойных кавычек
- внизу строка `круг: … · отправка: нет`
- бот не утверждает, что отправил

Прогони три круга: клиент, жена, человек из церкви. Эталоны пар — внутри профилей.

## Как пользоваться каждый день

```
бесшумный режим

чат: Виктория / New Martache
круг: рабочий

хвост:
<вставь 15–40 последних сообщений>

входящее:
<последнее сообщение>
```

Или короче, если круг ясен:

```
ответь жене
<вставить сообщение или хвост>
```

Отправить бот не должен. Копируешь черновик в Telegram сам.

## Связь с Telegram

Отдельного коннектора Telegram у Grok Bot нет.

Рабочий путь: вставлять хвост чата. Этого хватает для тона.

Паритет с Cursor: разрешить боту локальный компьютер и тот же CLI `tg-self`. Сессию в облако Grok не копировать.

Подробности: `references/телеграм.md`.

## Чего не загружать

- `_выгрузки/сообщения.jsonl`
- `voice_cache.jsonl`
- `.env`, `*.session`
- `ДОСТУПЫ.md`
- всю карту смыслов и финансы: этот бот про ответы, не про Ио
