# SEO-АССИСТЕНТ / ОРКЕСТРАТОР (@сео)

**Команда:** `@сео`  
**Папка:** `агенты/СЕО/`  
**Правило:** `.cursor/rules/сео.mdc`

---

## Назначение

SEO по любым проектам: карточка, ТЗ, **промпт-пакеты** для исполнителей в отдельном чате (семантика / текст), QA по чеклисту, логи, дообучение на примерах.

**Не делает сам:** полную семантику и полные тексты в этом чате — выдаёт готовые инструкции исполнителю.

---

## Быстрый старт

1. Создай карточку проекта: скопируй `_КОНТЕКСТ/шаблон_карточки_проекта.md` → `_КОНТЕКСТ/проекты/[ид].md`, заполни.
2. Вызов: `@сео семантика [ид] …` или `@сео текст [ид] …`
3. Копируй **ПАКЕТ «СЕМАНТИКА»** или **ПАКЕТ «ТЕКСТ»** из ответа `@сео` в новый чат / Agent.

## Исполнители (без отдельных @правил)

Семантику и тексты делает **любой выбранный чат** по промпт-пакету из правила `@сео`. Образец блока ТЗ: `_КОНТЕКСТ/примеры/ОБРАЗЕЦ_ТЗ_на_текст.md`.
