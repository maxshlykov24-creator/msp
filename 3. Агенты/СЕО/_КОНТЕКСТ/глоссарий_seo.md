# Мини-глоссарий SEO (для команды агентов)

Краткие определения; детали — в ТЗ и карточке проекта.

| Термин | Смысл |
|--------|--------|
| **Интент** | Задача пользователя за запросом: узнать (informational), найти сайт (navigational), сравнить/выбрать (commercial), купить/заказать (transactional). |
| **Кластер** | Группа запросов с одной задачей → как правило **одна посадочная страница**. |
| **LSI** | Тематически близкие слова и сущности, которые естественно раскрывают тему (не «список ключей ради списка»). |
| **E-E-A-T** | Experience, Expertise, Authoritativeness, Trustworthiness — опыт, экспертиза, авторитет, доверие (важно для YMYL и B2B). |
| **YMYL** | Темы, влияющие на здоровье, финансы, безопасность — повышенные требования к фактам и экспертности. |
| **ЧПУ** | Человекопонятный URL (слова в адресе страницы). |
| **Canonical** | Указание основной версии страницы при дублях. |
| **NAP** | Name, Address, Phone — единообразие контактов для локального SEO. |
| **SERP** | Страница выдачи поисковика по запросу. |
| **GSC** | Google Search Console. |
| **Технический аудит** | Проверки индексации, скорости, дублей, robots/sitemap и т.д. — по чеклисту СЕО. |
