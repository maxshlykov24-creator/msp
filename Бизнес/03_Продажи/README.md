# 03_Продажи

> Воронка, сделки, скрипты и процесс продаж — мои собственные, не клиентские внедрения.

---

## О папке

Всё, что относится к **притоку денег до старта проекта**: лиды, квалификация, этапы воронки, шаблоны писем, регламенты. Работа в amoCRM по своим сделкам — здесь. Технические интеграции CRM в рамках доставки клиенту — это [`04_Производство_внедрений`](../04_Производство_внедрений/README.md).

## Содержимое

- Скрипты и сценарии диалогов.
- [`ВОПРОС_КРИТЕРИЯ_УСПЕХА_ПРОЕКТА.md`](ВОПРОС_КРИТЕРИЯ_УСПЕХА_ПРОЕКТА.md) — ретроспективный вопрос при согласовании проекта (критерий успеха с точки зрения клиента).
- Описание воронки и статусов (в т.ч. экспорт/снимок из amoCRM для контекста).
- Шаблоны коммерческих предложений, привязанных к этапу продажи (не продуктовая «упаковка» — та в [`06_`](../06_Продукт_и_упаковка/README.md)).

## Как использовать

- Выгрузки и временные файлы из CRM сначала в `00_Inbox`, потом — сюда в осмысленную подпапку (например `Воронка/`, `Шаблоны/`).
- Не храни персональные данные клиентов без необходимости; маскируй в общих документах.
