# 00_Inbox

Inbox для хаоса. Сюда попадают файлы перед сортировкой.

---

## О папке

Временная точка входа для всего, что ещё не разложено по зонам `01_`–`06_` и `99_Системное`. Снимает трение «куда положить сейчас».

## Содержимое

Черновики, выгрузки, документы из переписок, сканы, экспорт из CRM — до решения о постоянном месте.

## Как использовать

1. Скидывай сюда всё новое по бизнесу, если не уверен в папке.
2. Периодически прогоняй раскладку: список файлов → целевая зона → перенос.
3. Не держи Inbox бесконечным складом: цель — опустошать.
