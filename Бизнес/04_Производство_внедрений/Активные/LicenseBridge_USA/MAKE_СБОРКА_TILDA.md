# Сборка Make: Tilda → Kommo (пошагово, по кликам)

Цель: заявка с формы Tilda падает в Kommo на этап **Первичный контакт** (`86527439`) воронки **Pipeline** (`11274779`), источник пишется в поле **Channel** (`143104`).

Логика та же, что у Facebook: **триггер ловит заявку → Kommo Create a Contact → Kommo Create a Lead.**
Подключение Kommo (Connection) уже создано на сценарии Facebook — переиспользуем то же.

---

## ЧАСТЬ 1. Сценарий в Make (триггер — webhook)

В отличие от Facebook (там polling Watch Leads), Tilda сама **пушит** заявку на webhook — мгновенно.

### 1.1 Создать webhook
1. Make → **Create a new scenario**.
2. Большая «**+**» по центру пустого холста → поиск **`Custom webhook`** → выбрать **Custom webhook (Trigger)**.
3. **Add** → имя `tilda-leads-in` → **Save**.
4. **Copy address to clipboard** — это `TILDA_WEBHOOK_URL`, понадобится в Tilda.
5. Модуль напишет «Determine data structure / waiting» — оставь так, заполнится после тест-заявки из Tilda (часть 2).

### 1.2 Создать контакт
6. «**+**» справа → **Kommo** → **Create a Contact**.
7. **Connection** → выбрать уже существующее подключение `licensebridgeusa.kommo.com`.
8. Поля (значения появятся после тест-заявки из части 2):
   - **Name** → поле `Name` из webhook
   - **Phone** → поле `Phone`
   - **Email** → поле `Email`

### 1.3 Создать сделку
9. «**+**» справа → **Kommo** → **Create a Lead**.
10. Поля:
    - **Name** → впиши `Tilda: ` + значение `Name`
    - **Pipeline** → **Pipeline** (`11274779`)
    - **Status** → **Первичный контакт** (`86527439`)
    - **Contacts → Add item → ID** → выбрать `ID` из шага Create a Contact
    - **Custom field Channel** (`143104`) → вписать `Tilda` (или подставить `source` из webhook)
11. Внизу слева → **ON**. Расписание для webhook-сценария — **Immediately as data arrives** (по умолчанию).

---

## ЧАСТЬ 2. Подключить webhook в Tilda

1. Tilda → нужный проект → **Настройки сайта** → **Формы** (Site Settings → Forms).
2. Найти блок **Webhook** → **Добавить**.
3. **URL вебхука** → вставить `TILDA_WEBHOOK_URL` из части 1.1.
4. Опцию «Передавать данные в JSON» можно оставить выключенной (Make примет и form-data).
5. **Сохранить**.
6. Включить сбор UTM: в настройках форм отметить **«Передавать UTM-метки»** — тогда в заявке придут utm_source и др.
7. Привязать webhook к формам: в каждом блоке формы (или в настройках формы) выбрать сервис приёма данных **Webhook**.

> Если webhook один на сайт — он применяется ко всем формам с выбранным сервисом «Webhook».

---

## ЧАСТЬ 3. Тест

1. В Tilda рядом с настройкой webhook есть кнопка **«Отправить тестовый запрос»** — нажми её.
   - Либо открой страницу сайта и реально отправь форму с тестовыми данными.
2. В Make: модуль Custom webhook поймает заявку и **определит структуру** (Determine data structure станет зелёным).
3. Теперь вернись в Create a Contact / Create a Lead и **сопоставь поля** (Name, Phone, Email), если они ещё не выбраны — после получения структуры в выпадашках появятся реальные поля Tilda.
4. Сохрани сценарий, **ON**, отправь ещё одну тест-заявку.
5. Проверь в Kommo: сделка **Tilda: …** на этапе **Первичный контакт**, контакт с телефоном/email, в поле Channel = `Tilda`.

---

## Если что-то красное
- **Webhook не ловит тест** → проверь, что URL в Tilda вставлен полностью и сценарий в Make сохранён (на этапе определения структуры он сам слушает, ON не обязателен).
- **Поля пустые в Kommo** → структура определилась по «пустому» тесту Tilda. Отправь реальную заявку с заполненными Name/Phone/Email, потом пересопоставь поля.
- **Имена полей не Name/Phone/Email** → Tilda отдаёт поля по их `name` из формы. Открой в Make полученный бандл и выбери реальные ключи.
- **Дубли с другими источниками** → антидубль-логику (Search Contacts + Router) добавляем тем же блоком «ПОТОМ», что и для Facebook.
