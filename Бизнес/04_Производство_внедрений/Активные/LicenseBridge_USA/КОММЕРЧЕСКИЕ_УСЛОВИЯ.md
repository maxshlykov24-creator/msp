# LicenseBridge USA — коммерческие условия

> Черновик для финализации перед отправкой клиенту.

## Рекомендуемая модель

Проект лучше продавать одним понятным пакетом на 3 недели, но внутри показать этапы:

1. **Аудит и план настройки** — понять текущую систему и точки потерь.
2. **Лиды, связь, распределение** — закрыть главную боль.
3. **Задачи, сроки и дисциплина** — контроль следующего шага и времени на этапах.
4. **Дашборд для РОПа** — понятная аналитика, которая автоматически подтягивает данные из Kommo.

Так клиент покупает не абстрактную «настройку CRM», а понятный результат: заявки доходят, менеджеры работают по правилам, РОП видит картину в дашборде.

## Вариант формулировки для клиента

> Предлагаю идти проектом на 3 недели. Внутри сначала быстро проверяем текущую систему и фиксируем план настройки, затем закрываем лиды, связь и распределение, после этого настраиваем контроль задач и времени на этапах, а в конце собираем дашборд для РОПа с ключевыми метриками.
