Новая форма Facebook в Kommo

Пошаговая инструкция: как добавить сценарий в Make, чтобы заявки с формы Facebook Lead Ads автоматически создавали контакт и сделку в Kommo.

Как устроена система

Один сценарий = одна форма Facebook

Каждый сценарий в Make состоит из трёх модулей. Заявка проходит по цепочке слева направо: Facebook отдаёт лид → Kommo создаёт контакт → Kommo создаёт сделку и привязывает её к контакту.

Аккаунты Facebook Сейчас используется один подключённый аккаунт — FB Feeder A (Paul Khopin). Аккаунт B (Александр) не используется: оба были привязаны к одной странице License Bridge USA.

Шаг 1. Создать сценарий

Make → Scenarios

1
Открой Make → раздел Scenarios.
2
Нажми Create a new scenario.
3
Добавь три модуля по порядку (подробнее в следующих разделах):
  1. Facebook Lead Ads → Watch Leads
  2. Kommo → Create a Contact
  3. Kommo → Create a Lead
4
Сразу задай понятное имя сценарию — см. раздел «Именование».

Шаг 2. Facebook Lead Ads — Watch Leads

Первый модуль — триггер

Этот модуль следит за новыми заявками с выбранной формы Facebook и передаёт их дальше по цепочке.

ПолеЗначение
ConnectionFB Feeder A (Paul Khopin)
PageLicense Bridge USA
FormКонкретная форма, которую подключаешь (например 30-06-2026 NY leads form with & From …)
Limit1 — обязательно
Limit = 1 — обязательно Kommo лучше принимает заявки по одной. Если Limit больше 1, возможны ошибки при обработке нескольких лидов одним запросом.

Шаг 3. Kommo — Create a Contact

Второй модуль — создание контакта

По каждой заявке создаётся контакт в Kommo. Данные берутся из блока Facebook Lead Ads.

ПолеЗначение
ConnectionMy Kommo connection (licensebridgeusa…)
Full NameИз Facebook: 1. Field data: Full name
Responsible User IDPavel

Зачем везде Pavel Kommo потом будет менять ответственного по сделкам, привязанным к этому пользователю. Поэтому Created by, Updated by и Responsible User ID должны совпадать.

Шаг 4. Kommo — Create a Lead

Третий модуль — создание сделки

Сделка создаётся на этапе «Новая заявка» и связывается с контактом из предыдущего шага.

Шаг 5. Тест и включение расписания

Run once → Every 15 minutes

1
Нажми Run once — сценарий выполнится один раз вручную.
2
Проверь в History, что все три модуля зелёные, и в Kommo появились контакт + сделка.
3
Если всё успешно — включи переключатель сценария и задай расписание Every 15 minutes.

Именование сценария

Чтобы не путать формы

Название должно сразу показывать: через какой аккаунт подключено, какая страница и какая форма.

Шаблон FB Feeder A (L B USA название формы)
ЧастьЗначение
FB Feeder AАккаунт Павла (Feeder A), через который подключена форма
(L B USA …)В скобках: код страницы L B USA (License Bridge USA) и далее — точное название формы из Facebook

Пример: FB Feeder A (L B USA 30-06-2026 NY leads form with …)

Типовые проблемы
