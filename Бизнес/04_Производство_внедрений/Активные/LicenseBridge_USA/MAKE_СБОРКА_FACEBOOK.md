# Сборка Make: Facebook Lead Ads → Kommo (пошагово, по кликам)

Цель вечера: лиды со всех ~15 страниц падают в Kommo на этап **Первичный контакт** (`86527439`) воронки **Pipeline** (`11274779`).

Порядок: **(1) Главный сценарий → (2) Первый фидер → (3) тест → (4) клонируем фидер на все страницы.**
Сегодня собираем **create-only** (заявка просто долетает и создаётся). Дедуп — блок «ПОТОМ» внизу, не блокирует запуск.

---

## ЧАСТЬ 1. Главный сценарий («мозги», собрать первым)

### 1.1 Создать сценарий и webhook

> **Уже есть сценарий `FB → Kommo (main)`?** Открой его — webhook мог быть создан раньше. URL был: `https://hook.us2.make.com/rtxuqa6uhrbjs15o3t8cnk82fn2mt3ry`. Если модуль **Custom webhook** уже на холсте — **не создавай новый**, переходи к п. 1.2 (жми «+» **справа** от webhook, не заходи снова в Webhooks).

> **Скрин «только Webhook response»?** Ты добавляешь модуль **не первым** или зашёл в Webhooks **после** другого модуля. Триггер Custom webhook **не показывается** в Actions — только Webhook response. Решение: **Back** → **новый пустой сценарий** → жми **только большую «+» по центру** (первый модуль) → в поиске набери **`Custom webhook`** (не открывай приложение Webhooks вручную) → выбери модуль с подписью **Trigger**.

1. Make → **Create a new scenario** (или открой существующий `FB → Kommo (main)`).
2. Большая «**+**» **по центру пустого холста** (не «+» справа от другого модуля).
3. В строке поиска набери **`Custom webhook`** → выбери модуль **Custom webhook** (тип: **Trigger**).
   - Если в списке только Webhook response — ты не на первом модуле. Вернись на шаг 1–2.
4. В модуле → **Add** → имя `fb-leads-in` → **Save**.
5. **Copy address to clipboard** — URL для всех фидеров:
   - `WEBHOOK_URL = https://hook.us2.make.com/rtxuqa6uhrbjs15o3t8cnk82fn2mt3ry` *(если создаёшь заново — будет другой URL)*
6. «Determine data structure / waiting» — нормально, заполнится после первого тест-лида из фидера.

### 1.2 Создать контакт в Kommo
6. «**+**» справа от webhook → найти **Kommo** → действие **Create a Contact**.
7. **Connection** → подключить аккаунт `licensebridgeusa.kommo.com` (если ещё не подключён — Add, авторизоваться).
8. Поля:
   - **Name** → нажми в поле, в правой панели выбери из webhook значение `name`.
   - **Phone** → выбери `phone` (телефон уже нормализуем в фидере, см. формулу ниже; либо оставь как есть на сегодня).
   - **Email** → выбери `email`.

### 1.3 Создать сделку в Kommo на нужном этапе
9. «**+**» справа → **Kommo** → **Create a Lead**.
10. Поля:
    - **Name** → впиши `FB: ` и добавь значение `name` (получится «FB: Имя клиента»).
    - **Pipeline** → выбрать **Pipeline** (id `11274779`).
    - **Status / Stage** → выбрать **Первичный контакт** (id `86527439`).
    - **Contacts / Link contact** → выбрать **ID контакта из шага Create a Contact** (поле `id` предыдущего модуля). Это привязывает сделку к контакту.
    - (необязательно сегодня) **Custom field Channel** (`143104`) → вписать значение `source` (название страницы).
11. Внизу слева **переключатель сценария → ON**. Расписание (часики) → **Immediately as data arrives**.

> Главный сценарий **никогда не клонируем** — webhook у него уникальный.

## ЧАСТЬ 2. Первый фидер (собрать, протестировать, потом клонировать)

### 2.1 Триггер Facebook
1. **Create a new scenario** → «**+**» → найти **Facebook Lead Ads** → триггер **Watch Leads**.
2. **Connection** → выбрать подключение **того кабинета**, которому принадлежит страница №1.
3. **Page** → выбрать **страницу №1**.
4. **Form** → **оставить пустым / Any** (так ловим ВСЕ формы этой страницы одним фидером).
5. **Limit** → `1`.

### 2.2 Отправка в главный сценарий (HTTP)
6. «**+**» справа → найти **HTTP** → **Make a request**.
7. Заполнить:
   - **URL** → вставить `WEBHOOK_URL` из части 1.1.
   - **Method** → **POST**.
   - **Body type** → **Raw**.
   - **Content type** → **JSON (application/json)**.
   - **Request content** → вставить шаблон ниже и подставить значения из Watch Leads (кликаешь в кавычки и выбираешь поле из левой панели: Full name, Phone number, Email):

```json
{
  "name": "{{Full name}}",
  "phone": "{{Phone number}}",
  "email": "{{Email}}",
  "source": "СТРАНИЦА_1",
  "form_id": "{{Form ID}}"
}
```
   `СТРАНИЦА_1` замени на реальное имя страницы (оно же попадёт в Channel сделки).

8. Сценарий → **ON**, расписание → **Immediately as data arrives**.

## ЧАСТЬ 3. Тест первой страницы

1. Открой **Facebook Lead Ads Testing Tool**: https://developers.facebook.com/tools/lead-ads-testing
2. Выбери **страницу №1** и её форму → **Create lead** → **Submit**.
3. В Make: оба сценария должны прогнаться (фидер → главный). Если главный «ждал структуру» — теперь он её получит.
4. Проверь в Kommo: появилась сделка **FB: …** на этапе **Первичный контакт**, контакт с телефоном/email привязан.
5. Не долетело — смотри в Make историю прогона (**History**) каждого сценария, красный модуль покажет ошибку.

---

## ЧАСТЬ 4. Клонируем фидер на все страницы

Когда первая страница работает:
1. На фидере → меню **•••** → **Clone**.
2. В клоне открой **Watch Leads** → поменяй **Page** на следующую страницу. Если страница из **второго кабинета** — поменяй ещё и **Connection**.
3. В HTTP-модуле поменяй только `"source": "СТРАНИЦА_N"` (имя новой страницы). URL и остальное не трогай.
4. Клон → **ON**.
5. Повтори для каждой страницы по чек-листу ниже.

> Главный сценарий не трогаем — все фидеры шлют в один и тот же webhook.

## Формула нормализации телефона (+1XXXXXXXXXX)

Чтобы телефоны были в одном формате (нужно для будущего дедупа), оберни телефон этой формулой.
Где вставлять: либо в HTTP-теле фидера вместо `{{Phone number}}`, либо в главном сценарии в поле Phone модуля Create a Contact.

```
{{ "+1" + right(replace(Phone number; "/[^0-9]/g"; ""); 10) }}
```
Что делает: убирает всё кроме цифр → берёт последние 10 цифр → ставит `+1` впереди.

## ПОТОМ (после того как заявки уже падают) — дедуп

Добавить в **главный сценарий** ПЕРЕД созданием контакта:
1. Между webhook и Create a Contact вставить **Kommo → Search Contacts** по нормализованному телефону.
2. После него — **Router** (Flow Control):
   - **Ветка «не найдено»** (фильтр: результат Search пустой) → текущие Create a Contact + Create a Lead.
   - **Ветка «найдено»** (фильтр: есть результат) → **Kommo → Create a Note** в найденную сделку: «повторная заявка FB: {{source}}». Если активной сделки нет — Create a Lead на существующий контакт.
3. Включить встроенное определение дублей в Kommo (Настройки) по телефону/email.

## План Б (если webhook так и не находится) — без главного сценария

Каждый фидер сам создаёт сделку в Kommo. Логику придётся клонировать на 15 страниц, зато **webhook не нужен**.

1. **Create a new scenario** → «+» → **Facebook Lead Ads** → **Watch Leads** (страница, форма = конкретная форма, см. ниже).
2. «+» → **Kommo** → **Create a Contact** (Name, Phone, Email из Watch Leads).
3. «+» → **Kommo** → **Create a Lead** (Pipeline `11274779`, этап `86527439`, контакт = `id` из шага 2).
4. **ON** → протестировать → **Clone** на остальные страницы.

> В этом Make **нет «Any form»** — на каждую форму отдельный выбор в Watch Leads (или один фидер на страницу, если форма одна активная).

## Если что-то красное (быстрая диагностика)
- **Watch Leads не видит страницу** → Facebook → Settings → Business Integrations → открыть приложение Make → отметить нужные страницы → Save.
- **HTTP 401/403 от webhook** → проверь, что URL вставлен полностью и главный сценарий **ON**.
- **Сделка без контакта** → в Create a Lead не выбран `id` контакта из шага Create a Contact.
- **Телефон кривой** → применить формулу нормализации выше.
