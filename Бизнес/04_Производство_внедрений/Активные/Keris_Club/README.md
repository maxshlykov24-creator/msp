# Keris Club

> Единая CRM-система на amoCRM для экосистемы Keris Club: питомник, груминг и общая клиентская база.

---

## О проекте

Keris Club — авторский премиум-питомник мальтипу F1 (8+ лет, шоу-класс, FCI), который вырастает в экосистему из трёх направлений: **питомник** (работает), **груминг** (запуск ~2 мес.) и **передержка** (перспектива). Запрос — выстроить систему «от начала до конца» на единой базе, а не точечный бот.

Предложение: **2 модуля сейчас + дашборд = 220 000 ₽ за 4 недели**. Аккаунт amoCRM создаётся с нуля, далее строятся процессы по направлениям. Передержка — отдельный будущий этап вне цены.

## Коммерческая сводка

| Модуль | Срок | Стоимость |
|--------|------|-----------|
| Этап 0 + Питомник (аккаунт с нуля) | ~12–14 дней | 110 000 ₽ |
| Груминг (кастомная запись) | ~7–9 дней | 80 000 ₽ |
| Дашборд KPI | ~3 дня | 30 000 ₽ |
| **Итого** | **4 недели** | **220 000 ₽** |

Оплата по результату: 80 000 (старт) → 80 000 (после питомника) → 60 000 (после груминга + дашборда). Клиент не платит вперёд за весь объём.
Гарантия срока: за каждую неделю просрочки по нашей вине — 6 мес подписки amoCRM в подарок (до 12 мес).
Ежемесячные расходы на стороне клиента: amoCRM 1199 ₽/польз. (мин. 2), сервер ~700 ₽/мес, **номерной канал ~4000 ₽/мес за номер** (≈2600 ₽ при оплате за год; эконом — 1 номер, премиум — 2), бот Telegram бесплатно/до ~1000 ₽, ИИ-обработка по объёму, SMS — по объёму. *(Уточнено 24.06.2026 — см. ниже.)*
