## 1. Утверждено Мишей (не переделываем)

- **Общая логика добавления заявки** одинакова для всех видов (продажа = эталон), лишнее в каждом виде убирается.
- **Продажа компании** — структура и порядок полей в целом согласованы (возможны мелкие доработки по визуалу).
- **Сертификат пластиковый** — структура согласована, доводка деталей (чаевые, остаток на сертификате).
- **Поиск товара**: приоритет — сканирование (пистолет), затем артикул, затем поиск по названию. Под маркировку — обяз. скан.
- **Касса не отслеживает локацию товара.** Консультант проверяет наличие ДО создания заявки и сам выбирает вид. Виды заявок не меняются автоматически.
- **Списание товара** — автоматически при переводе в «Успех».
- **Скидка**: на товар или весь чек, в % или ₽. 100% = подарок. Жёстких ограничений «не больше N%» не ставим.
- **Сертификат как способ оплаты**: ввод номера → видно остаток, можно списать часть (не больше номинала). Кнопка «остаток» подставляет сумму.
- **Переплата по сертификату — это возврат, не сдача** (оформляется отдельно как возврат).
- **Кнопка «остаток / вся сумма»** в оплате — подставляет недостающую сумму.
- **Чаевые**: либо консультант забрал наличкой сразу, либо задача Эдвину выдать (как со сдачей). Не только через Эдвина.
- **Комментарий — НЕ обязателен** по умолчанию (обяз. только там, где явно указано в оригинале ТЗ).
- **Этап продажи**: Миша — только «Успех» (если недоплата/передумал — переоформлять как отложку). В прототипе пока оставлено гибкое сохранение (см. §4 п.12 — переоформление без потери данных отложено).
- **Эдвин** видит сдачи: со статусом «не выдан» отправляет (галочка), «не выдан» → на след. день авто «выдан».

2. **Удалить нерабочие этапы** «ушёл смотреть конкурентов» / «не подошёл размер» — не заменять.
3. **Объединение сделок слив↔продажа**: менять ли номер заявки, как считать объединённые. Отложено.
4. **Товарные потоки / склад** (МойСклад): у товара 3 статуса — наличие (в наличии/резерв/нет), местоположение (Пятницкая/Бауманская/аренда/ателье/СДЭК/в пути/контрагент), привязка к заявке. Касса показывает только «в наличии или нет» + в каком магазине. Фильтр поиска по магазинам. Консультант принимает и перемещает товар через склад (списание — только по причине, через заявку).
5. **Имя клиента — приоритет «крайнего»**: имя, скорректированное консультантом, перетирает старое при завершении сделки.
6. **Частичная выдача (5 человек по частям)** для компании: как отслеживать выданное/оставшееся. Открытый вопрос.
7. **Банк-интеграция**: автоперевод в «Успех» при поступлении денег на счёт (подписка ~1000 ₽/мес или дольше без). Не сейчас.

9. **Триггер «Успех» сертификата** при фактическом использовании (баланс=0), а не при оплате.
10. **Память формы при переходах между разделами** (localStorage) — не вводить заново.

## 5. Соответствие исходному ТЗ (итерация «полное ТЗ», 11.06 вечер)

Все 16 видов заявок — **рабочие формы** по единому утверждённому паттерну (объединение карточек, «Общая сумма до скидки», Скидка+Оплата, Сдача→Эдвин, Чаевые, авто-слив по телефону, комментарий не обяз. кроме где требует ТЗ). Порядок полей выстроен по приоритету ТЗ.

| 2.2 | Продажа компании | ✅ | + дата оплаты, адрес магазина |

| 2.5 | **Отложка** | ✅ новое | отложенные товары, срок, оплата (вкл. сертификат), доплата, сдача→Эдвин, этапы |
| 2.6 | **Обещание** | ✅ новое | интересующие товары, «актуально до», источник+комментарий обяз., этап «Дано обещание» авто |

| 5.2 | **Обмен** | ✅ новое | позиции к возврату + новые, разница авто, доплата (оплата) / возврат (Эдвин), этап «Успех» |

**Сквозные фичи ТЗ (добавлены везде, где нужно):**
- **Дата оплаты** — авто=сегодня, редактируемая (во всех денежных формах).
- **Доплата** — кнопка раскрывает вторую оплату на остаток (Аренда, Отложка, Обмен).
- **Адрес магазина** — авто из справочника `STORE_ADDRESS`, чип в форме и строка в карточке заявки.
- **Возврат денег → Эдвин** — `ReturnBlock`, при «не возвращено» создаёт задачу в очереди Эдвина.
- **Этапы по виду заявки** — в списке смена этапа использует `STAGES_BY_KIND[kind]`, а не общий список.
- **Call-менеджер** — поле в онлайн-видах (Сертификат электр., Доставка).

**Решения по умолчанию (помечены в формах):**
- Доплата/возврат — прототип на моке (вторая оплата / запись в очередь Эдвина), без реального банка.
- Даты выдачи/возврата аренды и дата оплаты — авто=сегодня, ручное изменение.
