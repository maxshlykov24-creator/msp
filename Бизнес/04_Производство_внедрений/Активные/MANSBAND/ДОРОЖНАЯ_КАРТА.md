## Приоритеты прямо сейчас

```
1. КАССА         — блокирует всё остальное (без кассы нет корректного учёта и KPI)
2. СКЛАД         — платформа МойСклад: полупарки, комплекты, номенклатура
3. CRM           — автоматизации, ИИ-инструменты, статистика
```

## Касса (блокирующий блок)

**Цель:** кассир и консультанты работают через кассу — CRM обновляется автоматически, KPI считается без ручного ввода.

**Ключевые результаты:**
- ТЗ на кассу (Word) + база знаний + Миро с зонами ответственности
- Консультант через кассу двигает этапы сделки (Отложен → Собран → и т.д.)
- Снабженец через кассу/склад двигает: Ждёт товар → Товар в магазине
- % консультанта привязывается автоматически (в т.ч. при переходе клиента между шоурумами)
- Кассир фиксирует провалы + причины + номера → этап «Можно дожать» → кол-менеджер дожимает
- Статистика KPI и конверсии по консультантам

**Апсейл:** интеграция оценки кол-менеджера через ИИ (пункт CRM 6а)

## Склад (МойСклад)

**Цель:** полная платформа учёта с аналитикой и контролем консультантов.

**Ключевые результаты:**
- Шаблоны: первичная номенклатура (фабрика) + вторичная (наша) + приёмка
- Комплекты: правильные/неправильные полупарки с детализацией → видят консультанты и кол-менеджер
- Ежедневная таблица новых полупарков → контроль консультантов ‼️
- Закупочная цена (руб/долл) + розничная цена
- Автоминимальный остаток → система подсказывает когда закупать
- Статистика + таблица для товароведа
- База знаний с майн-картой

**Визуал-цель (из референса):**
> Кольцевая диаграмма по запасам (В работе / Доступно / Резерв / Медленно оборачиваемые).
> Пороги: зелёный — норма, жёлтый — внимание, красный — превышение.
> «Не просто сколько ткани, а насколько она здоровая для бизнеса.»

## CRM

**Цель:** система работает на данных, не на ощущениях. Ручной труд Ильи заменяется автоматикой.

### Срочное (апрель 2026)
- Перейти на дешёвую телефонию (Миша)
- Сохранить материалы Максима на Яндекс Диск (4 части)

### Аналитика
- Статистика по дате создания сделки (снежный ком по месяцам) — упрощённое ТЗ
- УПД автоматически в CRM
- Оценка звонка клиентом (IVR после звонка)
- Загрузка базы телефонов из WhatsApp в CRM

### ИИ-блок (следующий горизонт)
- **Камеры:** уникальные посещения + факт покупок
- **Оценка кол-менеджера:** автоматический разбор чатов/звонков по правилам → нарушения, рекомендации, штрафы (замена ручной работы Ильи)
- **Бот:** первые сообщения онлайн → доведение до даты встречи
- **Анализ провалов:** выжимка частых причин из ОС
- **Частые вопросы:** мониторинг чатов и звонков

## Программа лояльности

**Когда:** после стабильной работы кассы

**Механики:**
- Сторис с отметкой → отзыв за бонусы
- Уникальные промокоды
- Реферальная программа (кэшбэк для постоянных)
- Кэшбэк для Сары бонусами
- Пирамида лояльности за советы (механику проработать)
