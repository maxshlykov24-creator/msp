## Перед работой с бонусами

- [ ] Заказ **не создавать сразу «Доставлен»** — проходить обычные этапы
- [ ] Новый клиент **не в ПЛ**, пока не поставишь **Статус ПЛ = Активен** и **Уровень ПЛ**
- [ ] После любых правок по бонусам — **выйти из заказа и зайти снова** (поля обновляются не мгновенно)

---

## Регистрация клиента в программе

- [ ] Открыть **Заказ покупателя** → справа блок полей лояльности
- [ ] **Статус ПЛ** → **Активен**
- [ ] **Уровень ПЛ** → **Знакомство** (или нужный уровень)
- [ ] **Сохранить** → выйти из заказа → зайти снова
- [ ] Проверить: **Активно бонусов** = 300 (приветственные), есть запись в **Комментарии ПЛ**

---

## Списание бонусов в заказе

- [ ] Убедиться, что клиент **Активен** и есть **Активно бонусов**
- [ ] В поле **Списано бонусов** указать сумму (не больше **30% от заказа**)
- [ ] **Сохранить** → выйти → зайти снова
- [ ] Проверить **Списано бонусов**, **Комментарии ПЛ**, сумму заказа
- [ ] Отменить списание: **Списано бонусов = 0** → сохранить → выйти → зайти

---

## Ручное начисление / списание (вне заказа)

- [ ] **Контрагент** → **Документы** → **Операции с баллами**
- [ ] **+ Операция** → начислить или списать → сумма + **обязательный комментарий**
- [ ] Баланс смотреть в карточке контрагента: **Активные бонусы**, **Ожидают активации**

---

## Уровень и статус

- [ ] Сменить уровень: в **заказе** поле **Уровень ПЛ** (дублируется в карточке контрагента)
- [ ] **Понижать уровень вручную нельзя** — система откатит; только повышение
- [ ] Ручная смена уровня **фиксирует пол** — автоперерасчёт за год не опустит ниже
- [ ] **Заблокирован** — начисления и списания недоступны

---

## Если что-то не так

| Ситуация | Действие |
|----------|----------|
| Поля лояльности пустые после регистрации | Выйти из заказа → зайти снова; если не помогло — внести любое изменение в заказ и повторить |
| Списали меньше, чем просил | Превышен лимит 30% — смотри **Комментарии ПЛ** |
| Баланс в заказе не совпадает с контрагентом | Выйти/зайти в заказ; источник правды — **карточка контрагента** |
| Ошибка / непонятное поведение | Скрин + номер заказа → MS Product |
