# `агенты/` — вспомогательные правила Cursor (курс)

Здесь лежат **не** корпоративные «агенты MS Product», а инструменты из обучения (модуль выбора моделей), которые подключаются через `.cursor/rules/*.mdc` в корне `Бизнес/`.

**`@сео`:** данные и шаблоны в **`../агенты/СЕО/`** от корня репозитория (родительская папка к `Бизнес/`). Правило: [`сео.mdc`](../.cursor/rules/сео.mdc).

**`@архитектор`:** данные и шаблоны в **`АРХИТЕКТОР/`** внутри этой папки (от корня `Бизнес/` путь `агенты/АРХИТЕКТОР/`). Правило: [`архитектор.mdc`](../.cursor/rules/архитектор.mdc). [README](АРХИТЕКТОР/README.md).

Сейчас:

- **`МОДЕЛЬ/`** — контекст для команды **`@модель`** (рекомендация AI-модели под задачу). Правило: [`.cursor/rules/модель.mdc`](../.cursor/rules/модель.mdc).
- **`УБОРЩИК_ДОКУМЕНТОВ/`** — контекст для команды **`@уборщик`** (организация файлов, логи самообучения). Правило: [`.cursor/rules/уборщик.mdc`](../.cursor/rules/уборщик.mdc). [README](УБОРЩИК_ДОКУМЕНТОВ/README.md).

Единую схему бизнес-агентов и конфигов компании — по мере необходимости согласовывать с зонами `01_`…`08_` и [`РЕГЛАМЕНТ_ЗОНЫ_БИЗНЕС.md`](../99_Системное/РЕГЛАМЕНТ_ЗОНЫ_БИЗНЕС.md); не плодить дубли без ясного назначения.
