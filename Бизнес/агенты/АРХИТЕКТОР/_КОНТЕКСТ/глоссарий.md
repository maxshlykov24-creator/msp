# Глоссарий (бизнес + amoCRM + «МойСклад»)

Краткие определения для единого языка в ТЗ и схемах.

| Термин | Значение |
|--------|----------|
| **LTV** | Lifetime Value — суммарная прибыль или выручка от клиента за период жизни отношений. |
| **CAC** | Customer Acquisition Cost — стоимость привлечения клиента (маркетинг + продажи на одного платящего). |
| **Воронка** | Последовательность этапов продажи; в amoCRM — **воронка (pipeline)** и **статусы**. |
| **Сделка / лид** | В amoCRM заявка может вестись как **лид** и конвертироваться, либо работа идёт в **сделках** (зависит от настройки аккаунта и сценария). |
| **Покупатель (Customers)** | Модель повторных продаж в amoCRM (если используется); не путать с разовым лидом без схемы Customers. |
| **Контакт / компания** | В amoCRM сущности **Contact** и **Company**; связи со сделкой. |
| **Заказ покупателя** | В МС документ **`customerorder`** — типичная точка входа продажи. |
| **Счёт покупателю** | В МС **`invoice`** — выставление счёта (по процессу клиента). |
| **Отгрузка** | В МС **`demand`** (отгрузка) — списание со склада; цепочка может включать инвойс до/после по регламенту. |
| **Склад / остаток** | **`store`**, отчёты по stock; резерв может зависеть от настроек и документов. |
| **Контрагент** | В МС **`counterparty`** (покупатель/поставщик); тип организации и реквизиты. |
| **Webhook** | HTTP-уведомление о событии в системе; основа для real-time интеграций (с подпиской и проверкой дубликатов). |
| **Идемпотентность** | Повтор того же запроса не создаёт дубликат (часто внешний ключ, `externalCode`, проверка «уже обработано»). |
| **Middleware** | Прослойка (n8n, свой сервис) между amoCRM и МС: маршрутизация, ретраи, маппинг, логирование. |

Термины **AS-IS** / **TO-BE** — «как сейчас» / «как целевое состояние».

При противоречии с официальной документацией платформ — приоритет у документации; здесь смысловые ориентиры для ТЗ.
