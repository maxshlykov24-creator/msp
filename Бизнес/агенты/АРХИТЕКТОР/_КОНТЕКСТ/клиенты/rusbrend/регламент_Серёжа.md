# Чеклист смены — Серёжа

**Полная инструкция с визуалом:** [`инструкция/Серёжа_МойСклад.html`](инструкция/Серёжа_МойСклад.html) — открыть в браузере, можно сохранить в PDF (`Cmd+P`).

**Система:** МойСклад + таблица «Береза групп склад»  
**Обновлён:** 2026-06-30

---

## Начало смены

- [ ] МойСклад → **Отгрузки** → вчерашние партии в статусе **Отправлена**
- [ ] Таблица **Береза групп склад** → проверить строки на сегодня
- [ ] Заполнить **U — всего коробов** (если пусто)
- [ ] Флажок **I — Отгрузить** → подождать 5–10 сек → появился ID / ссылка
- [ ] Если нет → лист **errors** → общий чат → Макс

---

## Распределить сборщикам (массово)

- [ ] Отгрузки → закладка **Распределить** (или фильтр **Новая**) → **Найти**
- [ ] Выделить все → **Изменить** → **Сборщик**
- [ ] **Статус** → **В сборке**
- [ ] Сообщить сборщикам

---

## Сборка и отгрузка

- [ ] Контроль: фильтр **В сборке**
- [ ] Проверил короб → **На проверке** → **Проверено**
- [ ] Печать этикетки короба
- [ ] Паллета уехала → все коробы партии → **Отправлена**

---

## Приёмка (когда приехал товар)

- [ ] **Закупки → Заказы поставщику** → открыть заказ (создал Дима)
- [ ] **Создать документ → Приёмка** → фактическое кол-во → **Сохранить**
- [ ] Статус **Найдено расхождение** → сообщить Диме

---

## Если что-то не так

| Ситуация | Действие |
|----------|----------|
| Нет отгрузки после флага | errors → проверить **U** |
| Непонятная ошибка | Скрин → общий чат → Макс |
| Случайно удалил | **Показатели → Корзина** → восстановить |

---

> **Макс** — система, errors (общий чат). **Дима** — товар, план, заказы.
