# 05_Маркетинг_и_контент

> Привлечение внимания, контент, запуски, описание экспертизы наружу.

---

## О папке

Материалы для **роста спроса**: идеи постов, тексты, планы запусков, описание воронок на входе, ссылки на площадки. Не путать с «продажами в CRM» — то в [`03_Продажи`](../03_Продажи/README.md).

## Содержимое

- Контент-планы, черновики публикаций.
- Описание позиционирования для маркетинга (кратко; стратегия-«куда» в [`01_`](../01_Стратегия_и_управление/README.md)).
- Медиакиты, если ведёшь их локально.

## Как использовать

- Черновики из ассистентов и нейросетей можно складывать в `00_Inbox`, финальные версии — сюда по рубрикам/датам.
- Темы контента сверяй с продуктовой линейкой: [`06_Продукт_и_упаковка`](../06_Продукт_и_упаковка/README.md) — о чём говоришь в контенте, то и продаётся.
- Маркетинговые активности координируй со стратегическими целями: [`01_Стратегия_и_управление`](../01_Стратегия_и_управление/README.md).

## Связи

- [`01_Стратегия_и_управление`](../01_Стратегия_и_управление/README.md) — куда вписан маркетинг.
- [`06_Продукт_и_упаковка`](../06_Продукт_и_упаковка/README.md) — о чём говорим в контенте.
- [`03_Продажи`](../03_Продажи/README.md) — куда ведём трафик.
