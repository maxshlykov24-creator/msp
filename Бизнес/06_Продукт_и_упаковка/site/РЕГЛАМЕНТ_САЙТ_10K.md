# Регламент: сайт уровня $10 000 (Cursor)

> **Версия:** 1.0 | **Дата:** 2026-06-04  
> **Для кого:** Максим / MS Product — когда нужен красивый, «агентский» сайт, а не generic AI-slop.

**Когда пользователь говорит «хочу сделать сайт»** — ассистент открывает этот файл, выдаёт структурированный бриф и **не начинает код без референсов и ответов на наводящие вопросы**.

---

## 1. Планка качества

- Цель — сайт, который **выглядит как работа за ~$10 000** (уровень студии/агентства), а не шаблон за $200.
- Инструмент сборки: **Cursor** (не Claude Code), но **методология** — из гайда ниже.
- Сначала **вид и референсы**, потом код. Без «сделай красиво» в вакууме.

**Два навыка из начала ролика** (обязательно проверить/внедрить в Cursor перед серьёзной сборкой):

| Skill | Назначение | Claude Code | Cursor (аналог) |
|-------|------------|-------------|-----------------|
| **frontend-design** (Anthropic) | «Вкус», не-generic эстетика, production-grade UI | `.claude/skills/` | `npx skills add https://github.com/anthropics/skills --skill frontend-design --agent cursor` → `~/.cursor/skills/` или `.cursor/skills/` |
| **ui-ux-pro-max** | Design intelligence: палитры, типографика, UX-гайды, стеки | plugin / `.claude/skills/` | `uipro init --ai cursor` или `npx skills add https://github.com/nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max --agent cursor` |

**Статус на 2026-06-04:** skills **не установлены автоматически** — при первом запуске проекта сайта: проверить наличие в `~/.cursor/skills/`, при отсутствии — установить и зафиксировать в логе задачи.

**Cursor Skills вообще:** тот же open standard, что Claude Code — см. [skills.sh](https://skills.sh), [Agent Skills spec](https://agentskills.io). Встроенные skills Cursor: `~/.cursor/skills-cursor/` (не трогать).

## 3. Принцип работы (главное)

```
Референсы (как хочу) → наводящие вопросы → design system / прототип → код → полировка → деплой
```

**Не так:** «сделай лендинг для X» → сразу код → непонятный результат.

**Так:** пользователь приносит **3–5 примеров** (скриншоты, ссылки Dribbble/Behance, живые сайты) + ответы на вопросы → от этого «пляшет» вся система.

## 6. Протокол ассистента при старте «хочу сайт»

### Шаг 0 — выдать этот регламент (краткая выжимка в чат)

### Шаг 1 — референсы (блокер)

Спросить:

1. Есть ли **3–5 примеров** «как должно выглядеть»? (Dribbble, живые URL, скрины)
2. Что **точно нравится** в каждом? (hero, шрифт, цвет, анимация, «воздух», тёмная/светлая тема)
3. Что **точно не нужно**? (шаблонность, «AI slop», стоковые иллюстрации, перегруз анимацией)

**Без референсов — не переходить к коду.** Максимум: wireframe-описание или moodboard-запрос.

### Шаг 2 — наводящие вопросы (обязательно)

Задавать **последовательно**, 2–3 за раз:

| # | Вопрос |
|---|--------|
| 1 | **Тип сайта:** лендинг, визитка, SaaS, портфолио, e-commerce, другое? |
| 2 | **Аудитория и действие:** кто заходит и что должен сделать (CTA)? |
| 3 | **Бренд:** есть лого, цвета, шрифты, tone of voice? |
| 4 | **Стек:** React/Vite, Next.js, чистый HTML+Tailwind (как `site/index.html`), другое? |
| 5 | **Страницы/секции:** какие блоки обязательны (hero, кейсы, pricing, FAQ, контакты)? |
| 6 | **Контент:** тексты готовы или нужен черновик? |
| 7 | **Анимация:** минимум / умеренно / «вау» (как в референсах)? |
| 8 | **Деплой:** GitHub Pages, Vercel, свой VPS, домен уже есть? |
| 9 | **DoD:** как поймём, что сайт готов? (мобилка, PageSpeed, OG-превью, форма) |

### Шаг 3 — skills и инструменты

- Проверить **frontend-design** + **ui-ux-pro-max** в Cursor.
- При необходимости — MCP 21st.dev (если настроен в проекте).

### Шаг 4 — прототип вида

По `.cursorrules`: **сначала прототип/mockup на моках** → согласование → потом логика и прод.

### Шаг 5 — сборка → полировка → деплой

Этапы из гайда:

1. **Inspiration** — референсы зафиксированы  
2. **Build** — scaffold по референсам + skills  
3. **Refine** — 21st.dev, React Bits, polish pass  
4. **Deploy** — GitHub + Vercel / см. `README.md` в этой папке

## 8. Чеклист «$10K vs generic» (кратко)

- [ ] Есть референсы, а не только текстовый бриф  
- [ ] Уникальная типографика (не Inter + фиолетовый gradient по умолчанию)  
- [ ] Продуманный hero + чёткий CTA  
- [ ] Микро-анимации осмысленные, не декоративный шум  
- [ ] Мобилка проверена  
- [ ] OG / favicon / meta  
- [ ] Polish pass после первого черновика
