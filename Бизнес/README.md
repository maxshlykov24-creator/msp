# Бизнес

> Зона **компании** в vault: финансы, продажи, производство, маркетинг, продукт и системные описания для людей и ИИ. Ведётся так, чтобы сюда можно было подключать сотрудников и партнёров без смены структуры папок.

---

## О папке

`Бизнес/` — артефакты и процессы **компании MS Product** (клиенты, деньги компании, офферы, внедрения, ИИ-агенты). Сейчас все функции по сути закрывает **владелец**; по мере роста те же папки (`01_`…`08_`) наполняются ролями, агентами и регламентами, а не новой «отдельной папкой под команду». Каждая операционная зона содержит `_ai/` для артефактов, генерируемых ИИ-агентами.

Не заменяет `Личное/`: сырьё для быта и духа — в [`Личное/0. Входящее`](../Личное/0.%20Входящее) и ветках профиля по [`СТРУКТУРА_И_ПРИНЦИПЫ.md`](../Личное/1.%20Профиль/СТРУКТУРА_И_ПРИНЦИПЫ.md). Личная стратегия владельца и личные KPI — в [`РАСШИРЕННЫЙ_КОНТЕКСТ.md`](../РАСШИРЕННЫЙ_КОНТЕКСТ.md); дублировать их сюда объёмом не нужно — здесь то, что относится к **деятельности компании** и может жить в общем доступе (с учётом конфиденциальности по клиентам).

**Разграничение:** в `Бизнес/00_Inbox` — хаос по **работе и клиентам**; личный инбокс — в `Личное/0. Входящее`.

Глобальный срез владельца (стратегия, стек, личные цели): [`РАСШИРЕННЫЙ_КОНТЕКСТ.md`](../РАСШИРЕННЫЙ_КОНТЕКСТ.md). Слепок **компании** под эту зону: [`99_Системное/ПРОФИЛЬ_ПРОЕКТА.md`](99_Системное/ПРОФИЛЬ_ПРОЕКТА.md).

**Правила ведения папок (README, Inbox, проекты, ICQ):** [`99_Системное/РЕГЛАМЕНТ_ЗОНЫ_БИЗНЕС.md`](99_Системное/РЕГЛАМЕНТ_ЗОНЫ_БИЗНЕС.md) — в том числе карта **«офисное здание»** (вход → этажи → кабинеты → при необходимости шкафы).

## Как использовать

1. Новые файлы по бизнесу не по адресу — сначала в `00_Inbox`.
2. Для задач ИИ по работе: `@Бизнес` или конкретная папка + [`ПРОФИЛЬ_ПРОЕКТА.md`](99_Системное/ПРОФИЛЬ_ПРОЕКТА.md) (контекст компании; личные предпочтения и договорённости с ассистентом — в [`СИНХРОН_С_АССИСТЕНТОМ.md`](../СИНХРОН_С_АССИСТЕНТОМ.md)).
3. После наполнения Inbox — прогоняй раскладку: список файлов → целевая зона → перенос.
4. **Отдельное окно Cursor только на эту папку** (`Файл → Открыть папку → Бизнес/`): действует [`.cursorrules`](.cursorrules) в корне `Бизнес/` — контекст MS Product без личного vault; удобно для сотрудников и ИИ только по компании.
