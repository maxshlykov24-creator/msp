# 02_Финансы_и_риски

> Деньги бизнеса: цели по выручке, долги, подушка, юнит-экономика — на уровне документов и расчётов.

---

## О папке

Финансовый контур **предпринимательской** деятельности: планы прибыли, контроль обязательств (в т.ч. «хвосты» — детали в [`01_`](../01_Стратегия_и_управление/ХВОСТЫ.md)), модели перехода на фиксированные чеки. Личные траты и семейный бюджет — только если явно разграничиваешь подпапкой и не смешиваешь с операционкой компании.

## Содержимое

- [`РЕКВИЗИТЫ_ИП.md`](РЕКВИЗИТЫ_ИП.md) — ИНН, ОГРНИП, адрес, расчётный счёт и реквизиты банка (для счетов и договоров).
- [`ГРАНИЦЫ_И_ИСТОЧНИКИ.md`](ГРАНИЦЫ_И_ИСТОЧНИКИ.md) — что лежит в `02_`, что в [`РАСШИРЕННЫЙ_КОНТЕКСТ`](../../РАСШИРЕННЫЙ_КОНТЕКСТ.md); шаблон юнит-экономики; место для указания источника правды по таблицам.
- Таблицы целей и фактов (или ссылки на учётные системы).
- Списки долгов/кредиторов в обезличенном виде при необходимости.
- Заметки по рискам (зависимость от одного клиента, сезонность и т.д.).

## Как использовать

- Сверяй цели из [`01_Стратегия_и_управление`](../01_Стратегия_и_управление/README.md) с фактом: план → факт → дельта.
- Обновляй при изменении модели ценообразования (связь с [`06_Продукт_и_упаковка`](../06_Продукт_и_упаковка/README.md)).
- Чувствительные цифры — по правилам безопасности проекта; в README зон достаточно логики, без полных ПДн.

## Связи

- [`01_Стратегия_и_управление`](../01_Стратегия_и_управление/README.md) — цели, к которым подводят цифры.
- [`06_Продукт_и_упаковка`](../06_Продукт_и_упаковка/README.md) — влияние ценообразования на юнит-экономику.
