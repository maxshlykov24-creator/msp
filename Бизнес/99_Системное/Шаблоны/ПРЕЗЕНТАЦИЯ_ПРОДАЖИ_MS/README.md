> **Эталон UI/продукта (7 слайдов, тёмный MS):** MANSBAND Касса — [`04_Производство_внедрений/Активные/MANSBAND/kassa-prototype/presentation/index.html`](../../04_Производство_внедрений/Активные/MANSBAND/kassa-prototype/presentation/index.html)

Один HTML-файл, открывается в браузере. Стрелки / пробел — листать слайды. Без PowerPoint, без сборки.

**Для новых CRM-проектов** — бери за основу **Keris Club** (12 слайдов, светлая палитра клиента, модули, mock UI). Этот README — для **короткой** презентации продукта с прототипом (касса, интерфейс).

---

## Когда использовать

- Встреча с собственником / ЛПР **до** старта разработки
- Есть **прототип** или макет — показываем «можно потрогать»
- Нужно: боль → решение → демо → цена с DoD → «стартуем?»
- **Не** для: внутренней техдокументации, онбординга команды, постмортемов

---

## Структура (7 слайдов — не раздувать)

| № | Слайд | Задача |
|---|--------|--------|
| 1 | **Обложка** | Лого клиента + одна фраза ценности + подзаголовок «под вас, не коробка» |
| 2 | **Что болит** | 4 карточки — конкретные боли из разговора с клиентом |
| 3 | **Решение** | Одно предложение + 3–4 пункта «что получает продавец/бизнес» |
| 4 | **Демо** | 6 карточек фич прототипа (то, что реально покажете на экране) |
| 5 | **Почему это правильный выбор** | 4 пункта: не ломаем CRM, масштаб, цифры, рост — **без** СДЭК/маркировки/«фазы 3» |
| 6 | **План и оплата** | 3 этапа + DoD в каждом + платежи + штрафы за просрочку + итого |
| 7 | **Финал** | «Прототип готов. Стартуем?» + один конкретный следующий шаг |

### Что **не** класть в презентацию

- Слайд «архитектура» (amoCRM → МойСклад) — только если клиент сам технарь и просит
- «Что нужно от вас»: доступы, API, открытые вопросы 54-ФЗ
- Теги MVP, Phase 2, таблицы по фазам на месяцы вперёд
- Сноски «цена от ценности / часов»
- Жаргон без объяснения: MVP, scope, ledger, metadata-driven

## Слайд «План и оплата» — обязательная логика

Три колонки `.phase` (первая с классом `.hl`):

1. **Делаю** — срок, список DoD (что = «готово»), оплата при старте + по результату  
2. **Правки** — срок, DoD (тест клиента → список → принятие), «без доплат»  
3. **Внедрение** — срок, DoD (обучение, боевой запуск, первая смена/день), финальная оплата  

Под колонками — `.penalty-row`: два штрафа + блок **Итого** (сумма и схема платежей).

**DoD пишем глаголами результата**, не процессом:

- ✅ «Первая смена закрыта через кассу»
- ❌ «Проведём обучение»

## Как сделать презентацию под нового клиента

1. Скопировать папку шаблона в проект клиента, например:  
   `04_Производство_внедрений/Активные/{Клиент}/presentation/`
2. Переименовать `TEMPLATE.html` → `index.html`
3. Положить в папку: `logo-client.png`, скопировать лого MS из [`99_Системное/БРЕНД/`](../../БРЕНД/) (`logo-ms-transparent.png` для светлых, `logo-ms.png` для тёмного шаблона)
4. В `index.html` заменить все блоки `<!-- EDIT: ... -->` (поиск по `EDIT`)
5. Подогнать слайд 6 под реальные суммы, сроки, DoD и штрафы
6. Открыть в Chrome: двойной клик по `index.html` или `open index.html`
7. На встрече: слайды 1–5 → переключиться на живой прототип → вернуться на слайд 6–7
