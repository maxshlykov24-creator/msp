# Реестр проектов, клиентов и кода

**Назначение:** единая точка входа для ИИ и команды: кто есть клиент, какой репозиторий/папка к какому внедрению относится, что не смешивать.  
**Канон:** этот файл. **Зеркало для истории:** `агенты/ФОКУС/_КОНТЕКСТ/контекст_проектов.md` (только указатель).

**Обновлять:** при новом клиенте, новом репо в vault или смене приоритетов.  
**Дата актуализации содержания:** 2026-05-10

---

## Приоритет рассмотрения задач (@фокус)

```
1. ХВОСТЫ (старые обязательства) — всегда выше новых задач
2. Клиентские дедлайны / обещанное и горящее
3. Активные внедрения (проекты с прогрессом)
4. Техподдержка (SLA: реакция ≤2ч, старт ≤1 рабочий день)
5. Системное развитие MS Product
6. Операционка
```

### 1. MANSBAND (Миша) — МойСклад / Касса

- **Суть:** Магазин мужских костюмов. ~90%+ продаж — офлайн. amoCRM внедрена (менеджер по продажам). Сейчас критично: внедрить кассу МойСклад для фиксации розничных продаж.
- **Интеграции в коде (vault):** `Бизнес/04_Производство_внедрений/Активные/MANSBAND/talkme-amojo-bridge/` — **Talk-me ↔ amoCRM через Amojo**. Это **MANSBAND (Миша)**; не относить к другим клиентам (в т.ч. не смешивать с DKAcademy).
- **Статус задач:** `Бизнес/04_Производство_внедрений/Активные/MANSBAND/СТАТУС_ЗАДАЧ.md`
- **Дорожная карта:** `Бизнес/04_Производство_внедрений/Активные/MANSBAND/ДОРОЖНАЯ_КАРТА.md`
- **Контакты:** Миша (владелец), Женя (РОП), Илья (кол-менеджер)
- **Доп. доход:** оплачиваемые часы техподдержки (много запросов)
- **Тип задач:** внедрение (касса) + техподдержка
- **Приоритет задачи "касса":** `[хвост]` — долго тянется, критично закрыть

### 2. Ван Пак (Виктория) — перенос МойСклад

- **Суть:** Перенос аккаунта МойСклад на новый домен (зафиксировать клиента за MS Product). Перенести все документы, настройки, данные за текущий год.
- **Тип задач:** внедрение (перенос) + техподдержка (мало)
- **Статус:** в начале, приоритет — сделать быстро пока клиент свежий

### 3. Дима — МойСклад / маркетплейсы

- **Суть:** Новый проект. Внедрение МойСклад для бизнеса на маркетплейсах. Есть своё производство, упаковка товара, работают только по FBO.
- **Тип задач:** внедрение (новый)
- **Статус:** начало проекта, собирать требования

### 4. DKAcademy (Максим) — бот уведомлений

- **Суть:** Внедрение Telegram-бота с уведомлениями о статусе доставки через amoCRM. Цель — прогрев клиентов на повторные продажи после первой покупки.
- **Код (полный vault):** `dkacademy-bot/` — FastAPI + aiogram, LiveInform → amoCRM, onboarding в Telegram. Документация: `dkacademy-bot/README.md`, инциденты: `dkacademy-bot/AGENT_LEARNINGS.md`, перед деплоем см. `.cursor/rules/dkacademy-bot-handoff.mdc`.
- **Стек в брифе:** amoCRM + Telegram-бот (в т.ч. упоминания вроде Selos Bot — это **не** стек MANSBAND). **Не** Talk-me / Amojo из `MANSBAND/talkme-amojo-bridge/`.
- **Тип задач:** внедрение (разработка бота)
- **Приоритет типа:** `[система]` — строит повторные продажи клиента

## Типы задач для кайдзен-маркировки

| Маркер | Значение | Пример |
|--------|----------|--------|
| `[система]` | Строит масштабируемый результат | ТЗ, интеграция, бот, настройка |
