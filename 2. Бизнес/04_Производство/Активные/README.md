# Активные

> Проекты в работе прямо сейчас.

---

## О папке

Каждый активный проект — отдельная подпапка: `КЛИЕНТ_Название/` или `YYYY-MM_Название/`. Внутри — ТЗ, переписки по сути, схемы, чек-листы.

## Структура подпапки проекта (рекомендуемая)

```
КЛИЕНТ_Название/
├── README.md          — суть проекта, контакт, статус, следующий шаг
├── ТЗ.md              — техническое задание
├── Схемы/             — диаграммы потоков, скриншоты конфигов
└── Заметки/           — дневник внедрения, вопросы, решения
```

## Как использовать

- Создавай папку при старте проекта по шаблону из [`../Шаблоны_ТЗ/`](../Шаблоны_ТЗ/README.md).
- После сдачи переноси в [`../Архив/`](../Архив/README.md).
