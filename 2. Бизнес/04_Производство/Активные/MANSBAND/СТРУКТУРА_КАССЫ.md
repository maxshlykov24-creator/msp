# Mansband — Структура кассы (МойСклад)

> Источник: актуальная таблица структуры кассы. Последнее обновление: 03.04.2026.

---

## 6 правил кассы

1. **Нет телефона — нет клиента.** У каждого контрагента обязательно должен быть номер телефона, иначе система не фиксирует его как клиента.
2. **Никаких физических движений товара без документа.** Любое перемещение, подшив или выдача — сразу в системе. Нет документа — нет действия.
3. **Любое действие фиксируется сразу.** Записывать операции в моменте, не откладывая. Данные в кассе и CRM всегда актуальны.
4. **Продажа засчитывается только при Отгрузке и Входящем платеже.** Успешная сделка = товар списан со склада + деньги в статусе Успех поступили в кассу.
5. **Аренда только с фото паспорта в системе.** При выдаче товара в аренду — прикреплять фото документа к связанной отгрузке.
6. **Смена не закрыта без сверки баланса.** В конце дня продавец сверяет наличку и переводы с данными системы. Без этого выход из аккаунта запрещён.

## Глоссарий (термины)

| Термин | Определение |
|--------|-------------|
| **Разделы** | В верхней части МойСклад: Закупки, Продажи, Товары, Контрагенты, Склад, Деньги и прочее |
| **Подразделы** | То, что внутри разделов: Заказы покупателей, Отгрузки, Входящие платежи, Исходящие платежи, Возвраты покупателей, Перемещения и прочее |
| **Сотрудник** | Пользователь со своим логином и паролем. Сотрудник = Ответственный |
| **Контрагент** | Карточка клиента. Обязательны: Имя и Телефон |
| **Канал продаж** | Источник = Откуда пришёл клиент. Обязательное поле |
| **Дополнительные поля** | Специальные поля в Заказе: Источник, Цель покупки, План. даты отгрузки, № сертификата |
| **Остатки и движение** | Раздел для контроля наличия |
| **Остаток** | Общее количество товара, включая резервы |
| **Резерв** | Товар в статусе бронирования — вычитается из остатка |
| **Доступно** | Остаток − Резерв = реально доступное для продажи |
| **Перемещение** | Документ перемещения между складами (напр. Новокузнецкая → Бауманская) |
| **Документ** | Любая сущность: Заказ, Входящий платёж, Отгрузка, Перемещение и прочее |
| **Заказ** | Заказ = Сделка. Все в разделе Заказы покупателей |
| **Статус** | Статус = Этап. Текущий статус работы с клиентом |
| **Входящий платёж** | Фиксация поступления денег (Нал, Сбер Женя и др.) + кассу |
| **Отгрузка** | Физическая передача товара клиенту → списание с остатков |
| **Исходящий платёж** | Возврат денег клиенту или оплата расходов |
| **Возврат покупателя** | Документ-отмена Отгрузки. Возвращает товар на склад |
| **Совместные продажи** | Бонус делится между двумя консультантами |
| **Оплачено** | Авто-индикатор: получены ли деньги (полностью / частично / нет) |
| **Отгружено** | Авто-индикатор: физически передан товар клиенту |
| **Баланс** | Итог взаиморасчётов. Разница между суммой Заказа и Входящими платежами |
| **Сколько мы должны** | Аванс получен, товар ещё не отдан |
| **Сколько нам должны** | Товар передан, оплата не получена |
| **Связанные документы** | Цепочка Заказ → Платёж → Отгрузка → Возврат (выше списка товаров) |
| **Фильтры** | Инструмент быстрого поиска в списках документов |
| **Флажок Проведено** | Активный статус документа. Только при нём списывается товар и учитываются деньги |

## Процессы

### Авторизация
- Вход строго под своим логином
- При передаче рабочего места — обязательно выйти из аккаунта

### Навигация
- В браузере всегда открыты: **Заказы покупателей** (раздел Продажи) и **Остатки** (раздел Склад)

### Работа с контрагентом
- Обязательны: Имя + Телефон. Без них клиент не принят в систему

### Контроль наличия
- Проверка через Остатки → смотрим на **Доступно** (Остаток минус Резерв)

### Приёмка и перемещение
- Фиксация поступления товара или отправки. Принято только при флажке **Проведено**

### Подшив в ателье
- Создаётся Перемещение на основании Заказа. Обязательно — план. даты возврата
- После оформления **убирается** статус Проведено для возврата наличия на склад

### Списание при браке
- Создаётся документ Списание **без** статуса Проведено
- Финальное подтверждение — только РОП

### Инвентаризация
- Выборочная проверка по заданию руководителя. Подраздел Инвентаризация в разделе Склад

### Оформление заказа
- Создание Заказа покупателя с заполнением всех позиций и полей

### Управление резервом
- Бесплатная отложка: 1 день → снимается автоматически
- При Входящем платеже (аванс): резерв до 14 дней

### Создание связанных документов
- Входящий платёж, Отгрузка, Перемещение — через кнопку **Создать документ** внутри Заказа

### Фиксация оплаты
- Через документ Входящий платёж на основании Заказа
- Способ оплаты: Наличные, Сбер Женя и др.
- При частичной оплате — указать конкретную сумму

### Скидки и подарки
- Скидка в рублях или процентах
- Подарок = позиция в чеке со скидкой 100%

### Факт продажи (этап Успех)
- Создать Отгрузку на основании Заказа в момент передачи товара
- Создать Входящий платёж при поступлении денег

### Совместные продажи
- Ответственный = тот, кто завершил продажу
- Второй продавец — в поле **Второй ответственный**

### Работа с дожимом
- После ухода клиента без покупки → статус **Ушёл смотреть у конкурентов** или **Не оказалось размера**
- Иначе → заполнить Причина провала + Комментарий → статус **Провал**

### Аренда
- Документ Отгрузки на основании Заказа
- Обязательно: фото паспорта или прав в файлы документа

### Продажа сертификата
- Через отдельную позицию «Сертификат»

### Оплата сертификатом
- Через Входящий платёж, Способ оплаты = Сертификат + № сертификата
- Следить за итоговым балансом Заказа

### Начисление бонусов Сара
- При создании заказа по рекомендации → поле **Сара** = номер телефона реферера

### Возвраты и обмены
- Через документ Возврат покупателя на основании Заказа
- При обмене — дополнительно создать новую Отгрузку
- Следить за корректностью баланса

### Контроль баланса (конец смены)
- Фильтровать Входящие платежи по способам оплаты
- Сверить сумму в системе с фактической наличкой и переводами
