# Правила Cursor для workspace `Бизнес/`

Эта папка нужна, когда в Cursor открыт **только** каталог `Бизнес/` (без `Личное/` и корневых агентов).

## Зачем зеркало

| Файл | Полный vault (корень) | Только `Бизнес/` |
|------|----------------------|------------------|
| `@архитектор` | `.cursor/rules/архитектор.mdc` | `Бизнес/.cursor/rules/архитектор.mdc` |
| `@сео`, `@уборщик`, `@модель` | `.cursor/rules/*.mdc` | `Бизнес/.cursor/rules/*.mdc` (пути с `../Личное/`) |

В зеркалах пути **относительны к `Бизнес/`** — иначе агенты не найдут `Личное/` и `Входящее/` при изолированном workspace.

## Канон

При работе в **полном vault** приоритет у корневых `.cursor/rules/`.  
Дубли в `Бизнес/.cursor/rules/` **не удалять** — они обслуживают отдельное окно MS Product.

## Инбокс

Единый инбокс vault — **`Входящее/`** в корне репозитория (не `Бизнес/00_Inbox`).
