# Apps Script «RUSbrend × МойСклад» — установка и запуск

Скрипт делает две вещи по флажку в столбце **W** «Загружено в МойСклад»:
1. Извлекает штрихкод (из столбца **F** или из PDF-этикетки по ссылке в столбце **E**).
2. Полностью синхронизирует строку с МойСклад: создаёт товар, если его нет, или обновляет существующий (поля + атрибуты + ШК).

Результат пишется в столбец **X** (Статус).

---

## Шаг 1. Подготовить таблицу
1. Открой файл-таблицу с листом **`База`** (номенклатура).
2. Убедись, что есть столбец **W** «Загружено в МойСклад» с флажком (уже добавлен).
3. Заведи столбец **X** «Статус» (заголовок в строке 1). Туда скрипт пишет результат.

> Если лист называется не `База` — поправь `SHEET_NAME` в начале кода.

## Шаг 2. Создать проект Apps Script
1. В таблице: **Расширения → Apps Script**.
2. Удали содержимое `Code.gs`, вставь весь код из **`RUSbrend_МойСклад.gs`**.
3. (Опционально, но удобно) В настройках проекта включи «Показывать файл манифеста `appsscript.json`» и вставь содержимое из файла `appsscript.json` этой папки — тогда Drive-сервис и доступы подключатся автоматически. Иначе сделай Шаг 3 вручную.

## Шаг 3. Включить Drive API (advanced service)
В редакторе Apps Script слева: **Services (Сервисы) → +** → выбери **Drive API** → версия **v2** → Add.
(Нужно для конвертации PDF → Google Doc и чтения текста/OCR.)

## Шаг 4. Прописать токен МойСклад
**Project Settings (шестерёнка) → Script Properties → Add script property:**
- Property: `MS_TOKEN`
- Value: `<токен МойСклад>`

## Шаг 5. Установить триггер и выдать доступы
1. В выпадающем списке функций выбери **`setup`** → **Run**.
2. Google попросит разрешения (Spreadsheet, Drive, Docs, внешние запросы) — разреши.
3. Перезагрузи таблицу — появится меню **«МойСклад»**.

## Порядок запуска (как договаривались)

### А. Пилот извлечения ШК (без записи в МойСклад)
Меню **МойСклад → «1. Пилот: извлечь ШК (5 строк)»**.
Скрипт возьмёт первые 5 строк с артикулом, попробует достать ШК из PDF и напишет результат в столбец **X** (`[ПИЛОТ] ШК: ...`).
- Проверь: ссылки на PDF читаются, номера достаются, тип верный.
- Если у строки в столбце X «нет ссылки на PDF» — значит ячейка E содержит просто текст, а не ссылку/файл (см. раздел «Если ссылки не читаются»).

### Б. Пилот синхронизации
Меню **МойСклад → «2. Пилот: синхронизировать 5 строк»**.
Создаст/обновит 5 товаров в МойСклад со всеми полями и ШК. Проверь карточки в МойСклад.

### В. Массовый прогон
1. Проставь флажки **W** на нужных строках (можно протянуть по всем 327 без ШК).
2. Меню **МойСклад → «3. Синхронизировать ОТМЕЧЕННЫЕ»**.
3. Из-за лимита выполнения 6 минут скрипт идёт чанками: если строк много — он остановится по таймауту и покажет «запусти ещё раз». Просто запусти пункт 3 повторно — он продолжит (строки со статусом `OK` пропускаются).

> Также флажок работает «вживую»: поставил галочку в W у одной строки — она синхронизируется автоматически (триггер `onEdit`).

### В2. Быстро отметить уже загруженные (без пересинка)
Меню **МойСклад → «4. Отметить уже загруженные (W=✓, без пересинка)»**.
Скрипт делает один запрос всех артикулов из МойСклад и для каждой строки матрицы, чей артикул уже в МС, ставит флажок **W** и статус `OK · уже в МС` — **без** обращения к PDF/OCR и без перезаписи карточки. Это безопасный способ «проставить флажок у всех», не упираясь в лимит выполнения.
Новые товары (которых ещё нет в МС) этим пунктом не трогаются — их добавляешь флажком W по одному (создадутся через `onEdit`) или массово через пункт 3.

> Оптимизация: при обновлении уже существующего товара, у которого ШК уже проставлен, скрипт не лезет в PDF/OCR (экономия времени и защита от таймаутов).

### В3. Проставить флажок W всем + долить ШК из PDF (без дублей)

Контекст: штрихкоды для ~257 товаров лежат **только внутри PDF** на Google Drive (столбец E). Через прямой API их не достать — нужен этот скрипт (у него есть доступ к Drive). Дублей не будет: `syncRow_` ищет товар по артикулу и **обновляет** существующий (`PUT`), новый создаёт только если артикула нет.

**Безопасно ли массово ставить галки в W?** Да. Массовая заливка значений в столбец W (протянуть/вставить сразу на много строк) **не запускает** автотриггер `onEdit` (он срабатывает только на ручное изменение одной ячейки). Поэтому товары не начнут создаваться лавиной — обработкой управляешь ты через меню.

Два варианта:

- **Только отметить флажком (быстро, без ШК):** меню **«4. Отметить уже загруженные»** — поставит W и статус `OK · уже в МС` без обращения к PDF. Дублей нет.
- **Отметить + долить ШК из PDF:** проставь W (можно сразу всем или батчами по ~50 строк) → меню **«3. Синхронизировать ОТМЕЧЕННЫЕ»**. Скрипт обновит товары и для тех, у кого ШК ещё нет, вытащит его из PDF. Из-за OCR это небыстро — идёт чанками, повторяй пункт 3, пока не закончатся строки без статуса `OK`. У товаров, где ШК уже есть, PDF/OCR не трогается (оптимизация).

> Итог: чтобы «проставить флажок всем и долить недостающие ШК без дублей» — ставь W на все строки и гоняй пункт 3 батчами. Если ШК сейчас не нужны, ограничься пунктом 4.

### Г. Разбор ошибок
- Меню **«Снять флажки без статуса OK»** — снимет галочки там, где не получилось, чтобы переотметить после правок.
- Частые статусы в X:
  - `OK · создан/обновлён · id=...` — успех.
  - `ОШИБКА · нет ссылки на PDF...` — в E нет ссылки.
  - `ОШИБКА · ШК в PDF не найден...` — в PDF нет распознаваемого номера.
  - `ОШИБКА · HTTP 4xx ...` — проблема с данными/доступом МойСклад.

## Логика штрихкода
1. Если столбец **F** заполнен — берётся он (`OZN…` → Code128, 13 цифр → EAN-13, 8 → EAN-8).
2. Иначе — PDF по ссылке из **E**: конвертация в Google Doc → текст (или OCR) → поиск `OZN…` или 13 цифр с верной контрольной суммой EAN-13.
3. Если ничего валидного — ШК не пишется, строка помечается ошибкой (на ручную проверку).

## Маппинг столбцов → МойСклад
| Лист | Поле МойСклад |
|---|---|
| A Магазин | атрибут «Организация» (RUSbrend/GripOn) |
| C Артикул | `article` + `code` |
| D Наименование | `name` |
| E ШК (PDF) | источник штрихкода |
| F Баркод | штрихкод (приоритет) |
| G короб S/M/L | «Часто используемый короб» |
| H | «Количество в выбранном коробе» |
| J/K/L | «Помещается в короб S/M/L» |
| N | «Количество в пакете» |
| Q | «Размер пакета» |
| R вес, грамм | `weight` (в кг) + «Вес г факт» |
| S Комментарий | `description` |
| T | «Короб, шт» |
| U | «Вес короба, кг» |

## Если ссылки на PDF не читаются (столбец E — просто текст)
Скрипт читает: обычную гиперссылку, формулу `=HYPERLINK(...)`, ссылку внутри rich-text.
Если в E лежит **Drive-«чип»** (умная вставка файла) или просто имя файла — ссылку получить нельзя. Варианты:
- сделать в E настоящие гиперссылки на файлы Drive, или
- сложить все PDF в одну папку Drive и доработать скрипт под поиск файла по имени в папке (задать `PDF_FOLDER_ID`) — скажи, добавлю функцию.

## Безопасность
- Токен хранится в Script Properties, не в коде.
- Идемпотентность: повторный прогон не плодит дубли (товар ищется по артикулу; строки со статусом OK пропускаются).
