# Регламент руководителя — Дима

**Система:** МойСклад + таблица «Склад Белград»
**Обновлён:** 2026-05-21

---

## Перед закупкой

- [ ] Проверить остатки: **МойСклад → Склад → Остатки** → фильтр по складу **«Основной»**
- [ ] При необходимости фильтровать по организации: **RUSbrend** или **GripOn** раздельно
- [ ] Определить что и сколько заказывать
- [ ] **МойСклад → Закупки → Заказы поставщикам → Создать**
- [ ] Выбрать поставщика → добавить артикулы и количества → сохранить
- [ ] Сообщить Серёже — товар ожидается, он оформит приёмку по факту

---

## Запуск отгрузки (ежедневно)

- [ ] Открыть таблицу **«Склад Белград»**, лист **«План работы»**
- [ ] По строкам плана на сегодня — поставить **флажок в колонке I «Отгрузить»**
- [ ] Через 5–10 секунд в колонке **J «ID МойСклад»** появятся ID созданных отгрузок
- [ ] Если ID не появились — открыть лист **«Errors»** и разобраться

> В ближайшем будущем флажки будет ставить Серёжа самостоятельно.

---

## Контроль остатков

- [ ] **МойСклад → Склад → Остатки** — актуальная картина по каждому артикулу
- [ ] Если остаток близится к нулю — создавать Заказ поставщику (см. выше)
- [ ] Для разделения RUSbrend / GripOn → фильтр по полю **«Организация»**

---

## Добавить новый артикул

- [ ] **МойСклад → Товары → Создать**
- [ ] Заполнить обязательно:
  - Наименование
  - Артикул (числовой, как в матрице)
  - Штрихкод Ozon (начинается с OZN...)
  - Вес (кг)
  - Описание — инструкция сборщику (что проверять, как паковать)
  - **Организация** — RUSbrend или GripOn
  - **Часто используемый короб** — S / M / L
  - **Количество в выбранном коробе** — число штук
- [ ] Сохранить → сообщить Серёже, можно добавлять в план работ

---

## Контроль работы склада

- [ ] **МойСклад → Отгрузки** → смотреть статусы:
  - «Новая» — ещё не взяты в работу
  - «В сборке» — сборщик работает
  - «Проверено» — готово, ждёт отправки
  - «Отправлена» — уехало
- [ ] Если отгрузки «зависают» в статусе «Новая» долго — уточнить у Серёжи

---

## Если что-то пошло не так

| Ситуация | Действие |
|---|---|
| Ошибка в колонке J / лист Errors | Прочитать описание → написать Максиму |
| Артикул не найден при постановке флажка | Добавить товар в МойСклад (раздел выше) |
| Нужно отменить уже созданные отгрузки | МойСклад → Отгрузка → статус **«Отменена»** |
| Остатки в МойСклад не сходятся с реальностью | Проверить — все ли приёмки провёл Серёжа |
