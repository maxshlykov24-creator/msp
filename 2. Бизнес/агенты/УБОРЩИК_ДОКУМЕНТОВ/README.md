# УБОРЩИК ДОКУМЕНТОВ (@уборщик)

> Версия: 1.0 | Дата создания: 26 апреля 2026

Агент лежит в **зоне `Бизнес/`** (как в задании модуля 5: не в папке обучения). Правила Cursor: [`.cursor/rules/уборщик.mdc`](../.cursor/rules/уборщик.mdc) (от корня воркспейса `Бизнес/`).

**Вызов `@уборщик`:** открой папку `Бизнес/` **отдельным воркспейсом** в Cursor, чтобы подтянулось `.cursor/rules/уборщик.mdc` (тот же приём, что в корневом `.cursorrules` для MS Product).

**Личный vault** при воркспейсе `Бизнес/`: пути `../Входящее/`, `../Личное/...`.

---

## ЧТО ЭТО

**Уборщик документов** — AI-агент для организации файлов и папок. Анализирует структуру, предлагает улучшения, раскладывает файлы, удаляет дубликаты. Включает систему самообучения — становится лучше с каждым использованием.

---

## КАК ВЫЗВАТЬ

```
@уборщик [задача]
```

### Примеры:

```
@уборщик наведи порядок в папке Downloads

@уборщик создай структуру для проекта "Мой курс"

@уборщик найди дубликаты в Documents

@уборщик разбери ../Входящее/

@уборщик переименуй файлы в папке по стандарту YYYY-MM-DD
```

---

## ЧТО УМЕЕТ

| Задача | Описание |
|--------|----------|
| Анализ структуры | Показывает текущее состояние папки |
| Организация файлов | Раскладывает по папкам (тип / проект / дата / статус) |
| Удаление дубликатов | Находит и предлагает удалить |
| Создание структуры | Строит логичную иерархию для нового проекта |
| Переименование | Приводит имена к формату `YYYY-MM-DD_название` |
| Разбор инбокса | Организует `Входящее/` по правилам vault |

---

## СИСТЕМА САМООБУЧЕНИЯ

### Цикл:

1. Пользователь даёт задачу
2. Агент проверяет `_КОНТЕКСТ/примеры/` и `_ЛОГИ/` на прошлый опыт
3. Выполняет задачу с учётом накопленных знаний
4. Запрашивает обратную связь
5. Сохраняет результат:
   - «Отлично» / «Хорошо» → `_КОНТЕКСТ/примеры/YYYY-MM-DD_тип.md`
   - «Нужны правки» / «Плохо» → `_ЛОГИ/YYYY-MM-DD.md`

### Результат:

Чем больше задач — тем точнее агент попадает в ожидания с первого раза.

## БЕЗОПАСНОСТЬ

- Всегда показывает план перед выполнением
- Спрашивает подтверждение на удаление
- Не трогает `.git`, `node_modules`, `.cursor/`, системные папки
- Не работает с `Бизнес/` без явного запроса
- При работе с `Личное/` — сверяется с `СТРУКТУРА_И_ПРИНЦИПЫ.md`
