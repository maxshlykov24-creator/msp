# Инструменты для Александра (на бумаге, без техники)

## 1. Тетрадь учёта — главное

Заведи тетрадь. Раздели на два раздела: «Бронницы» и «Чечевилово». Каждый день — одна строка:

| Дата | Выручка за день | Потрачено на товар | Другие расходы | Что за расход |
|------|-----------------|--------------------|----------------|---------------|
|      |                 |                    |                |               |

В конце недели и месяца — сложить столбцы по каждому магазину. Так впервые увидишь: **сколько пришло и сколько осталось** — по каждой точке отдельно.

> Строки по Чечевилово ты заполняешь из ежедневных отчётов продавца (файл `08`). Тебе не надо там быть — Виталик присылает цифры каждый вечер, ты переносишь в тетрадь.

## 2. Разделение «касса / личное»

- Деньги бизнеса не смешивать с домашними.
- Назначь себе и жене зарплату (например, по 50 тыс.) и бери **только** её.
- На продукты домой — из зарплаты, не из кассы магазина.
- Так станет видно: бизнес тебя кормит или ты его кормишь.

## 3. Контроль без программы (просто и быстро)

У тебя ~100 позиций, с добавками 130–140. Считать остаток всех каждую неделю — невозможно и не нужно. Не пытайся — в этом главная ошибка. Держись двух опор:

**Опора 1. Деньги — под контролем сразу по ВСЕМ 130 позициям.** Каждая продажа записана в тетрадь продаж с суммой, итог сходится с кассой (файл `08`). Значит деньги мимо кассы не утекут — по любой позиции, хоть по поилке. Для этого пересчитывать товар НЕ надо.

**Опора 2. Пересчёт товара нужен только чтобы поймать, что мешок ушёл не пробитый.** А это риск в дорогих ходовых (зерно, комбикорм), не в мелкой добавке. Поэтому считаем не всё, а по слоям:

### Каждый день — деньги (по фото от продавца)

- Продавец ведёт тетрадь продаж (товар, мешков, сумма) и вечером шлёт фото страницы (файл `08`).
- **Двойная проверка:** «Итого выручка» из тетради продаж должно совпасть с Нал + Перевод. И касса должна сходиться. Не сходится — спросить в тот же день.
- Это ловит, если что-то продано мимо кассы.

### Раз в неделю — главный товар, в мешках (20–30 минут)

- Не весь товар, а только **главные позиции, что дают ~80% выручки** (обычно 15–25 штук: пшеница, зерносмесь, кукуруза, основные комбикорма).
- Считаем в **мешках, не в деньгах**. Цены не трогаем, калькулятор не нужен.
- «Продано» берём прямо из тетради продаж: сложить столбец «Мешков» по каждой позиции за неделю (файл `08`).
- По каждой позиции формула: **было + привезли − продано = должно остаться.** Пересчитал по факту — сходится?
- Не сходится по мешкам — вот она, утечка.

### Раз в месяц — полный пересчёт всех 130 позиций (1,5–2 часа)

- Один раз сделать **список всех позиций** (распечатать). Дальше каждый месяц просто идёшь по полкам и пишешь количество напротив — по зонам магазина, так быстрее. Список переиспользуется.
- Сюда же — добавки и вся мелочь (в недельную они не входят).
- Тут можно прикинуть и на деньги — но для общей картины (сколько денег лежит в товаре), а не чтобы ловить вора.
- **Сократи ассортимент.** По итогам пересчёта выкинь позиции, что почти не продаются и морозят деньги (тот же собачий корм?). Меньше позиций = проще учёт + свободные деньги. Это прямая выгода.

**Программу сейчас не внедряем.** Сначала пусть это войдёт в привычку на бумаге. Программу (простая таблица или учётная) подключим позже, когда обороты и привычка оправдают — тогда она будет помощником, а не обузой.

### Лист недельного пересчёта (главный товар)

Распечатай или начерти в тетради такую таблицу. Заполняется за 20–30 минут:

| Товар | Было | Привезли | Продано (по записи) | Должно остаться | По факту | Разница |
|-------|------|----------|---------------------|-----------------|----------|---------|
| Пшеница |  |  |  |  |  |  |
| Зерносмесь |  |  |  |  |  |  |
| Кукуруза |  |  |  |  |  |  |
| Комбикорм (осн.) |  |  |  |  |  |  |
| ... (до 15 строк) |  |  |  |  |  |  |

Где «Разница» не ноль — там разбираемся.

Это не про недоверие. Это порядок. **Где считают — там не воруют.**
