# Аналитика и метрики для бизнеса

> Использовать в диагностике: показать клиенту, какие показатели должны отслеживаться, выявить где у него слепые зоны. Само по себе продаёт необходимость порядка в системе.

### Юнит-экономика: метрики и расчёт (Skillbox)

**Ссылка:** [https://skillbox.ru/media/management/razbor-metodiki-yunitekonomika/](https://skillbox.ru/media/management/razbor-metodiki-yunitekonomika/)
**Когда использовать:** при настройке аналитики после внедрения — объяснить клиенту, какие цифры должны быть в системе и что они означают.

#### Ключевые метрики (выжимка)


| Метрика       | Что считает                          | Формула                       |
| ------------- | ------------------------------------ | ----------------------------- |
| **UA**        | Привлечённые пользователи            | —                             |
| **CPA**       | Стоимость привлечения 1 пользователя | AC / UA                       |
| **CAC**       | Стоимость привлечения 1 клиента      | (реклама + услуги) / клиентов |
| **CR**        | Конверсия                            | покупатели / посетители       |
| **APC**       | Среднее число покупок на клиента     | покупки / клиенты             |
| **AvP / AOV** | Средний чек                          | выручка / заказы              |
| **COGS**      | Себестоимость проданного             | переменные затраты на единицу |
| **ARPC**      | Средний доход с 1 клиента            | (AvP − COGS) × APC            |
| **ARPU**      | Средний доход с 1 пользователя       | ARPC × CR                     |
| **CM**        | Маржинальная прибыль                 | (ARPU − CPA) × UA             |
| **LTV**       | Пожизненная ценность клиента         | LT × AvP × APC                |


#### Модели юнит-экономики

- **Клиентская** — считаем прибыль за всё время жизни клиента. Подходит для повторных продаж, подписок, B2B.
- **Транзакционная** — считаем прибыльность одной продажи. Подходит для разовых сделок.

#### Ключевые проверки

- `ARPU > CPA` → реклама выгодна
- `ARPC > CAC` → клиент окупается
- `CM > 0` → бизнес зарабатывает на продукте

### Ключевые метрики для магазина одежды (Mansband, 2025)

**Когда использовать:** при работе с ретейл-клиентами — как чеклист того, что должна давать система после внедрения.

#### 1. Финансовые


| Метрика                  | Что даёт                                       | Зачем фокус                          |
| ------------------------ | ---------------------------------------------- | ------------------------------------ |
| Выручка                  | Рост, сезонность, эффект акций                 | Оперативные решения при просадке     |
| Валовая прибыль          | Реальная доходность без «объёмного шума»       | Продавать не больше, а выгоднее      |
| Маржинальность (%)       | Какие товары / продавцы / каналы дают максимум | Исключение низкомаржинальных позиций |
| Средний чек (AOV)        | Сила апсейла, убеждения продавцов              | Рост выручки без роста трафика       |
| Конверсия в покупку (CR) | Эффективность продавцов и мерчендайзинга       | Рост без затрат на маркетинг         |


#### 2. Ассортимент и товары


| Метрика                   | Что даёт                             | Зачем фокус                                         |
| ------------------------- | ------------------------------------ | --------------------------------------------------- |
| Оборачиваемость склада    | Скорость «деньги → деньги»           | Больше оборотов = больше прибыли на том же капитале |
| Неликвиды / дни на складе | Выявление «замёрших» денег           | Ускорение кэша, план уценок                         |
| ABC/XYZ-анализ            | Хиты vs стабильные vs шумные позиции | Правильные закупки, фокус на полке                  |
| Продажи по размерам       | Точность закупки                     | Минимизация остатков и убытков                      |


#### 3. Клиенты и поведение


| Метрика                       | Что даёт                      | Зачем фокус                                  |
| ----------------------------- | ----------------------------- | -------------------------------------------- |
| LTV                           | Ценность клиента во времени   | Переход от разовых продаж к циклу лояльности |
| Повторные покупки / Retention | Лояльность, удовлетворённость | Рост LTV, предсказуемость выручки            |
| Частота покупок               | Ритм возврата клиента         | Стимулы: акции, ДР, «новинки для вас»        |


#### 4. Маркетинг и воронка


| Метрика                 | Что даёт                         | Зачем фокус                     |
| ----------------------- | -------------------------------- | ------------------------------- |
| CAC                     | Эффективность рекламы по каналам | Отключить нерентабельные каналы |
| ROMI                    | Доход на 1 ₽ в рекламе           | Рост ROI без увеличения бюджета |
| Конверсии по источникам | Какой канал реально продаёт      | Перераспределение бюджета       |


#### 5. Продавцы и точки


| Метрика                                   | Что даёт                        | Зачем фокус                       |
| ----------------------------------------- | ------------------------------- | --------------------------------- |
| Продажи / маржа / средний чек по продавцу | Кто приносит прибыль            | Обучение слабых, поощрение лучших |
| Upsell / кросс-сейл                       | Сила убеждения и вовлечения     | Рост среднего чека                |
| Конверсия от посетителя к чеку            | Эффективность без роста трафика | Повышение КПД шоурума             |
