- Учебные материалы курса — [`3. Разум/3.1. Изучение/3.1.4. Курсы/1. Учебные материалы/README.md`](3.%20Разум/3.1.%20Изучение/3.1.4.%20Курсы/1.%20Учебные%20материалы/README.md)

## Порядок работы со структурой (цепочка)

1. **`_ВХОДЯЩЕЕ/`** (корень vault) — сырой вход; разнос по `1. Личное/` и `2. Бизнес/` в идеале каждый день, максимум до нескольких дней.
2. **`СТРУКТУРА_И_ПРИНЦИПЫ.md`** — при сомнении в зоне открываю в первую очередь.
3. **`КАРТА_ЦЕЛЕЙ_И_РЕГЛАМЕНТОВ.md`** — маршрут к целям/регламентам зоны.
4. **`ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md`** (`1. Повторки/1.3. Планирование/1.3.1. Неделя/`) — очередь идей после разборов Входящего.
5. **`СИНХРОН_С_АССИСТЕНТОМ.md`** (корень vault) — договорённости с ИИ; не подменяет регламент раскладки.

**Вне цепочки:** [`2. Бизнес/08_Системное/_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md`](../2.%20Бизнес/08_Системное/_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md) — стратегия MS Product.

## Верхний уровень

- `1. Повторки/` — открывашка, закрывашка, планирование
- `2. Дух/` — духовная жизнь, Писание, проповеди, служение
- `3. Разум/` — интеллект, семья, люди, финансы, обучение, путешествия, устойчивость
- `4. Тело/` — здоровье и спорт
- `5. Документы/` — паспорта, договоры, официальная медицина, налоги
- `6. Прочее/` — редкое без своей ветки

Новое без места — в **`_ВХОДЯЩЕЕ`**, затем разнос по веткам выше.

## Отделы личной зоны (с 2026-08-19, Модуль 2)

У семи зон есть ИИ-руководитель. В папке отдела лежат `РУКОВОДИТЕЛЬ.md` (промпт с целями, границами и чек-листом первого дня), `БАЗА_СМЫСЛОВ.md`, `ВХОДЯЩЕЕ/`, `ЛОГИ/`.

| Зона | Вызов |
|---|---|
| `1. Повторки/` — ритм и учёт задач | `@dept-ритм` |
| `2. Дух/` | `@dept-дух` |
| `3. Разум/3.1. Изучение/` — обучение до внедрения | `@dept-обучение` |
| `3. Разум/3.3. Люди/` — друзья, родня, подарки | `@dept-люди` |
| `3. Разум/3.6. Семья/` — жена, быт, дети | `@dept-семья` |
| `3. Разум/3.10. Устойчивость/` — паттерны спада | `@dept-устойчивость` |
| `4. Тело/` — зал и здоровье | `@dept-тело`, `@анатолий` |

Личные финансы отдельного отдела не имеют: контур один с бизнесом, ведёт `@dept-финансы`. `5. Документы/` и `6. Прочее/` руководителя не имеют. Полный состав — [`_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md`](../_СИСТЕМА/РЕЕСТР_КОМАНДЫ.md).
