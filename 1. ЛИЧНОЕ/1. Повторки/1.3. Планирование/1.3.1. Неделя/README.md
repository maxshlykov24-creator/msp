### Как вести неделю вместе с Ио

- **«Что сейчас?»** Сначала выяснить, какой блок идёт и какое обязательство актуально. В рамках рабочего блока выбрать одно действие по проекту. Если блок уже занят семьёй, духовным временем или спортом, обычная недатированная задача подождёт. Срочный случай, вытесняющий план, Ио объясняет и предлагает свободное время для переноса.
- **«Разбери хвосты»** — Ио сам берёт карточки «на-сверку» одного проекта, сверяет их с последним сообщением, решением, документом или фактом оплаты по соответствующему периоду. Обновляет исходную карточку. При подтверждённом результате убирает её из очереди. Вопрос Максиму остаётся только при отсутствии свидетельства или при личном выборе. Срок в календаре появляется у выбранного действия.
- **«Итоги недели»** — по обещанным этапам показать, что принято и чей ход, со ссылкой на подтверждение. По сферам сравнить план с фактически проведённым временем, если есть запись фокуса, отметка с длительностью или ответ Максима. Пустая история означает, что факта пока нет. Плановые часы не подставлять за фактические.

### Полнота ревизии задач

20 ноября Ио прочитал все 34 списка TickTick по отдельности, включая личный Inbox и закрытый «Отдых». Исходно — 1 384 уникальные открытые записи, из них 52 в закрытом списке. В действующих списках было 784 заметки и 548 карточек задач или чек-листов. Из 121 записи с прошедшей датой 111 имели тип «заметка». Старые даты записей сохраняются. Семь исходных задач закрыты по результату, две инструкции переведены в заметки с сохранением исходного текста. Три клиентские карточки уточнены по источникам.

Метка **«на-сверку»** поставлена на 75 карточек с возможным обязательством или неясным результатом. Они доступны Ио по фильтру TickTick. Содержание остальных недатированных записей остаётся в родных списках. Часть из них тоже может оказаться обязательством. Ио включает их в очередную предметную сверку по клиенту или сфере, начиная с обещанного человеку. Первичное чтение всех карточек завершено. Фактический результат по каждой старой задаче требует своего источника.

Для повторного разбора перечитать проекты TickTick, в каждом запросить все открытые карточки и сверить уникальные ID, тип, родителя, колонку, повтор, дату и метку. При просмотре недели отдельно запросить задачи по диапазону и события Google. У задач с повтором проверить также ближайшее вхождение. Если проект закрыт, показать его отдельно. Сводный фильтр с лимитом выдачи не подходит для подсчёта всей базы.
