# Повторки — цели и регламент

Дневной и недельный контур. Утро с Богом — обязательный приоритет, часть полного дня, не якорь «потом». Семью и обучение не наращиваем, пока контур не жив. Источник: карта личного §3, §6, §9; решение владельца 2026-08-19.

Пакет на 90 дней: [`1.3. Планирование/1.3.3. 03 месяца/2026-08-20_Цели_август–ноябрь_2026.md`](1.3.%20Планирование/1.3.3.%2003%20месяца/2026-08-20_Цели_август–ноябрь_2026.md).

## Цель зоны

Вернуть дневной контур: утро с Богом, открывашка, кинжал в TickTick, закрывашка вечером. Недельный контур — после 12 полных дней из 14.

---

## Правило дня (if–then)

```
Сначала утро с Богом. Потом открывашка и кинжал. Потом мессенджер.
Мессенджер до кинжала не открываю.
Открыл раньше — закрыл, вернулся к утру или к трём строкам.
```

Кинжал = одна дыра из [`2. БИЗНЕС/01_Стратегия/ХВОСТЫ.md`](../../2.%20БИЗНЕС/01_Стратегия/ХВОСТЫ.md), не «доделать всё». Порядок: Keris → Pleep → касса Mansband.

Новый чат «что сегодня» не нужен. Вопрос дня — в файле и в TickTick. `@dept-ритм` — только если застрял.

## Утро — до Cursor и до чатов

1. **Утро с Богом.** Как уже держится: прогулка и молитва. Не часы, не конспект, не вина. Факт: было / не было. Запись в `2.4. Личные записи/` — по желанию, не условие счёта. Источник: 21 вопрос, п. 6; карта личного §3.
2. Скопировать [`1.1. Открывашка/ШАБЛОН.md`](1.1.%20Открывашка/ШАБЛОН.md) в `1.1. Открывашка/ДД.ММ.ГГГГ.md`. Строка «утро с Богом» + три строки: позиция / кинжал / граница.
3. TickTick Today: список «Прочее» + **1 сейчас + ≤2 слота**. Не весь бэклог. Источник: вердикт TickTick 2026-07-24.
4. Кинжал занести в TickTick с датой сегодня. Без даты это не сегодня.

## День

Входящее из мессенджера → колонка «Входящее» в TickTick, не сразу делать. Мессенджер — слотами после кинжала, не лентой.

## Вечер

1. Скопировать [`1.2. Закрывашка/ШАБЛОН.md`](1.2.%20Закрывашка/ШАБЛОН.md) в `1.2. Закрывашка/ДД.ММ.ГГГГ.md`.
2. Сверить кинжал: закрыт или нет. Без самобичевания.
3. Три дела на завтра — каждое с датой в TickTick. Нет даты — это горизонт, не завтра.
4. Отметить: день полный? (утро с Богом + открывашка + кинжал с датой + закрывашка)

Задачи на ночь не решать. Источник: закрывашка 19.08.2026.

## Что считать полным днём

Утро с Богом + открывашка 3 строки + кинжал в TickTick с датой + закрывашка вечером. Без утра с Богом день неполный, даже если кинжал закрыт.

Счёт: 12 из 14 дней до 2026-09-02, дальше 10 из 13 недель. Ведётся в файле квартала, не в голове.

## TickTick — четыре повторки, ставит владелец

Не через API. Поля:

| Имя | Когда | Что |
|---|---|---|
| Утро с Богом | первое утром | прогулка и молитва; да / нет |
| Открывашка | следом, до работы | файл `ДД.ММ.ГГГГ.md` по шаблону |
| Кинжал | тот же слот | одна дыра из хвостов, дата сегодня |
| Закрывашка | вечер | файл + 3 дела на завтра с датой |

Остальное в Today не тащить. Горизонт и инсайты — не в календарь. Источник: вердикт TickTick 2026-07-24, пилот не запускался.

## Неделя

После 12/14 полных дней: один файл в `1.3. Планирование/1.3.1. Неделя/`, формат `ГГГГ-ММ-ДД_Неделя.md`. Пятница: хвосты + счёт контура. Кайдзен и делегирование — там же, не в открывашке.

Ревью `ПРЕДЛОЖЕНИЯ_ПО_СТРУКТУРЕ.md` — по желанию, отдельной нормы нет.

## Границы

- Cursor по расписанию — не раньше 7 полных дней подряд. Сначала руки.
- Новых агентов под ритм не создаём.
- Зал — цель 3 пакета 90 дней. Жена — якорь в TickTick «Прочее», не в очках до 02.09.
- Правка задач в TickTick через API — только после отдельного «да».
