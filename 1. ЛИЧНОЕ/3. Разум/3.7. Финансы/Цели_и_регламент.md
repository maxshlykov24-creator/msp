# Финансы — цели и регламент

Детальная зона денег: смыслы, правила, десятина, учёт трат. Официальные бумаги — только в `5. Документы/5.3. Налоги` и смежные папки.

## Цели

1. **Отдать все долги** (банки + хвосты проектов) — приоритет №1, пока не закрыто.
2. Вести учёт так, чтобы каждый месяц был **план**, а не «по течению».
3. Десятина / пожертвования — отдельной группой, не смешивать с бытом.

## Регламент

- **Импорт:** раз в неделю (или по запросу) — CSV Тинькофф в `inbox/` → `import_tinkoff.py` → `aggregate.py` → дашборд.
- **Разметка:** спорное только в `review_queue`; новые правила — в `rules.yaml`, не руками в журнале пачками.
- **Долги:** ≥30% входящих на погашение (лучше 50%, если месяц позволяет). Остатки — в `debts.yaml` после сверки с банком.
- **План месяца:** файл `plan/YYYY-MM.yaml` до/в начале месяца; лимиты на второстепенные (такси, кафе, фастфуд) — жёсткие.
- **Переводы между своими счетами:** не расход и не доход.
- **Десятина / проценты / пожертвования:** группа «Десятина и пожертвования».

## Границы v1

- Только **Тинькофф CSV**. Сбер — позже.
- Старт с **текущего месяца**; год и весь прошлый период — волнами v1.1 / v1.2.
- Советы и разбор утечек — в чате с ассистентом после импорта, не в UI дашборда.

## Частота

| Что | Когда |
|-----|--------|
| Импорт CSV + дашборд | Еженедельно |
| Сверка `debts.yaml` | После крупного платежа / раз в месяц |
| Новый `plan/YYYY-MM.yaml` | 1-е число (или закрывашка предыдущего) |

## Метрики

- Сумма долга (банки + проекты)
- План vs факт платежа по долгам за месяц
- Расход месяца без переводов; доля второстепенных
- Топ утечек (статья / мерчант)
