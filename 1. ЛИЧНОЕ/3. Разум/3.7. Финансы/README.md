# Финансы (разум) — система учёта v1

Учёт денег в vault: **Тинькофф CSV → авторазбор → премиум-дашборд**.  
Цель №1: **отдать долги**. Сбер и история Excel — позже.

## Быстрый старт (каждую неделю)

1. Выгрузи CSV из Т-Банка (операции за период).
2. Положи файл в `inbox/` (имя любое, `*.csv`).
3. Запусти:

```bash
cd "1. ЛИЧНОЕ/3. Разум/3.7. Финансы"
python3 scripts/import_tinkoff.py
python3 scripts/aggregate.py --month 2026-07
```

4. Открой `dashboard/index.html` в браузере.
5. Если есть `data/review_queue.json` — разбери спорные (или кинь мне в чат).

Проверка пайплайна на фикстуре (апрель 2026 из старого Excel):

```bash
python3 scripts/import_tinkoff.py --file scripts/fixtures/tinkoff_2026-04_sample.csv
python3 scripts/aggregate.py --month 2026-04
```

Перед боевым июлем очисти журнал: удали `data/operations.jsonl` и обнули `data/review_queue.json`.

## Структура

| Путь | Назначение |
|------|------------|
| `taxonomy.yaml` | Группы и статьи |
| `rules.yaml` | Авторазметка мерчантов / MCC / категорий банка |
| `debts.yaml` | Остатки кредитов и хвостов проектов |
| `plan/YYYY-MM.yaml` | Бюджет месяца + целевой платёж по долгам |
| `inbox/` | Сырые CSV (не в git) |
| `data/operations.jsonl` | Журнал операций (не в git) |
| `data/review_queue.json` | Неразмеченные |
| `dashboard/` | DIVO-style дашборд |
| `Цели_и_регламент.md` | Смыслы и ритм |
