# Промпт деплоя · data-analyst на OpenClaw

> Тот же путь, что для агента М3 (Remote-SSH + один промпт Cursor). Это ВТОРОЙ агент под тем же gateway — sales-агент из М3 продолжает работать. Read-only по данным: аналитик источники только читает, ничего в CRM не пишет.

## Где взять сервер

VPS у тебя уже есть с М3 — там стоит OpenClaw. Новый сервер не нужен, аналитик садится тем же gateway. Если М3 не делал — подними VPS по `../../03_*/` (тот же runbook), потом возвращайся сюда.

## Перед деплоем (на своём компе)

1. Сначала прогони **базу** в Cursor (`../ЗАПУСК.md`) — 5+ раз на демо-данных, сверь цифры с реальностью, поправь словарь метрик. На сервер едет уже проверенный скилл.
2. Заполни `.env` (`../.env.example`): `OPENROUTER_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Опц.: `YANDEX_METRIKA_TOKEN`.
3. Заведи бота: @BotFather → `/newbot` → токен в `TELEGRAM_BOT_TOKEN`. Узнай ID **тест-чата** (свой личный): напиши боту что угодно и глянь `getUpdates`, или через @userinfobot. На старте шлём в тест-чат, не в команду.
4. Перенеси папки на сервер (скилл + шаблон + демо-данные + пресет):
   ```bash
   rsync -avz --exclude='.env' \
     ../skill ../dashboard-template ../data-example ./ \
     root@<VPS>:/opt/analyst-bot/
   ```
   (`.env` НЕ коммитим и НЕ заливаем в общий путь — секреты подставляем на сервере отдельно.)

## Команда агенту Cursor (Remote-SSH на VPS, копировать целиком)

```
Я на своём VPS, где уже работает OpenClaw из М3 (агент lead-qualifier).
ЗАДАЧА: добавить ВТОРОГО агента data-analyst (AI-Аналитик) под тот же gateway.
Он по расписанию строит дашборд, делает PNG-скрин и шлёт его в Telegram с выводами.

ВХОД:
- В /opt/analyst-bot/ лежат: skill/, dashboard-template/, data-example/, workspace/,
  tools/, openclaw.config.example.json
- Секреты в /opt/analyst-bot/.env: OPENROUTER_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
  (опц. YANDEX_METRIKA_TOKEN)

ШАГИ (после каждого — проверка, если упало — покажи ошибку, не выдумывай):
1. Поставь headless-браузер для рендера дашборда в PNG (одно из, что есть в системе):
   npx playwright install chromium   ИЛИ   apt-get install -y chromium
   Проверь: chromium --version  (или: npx playwright --version)
2. chmod +x /opt/analyst-bot/tools/*.sh
3. cd /opt/analyst-bot && set -a && . ./.env && set +a
4. Зарегистрируй агента:
   openclaw agents create data-analyst --workspace /opt/analyst-bot/workspace --config /opt/analyst-bot/openclaw.config.example.json
   openclaw agents list   # должны быть и lead-qualifier, и data-analyst
5. Подключи Telegram-канал агента:
   openclaw channels add telegram --token "$TELEGRAM_BOT_TOKEN" --agent data-analyst --name "analyst-tg"
6. Расписание (3 пресета из openclaw.config.example.json, TZ Europe/Moscow):
   - если твоя версия OpenClaw читает heartbeat.schedule из конфига — проверь, что пресеты подхватились:
     openclaw agents show data-analyst
   - если нет — повесь внешний cron на tools/render+send для каждого пресета, например утренний срез:
     (crontab -l 2>/dev/null; echo '0 9 * * 1-5 cd /opt/analyst-bot && . ./.env && ./tools/send_report.sh "Утренний срез"') | crontab -
7. ТЕСТ отправки в тест-чат (НЕ дожидаясь расписания):
   cd /opt/analyst-bot && . ./.env && ./tools/send_report.sh "Утренний срез"
   → проверь, что в Telegram пришла КАРТИНКА дашборда + текст выводов, цифры читаемые.
8. Резюме: агент data-analyst зарегистрирован, канал подключён, тест-отчёт ушёл в тест-чат,
   расписание стоит на 3 пресета. Напиши, что проверить глазами.

Если команда упала (формат изменился между версиями OpenClaw) — покажи ошибку, не выдумывай флаги.
```

## После деплоя

1. Дождись (или запусти руками) первый **Утренний срез** в тест-чат. Открой картинку — читается ли с телефона, верны ли дельты, не «голые» ли числа.
2. Пару дней последи: цифры из отчёта сверь с реальностью в CRM/Метрике. Расходятся — правь словарь метрик в `skill/`, не правь отчёт.
3. Когда доверяешь — поменяй `TELEGRAM_CHAT_ID` на рабочий чат / канал команды и сними approval с отправки (`exec.ask: never` в конфиге).

> Безопасность: реальные токены — только в `.env` на сервере, никогда в `openclaw.config.example.json` (он коммитится). Доступ к источникам — read-only: аналитик читает CRM/Метрику, но ничего туда не пишет.
