# StartPack M7 · Аналитик

> Сотрудник-аналитик: подключает источники (CRM, Метрика, расходы), приводит к одному виду, строит дашборд с выводами и собирает статистику «одной кнопкой к митапу» с историческим срезом. Качество держит 7-шаговый пайплайн с GATE — аналитик не врёт цифрами, а не «дорогая модель».

## Два трека

### База — Cursor (`skill/`)
Агент в Cursor на твоём компьютере. Подключаешь источник (`skill/КОННЕКТОРЫ.md`), спрашиваешь словами или жмёшь пресет — он тянет данные → нормализует в SSOT → считает (с дельтами и аномалиями) → рисует HTML-дашборд → пишет выводы → сохраняет snapshot. Без сервера. Зачёт сдаётся здесь.

### Надстройка — OpenClaw (`bot-preset/`)
Тот же аналитик 24/7 на сервере (из М3): по расписанию строит дашборд, делает PNG-скрин и **сам шлёт отчёт в Telegram** с выводами. Второй агент под тем же gateway, что sales-бот. **НЕ обязательна для зачёта.**

## Логика — `../ЛОГИКА_АНАЛИТИКА.md`
7 шагов с GATE, визуальный язык графиков (какой график под какой вопрос), отчёты по отделам, кнопка к митапу, исторический срез и исторические выводы.

## Площадка
HTML-дашборд: Chart.js вшит для офлайн/РФ, палитра v15 (Red `#C5443A` / Green `#1F4434` / Ink, шрифты Bricolage/Onest/JBM), печать в PDF к митапу — подход `cjm-визуализатор`.

## Старт
`ЗАПУСК.md` → 3 шага. Хочешь отчёты в Telegram сами — `bot-preset/README.md`.

## Статус
**Собран, к съёмке.** Перед записью: dry-run на обезличенных `data-example/` (5+ прогонов), 1–2 snapshot'а для показа исторического среза.
