# Демо-данные · Аналитик (Модуль 7)

Обезличенные примеры для прогона скилла и съёмки. Ниша — натяжные потолки, май 2026. Реальных ПД нет, менеджеры вымышленные.

- **deals.csv** — `date, manager, stage, amount`. Сделки CRM (оплаченные + незакрытые остатки). ∑ оплачено = 6 707 000 ₽, 79 сделок.
- **traffic.csv** — `week, source, visits, leads`. Трафик и заявки по неделям и источникам. ∑ визитов 8 200, лидов 410.
- **expenses.csv** — `item, amount`. Разнос расходов (БДДС) за месяц.

> ⚠️ **Финансы подрядчиков скрывать в клиентских доках.** Строки `ФОТ отдела продаж`, `Замерщики (подряд)`, `Материалы и монтаж` — внутренние числа. В отчёт, который уходит клиенту, их не выносим (см. `../../КОНТРОЛЬ_КАЧЕСТВА.md`). Числа людей (лиды/квалы/встречи/сделки) — показывать можно.

Свои данные ученик подключает по `../skill/КОННЕКТОРЫ.md` (CSV / Google Sheets / MCP / Метрика / любой API).
