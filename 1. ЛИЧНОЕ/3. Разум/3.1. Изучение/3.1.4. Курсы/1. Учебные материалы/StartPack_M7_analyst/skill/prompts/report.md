# Промпт · пресет к митапу (шаги 3–7, «одной кнопкой»)

Задача: собственник выбрал пресет — собираешь готовую картину к митапу за один шаг, с историческим сравнением и выводами.

## Что делаешь (по кнопке)
1. **Тянешь свежие данные** из подключённых источников (см. `КОННЕКТОРЫ.md`).
2. **Сравниваешь с прошлым срезом** — берёшь предыдущий snapshot из `_ДАННЫЕ/snapshots/`, считаешь дельты по всем метрикам (код, не «на глаз»).
3. **Строишь дашборд** по `../dashboard-template/dashboard.html` под выбранный пресет (KPI-плитки → динамика → разрезы → светофор аномалий).
4. **Пишешь выводы** — что выросло, что просело, узкие места, рекомендации (actionable: «сделать X»). Где есть история — исторический вывод («3-й месяц растёт органика, но просела конверсия продаж → узкое место сместилось в продажи, разобрать звонки М5»).
5. **Сохраняешь новый snapshot** в `_ДАННЫЕ/snapshots/<пресет>_<дата>.json` — старое не затираешь.

Запрос словами работает так же: «собери к завтрашнему совету сводку по всем отделам за квартал с выводами».

## Пресеты (метрики — правятся под бизнес из его SSOT)
- **Продажи · неделя** (планёрка ОП): воронка + конверсии, выручка (линия vs прошлая неделя), средний чек, цикл сделки, рейтинг менеджеров (бар), причины отказов.
- **Маркетинг · месяц** (разбор каналов): трафик и источники (Метрика), CPL по каналам, ROI Директа, органика с сайта (М6), динамика заявок.
- **Совет директоров · квартал** (сводка): главные KPI по всем отделам + тренды из snapshot'ов + исторические выводы (что сместилось за квартал).
- **Утренний срез** (за вчера): KPI-плитки + светофор аномалий. Коротко — «что требует внимания сегодня».

## GATE
- [ ] Свежие данные подтянуты, период подписан.
- [ ] Есть сравнение с прошлым snapshot (дельты по метрикам).
- [ ] Дашборд: KPI с дельтой + ≥2 графика + светофор аномалий.
- [ ] Выводы actionable, не «цифры изменились».
- [ ] Новый snapshot сохранён.
