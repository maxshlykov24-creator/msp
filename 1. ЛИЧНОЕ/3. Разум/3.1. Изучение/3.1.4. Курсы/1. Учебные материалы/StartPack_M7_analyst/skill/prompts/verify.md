# Промпт · самопроверка перед сдачей (для ДЗ)

Задача: перед тем как отдать дашборд — агент сам сверяется с фактом, проверяет полноту и заполняет блок сдачи. Не «на доверии», а сверкой с источником.

## Что делаешь
1. **Сверь цифры дашборда с источником.** Возьми 2–3 ключевых числа с дашборда (выручка, число сделок) и пересчитай прямо из `_ДАННЫЕ/raw/` кодом. Сходятся — ок. Разошлись — чини дашборд, не сдавай.
2. **Проверь состав** дашборда:
   - KPI-плитки ≥3, у каждой **дельта к прошлому периоду**;
   - графиков ≥2, тип под вопрос (динамика / доли / воронка / рейтинг);
   - блок выводов есть и они **actionable** («сделать X»), не «выручка изменилась».
3. **Проверь чистоту** — ПД клиентов замаскированы (телефоны/ФИО → маска); финансы подрядчиков не торчат в клиентском доке (если это клиентский отчёт).
4. **Заполни «БЛОК СДАЧИ · Модуль 7»** — формат строго по `../../ДОМАШКА.md`:

```
БЛОК СДАЧИ · Модуль 7

Источник подключён: <какой> · период: <…>
Дашборд: <ссылка / PDF / «локально»>
KPI-плиток: __ (с дельтой к прошлому периоду: ДА/НЕТ)
Графиков: __ (типы: динамика / доли / воронка / рейтинг)
Выводы написаны (что выросло/просело/что делать): ДА/НЕТ
Вопрос словами + ответ: <…>
Что подтвердил агент при проверке: <…>

Полнота: __%
Готов к сдаче: ДА/НЕТ
```

## GATE
- [ ] Контрольные цифры дашборда **сходятся с источником** (пересчёт кодом показан).
- [ ] KPI с дельтой + ≥2 графика + выводы actionable — на месте.
- [ ] ПД замаскированы, финансы подрядчиков скрыты (если клиентский).
- [ ] Блок сдачи заполнен честно (не «100%/ДА» без дашборда — Вебстраж завернёт).
