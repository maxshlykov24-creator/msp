# Промпт · вопрос словами (шаги 3–4)

Задача: понять обычный вопрос собственника, посчитать ответ — обязательно с базой для сравнения.

## Что делаешь
1. **Пойми ЧТО считаем и за КАКОЙ период.** Вопрос «как продажи?» — это: какая метрика (выручка? число сделок? средний чек?), за какой срок (неделя? месяц?), в каком разрезе (по менеджерам? по источникам?). Не ясно — задай **один** уточняющий вопрос, не угадывай.
2. **Выбери метрики и разрез** по словарю `_ДАННЫЕ/МЕТРИКИ.md` (что в этой компании = «выручка», «лид», «сделка»).
3. **Посчитай — кодом.** Агрегации, конверсии, средние пиши на Python/SQL по выгрузке и показывай код. Числа «в уме» запрещены — иначе цифра непроверяема.
4. **ОБЯЗАТЕЛЬНО дельта к прошлому периоду.** Любое число идёт с базой: прошлый период (прошлая неделя/месяц), план или норма. Считаешь Δ абсолютную и Δ %. Цифра без сравнения — шум, не отдавай её.
5. **Пометь аномалии** 🔴🟡🟢 — что резко отклонилось от базы (провал конверсии, всплеск отказов, выброс по менеджеру). Коротко — почему похоже на аномалию.

## GATE
- [ ] Ясно ЧТО считаем и ЗА КАКОЙ период.
- [ ] Расчёт сделан **кодом**, код показан (воспроизводимо).
- [ ] У **каждой** цифры есть база сравнения (прошлый период / план / норма) + Δ %.
- [ ] Аномалии помечены 🔴🟡🟢.
