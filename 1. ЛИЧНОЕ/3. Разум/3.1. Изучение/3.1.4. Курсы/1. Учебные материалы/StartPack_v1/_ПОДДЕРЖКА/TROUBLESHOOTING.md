# Типовые проблемы и решения

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

Список собран из боли первых учеников. Если твоей проблемы нет — пиши Лине (`КОНТАКТЫ.md`).

## Windows и кириллица

**Если ты на Windows — сначала пройди [`WINDOWS_SETUP.md`](WINDOWS_SETUP.md).** Это закрывает 90% проблем с кодировкой за 5 минут (системный UTF-8 + правильный путь распаковки + настройки Cursor).

Признаки что нужно туда:
- В Cursor вместо русского — `?????` или `\320\237\321\200`.
- PowerShell не находит файлы с русскими именами.
- Cursor открывает папку 10+ секунд.
- Пути типа `C:\Users\Иван\Документы\Мой бизнес\StartPack\` — сразу переноси в `C:\StartPack\`.

## Cursor

### 1. Cursor не подхватил `.cursorrules`

**Симптом:** агенты отвечают на английском, не знают про CEO/Архивариуса.

**Решение:**
1. Убедись, что открыл папку `StartPack_v1/`, а не родительскую (Файл → Open Folder).
2. Перезапусти Cursor (`⌘Q` → запусти снова).
3. Проверь, что в чате внизу написано «Active rules: 4» (или сколько у тебя).

### 2. Правила `.cursor/rules/*.mdc` не применяются

**Симптом:** CEO не активируется при «привет».

**Решение:** в Cursor → Settings → Rules → проверь, что `00-ядро.mdc` со статусом `Always`. Остальные — `Auto Attached` по globs.

### 3. CEO отвечает по-английски

**Симптом:** ответ на английском несмотря на промпт.

**Решение:** напиши «отвечай по-русски» — CEO запишет правило в `ИНСАЙТЫ_О_ВЛАДЕЛЬЦЕ.md`. Если повторится — проверь, что `СТИЛЬ_РАБОТЫ.md` не пустой.

## Агенты

### 4. CEO сразу лезет делать задачу, не спрашивает контекст

**Симптом:** не запустился onboarding, профиль остался пустым.

**Решение:** напиши «открой PROFILE.md, давай заполним». CEO увидит `<пусто>` и запустит протокол. Если игнорирует — открой `_АГЕНТЫ/CEO/СИСТЕМНЫЙ_ПРОМПТ.md` и убедись, что он не повреждён.

### 5. Архивариус разложил файл не туда

**Решение:**
1. Скажи «верни обратно» — он откатит.
2. Объясни, куда правильно: «договоры с подрядчиками — в `_ЗНАНИЯ/ДОГОВОРЫ/ПОДРЯДЧИКИ/`».
3. Архивариус запомнит как правило (CEO допишет в его промпт).

### 6. Создал агента в обход `agent-creator`

**Симптом:** агент работает, но CEO его не видит, маршрутизация ломается.

**Решение:** удали папку, запусти `agent-creator` нормально. Не пытайся «починить» — быстрее пересобрать.

### 7. Агент даёт устаревшие данные

**Симптом:** маркетолог пишет «у вас цена 50 000», хотя уже 60 000.

**Решение:** Архивариус устарел `_ЗНАНИЯ/ПРОДУКТЫ.md`. Скажи «обнови продукты», обнови сам, дальше агенты подхватят.

## Файлы

### 8. Случайно удалил файл из `_АРХИВ/`

**Решение:** в Cursor — `⌘Z` пока возможно. Если поздно — Time Machine / iCloud / Яндекс.Диск history. На будущее — Архивариус не удаляет, только переносит в `_АРХИВ/`. Удалять — задача владельца.

### 9. Имена файлов с пробелами и спецсимволами ломают команды

**Решение:** Архивариус сам переименует по конвенции. Если пишешь сам — следуй `_АГЕНТЫ/Архивариус/ПРАВИЛА_ИМЕН.md`.

### 10. `_РАБОТА/ВХОДЯЩЕЕ/` забилось до 100+ файлов

**Решение:** «разложи входящее партиями по 20». Не пытайся за один раз — Архивариус устанет уточнять.

## Доступ к моделям

### 11. Cursor требует логин в Anthropic / отказывает из РФ

**Решение:**
- Используй модели OpenAI (GPT-4) или встроенные в Cursor — они доступны из РФ.
- Альтернатива: Cursor Pro подписка через зарубежную карту, доступ через VPN при работе.
- Локальные модели через Ollama (Llama, Qwen) — работают офлайн, но качество хуже.

### 12. Не работает «Apply changes» в Cursor

**Решение:** обнови Cursor до последней версии. Если не помогает — в чате попроси «дай diff в формате патча, я применю руками».

## Команда

### 13. Агенты противоречат друг другу

**Симптом:** Маркетолог пишет про скидку, Юрист говорит «скидка не действует».

**Решение:** один из них смотрит устаревшую `_ЗНАНИЯ/ПРОДУКТЫ.md`. Обнови её, оба перечитают.

### 14. Не помню, какого агента звать

**Решение:** открой `_АГЕНТЫ/README.md` — там карта «кому какую задачу отдавать». Или просто пиши CEO — он маршрутизирует.

### 15. Слишком много агентов, забываю про них

**Решение:** на ретроспективе с CEO архивируй неиспользуемых. Лучше 5 живых, чем 15 мёртвых.
