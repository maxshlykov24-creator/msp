# FAQ

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

## Общие

**Что такое StartPack?**
Папка с готовой ИИ-командой (CEO + Архивариус) и инструментами, чтобы добавлять новых агентов под себя. Открываешь в Cursor — работает.

**Это бесплатно?**
StartPack входит в курс. Лицензия — для ученика 2-го потока (см. `LICENSE.md`).

**Можно отдать партнёру/коллеге?**
Нет. Лицензия персональная. Внутри своего бизнеса — да.

**Я не программист — справлюсь?**
Да. Cursor — обычное приложение, чат как в Telegram. Команды Bash агенты пишут сами.

## Cursor

**Какую модель выбрать?**
Для большинства задач — GPT-4 / Claude Sonnet. Для длинных стратегических разборов — Claude Opus / GPT-4 Turbo.

**Сколько стоит Cursor?**
Базовый тариф $20/мес. Достаточно для работы с StartPack.

**Есть ли альтернатива Cursor?**
Да, тот же CLAUDE.md работает в Claude Code (если есть доступ). Хуже — обычный Claude.ai с копированием файлов вручную.

## Агенты

**Сколько агентов оптимально?**
3–7. Меньше — не охватишь задачи. Больше — забудешь, кто за что.

**Можно создать агента «универсал»?**
Технически да, но он быстро деградирует. Лучше 3 узких, чем один широкий.

**Как удалить агента?**
1. Перенеси папку `_АГЕНТЫ/<Имя>/` в `_АРХИВ/ГГГГ-ММ/агенты/`.
2. Удали файл `.cursor/rules/<NN>-<имя>.mdc`.
3. Убери строку из `_АГЕНТЫ/README.md`.

## Память и адаптация

**Агент «забывает» правила между сессиями?**
Нет, если правило записано в файл (`СИСТЕМНЫЙ_ПРОМПТ.md` агента или `ИНСАЙТЫ_О_ВЛАДЕЛЬЦЕ.md`). Если не записано — забывает (норма для LLM).

**Можно ли «обучить» агента на моих текстах?**
Не «обучить» в смысле дообучения модели — но можно положить твои тексты в `_ЗНАНИЯ/ПРИМЕРЫ_ТЕКСТОВ/`, агент будет читать перед задачей и подражать.

## Безопасность

**Агенты видят мои данные?**
Внутри Cursor — да, это его задача. Дальше — зависит от модели:
- Claude / GPT через API в режиме «privacy» — не используются для обучения.
- В режиме по умолчанию — могут анонимно использоваться.
Проверь настройки приватности в Cursor → Settings → Privacy.

**Стоит ли класть в `_ЗНАНИЯ/` чувствительные данные?**
Реквизиты, финансы — нормально. Пароли, токены, коды доступа — **нет**. Для них — отдельный менеджер паролей (1Password, Bitwarden).

## Обновления

**Будет ли StartPack v2?**
Да. Раз в квартал. Обновления — через `_ПОДДЕРЖКА/ОБНОВЛЕНИЯ.md`.

**Накатить новую версию — потеряю свои данные?**
Нет. Системные файлы перезаписываются, твои `_ПРОФИЛЬ/`, `_ЗНАНИЯ/`, `_РАБОТА/`, `_АРХИВ/` и созданные тобой агенты — остаются.
