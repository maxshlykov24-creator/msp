# StartPack — твоя ИИ-команда в коробке

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес» · Только для учеников 2-го потока

Открыл папку → представился CEO-агенту → за 30 минут у тебя есть профиль и **карта смыслов** (`_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md`) — единая точка правды о твоём бизнесе. Это и есть твой **SSOT** (в следующих модулях её зовут «SSOT-файл компании» / «Единый Источник Правды»; после Модуля 2 файл переедет из `_ЗНАНИЯ/` в `80_СИСТЕМА/`, имя то же). CEO задаёт всего 3 вопроса, потом ты даёшь 5 ссылок (сайт + соцсети + облако + ZIP + 3 голосовые), и команда сама вытаскивает 80% контекста.

Аудитор Контекста раз в неделю показывает светофор по 21 разделу карты — где зелёное, где дыры. Твоя задача — довести карту до 🟢 (≥80% полей подтверждено). Дальше команда работает на полной мощности.

## С чего начать

**1.** Открой эту папку в **Cursor** (File → Open Folder).
**2.** Открой [`0_СТАРТ.md`](0_СТАРТ.md) — 7 шагов на одном экране. Подробная версия — [`НАЧНИ_ОТСЮДА.md`](НАЧНИ_ОТСЮДА.md).
**3.** Открой чат Cursor (`⌘L`), напиши: `привет, помоги начать` — CEO представится и поведёт.

Если что-то не так — [`_ПОДДЕРЖКА/TROUBLESHOOTING.md`](_ПОДДЕРЖКА/TROUBLESHOOTING.md).

## Принципы

- **Один CEO — много рук.** CEO маршрутизирует, остальные исполняют. Не бросай задачу всем сразу.
- **Стартовый минимум — 2 агента.** Не нагребай сотрудников впрок. Появилась реальная задача → собрал агента под неё через `agent-creator`.
- **Агенты учатся на тебе.** Дал feedback — CEO зашьёт правило в системный промпт. Через месяц команда знает твой голос.
- **Файлы — единая память.** Не держи знания в голове и в чатах. Закидывай в `_РАБОТА/ВХОДЯЩЕЕ/`, Архивариус разложит.
