# Команда — карта агентов

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

Это твоя ИИ-команда. Стартует с **3 предустановленных агентов**. Дальше расширяется через [`agent-creator`](../_СКИЛЛЫ/agent-creator/).

## Команда

| Имя | Зачем | Триггеры активации |
|---|---|---|
| [CEO](CEO/) | Маршрутизирует, ведёт onboarding, адаптируется под MBTI владельца, проводит ретро | «привет», «помоги начать», «что делать», «разбери задачу», «ретро» |
| [Архивариус](Архивариус/) | Раскладывает файлы, держит индекс, naming convention | «разложи входящее», «найди файл», «куда это», «обнови индекс» |
| [Аудитор Контекста](Аудитор_Контекста/) | Считает полноту `_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md`, светофор по 21 разделу, топ-3 пробела | «проверь карту», «насколько я загрузил бизнес», «как с контекстом» (+ автоматически раз в неделю) |

*Тут будут появляться твои собственные агенты, собранные через `agent-creator`.*

## Кому какую задачу отдавать

| Задача | Кому |
|---|---|
| **Точка входа для любой задачи (если не уверен)** | **CEO** — он маршрутизирует |
| Файлы, папки, порядок, переименования, индексация | Архивариус |
| Проверка полноты карты смыслов / scoring контекста | Аудитор Контекста |
| Загрузка бизнеса в команду (5 ссылок + ZIP + 3 голосовые) | Скилл [`auto-context-pull`](../_СКИЛЛЫ/auto-context-pull/) |
| Создание нового сотрудника | Скилл [`agent-creator`](../_СКИЛЛЫ/agent-creator/) |
| Стратегия, разбор боли, ретро | CEO |
| Контентные задачи (тексты, посты) | Маркетолог (когда соберёшь) |
| Юридические задачи (договоры, риски) | Юрист (когда соберёшь) |
| Продажные задачи (КП, скрипты) | Продажник (когда соберёшь) |
| Финансы, бухгалтерия | Бухгалтер (когда соберёшь) |
| Аналитика, цифры, отчёты | Аналитик (когда соберёшь) |

## Как добавить нового агента

```
ты → CEO: «нужен SMM-щик»
CEO → ты: «давай через agent-creator, 4 вопроса»
```

Или прямо:
```
ты → чат: «создай агента-SMM-щика»
```

`agent-creator` создаст папку, добавит правило, обновит эту таблицу выше.

## Принципы команды

- **Один CEO, один Архивариус, один Аудитор на StartPack.** Не клонируй — это инфраструктурные роли.
- **Один агент = одна роль.** Не нагружай Маркетолога юридикой.
- **5–7 агентов — оптимум.** Меньше — не охватишь, больше — забудешь.
- **Раз в месяц — чистка.** Архивируй неиспользуемых на ретро.
