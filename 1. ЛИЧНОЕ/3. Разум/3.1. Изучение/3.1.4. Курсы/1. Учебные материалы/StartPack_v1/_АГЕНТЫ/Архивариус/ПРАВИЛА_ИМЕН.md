# Правила именования файлов и папок

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

## Базовая формула

```
ГГГГ-ММ-ДД_короткое-описание_версия.расш
```

Примеры:
- `2026-05-15_договор-аренды-офис_v1.pdf`
- `2026-05-20_презентация-инвесторы_v3.pptx`
- `2026-05-22_отчёт-выручка-апрель.xlsx`

## Правила

| Элемент | Как писать |
|---|---|
| Дата | `ГГГГ-ММ-ДД` (изо-формат, сортируется правильно) |
| Разделитель блоков | `_` (нижнее подчёркивание) |
| Разделитель внутри слова | `-` (дефис) |
| Регистр | строчные буквы, кроме аббревиатур (`НДС`, `ИП`) |
| Версия | `_v1`, `_v2`, `_финал` (последний — только если правда финал) |
| Язык | русский для бизнес-файлов, английский — только для технических |
| Пробелы | **нет**. Только `_` и `-` |
| Спецсимволы | нет (`!`, `?`, `*`, `«»`, `:` — запрещены) |

## Системные файлы (другая конвенция)

Файлы в `_СИСТЕМА/`, `_АГЕНТЫ/`, `_СКИЛЛЫ/`, `_ПОДДЕРЖКА/`:
- `ВЕРХНИЙ_РЕГИСТР_С_ПОДЧЁРКИВАНИЯМИ.md` (например `СИСТЕМНЫЙ_ПРОМПТ.md`).
- Без дат — это эволюционирующие документы, не снимки.
- Стандартизованные имена (`SKILL.md`, `README.md`, `LICENSE.md`) — английский, как в opensource-практике.

## Папки

- Системные (с префиксом `_`): `ВЕРХНИЙ_РЕГИСТР` или `Заглавная_буква` — `_ПРОФИЛЬ/`, `_АГЕНТЫ/CEO/`.
- Рабочие: тоже `ВЕРХНИЙ_РЕГИСТР` для консистентности — `ВХОДЯЩЕЕ/`, `В_РАБОТЕ/`.
- Подпапки задач в `В_РАБОТЕ/`: `ГГГГ-ММ-ДД_короткое-название/`.

## Архив

```
_АРХИВ/ГГГГ-ММ/<оригинальное_имя>__причина.расш
```

Причины (двойное подчёркивание разделяет):
- `__устарело` — заменено новой версией
- `__дубликат` — есть точная копия в активной части
- `__отменено` — задача закрыта без результата
- `__финал` — задача завершена, файл в долгосрочное хранение

Пример: `_АРХИВ/2026-06/договор-аренды_v1__устарело.pdf` (заменён на `v2` в активной части).

## Что делать с неконвенциональными именами на входе

Получили `Договор Иванов финал ПРАВКИ ОКОНЧАТЕЛЬНО (4).docx`?

1. Архивариус **не возмущается**.
2. Переименовывает в `2026-05-22_договор-иванов_v4.docx`.
3. Перекладывает в нужное место.
4. Если в имени есть смысловой контекст («ПРАВКИ ОКОНЧАТЕЛЬНО») — **уточняет у владельца** одной строкой: «это финал или ещё в работе?».
