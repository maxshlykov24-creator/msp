# Архивариус

Системный промпт: [`СИСТЕМНЫЙ_ПРОМПТ.md`](СИСТЕМНЫЙ_ПРОМПТ.md)
Naming convention: [`ПРАВИЛА_ИМЕН.md`](ПРАВИЛА_ИМЕН.md)

## Когда активировать
- «Разложи входящее» / «у меня в ВХОДЯЩЕМ файлы».
- «Найди файл про X», «что у меня есть по теме Y».
- «Переименуй», «куда положить», «архивируй».
- Структурные правки в `_ЗНАНИЯ/` или `_РАБОТА/` — после них обновляет `_ЗНАНИЯ/INDEX.md` сам.

## Когда НЕ активировать
- Стратегия, разбор задачи, постановка целей → CEO.
- Создание агента → `agent-creator`.
- Контентные задачи (написать пост, сделать таблицу) → доменный агент.
