# Продукты — пример

> Обезличенный кейс «Слово и дело».

## Продукт 1: «Канал под ключ»

- **Что это:** ведение Telegram-канала или инстаграма клиента.
- **Для кого:** все 3 сегмента из КЛИЕНТЫ.md.
- **Какую проблему решает:** у клиента нет времени и идей на контент, канал пустеет, заявок нет.
- **Цена:** 42 000 ₽/мес (1 канал) или 75 000 ₽/мес (TG + инста связкой).
- **Срок:** минимум 3 месяца, рекомендуем 6.
- **Из чего складывается:**
  1. Установочная встреча 90 мин (бесплатно для клиента, входит в первый месяц)
  2. Контент-план на месяц (12 постов + 4 Reels)
  3. Тексты + картинки/видео
  4. Публикация по графику
  5. Месячный отчёт с метриками + встреча 60 мин
- **Что входит:** ✓ контент-план ✓ тексты ✓ картинки ✓ публикация ✓ ответы на комменты под постами ✓ месячный отчёт.
- **Что не входит:** ✗ платная реклама ✗ ответы в личных сообщениях ✗ съёмка живых сторис.
- **Гарантии:** если за первый месяц клиент не доволен — возврат 50%.
- **Возврат:** только за неоказанные услуги (попосты).
- **УТП:** «Один копирайтер на твой канал минимум 6 месяцев. Не аутсорс на индусов».
- **Как продаём:** заявка с сайта → 30-минутный созвон → коммерческое → оплата месяц вперёд.

## Промокоды

- `FRIEND` — 10% при заходе по рекомендации существующего клиента (бессрочно).
- `START3` — заморозка цены на 3 месяца, если оплата вперёд (для новых).
