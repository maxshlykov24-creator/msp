# Исходники бизнеса

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

Сюда складывается **сырьё**: всё что ты дал команде о своём бизнесе. На основе этого CEO заполняет файлы в `_ЗНАНИЯ/` (О_БИЗНЕСЕ, КЛИЕНТЫ, ПРОДУКТЫ, …).

**Правило:** каждое утверждение в `_ЗНАНИЯ/*.md` ссылается на исходник отсюда. Не выдумываем — извлекаем.

## Категории

| Папка | Что кладём |
|---|---|
| [`сайт/`](сайт/) | URL и скачанные страницы сайта, посадочные, лид-магниты |
| [`регламенты/`](регламенты/) | Должностные, чек-листы, SOP, корпоративные правила |
| [`продукты/`](продукты/) | Прайсы, описания, тарифы, портфолио |
| [`продажи/`](продажи/) | Скрипты, КП, договоры, скриншоты воронки CRM, выгрузки сделок |
| [`клиенты/`](клиенты/) | Кейсы, отзывы, портреты ЦА, транскрипты звонков |
| [`финансы/`](финансы/) | Агрегированные цифры, метрики, юнит-экономика |
| [`конкуренты/`](конкуренты/) | Скриншоты, прайсы, аналитика конкурентов |
| [`бренд/`](бренд/) | Логотипы, гайдлайн, голос, миссия |
| [`прочее/`](прочее/) | Сертификаты, презентации, всё неклассифицируемое |

## Как пополнять

1. Через скилл [`business-discovery`](../../_СКИЛЛЫ/business-discovery/) — основной путь, разложит и разберёт автоматически.
2. Просто кинуть файл в `_РАБОТА/ВХОДЯЩЕЕ/` и сказать Архивариусу «это в исходники бизнеса» — он определит категорию.
3. Положить руками в нужную подпапку — Архивариус подхватит при следующей индексации.

## Что НЕ класть

- Пароли, API-токены, ключи доступа.
- Полные банковские выписки с номерами счетов.
- ПД клиентов в нарушение 152-ФЗ.
- Чужие конфиденциальные документы без прав.

См. полный чек-лист «что нести» в [`_СКИЛЛЫ/business-discovery/ЧЕК-ЛИСТ_ИСХОДНИКОВ.md`](../../_СКИЛЛЫ/business-discovery/ЧЕК-ЛИСТ_ИСХОДНИКОВ.md).

## Жизненный цикл

- Свежие исходники добавляются по мере роста бизнеса.
- Устаревшее (старый прайс, отменённый регламент) → Архивариус переносит в `_АРХИВ/ГГГГ-ММ/исходники/__устарело`.
- Не чистим всё подряд — старая версия может пригодиться для сравнения «как было».
