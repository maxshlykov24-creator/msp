# 🎱 Старт за 5 минут

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

1. **Распакуй ZIP.**
   Windows → в путь без кириллицы и пробелов: `C:\StartPack\`.
   Mac → куда угодно.

2. **Поставь Cursor** — [cursor.com](https://cursor.com) → Download.

3. **Открой папку в Cursor.**
   `File → Open Folder` → выбери `StartPack_v1`.

4. **Открой чат:** `Cmd+L` (Mac) / `Ctrl+L` (Windows).

5. **Напиши:** «привет, помоги начать».

6. **Дай CEO 5 ссылок,** когда попросит:
   сайт · соцсети · облако · ZIP (Архивариус назовёт точный путь у тебя на машине) · 3 голосовые.

7. **Доведи карту смыслов до 🟢** — это вся домашка.
