# Словарь терминов

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

Когда агент или ученик встречает незнакомое слово — открывает этот файл, не угадывает.

## Базовое

**Агент** — ИИ-сотрудник с ролью, промптом и зоной ответственности. Живёт в `_АГЕНТЫ/<Имя>/`. У каждого агента есть `SKILL.md` (паспорт) и `СИСТЕМНЫЙ_ПРОМПТ.md` (роль).

**Скилл** — навык/инструмент, не роль. Скилл может быть «фабрикой» (создаёт агентов), «процессом» (проводит ритуал), «справочником» (даёт знания). Живёт в `_СКИЛЛЫ/<имя-скилла>/`. У скилла есть `SKILL.md`.

**CEO** — главный агент-маршрутизатор. Один на StartPack. Не делает работу руками — направляет.

**Архивариус** — агент порядка в файлах. Один на StartPack. Не пишет контент.

**Профиль** — твой паспорт владельца в `_ПРОФИЛЬ/PROFILE.md`. Без заполненного профиля агенты не работают.

## Память и обучение

**Инсайты** — оперативные правила, которые CEO накопил о тебе. Файл: `_АГЕНТЫ/CEO/ЛОГИ/ИНСАЙТЫ_О_ВЛАДЕЛЬЦЕ.md`. Растёт с каждой сессией.

**Стиль** — устойчивые правила общения с тобой. Файл: `_ПРОФИЛЬ/СТИЛЬ_РАБОТЫ.md`. Меняется редко.

**Корректировки от владельца** — раздел внутри `СИСТЕМНЫЙ_ПРОМПТ.md` каждого агента. Сюда CEO дописывает feedback, адресный к этому конкретному агенту.

**Ретро (ретроспектива)** — еженедельный разбор с CEO 15 минут. Файлы хранятся в `_АГЕНТЫ/CEO/ЛОГИ/РЕТРО/ГГГГ-ММ-ДД_ретро.md`.

## Файлы и порядок

**Индекс** — карта базы знаний `_ЗНАНИЯ/INDEX.md`. Поддерживается Архивариусом.

**Naming convention** — правила имени файлов: `_АГЕНТЫ/Архивариус/ПРАВИЛА_ИМЕН.md`. Базовая формула: `ГГГГ-ММ-ДД_короткое-описание_версия.расш`.

**Архив** — папка `_АРХИВ/ГГГГ-ММ/` для устаревших файлов. Не удаляем — переносим.

**ВХОДЯЩЕЕ / В_РАБОТЕ / ГОТОВО** — три состояния задачи в `_РАБОТА/`. Файлы движутся слева направо.

## Технические

**Cursor** — IDE с встроенным ИИ-чатом. Главный инструмент для работы со StartPack.

**Системный промпт** — текстовый файл, описывающий роль агента. Cursor (или Claude Code) подгружает его, когда агент активируется.

**`.cursorrules`** — корневой файл правил Cursor. Применяется ко всему рабочему пространству.

**`.cursor/rules/*.mdc`** — модульные правила. Активируются по `globs` (на какие файлы влияют) или вручную (`alwaysApply: false`).

**Триггер** — слово или фраза, по которой активируется агент. Описаны в `SKILL.md` каждого.

## Курс

**SSOT** — Single Source of Truth, единый источник правды. В курсе это твоя **карта смыслов** — главный файл `КАРТА_СМЫСЛОВ.md`. В Модуле 1 он лежит в папке `_ЗНАНИЯ/`, после реорганизации в Модуле 2 переезжает в `80_СИСТЕМА/` — имя файла то же. Когда в любом модуле встречаешь «SSOT» / «SSOT-файл компании» / «Единый Источник Правды» — речь про неё (агент найдёт файл по имени, где бы он ни лежал). Рядом есть SSOT-ы поменьше: `PROFILE.md`, остальные файлы смыслов, системные промпты агентов.

**Лесенка** — методология курса: 1 неделя / 4 недели / после. Темп ученик выбирает сам.
