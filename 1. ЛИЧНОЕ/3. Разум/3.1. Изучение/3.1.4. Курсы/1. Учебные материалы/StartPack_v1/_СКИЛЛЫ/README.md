# Скиллы — навыки команды

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

**Скилл ≠ агент.** Агент — роль с системным промптом. Скилл — инструмент или процесс, которым пользуется любой агент (или владелец напрямую).

## Доступные скиллы

| Скилл | Зачем | Кто вызывает |
|---|---|---|
| [auto-context-pull](auto-context-pull/) | **Основной маршрут discovery.** Полуавтоматический сбор контекста: 5 ссылок (сайт + соцсети + облако + ZIP + 3 голосовые) → команда читает сама → заполняет `_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md` | CEO сразу после Onboarding |
| [agent-creator](agent-creator/) | Собирает нового агента под задачу за 4 вопроса | CEO (по запросу) или владелец напрямую |
| [business-discovery](business-discovery/) | **Fallback** для бизнесов без сайта/облака — детальный чек-лист 9 категорий через `_РАБОТА/ВХОДЯЩЕЕ/` | CEO, если auto-pull не подходит |

## Как вызвать скилл

В чате Cursor:
- Напрямую: «запусти agent-creator», «создай агента».
- Через CEO: он сам предложит, когда задача требует нового сотрудника.

## Чем отличается от агента

| Параметр | Агент | Скилл |
|---|---|---|
| Имеет роль и личность | Да | Нет |
| Имеет состояние и логи | Да | Нет (или минимальное) |
| Постоянно «активен» по триггерам | Да | Запускается явно |
| Можно дать feedback в системный промпт | Да | Только обновлять инструкцию |
| Пример | «Маркетолог», «Юрист» | «agent-creator», «humanizer-ru», «week-retro» |

## Что планируется в v1.3

- `humanizer-ru` — очистка русских текстов от AI-следов (для Маркетолога и других контентных).
- `week-retro` — структурированный шаблон еженедельной ретроспективы.
- `business-canvas` — генератор Lean Canvas из `_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md`.

См. [`../_СИСТЕМА/ВЕРСИЯ.md`](../_СИСТЕМА/ВЕРСИЯ.md) → Дорожная карта.
