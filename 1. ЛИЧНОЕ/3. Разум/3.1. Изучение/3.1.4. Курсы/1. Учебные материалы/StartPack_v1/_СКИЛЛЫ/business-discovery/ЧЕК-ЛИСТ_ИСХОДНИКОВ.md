# Чек-лист — что принести на discovery

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»
>
> **С 1.3.0 это fallback.** Основной маршрут — `auto-context-pull` (5 ссылок + ZIP + 3 голосовые). Этот детальный чек-лист CEO даёт владельцу, у которого нет сайта/облака, или который сам захотел разобрать материалы по категориям.

CEO даёт этот чек-лист ученику в начале discovery. Ученик кидает что есть в `_ЗНАНИЯ/_ИСХОДНИКИ/<категория>/` или просто URL/текст в чат — Архивариус разложит. Цель — добить **карту смыслов** (`_ЗНАНИЯ/КАРТА_СМЫСЛОВ.md`) до 🟢 (≥80% полей подтверждено).

## 🌐 Сайт и каналы (`_ИСХОДНИКИ/сайт/`)

- [ ] Главный сайт — URL.
- [ ] Все посадочные / квизы / лид-магниты — URL.
- [ ] Telegram-канал, инстаграм, YouTube — ссылки.
- [ ] Блог / база знаний / документация — URL.
- [ ] Скриншоты главных страниц если сайта нет.

## 💼 Продукты (`_ИСХОДНИКИ/продукты/`)

- [ ] Прайс-лист (Excel / PDF / страница сайта).
- [ ] Описания услуг / карточки товаров.
- [ ] Тарифы и пакеты.
- [ ] Промокоды и акции, действующие сейчас.
- [ ] Фото / рендеры / портфолио.

## 📞 Продажи (`_ИСХОДНИКИ/продажи/`)

- [ ] Скрипт продажи (звонок / переписка).
- [ ] КП-шаблон (один или несколько).
- [ ] Договор-шаблон.
- [ ] Скриншот воронки CRM (стадии, конверсии).
- [ ] Выгрузка последних 20–50 сделок (CSV/Excel) — обезличенная.
- [ ] Типичные возражения и ответы.

## 👥 Клиенты (`_ИСХОДНИКИ/клиенты/`)

- [ ] Портреты ЦА (если есть документ).
- [ ] Реальные кейсы (5–10 штук) — что было, что сделали, что стало.
- [ ] Отзывы (текстом, скриншотами с площадок).
- [ ] Выгрузка из CRM по сегментам.
- [ ] Транскрипты звонков с клиентами (если ведёшь).

## 📋 Регламенты и процессы (`_ИСХОДНИКИ/регламенты/`)

- [ ] Должностные инструкции / роли в команде.
- [ ] Чек-листы по процессам (приём заявки, исполнение, доставка, поддержка).
- [ ] SOP / стандарты работы.
- [ ] Memo и важные внутренние решения.
- [ ] Корпоративные правила (если есть).

## 💰 Финансы (`_ИСХОДНИКИ/финансы/`)

- [ ] Выручка / расходы за последние 12 мес (агрегировано).
- [ ] Юнит-экономика / маржа по продуктам.
- [ ] Метрики LTV, CAC, ARPU (если считаешь).
- [ ] Источники доходов в разбивке по каналам.

*Не клади сюда выписки со счетов и реквизиты с полными номерами — только агрегаты.*

## 🥊 Конкуренты (`_ИСХОДНИКИ/конкуренты/`)

- [ ] Список 3–5 главных конкурентов: название + URL.
- [ ] Скриншоты их сайтов / прайсов.
- [ ] Что у них лучше / хуже (если знаешь).

## 🎨 Бренд (`_ИСХОДНИКИ/бренд/`)

- [ ] Логотип, фавикон, фирменные цвета.
- [ ] Брендбук / гайдлайн (если есть).
- [ ] Голос и тон (примеры удачных постов от твоего имени).
- [ ] Миссия / ценности / позиционирование текстом.

## 📦 Прочее (`_ИСХОДНИКИ/прочее/`)

- [ ] Награды, сертификаты, лицензии.
- [ ] Презентации (питч-дек, презентация для партнёров).
- [ ] Стратегические документы (дорожные карты, OKR, цели на год).
- [ ] Что-то важное, что не подошло в категории — кидай сюда.

---

## Что НЕ нужно нести
- Пароли, токены доступа, ключи API → отдельный менеджер паролей.
- Полные банковские выписки → только агрегаты.
- Персональные данные клиентов в нарушение 152-ФЗ → согласие или обезличивание.
- Чужие конфиденциальные документы (NDA, чужие договоры) → не клади без права.

## Минимальный набор для старта

Если совсем нет времени — собери хотя бы это:
1. URL сайта (1 строка).
2. Прайс или описание главных продуктов.
3. 3 кейса в формате «было → стало».
4. Скриншот воронки CRM или текстовое описание стадий.
5. 1 реальный отзыв.

С этим минимумом discovery займёт 30 минут и даст 60% картины.
