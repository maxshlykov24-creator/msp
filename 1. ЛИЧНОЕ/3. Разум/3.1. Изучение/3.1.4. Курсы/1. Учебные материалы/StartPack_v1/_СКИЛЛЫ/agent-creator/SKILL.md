# agent-creator

Полный протокол: [`ИНСТРУКЦИЯ.md`](ИНСТРУКЦИЯ.md)
Шаблоны для генерации: [`ШАБЛОН_АГЕНТА/`](ШАБЛОН_АГЕНТА/)
Готовые примеры: [`ПРИМЕРЫ/`](ПРИМЕРЫ/) — Маркетолог, Юрист

## Когда активировать
- Прямые: «создай агента / сотрудника / Маркетолога / Юриста / SMM / аналитика».
- Косвенные: «эту задачу некому отдать», «мне не хватает Х», «хочу делегировать Y».
- CEO предложил при маршрутизации, владелец согласился.

## Что на выходе (за 3-5 минут диалога)
1. Папка `_АГЕНТЫ/<Имя>/` с тремя файлами: `SKILL.md`, `СИСТЕМНЫЙ_ПРОМПТ.md`, `README.md`.
2. Файл `.cursor/rules/<NN>-<имя>.mdc` с триггерами.
3. Запись в `_АГЕНТЫ/README.md` (карта команды).
4. Уведомление в `_АГЕНТЫ/CEO/ЛОГИ/ИНСАЙТЫ_О_ВЛАДЕЛЬЦЕ.md`: «появился агент Х».

## Принципы
- **Один агент = одна роль.** Не швейцарский нож. Если просят «маркетолог + продажник» — создаём двоих.
- **Имя — существительное единственного числа на русском.** «Маркетолог», «Юрист», «Продажник», «Дизайнер», «Аналитик».
- **Не пиши промпт «на коленке».** Используй шаблоны из `ШАБЛОН_АГЕНТА/`.
- **Вдохновляйся примерами.** В `ПРИМЕРЫ/` — два готовых эталона, переиспользуй структуру.
