# Архив

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес»

Сюда уезжает всё, что отжило, но удалять рано. Архивариус — единственный, кто пишет сюда автоматически.

## Структура

```
_АРХИВ/
├── ГГГГ-ММ/                          ← по году-месяцу архивации
│   ├── <имя_файла>__причина.расш
│   ├── <имя_папки>__причина/
│   └── ...
└── README.md (этот файл)
```

## Причины (суффиксы)

| Суффикс | Что значит |
|---|---|
| `__устарело` | Заменено новой версией в активной части |
| `__дубликат` | Точная копия есть в активной части |
| `__отменено` | Задача закрыта без результата |
| `__финал` | Задача завершена, файл идёт в долгосрочное хранение |

Примеры:
- `2026-06/договор-аренды_v1__устарело.pdf`
- `2026-07/проект-сайт-х__отменено/` (целая папка задачи)

## Правила

- **Не удаляем.** Только переносим. Удаление — только владелец явно.
- **Не чистим архив.** Он растёт. Раз в год — на ретроспективе можно решить, что вынести в `_АРХИВ/_ХОЛОДНЫЙ/` (в zip) или удалить — но это решение владельца.
- **Имена файлов сохраняем.** Только добавляем суффикс с причиной.

## Как восстановить

Просто перенести из `_АРХИВ/ГГГГ-ММ/` обратно в `_ЗНАНИЯ/` или `_РАБОТА/`. Архивариус увидит, обновит индекс.

## Поиск

`grep -rli "что-то" _АРХИВ/` или попроси Архивариуса: «найди в архиве файл про X».
