# Запуск ИИ-Слушателя звонков

Ставим на ту же VPS, что и в Модуле 3. Питон 3.11+.

## 1. AssemblyAI — ключ и бюджет
1. Регистрация по реф-ссылке (даёт бонус на баланс): **https://assemblyai.cello.so/61A0jvRYzVU**
2. Пополни баланс на $10 — этого хватает надолго (примерно $0,09–0,15 за час разговора).
3. Скопируй **API key** из личного кабинета.

## 2. Telegram-бот
1. Напиши @BotFather → `/newbot` → получи **токен**.
2. Узнай свой `chat_id`: напиши боту любое сообщение, затем открой
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе будет `chat.id`.
   (Для канала/группы — добавь бота туда и возьми id оттуда; для каналов id с минусом.)

## 3. Установка
```bash
cd StartPack_M5_base
python3 -m venv .venv && source .venv/bin/activate
pip install -r app/requirements.txt
cp .env.example .env          # заполни ASSEMBLYAI_API_KEY, TELEGRAM_*, CRM
```

## 4. Локальный прогон (проверка до CRM)
```bash
cd app && uvicorn main:app --host 0.0.0.0 --port 8000
```
В другом терминале:
```bash
bash curl_test.sh "https://ПРЯМАЯ_ССЫЛКА_НА_mp3"
```
Через ~30–90 сек транскрипт со спикерами придёт в Telegram. Это и есть базовый результат.

## 5. Доступ снаружи (чтобы CRM достучалась)
CRM шлёт вебхук на публичный HTTPS-адрес. Варианты:
- **Свой домен + reverse-proxy** (nginx/Caddy) на порт 8000, как в Модуле 3.
- Быстрый тест: туннель (`cloudflared tunnel` / `ngrok http 8000`) — даст временный HTTPS-URL.

Этот URL подставляешь в настройку вебхука CRM (см. `ИНСТРУКЦИЯ_AMO.md` / `ИНСТРУКЦИЯ_BITRIX.md`).

## 6. Автозапуск (systemd)
`/etc/systemd/system/listener.service`:
```ini
[Unit]
Description=AI Listener
After=network.target

[Service]
WorkingDirectory=/opt/listener/app
ExecStart=/opt/listener/.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
EnvironmentFile=/opt/listener/.env
Restart=always

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl daemon-reload && sudo systemctl enable --now listener
curl -s http://localhost:8000/healthz     # → {"status":"ok"}
```

## 7. (Опц.) Оценка звонка
1. `cp company_context.example.md company_context.md` и заполни под свой бизнес (возьми из карты смыслов = SSOT компании, собранной в М1–М2).
2. В `.env`: `LLM_ENABLED=true`. Перезапусти сервис.
3. Теперь в Telegram придёт транскрипт + балл по твоему чек-листу + красные флаги.

## Если записи звонков доступны только из РФ
Ссылки телефонии (UIS/Мегафон и др.) часто открываются только с российского IP — держи сервер в РФ. Если при этом AssemblyAI/Telegram у тебя заблокированы, пропиши прокси (exit-node) в `.env`:
```
HTTPS_PROXY=http://user:pass@host:port
```
Запись скачивается напрямую (РФ), а к AssemblyAI/Telegram сервис идёт через прокси. Стек «свой сервер + exit-node» — тот же, что разбирали для обхода блокировок.
