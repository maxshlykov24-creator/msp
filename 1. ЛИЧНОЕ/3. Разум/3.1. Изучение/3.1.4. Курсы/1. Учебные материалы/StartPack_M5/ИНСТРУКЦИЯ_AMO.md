# Подключение AmoCRM

Цель: когда в AmoCRM появляется звонок с записью — наш сервис получает вебхук, скачивает запись и присылает транскрипт в Telegram.

## Как в AmoCRM появляется запись звонка
Звонок в AmoCRM прилетает от вашей телефонии (Mango, UIS, Sipuni, Билайн и т.д.) и оседает **примечанием** (note) на сделке или контакте: тип `call_in` (входящий) / `call_out` (исходящий), а ссылка на mp3 лежит в `params.link`. Поэтому ловим момент добавления такого примечания.

## Вариант А (простой): вебхук «Цифровой воронки»
Подходит, если телефония кладёт ссылку на запись прямо в данные вебхука.

1. AmoCRM → **Настройки** → **Интеграции** → **Вебхуки** (или раздел «Цифровая воронка» → «Вебхук»).
2. Добавить вебхук, URL: `https://ВАШ_ДОМЕН/webhook/amo-call`
3. Событие: **«Примечание добавлено»** (note added). Если доступна фильтрация — только примечания-звонки.
4. Сохранить. Сделать тестовый звонок → проверить, что в логах сервиса пришёл вебхук.

Сервис сам найдёт ссылку (`link`), телефон (`phone`) и длительность (`duration`) в данных вебхука.

## Вариант Б (надёжный): вебхук + дотягивание через API
Если в вебхуке нет прямой ссылки — сервис достанет её сам по API. Для этого нужен токен:

1. AmoCRM → **Настройки** → **Интеграции** → **Создать интеграцию** → внешняя.
2. Права: **на чтение** сделок, контактов и примечаний.
3. Получить **долгосрочный токен** (long-lived token).
4. В `.env` заполнить:
   ```
   AMOCRM_SUBDOMAIN=ваш_поддомен      # из ваш_поддомен.amocrm.ru
   AMOCRM_LONG_TOKEN=ваш_долгосрочный_токен
   ```
5. Вебхук настраивается как в Варианте А. Если прямой ссылки нет, сервис по `element_id` сделки найдёт свежий звонок с записью (в т.ч. на связанном контакте).

## Проверка
- Сделайте реальный звонок (или импортируйте запись), дождитесь примечания-звонка в AmoCRM.
- В логах сервиса должно появиться `[amo] звонок обработан`, а в Telegram — транскрипт.
- Если записи нет в вебхуке и не настроен токен — в логах будет `ссылка на запись не найдена`.

## Частые проблемы
- **Вебхук не приходит** — проверьте, что URL доступен снаружи по HTTPS (см. `ЗАПУСК.md`).
- **Запись не скачивается** — ссылки телефонии бывают доступны только с российского IP. Сервер должен быть в РФ (или см. раздел про прокси в `ЗАПУСК.md`).
- **Ссылка с экранированием** (`https:\/\/...`) — сервис чистит её сам.
