# StartPack M5 · ИИ-Слушатель звонков (база)

Маленький сервис: звонок завершился в CRM → вебхук → запись скачивается → AssemblyAI делает транскрипт со спикерами → текст приходит в Telegram. Опционально — оценка звонка по чек-листу твоей компании.

## Что внутри
```
app/
  main.py        — приём вебхуков AmoCRM/Bitrix24 (FastAPI), обработка в фоне
  crm.py         — извлечение ссылки на запись из вебхука (Amo / Bitrix)
  amocrm.py      — API AmoCRM: дотянуть запись, (опц.) вернуть примечание
  bitrix.py      — API Bitrix24: voximplant.statistic.get, (опц.) комментарий
  asr.py         — AssemblyAI: транскрибация + диаризация (кто говорит)
  format.py      — сборка сообщения для Telegram
  telegram.py    — отправка результата
  llm.py         — опц.: оценка звонка через AssemblyAI LLM Gateway
  prompts/eval_skeleton.txt — универсальный скелет оценки
  config.py, net.py, requirements.txt
company_context.example.md  — шаблон контекста компании (для оценки)
.env.example                — настройки
curl_test.sh                — ручной тест без CRM
ИНСТРУКЦИЯ_AMO.md / ИНСТРУКЦИЯ_BITRIX.md — настройка вебхука в CRM
ЗАПУСК.md                   — пошаговый деплой на VPS
```

## Быстрый старт
1. `ЗАПУСК.md` → ключ AssemblyAI + Telegram-бот + установка.
2. `bash curl_test.sh <ссылка_на_mp3>` → транскрипт в Telegram.
3. Подключи свою CRM по `ИНСТРУКЦИЯ_AMO.md` или `ИНСТРУКЦИЯ_BITRIX.md`.
4. (Опц.) Включи оценку: заполни `company_context.md`, поставь `LLM_ENABLED=true`.

## Два режима
- **База** (`LLM_ENABLED=false`): только транскрибация. Ничего, кроме ключа AssemblyAI и Telegram, не нужно.
- **С оценкой** (`LLM_ENABLED=true`): транскрипт + балл по твоему чек-листу + красные флаги + следующий шаг. Движок универсальный — под бизнес настраивается файлом `company_context.md`.

## Принцип
Универсальный движок один на все бизнесы. Вся специфика твоей компании (продукт, ICP, чек-лист, запрещённые фразы) живёт в `company_context.md` и докручивает оценку под тебя — этот контекст ты уже собрал в карте смыслов (SSOT-файл компании) в Модулях 1–2.
