## 5. Приёмы и грабли

**Режет счёт**

1. Каскад: дешёвая просеивает, дорогая решает спорные.
2. Суффикс `:batch` — обычно минус 50%. Пиши `anthropic/claude-sonnet-5:batch`.
3. Режь выход, не вход. «Только JSON, без объяснений».
4. Не грузи всю базу на каждый запрос.
5. Промпт крути на `:free`, финальный прогон — на боевой.

**Ломает деньги и нервы**

1. Лечить плохой контекст дорогой моделью.
2. Ставить `:latest` или `openrouter/auto` на бой — поведение плывёт.
3. Флагман на однотипном конвейере (тысячи звонков на Opus).
4. Дешёвая модель на тексте, который читает клиент.
5. Не поставить месячный потолок на ключ OpenRouter.

`:free` — лимиты, очереди, нет гарантии завтра. Для отладки да, для процесса бизнеса нет.

## 6. Тройной прогон

Если задача важная — не верь одной модели.

1. Один и тот же промпт.
2. Sonnet 5 — daily структура и код.
3. Terra или Gemini 3.1 Pro — другой угол.
4. Свести лучшее. Спор о качестве — Sol или Fable.

Двадцать своих примеров с эталоном надёжнее ощущения «эта умнее». Совпала дешёвая на 18 из 20 — ставь её, умную оставь на спорные.

Проверить цены перед постановкой на поток:

```bash
curl -s https://openrouter.ai/api/v1/models > models.json
python3 -c "
import json
models = json.load(open('models.json'))['data']
for m in sorted(models, key=lambda x: float(x['pricing']['prompt'])):
    vhod  = float(m['pricing']['prompt'])     * 1000000
    vyhod = float(m['pricing']['completion']) * 1000000
    print(m['id'], '| вход', round(vhod, 3), '| выход', round(vyhod, 3))
"
```
