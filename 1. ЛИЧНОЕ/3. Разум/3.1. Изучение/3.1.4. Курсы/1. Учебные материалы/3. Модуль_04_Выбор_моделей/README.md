## 🚀 С ЧЕГО НАЧАТЬ:

1. **Прочитай инструкцию** (файл со "Старт" или главный README)
2. **Открой презентацию** в браузере (двойной клик)
3. **Следуй шагам** из инструкции
4. **Используй шаблоны** для своих задач

---

## 💡 ВАЖНО:

- Все файлы открываются в Cursor или браузере
- Презентации (.html) — только в браузере
- Markdown (.md) — в Cursor или любом редакторе
- Не торопись — лучше качественно, чем быстро

## 🤖 АГЕНТ @модель

**Автоматический выбор оптимальной AI-модели**

### Что это:
Агент помогает выбрать лучшую модель для любой задачи за < 1 сек

### Как установить:
Агент снят с маршрута 2026-08-13 (`99_АРХИВ/2026-08-13_роли/данные/МОДЕЛЬ/`). Живая таблица — `ТАБЛИЦА_ВЫБОРА_МОДЕЛЕЙ.md`. Вернуть агента — только по явному «да». Китовый инсталлятор лежит в `агент_модель/`.

### Как использовать:
```
@модель какая модель для [твоя задача]
```

**Примеры:**
- `@модель какая модель для написания поста`
- `@модель оцени задачу: Python скрипт`
- `@модель создай план --detail`
