# 🎱 StartPack «Конструктор: собери шестого»

> © 2026 Денис Леушин · Курс «Внедрение ИИ в бизнес» · Модуль 09 · denispleada.ru

Рабочее пространство для сборки твоего **шестого AI-сотрудника** — своего, под свою задачу. Открой папку в Cursor и начни с [`НАЧНИ_ОТСЮДА.md`](НАЧНИ_ОТСЮДА.md).

## За один проход
1. Прочитай фрейм → 2. Скажи Cursor «собери шестого, думай как конструктор-агентов» → 3. (опц.) подключи Тэн → 4. собери один шаг, проверь на живом примере.

## Граница
Фрейм отвечает **кого и зачем** собираем. Тэн — **как собрать надёжно**. Сначала фрейм, потом Тэн.

Учебные/технические вопросы — **@denispleada**.
