# _РАБОТА — твои собранные агенты

Сюда Конструктор складывает файлы каждого собранного сотрудника. Один агент — одна папка:

```
_РАБОТА/
  <имя-агента>/
    README.md            — кто это и на какой боли срабатывает
    SKILL.md             — как думает (роль × модель × фронт × ограничения)
    СИСТЕМНЫЙ_ПРОМПТ.md   — ядро поведения
```

Шаблон этих трёх файлов — в [`../_СКИЛЛЫ/agent-creator/ШАБЛОН_АГЕНТА/`](../_СКИЛЛЫ/agent-creator/ШАБЛОН_АГЕНТА/). Начни с самого узкого/дорогого шага своей задачи — это и есть твой шестой.
