# 🛠 Тэн — твоя инженерная команда для сборки шестого

> Тэн — это русский вход к **gstack**: open-source «виртуальной инженерной команде» Гарри Тана (президент YC) для AI-редакторов. Целиком репозиторий в StartPack не вшит (он тяжёлый — 54 МБ, браузерный тулинг). Ставится одной командой ниже.

## Зачем он тебе
Собрать шестого «на удачном промпте» — лотерея. Тэн даёт собрать **по-взрослому**: спланировать, отревьюить чужим взглядом и проверить, что агент реально работает. Это та же логика, по которой собраны мои агенты в PLEADA.

```
spec (что строим)  →  ревью плана (CEO / инженер / дизайн)  →  сборка  →  ревью кода  →  «почему не работает» (debug)
```

## Установка (1 команда)
Открой терминал в этой папке и запусти:

```bash
bash _ТЭН/setup.sh
```

Скрипт склонирует gstack в `_ТЭН/gstack/` (нужен `git`). Полный интерактивный/браузерный тулинг — по желанию: внутри `_ТЭН/gstack/` выполни `./setup --prefix` (нужен runtime `bun` и Claude Code; на Cursor работает методологическая часть — как контекст и чек-листы).

> ⚠️ Без Claude Code/bun команды gstack всё равно полезны: открой нужный `.md` из `_ТЭН/gstack/` и попроси Cursor пройтись по его чек-листу для твоего агента. Карта — [`КОМАНДЫ_ТЭН.md`](КОМАНДЫ_ТЭН.md).

## Как звать
Пиши задачу по-русски, Тэн сам подберёт нужную команду:
- «Тэн, спланируй моего агента по-взрослому» → spec + ревью плана
- «Тэн, отревьюй, что я собрал» → review
- «Тэн, почему агент не делает то, что нужно» → investigate (поиск корня)
