# 3 · Сборка агента (Mac)

> На этом шаге Cursor по одному промпту собирает workspace агента из артефактов твоего бизнеса (М2). Ты не пишешь markdown — Cursor пишет за тебя.

## Перед стартом проверь

- [ ] Прошёл `1_УСТАНОВКА.md` → `node --version` показывает v20+ или v22+, `openclaw doctor` зелёный.
- [ ] Прошёл `2_ДОСТУПЫ.md` → у тебя на руках 4 ключа (TG-токен от BotFather, OpenRouter API key, IP+root-пароль VPS Timeweb, SSH-ключ создан).
- [ ] Cursor открыт в корне твоего StartPack (там, где есть `_ЗНАНИЯ/`, `_БИЗНЕС/`, `_АГЕНТЫ/`).

## Шаг 1 · Скопировать шаблон агента в StartPack

В терминале Mac (внутри Cursor: `Ctrl+`` ` `):

```bash
# Замени <путь_к_набору> на свой (где распаковал m3-mac.zip)
cp -r <путь_к_набору>/agent_template ~/StartPack/_АГЕНТЫ/AI-Менеджер_1-й_линии
ls ~/StartPack/_АГЕНТЫ/AI-Менеджер_1-й_линии
```

Должно появиться:
- `README.md`
- `ПРОМПТ_СБОРКИ.md`
- `ПРОМПТ_ДЕПЛОЯ.md`
- `openclaw.config.example.json`
- `.env.example`
- `workspace/` (с шаблонами `IDENTITY.md`, `BOOTSTRAP.md`, `MODE_LEAD_QUAL.md`, `AGENTS.md`, `HEARTBEAT.md` — все с метками `🟡` в местах под твой бизнес)

## Шаг 2 · `.env` с твоими ключами

```bash
cd ~/StartPack/_АГЕНТЫ/AI-Менеджер_1-й_линии
cp .env.example .env
nano .env    # или открой в Cursor: код+нажми на .env в дереве
```

Заполни:
```
TG_BOT_TOKEN_LEAD_QUAL=<токен от BotFather из шага 2_ДОСТУПЫ §1>
OPENROUTER_API_KEY=<ключ от OpenRouter из шага 2_ДОСТУПЫ §2>
HANDOFF_MANAGER_TG=<твой Telegram username, например @denis>
```

Сохранить: Ctrl+O, Enter. Выйти: Ctrl+X.

## Шаг 3 · Промпт сборки в Cursor

1. Открой Cursor в корне `~/StartPack/`.
2. Открой Cursor-чат: **`Cmd+L`** → выбери режим **Agent**.
3. Открой файл `_АГЕНТЫ/AI-Менеджер_1-й_линии/ПРОМПТ_СБОРКИ.md`, скопируй блок «**Команда агенту**» целиком (под заголовком `## Команда агенту`).
4. **Допиши 3 жёлтые места** в начале промпта:
   - `🟡 ICP_ОПИСАНИЕ` — кто твой клиент в одну фразу (пример: «B2B-собственники салонов красоты СПб, чек 50–200 тыс ₽»).
   - `🟡 КАК_ПРИШЛИ_ЛИДЫ` — основной канал (Instagram-реклама / SEO / реферальная сеть / холодные звонки).
   - `🟡 ХЭНДОФФ_СЦЕНАРИЙ` — что должно произойти, когда лид «горячий» (пример: «бот пишет резюме в формате X, кидает в группу #leads-hot, тегает менеджера»).
5. Отправь промпт.

Через 1–2 минуты Cursor:
- Прочитает `_ЗНАНИЯ/КОНТЕКСТ.md`, `_БИЗНЕС/ВОРОНКА.md`, `_БИЗНЕС/МАТРИЦА_РОЛЕЙ.md`.
- Заполнит все 5 файлов в `workspace/` — заменит каждое `🟡` на текст из артефактов М2.
- Покажет diff. Прими (Accept All).

## Шаг 4 · Проверка качества (1 минута)

```bash
cd ~/StartPack/_АГЕНТЫ/AI-Менеджер_1-й_линии
grep -r "🟡" workspace/    # должно вывести пусто
```

Если вывело строки — там, где Cursor не нашёл ответа в твоих артефактах. Открой эти файлы, дозаполни вручную или попроси Cursor «допиши маркер 🟡 в файле X — вот что подставить».

## Шаг 5 · Локальный тест (опционально, 3 мин)

Прежде чем гнать на VPS, проверь, что бот вообще отвечает локально:

```bash
cd ~/StartPack/_АГЕНТЫ/AI-Менеджер_1-й_линии

# Конфигурация (один раз)
openclaw configure   # wizard про OpenRouter ключ

# Зарегистрировать агента
openclaw agents create lead-qualifier \
  --workspace ./workspace \
  --config ./openclaw.config.example.json

# Подключить Telegram
source .env
openclaw channels add telegram \
  --token "$TG_BOT_TOKEN_LEAD_QUAL" \
  --agent lead-qualifier

# Запустить gateway в foreground
openclaw gateway run
```

В терминале появится:
```
Gateway listening on port 19000
Agent registered: lead-qualifier
Channel connected: telegram (@your_bot)
```

→ Открой Telegram, найди свой бот, напиши `/start`. Должен поприветствовать твоим тоном (как в `_ЗНАНИЯ/КОНТЕКСТ.md`) и задать первый квалификационный вопрос.

**Если ответил — переходи к `4_ДЕПЛОЙ_VPS.md`.** Локальный gateway убей `Ctrl+C`.

**Если молчит** — открой `5_TROUBLESHOOTING.md` § «Бот молчит».
