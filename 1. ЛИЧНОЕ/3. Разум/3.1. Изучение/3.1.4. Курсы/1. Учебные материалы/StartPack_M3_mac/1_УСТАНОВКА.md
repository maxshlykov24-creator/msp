# Mac · настройка под Модуль 3 (OpenClaw)

> Если ты на Windows — открой `WINDOWS_SETUP_M3.md`.
> На Mac большая часть из коробки работает, нужны 4 короткие проверки.

## Что нужно

М3 теперь на **OpenClaw** (Node.js фреймворк), а не на Python. Это упрощает: ты не пишешь код, только markdown-конфиги. Cursor пишет markdown за тебя.

## 1. Node.js 20+ через Homebrew

⚠️ **Критично:** OpenClaw требует Node.js **20 LTS или новее**. На 18 — не запустится. На 22 LTS — работает.

Проверка:
```bash
node --version    # должно быть v20.x.x или v22.x.x
```

Если `command not found` или ниже 20 — установи через Homebrew:

```bash
# Если нет Homebrew:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установка Node.js LTS (на момент 2026-05 это 22.x)
brew install node@22

# Если до этого был более старый Node — указать новый явно
brew unlink node 2>/dev/null
brew link --force --overwrite node@22
```

После установки `node --version` должна показать `v20.x.x` или `v22.x.x`.

## 2. OpenClaw

```bash
npm install -g openclaw
openclaw --version    # 2026.5.x или новее
```

⏱ ~30 секунд. Это весь установочный процесс — один npm-пакет, ставит CLI глобально.

Проверка работоспособности:
```bash
openclaw doctor
# должен пройти все проверки (зелёные галочки)
```

Если `command not found` после `npm install -g`:
- Проверь куда npm ставит global: `npm prefix -g` → должно быть `/opt/homebrew` (M1/M2 Mac) или `/usr/local` (Intel Mac).
- Этот путь должен быть в `$PATH`. Если нет — добавь в `~/.zshrc`:
  ```bash
  echo 'export PATH="$(npm prefix -g)/bin:$PATH"' >> ~/.zshrc
  source ~/.zshrc
  ```

## 3. Запуск OpenClaw локально (для теста)

```bash
# В корне твоей папки агента (где лежит workspace/, tools/, .env)
cd ~/StartPack/_АГЕНТЫ/AI-Менеджер_1-й_линии

# Конфигурация (один раз)
openclaw configure
# wizard задаст вопросы про OpenRouter ключ и провайдеров

# Создать агента
openclaw agents create lead-qualifier \
  --workspace ./workspace \
  --config ./openclaw.config.example.json

# Подключить Telegram (читает токен из .env)
source .env
openclaw channels add telegram \
  --token "$TG_BOT_TOKEN_LEAD_QUAL" \
  --agent lead-qualifier

# Запустить gateway в foreground для теста
openclaw gateway run
```

Через 2–3 секунды в терминале появится:
```
Gateway listening on port 19000
Agent registered: lead-qualifier
Channel connected: telegram (@your_bot_username)
```

→ Открой Telegram, напиши боту `/start`. Должен ответить.

Для прерывания: **Ctrl+C** (закроет gateway, освободит порт).

## 4. SSH client (для деплоя на VPS)

OpenSSH client встроен в macOS — ничего ставить не нужно.

### SSH-ключ

```bash
ssh-keygen -t ed25519 -C "course-m3"
# Enter, Enter, Enter (без пароля для простоты)
```

Сохранится в `~/.ssh/id_ed25519` (приватный) и `~/.ssh/id_ed25519.pub` (публичный).

⚠️ **Права на папку и ключ важны** (на Mac в отличие от Windows):
```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub
```

Если права кривые — `ssh` ругается «WARNING: UNPROTECTED PRIVATE KEY FILE» и не подключается.

### Скопировать публичный ключ

```bash
cat ~/.ssh/id_ed25519.pub | pbcopy
```

`pbcopy` положил в буфер обмена. Cmd+V в Timeweb при создании VPS.

## 5. Возможные предупреждения macOS

### Codesign warning

При первом запуске `node` или `openclaw` может появиться окошко:
> «`node` is from an unidentified developer».

Решение: Системные настройки → Конфиденциальность и безопасность → внизу будет «Разрешено всё равно» для node → нажать.

(Только при первом запуске после установки. На последующих не повторяется.)

## 7. Часто полезные mac-only команды

```bash
# Открыть папку в Finder из терминала
open .

# Скопировать в буфер обмена
cat file.txt | pbcopy

# Вставить из буфера
pbpaste > file.txt

# Звуковое уведомление (полезно после долгой команды)

```

## Шпаргалка

| Команда | Что |
|---|---|
| `node --version` | проверка Node (нужно v20+) |
| `npm install -g openclaw` | установка OpenClaw глобально |
| `openclaw doctor` | автопроверка работоспособности |
| `openclaw configure` | первичный wizard |
| `openclaw agents create <name>` | создать агента |
| `openclaw channels add telegram` | подключить TG-бот |
| `openclaw gateway run` | запустить локально (foreground) |
| `openclaw gateway stop` | остановить |
| `Ctrl+C` | прерывание gateway |
| `ssh root@<IP>` | подключиться к VPS |
| `cat ~/.ssh/id_ed25519.pub \| pbcopy` | скопировать публичный SSH-ключ |

Готов к запуску. На VPS дальше — см. `ДЕПЛОЙ_VPS.md`.
