# 🍎 Шпаргалка команд — Mac

> Все нужные команды М3 на одной странице. Распечатай или держи открытой.

## Установка окружения (один раз)

```bash
# Homebrew (если нет)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Node.js LTS (нужно v20+)
brew install node@22
brew link --force --overwrite node@22

# OpenClaw
npm install -g openclaw

# Проверки
node --version          # v20.x.x или v22.x.x
openclaw --version      # 2026.5.x+
openclaw doctor         # все галочки зелёные
```

## SSH-ключ (один раз)

```bash
ssh-keygen -t ed25519 -C "course-m3"   # Enter, Enter, Enter
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub

# Скопировать публичный в буфер обмена → вставить в Timeweb
cat ~/.ssh/id_ed25519.pub | pbcopy
```

## Сборка агента локально

```bash
cd ~/StartPack/_АГЕНТЫ/AI-Менеджер_1-й_линии

cp .env.example .env
nano .env                 # заполни 3 ключа

# В Cursor: Cmd+L → Agent → промпт из ПРОМПТ_СБОРКИ.md

# Проверка что не осталось 🟡
grep -r "🟡" workspace/   # должно быть пусто
```

## Запуск gateway локально (тест)

```bash
cd ~/StartPack/_АГЕНТЫ/AI-Менеджер_1-й_линии

openclaw configure
openclaw agents create lead-qualifier \
  --workspace ./workspace \
  --config ./openclaw.config.example.json

source .env
openclaw channels add telegram \
  --token "$TG_BOT_TOKEN_LEAD_QUAL" \
  --agent lead-qualifier

openclaw gateway run      # foreground
# Ctrl+C — стоп
```

## Деплой на VPS

```bash
# Подключиться
ssh root@<IP_VPS>

# Скопировать только нужное
scp -r workspace tools openclaw.config.example.json README.md \
  root@<IP_VPS>:/opt/manager-bot/

# На VPS — править .env через nano
ssh root@<IP_VPS> "nano /opt/manager-bot/.env"
```

## Управление gateway на VPS

```bash
# Подключение
ssh root@<IP_VPS>

# Логи
journalctl -u openclaw-gateway -f       # live tail, Ctrl+C для выхода
journalctl -u openclaw-gateway -n 100   # последние 100 строк

# Перезапуск
systemctl restart openclaw-gateway
systemctl status openclaw-gateway

# Стоп / старт
systemctl stop openclaw-gateway
systemctl start openclaw-gateway
```

## Если что-то сломалось

| Симптом | Команда диагностики |
|---|---|
| `node: command not found` | `which node` → если пусто, переустановить через brew |
| `openclaw: command not found` после npm install -g | `npm prefix -g` → проверь, что путь в `$PATH` |
| `openclaw doctor` ругается | прочитай вывод дословно, обычно подсказывает |
| Bot не отвечает | `journalctl -u openclaw-gateway -n 50` на VPS |
| `WARNING: UNPROTECTED PRIVATE KEY FILE` | `chmod 600 ~/.ssh/id_ed25519` |
| `Permission denied (publickey)` | проверь, что в Timeweb сохранён правильный `.pub` |
