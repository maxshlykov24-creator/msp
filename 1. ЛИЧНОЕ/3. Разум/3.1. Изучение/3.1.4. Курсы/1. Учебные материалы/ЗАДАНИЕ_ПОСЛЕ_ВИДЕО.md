**Сложность:** Средняя  
**Предварительные требования:** Просмотрены оба видео модуля 5

## ⚠️ ВАЖНО: ГДЕ ВЫПОЛНЯТЬ ЗАДАНИЕ

**Все работы выполняются в твоей рабочей папке проекта (папка "бизнес" или твой проект).**

**Структура, которую ты создашь:**
```
твоя_папка_бизнеса/
├── .cursor/
│   └── rules/
│       └── [название_агента].mdc  ← файлы правил агентов

**Не создавай агентов в папке обучения!**

### ЭТАП 2: Создание первого агента (60-90 минут)

**Следуй методологии из видео 2 (7 шагов):**

#### Шаг 1: Контекст компании

**Что сделать:**
- Если есть файл с контекстом компании (например, `ВТОРОЙ_МОЗГ.md`) — загрузи его в Cursor
- Если нет — создай краткое описание:
  - Название компании/проекта
  - Чем занимается
  - Как общается с клиентами (тон, стиль)
  - Целевая аудитория

**Где сохранить:**
```
Создай файл в своём проекте, например:
- КОНТЕКСТ_КОМПАНИИ.md
- или в папке проекта/КОНТЕКСТ_КОМПАНИИ.md
```

#### Шаг 2: Определение должности

**Ответь на вопросы:**

1. **Какую работу выполняет этот сотрудник?**
   ```
   [Твой ответ]
   ```

2. **Какие задачи делает ежедневно/еженедельно?**
   ```
   [Список задач]
   ```

3. **Что на выходе?** (пост, отчёт, решение, документ)
   ```
   [Опиши результат]
   ```

4. **Критерии качества — как понять что хорошо?**
   ```
   [Как оцениваешь качество работы]
   ```

#### Шаг 3: Кейсы из интернета (опционально, но рекомендуется)

**Что сделать:**
- Найди примеры похожих агентов или решений
- Посмотри, как другие решают эту задачу
- Выпиши лучшие практики

**Где искать:**
- GitHub (поиск по "cursor agent" + твоя задача)
- Сообщества Cursor
- Примеры из курса

**Сохрани в:**
```
3. АГЕНТЫ/[НАЗВАНИЕ_АГЕНТА]/_КОНТЕКСТ/кейсы.md
```

#### Шаг 4: Мнение эксперта (опционально)

**Если есть возможность:**
- Возьми консультацию у специалиста (30-60 минут)
- Попроси оценить твой проект
- Выпиши ключевые инсайты

**Сохрани в:**
```

#### Шаг 5: Формирование плана

**Что сделать:**

В Cursor напиши:
```

Задачи: [список задач]
Выход: [что на выходе]
Критерии качества: [как оцениваешь]
```

**Или используй шаблон агента:**
```
ШАБЛОН_АГЕНТА.mdc (из материалов для ученика)
```

**Важно:**
- ✅ Работай в режиме **ПЛАН** (не в режиме агента)
- ✅ Внимательно прочитай план перед выполнением
- ✅ Верифицируй план — убедись, что всё правильно
- ✅ Используй правильную модель (Opus для планирования, Claude для креатива)

#### Шаг 6: Создание агента

**Что будет создано:**

1. **Файл правил:**
   ```
   твоя_папка_бизнеса/.cursor/rules/[название_агента].mdc
   ```

2. **Структура папок:**
   ```
   твоя_папка_бизнеса/3. АГЕНТЫ/[НАЗВАНИЕ_АГЕНТА]/
   ├── _КОНТЕКСТ/
   │   ├── примеры/
   │   └── кейсы.md (если есть)
   └── _ЛОГИ/
   ```

3. **Команда для вызова:**
   ```
   @[команда_агента]
   ```

**Проверь что создано (в твоей папке бизнеса):**
- ✅ Файл правил в `.cursor/rules/`
- ✅ Папка агента в `3. АГЕНТЫ/`
- ✅ Есть папки `_КОНТЕКСТ/примеры/` и `_ЛОГИ/`

#### Шаг 7: Тестирование и самообучение

**Дай агенту 3-4 задачи:**

**Задача 1: Базовая**
- Дай простую задачу
- Получи результат
- Дай обратную связь: "Нужны правки" + укажи что улучшить

**Задача 2: Похожая**
- Дай похожую задачу
- Проверь что агент применил урок из задачи 1
- Дай оценку: "Отлично" если применил, "Нужны правки" если нет

**Задача 3: Более сложная**
- Дай более сложную задачу
- Проверь что агент использует примеры из `_КОНТЕКСТ/примеры/`
- Дай оценку

**Задача 4: Стандартная (опционально)**
- Дай стандартную задачу, которую будешь давать регулярно
- Проверь что результат соответствует ожиданиям

**Проверь самообучение (в твоей папке бизнеса):**

1. **Проверь логи:**
   ```
   Открой: твоя_папка_бизнеса/3. АГЕНТЫ/[АГЕНТ]/_ЛОГИ/[дата].md
   ```
   Должны быть записи о задачах и уроках.

2. **Проверь примеры:**
   ```
   Открой: твоя_папка_бизнеса/3. АГЕНТЫ/[АГЕНТ]/_КОНТЕКСТ/примеры/
   ```
   Должны быть успешные кейсы.

**✅ Если файлы есть — самообучение работает!**

## 💡 СОВЕТЫ ПО ВЫПОЛНЕНИЮ

### Для выбора задач:
1. Начни с самой "горящей" задачи
2. Не выбирай абстрактные задачи — нужны конкретные
3. Выбирай задачи, которые делаешь регулярно

### Для создания агентов:
1. Используй `@создай_сотрудника` — это проще
2. Работай в режиме **ПЛАН** — всегда
3. Верифицируй план перед выполнением
4. Не усложняй на старте — начни с базового функционала

### Для тестирования:
1. Обязательно давай обратную связь после каждой задачи
2. Проверяй логи и примеры — это ключ к пониманию самообучения
3. Не пропускай тестирование — без этого агент не научится

### Для дообучения:
1. Загружай реальные примеры своих работ
2. Показывай примеры конкурентов (если релевантно)
3. Дообучай постепенно — не всё сразу

### Типичные ошибки:
- ❌ Пропустить тестирование самообучения
- ❌ Не давать обратную связь агенту
- ❌ Создать слишком сложного агента на старте
- ❌ Забыть про структуру папок для логов
- ❌ Работать в режиме агента вместо режима плана
