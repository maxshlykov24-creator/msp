# Учебные материалы (модуль 02: личные задачи)

Материалы курса: инструкции и шаблоны для сборки личной структуры. **Это не инбокс** — сырьевые заметки и файлы без места клади в **[`Входящее`](../../../../Входящее)** (на уровне `Личное`).

## Файлы в этой папке

- **Старт_2_модуль.md** — главная инструкция (начни с этого файла)
- **presentation.html** — презентация урока (открой в браузере)
- **ШАБЛОН_СОЗДАНИЯ_ПАПКИ_ЛИЧНОЕ.md** — шаблон для копирования
- **ШАБЛОН_СТРУКТУРЫ_ЖИЗНЬ.md** — шаблон дерева жизни (актуальный эталон — [`Личное/`](../../../../..))

## Подпапка «Обучение Cursor»

Инструкции по паспорту Cursor, оплате, установке: **[`Обучение Cursor/README.md`](Обучение%20Cursor/README.md)** и нумерованные файлы `01_…`–`05_…` в той же подпапке.

## Подпапка «Модуль 04: Выбор моделей»

Презентация, таблица выбора моделей, инсталлятор агента **`@модель`**: **[`3. Модуль_04_Выбор_моделей/README.md`](3.%20Модуль_04_Выбор_моделей/README.md)**. Рабочие правила и данные агента после установки — в корне проекта: `агенты/МОДЕЛЬ/`, `.cursor/rules/модель.mdc`.

## С чего начать

1. Прочитай **Старт_2_модуль.md**
2. Открой презентацию в браузере
3. Следуй шагам; актуальная логика папок профиля — в `Личное/СТРУКТУРА_И_ПРИНЦИПЫ.md`
