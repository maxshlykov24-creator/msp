## Находки

### [P_] Короткое название

- **Область:** безопасность / устойчивость / технологии.
- **Наблюдение:** факт из источника.
- **Источник:** тип источника, непрозрачный ID, дата; без секрета.
- **Вывод:** вероятное значение.
- **Уверенность:** высокая / средняя / низкая.
- **Влияние:** риск для бизнеса.
- **Следующий шаг:** безопасное действие после согласования.
- **Откат/страховка:** что подготовить перед изменением.
- **Ограничение:** что не удалось проверить.
