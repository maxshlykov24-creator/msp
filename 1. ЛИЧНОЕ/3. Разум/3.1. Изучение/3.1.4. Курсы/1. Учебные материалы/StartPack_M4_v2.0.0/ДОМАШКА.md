## Что нужно сдать (3 артефакта)

### 1. Один `.md`-транскрипт, полученный через `transcribe.py` (или MyMeet веб-кабинет)

Прикрепи `.md`-файл, который реально получился у тебя. Это может быть:
- Транскрипт твоей обезличенной встречи / созвона / голосового;
- Любой публичный аудио / видео (короткий — ≤5 мин) для теста;
- Один из тестовых файлов из `_ТЕСТОВЫЕ_АРТЕФАКТЫ/`.

**Что Лина проверит:**
- Файл реально `.md` (не плоский текст, не аудио).
- В шапке — метаданные: дата, источник, провайдер, длительность, число спикеров.
- В теле — текст со спикерами (если AssemblyAI / MyMeet) или сплошной текст (если OpenRouter Whisper).
- Файл лежит в одной из 5 категорий (`митапы`, `созвоны-подрядчики`, `клиенты`, `эксперты-консультанты`, `личное`) — не в `_INBOX/`.

⚠️ Любой из 3 провайдеров — годится. Главное чтобы файл получился осмысленным.

### 2. Скриншот Cursor с разбором этого транскрипта

Открой свой `.md` → возьми один из готовых промптов в `StartPack_M4/ПРОМПТЫ_РАЗБОРА.md` (по типу твоего файла) → Cursor разберёт и пополнит твой контекст.

Скриншот окна Cursor: слева `.md`, справа — что сделал Cursor (резюме / задачи / обновление карточки клиента / follow-up письмо — что выбрал).

**Зачем:** убедиться что ты освоил **главное** — что Транскрибатор работает в паре с Cursor. Сам по себе `.md`-файл бесполезен. Связка `.md` + Cursor + контекст компании = смысл модуля.

⚠️ Это **не код-задание**. Это **демонстрация рабочего процесса**. Промпт можно копировать as is.

### 3. Скриншот папки `_ТРАНСКРИПТЫ/` в твоей бизнес-папке Cursor

Покажи, что папочная структура развёрнута: 5 категорий + `_INBOX/`. В одной из них (или нескольких) уже лежит твой `.md`.

**Зачем:** чтобы система была не разовой, а постоянной. К Модулю 6 у тебя будет 30–50 файлов — но без правильной папочной структуры всё свалится в кучу.

## FAQ

### У меня нет своих встреч для теста — что делать?

В `_ТЕСТОВЫЕ_АРТЕФАКТЫ/` лежат 3 готовых аудио. Используй один из них. Или возьми любой публичный подкаст / выступление на YouTube — скачай аудио (mp3 / m4a) через любой extractor, прогони через `transcribe.py`.

### Какой провайдер выбрать на старт?

Если хочешь покрыть и встречи, и голосовые — **AssemblyAI + OpenRouter** (оба ключа в `.env`, скрипт сам выберет). Если совсем не хочешь возиться с зарубежной оплатой — **MyMeet** (через веб-кабинет, без скрипта). Один минимум обязателен.

### Можно сдать без скрипта, через веб-кабинет MyMeet?

Да. MyMeet выдаёт готовый `.md` — положи его в правильную папку `_ТРАНСКРИПТЫ/<категория>/` и сделай разбор в Cursor. Это полноценный путь сдачи.

### Где взять разные типы аудио для теста?

- **Голосовое:** запиши прямо в TG (своему боту-помощнику или в Saved Messages), скачай файл.
- **Audio:** любой mp3 — диктофон смартфона, экспорт из MyMeet / Otter.
- **Video:** запиши экран на 30 сек с микрофоном (QuickTime, OBS, Loom).
- **Длинная встреча:** возьми обезличенную Zoom-запись из прошлой недели.

### Можно подключить amoCRM / Битрикс24 / Google Sheets?

Это будет в Модуле 5. Сначала освой базовый цикл «файл → транскрипт → контекст».

### Нужно ли что-то делать с `.md`-файлами регулярно?

Для зачёта — нет. Для жизни — **да**. Раз в неделю заходи в `_ТРАНСКРИПТЫ/` и проси Cursor: «по всем .md за неделю сделай дайджест». Готовый промпт — в `ПРОМПТЫ_РАЗБОРА.md → Бонус · Дайджест за неделю`. Это и есть **главная управленческая практика после курса**.

### Что делать с папкой через 3 месяца, когда там 200 файлов?

Cursor отлично работает с большими объёмами текста. Раз в квартал имеет смысл попросить Cursor «прочитай всё в `_ТРАНСКРИПТЫ/эксперты-консультанты/` и сделай сводную карту рекомендаций всех экспертов» — получишь собственную карту знаний по своему бизнесу.
