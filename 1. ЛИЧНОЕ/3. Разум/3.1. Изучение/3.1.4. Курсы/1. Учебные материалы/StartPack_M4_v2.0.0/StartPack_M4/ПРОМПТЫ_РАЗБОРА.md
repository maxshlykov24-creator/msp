# Промпты разбора транскриптов в Cursor

> 5 готовых промптов под 5 типов разговора. Скопируй, открой `.md` в Cursor, вставь в чат (Cmd+L / Ctrl+L) — Cursor разберёт и пополнит твой контекст компании.

**Общая логика:** транскрипт даёт сырьё. Cursor превращает его в обновления конкретных файлов твоего бизнес-проекта: `_КОНТЕКСТ/`, `_СОТРУДНИКИ/`, `_КЛИЕНТЫ/`, `_ПОДРЯДЧИКИ/`, `_ИДЕИ/`. Эти папки ты собрал в Модуле 2 (Оцифровка).

---

## 1. Митап / конференция / профильная встреча

```
Прочти этот транскрипт митапа. Сделай:

1) Список спикеров (Speaker A, B, C…) и кто из них кто, насколько можно понять по контексту.
2) 5–7 ключевых идей которые прозвучали, с цитатами и тайм-кодами.
3) 3–5 практических инсайтов которые применимы к моему бизнесу (см. _КОНТЕКСТ/КОМПАНИЯ.md).
4) Если упоминались инструменты, книги, имена — выпиши отдельным списком.
5) Предложи 1–2 файла в моём проекте куда стоит дописать заметки из этого митапа.

Заверни в формат markdown, готовый положить в _ИДЕИ/митапы/<дата>_<тема>.md.
```

---

## 2. Созвон с подрядчиком / партнёром

```
Это транскрипт рабочего созвона. Сделай:

1) Резюме на 3–5 пунктов: о чём договорились.
2) Список задач с ответственным и дедлайном (если упоминались).
3) Открытые вопросы которые остались без ответа.
4) Если обсуждались цены / условия — выпиши отдельным блоком.
5) Черновик follow-up письма подрядчику с фиксацией договорённостей (краткий, деловой).
6) Если подрядчик новый — предложи карточку в _ПОДРЯДЧИКИ/<имя>.md (контакты, специализация, ставка, статус).

И сразу — заголовок для КП если из разговора понятна задача под коммерческое предложение.
```

---

## 3. Встреча с клиентом (видеосвязь, Zoom)

```
Это запись встречи с клиентом. Сделай:

1) Карточку клиента в _КЛИЕНТЫ/<имя>.md или обнови существующую: контекст бизнеса, боль, бюджет, сроки, ЛПР.
2) Возражения которые прозвучали — отдельным списком (это золото для лендингов и КП).
3) Обещания которые я дал клиенту — с дедлайнами, чтобы не забыть.
4) Что клиент ХОЧЕТ vs. что ему НА САМОМ ДЕЛЕ нужно (читай между строк).
5) Follow-up письмо клиенту с резюме встречи и next step.
6) Если из разговора понятна задача под КП — черновик заголовка и 3 ключевых блока.

Главное — найти что клиент сказал, но я мог пропустить в моменте.
```

---

## 4. Эксперт / консультант / бизнес-тренер / сопровождение

```
Это разговор с экспертом по моему бизнесу. Цель — НЕ потерять его взгляд после встречи.

Сделай:
1) Рекомендации эксперта пронумерованным списком — что предложил сделать.
2) Под каждой рекомендацией — обоснование (почему он так считает).
3) Что из этого ПРОТИВОРЕЧИТ моему текущему _КОНТЕКСТ/КОМПАНИЯ.md или _БИЗНЕС/ВОРОНКА.md — отдельным блоком (важно!).
4) Конкретные инсайты которые надо вписать в стратегию (с тайм-кодами, чтобы можно было перепроверить).
5) Открытые вопросы которые я не задал, но стоило бы — для следующей встречи.

И — пополни _ЭКСПЕРТЫ/<имя>.md его карточкой: специализация, что советует, чему верить, ставка/формат.

Принцип: его взгляд должен остаться в моей компании, даже если завтра он перестанет на меня работать.
```

---

## 5. Голосовое самому себе / разговор с другом про бизнес / идея на ходу

```
Это моё голосовое (или разговор с другом про бизнес). Сырое, без структуры.

Сделай:
1) Главную мысль одной фразой.
2) Идеи которые прозвучали — отдельным списком.
3) Если есть гипотезы для проверки — выдели их и оцени по ICE (Impact / Confidence / Ease).
4) Если упоминал конкретные люди / компании / суммы / даты — выпиши отдельно (это часто теряется).
5) Предложи куда это положить: _ИДЕИ/, _ГИПОТЕЗЫ/, _ЗАМЕТКИ/, или дописать в _КОНТЕКСТ/КОМПАНИЯ.md.

Если разговор был с другом — отметь что важного сказал он (часто люди со стороны видят то, что я не вижу).
```

## Бонус · Дайджест за неделю

Раз в неделю — пройдись по всем `.md` в `_ТРАНСКРИПТЫ/` за последние 7 дней:

```
Открой все .md в _ТРАНСКРИПТЫ/ созданные за последние 7 дней. Сделай:

1) Дайджест: 5–7 главных тем недели через призму моего бизнеса.
2) Все обещания которые я дал клиентам / подрядчикам / партнёрам — единым списком с дедлайнами.
3) Все возражения клиентов которые прозвучали — для обновления лендингов и КП.
4) Все рекомендации экспертов — какие я уже выполнил, какие ещё нет.
5) 3 главных решения которые мне нужно принять на этой неделе (с обоснованием).

Главное — что я мог пропустить в потоке встреч и теперь видно только в перспективе недели.
```

Это и есть **главная управленческая практика после курса.** Не нужно помнить — нужно фиксировать и раз в неделю смотреть свежим взглядом.
