# StartPack М4 · Транскрибатор встреч

Содержимое:

| Файл | Что |
|---|---|
| `transcribe.py` | Готовый Python-скрипт. 3 STT-провайдера (AssemblyAI / OpenRouter / MyMeet) с авто-выбором |
| `.env.example` | Шаблон файла с ключами. Скопируй в `.env` и впиши свои |
| `_ТРАНСКРИПТЫ/` | Папочная структура (5 категорий) + `_INBOX/` для новых файлов |
| `ПРОМПТЫ_РАЗБОРА.md` | 5 готовых Cursor-промптов под 5 типов разговора + бонус «дайджест за неделю» |
| `BOT_NA_VPS.md` | Бонус: как обернуть скрипт в TG-бота на VPS из М3 для 24/7 работы |

## Быстрый старт (5 минут)

1. Скопируй всю папку `StartPack_M4/` в свой бизнес-проект Cursor (рядом с `_КОНТЕКСТ/`, `_БИЗНЕС/` из М2).
2. `cp .env.example .env` — впиши минимум один из ключей (см. `ИНСТРУКЦИЯ_ДОСТУПЫ.md` в материалах модуля).
3. `pip install requests` (если не стоит).
4. Положи любое аудио в `_ТРАНСКРИПТЫ/_INBOX/`.
5. В Cursor скажи: «обработай файл `_ТРАНСКРИПТЫ/_INBOX/имя.mp3`». Cursor запустит `transcribe.py`.
6. Готовый `.md` появится в `_ТРАНСКРИПТЫ/<категория>/`.
7. Открой `.md` в Cursor → возьми промпт из `ПРОМПТЫ_РАЗБОРА.md` → пополни свой контекст компании.

Привычка: **после каждой встречи / голосового / созвона — файл в `_INBOX/`, разбор в Cursor, контекст растёт.**
