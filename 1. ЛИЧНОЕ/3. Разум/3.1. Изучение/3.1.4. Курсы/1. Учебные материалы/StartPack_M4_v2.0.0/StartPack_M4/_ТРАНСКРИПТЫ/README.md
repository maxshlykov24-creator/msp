# Папка `_ТРАНСКРИПТЫ/`

Сюда складываются `.md`-расшифровки всего, что говорится про твой бизнес. **Это твоя живая база контекста.**

## Как пользоваться

1. Положи аудио/видео в `_INBOX/`.
2. Скажи Cursor: «обработай новый файл из инбокса». Cursor запустит `transcribe.py`.
3. Скрипт по имени файла / caption-подсказке поймёт категорию и положит `.md` в нужную папку (см. ниже).
4. Откроешь `.md` → попросишь Cursor разобрать на смыслы и пополнить твой `_КОНТЕКСТ/` (из М2).

## 5 категорий

| Папка | Что туда |
|---|---|
| `митапы/` | Конференции, выступления, профильные встречи — где много спикеров |
| `созвоны-подрядчики/` | Рабочие звонки с подрядчиками, обсуждение задач и КП |
| `клиенты/` | Видеовстречи и созвоны с клиентами — возражения, обещания, follow-up |
| `эксперты-консультанты/` | Бизнес-тренеры, наставники, консалтеры — взгляд эксперта в твою компанию |
| `личное/` | Голосовые самому себе, разговоры с другом про бизнес, идеи на ходу |

Если категория не определилась автоматически — файл лежит в `_INBOX/`, ты вручную скажи Cursor «переложи в созвоны-подрядчики».

## Главная мысль

Транскрипт сам по себе бесполезен. **Ценность появляется когда Cursor разбирает его и пополняет твой контекст компании.** Готовые промпты разбора под каждый тип — в [ПРОМПТЫ_РАЗБОРА.md](../ПРОМПТЫ_РАЗБОРА.md).

Принцип: **взгляд каждого человека (эксперта, клиента, партнёра) должен остаться в твоей компании.** Без транскрипта он уходит вместе с человеком.
