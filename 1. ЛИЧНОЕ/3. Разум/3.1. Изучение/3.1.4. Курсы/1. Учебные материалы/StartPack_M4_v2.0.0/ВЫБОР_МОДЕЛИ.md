# Выбор STT-провайдера

> В М4 — **3 STT-провайдера на выбор.** Скрипт `transcribe.py` умеет работать со всеми тремя и сам выбирает подходящий по контексту. LLM-разбора смыслов здесь нет — это работа Cursor поверх готового `.md`.

## Зачем три, а не один

Один провайдер не закрывает все кейсы:

| Сценарий | Какой провайдер сильнее |
|---|---|
| Митап, планёрка, Zoom с командой (2+ спикеров) | **AssemblyAI** — диаризация из коробки |
| Голосовое на ходу, монолог, заметка | **OpenRouter Whisper** — дёшево и быстро |
| Не пробивается оплата с РФ-карты | **MyMeet** — российский, рубли, ИП Россия |
| Хочется без скрипта вообще, только UI | **MyMeet** — есть удобный веб-кабинет |

Поэтому `transcribe.py` поддерживает все три. Минимально достаточно одного ключа.

## Сравнение

| Параметр | **AssemblyAI universal-2** | **OpenRouter Whisper-large-v3** | **MyMeet** |
|---|---|---|---|
| Качество RU | ★★★★ | ★★★★ | ★★★★ |
| Диаризация (спикеры) | ✅ встроена | ❌ нет | ✅ есть |
| Видео-формат (mp4/mov) | ✅ напрямую | ❌ только audio | ✅ напрямую |
| Цена | ~$0.37/час | ~$0.36/час | ₽ по подписке (от ~990 ₽/мес) |
| Оплата с РФ-карты | ❌ нужен PDPAI / WantToPayBot | ❌ нужен PDPAI / WantToPayBot | ✅ напрямую (российское ИП) |
| Free на старте | $50 (~135 часов) | от $1 (нужно пополнить) | пробный тариф |
| Веб-кабинет без кода | базовый | нет | ✅ удобный |
| API | стабильное | стабильное | развивается |
| Тот же ключ нужен в | — | М5 (LLM для оценки) | — |

## Логика авто-выбора в `transcribe.py`

Если ученик не указал `--provider`, скрипт смотрит:

1. **Caption-подсказка** в имени файла или флаге `--hint`:
   - содержит «встреча / митап / созвон / клиент / подрядчик / эксперт» → **AssemblyAI**
   - содержит «голосовое / монолог / идея / заметка / voice» → **OpenRouter Whisper**
2. **Размер файла:** > 10 МБ → AssemblyAI (вероятно длинная встреча).
3. **По умолчанию:** OpenRouter Whisper (дешевле).

**Override вручную:**
```bash
python transcribe.py meeting.mp3 --provider assembly
python transcribe.py voice.ogg --provider openrouter
python transcribe.py zoom-call.mp4 --provider mymeet
```

**Fallback:** если выбранный провайдер вернул ошибку, скрипт выводит понятное сообщение. Ручной перезапуск с другим `--provider`.

## Когда что выбирать

### AssemblyAI — встречи / совещания / переговоры

- Митап, конференция, выступление со спикерами
- Совещание команды, планёрка, ретроспектива
- Видеовстреча с клиентом или подрядчиком
- Любое аудио где **важно разделить кто что сказал**

Диаризация AssemblyAI работает хорошо на русском, mp4 принимает напрямую (не нужен `ffmpeg`).

### OpenRouter Whisper — голосовые / монологи / заметки

- Голосовое самому себе на ходу
- Запись монолога-планирования
- Диктофонная заметка после встречи
- Короткие фрагменты <2 мин

Whisper не разделяет спикеров — на двухголосном файле получишь сплошной текст. Зато быстро и дёшево.

### MyMeet — для тех кто не хочет связываться с зарубежными API

- Карта РФ не пробивается через PDPAI / WantToPayBot
- Хочется веб-кабинет вместо скрипта (закинул файл — скачал `.md`)
- Нужна интеграция с Zoom Cloud Recording (MyMeet умеет сам забирать записи)

Если **только MyMeet** — скрипт `transcribe.py` опционален. Можно вообще не настраивать `.env`, работать через UI mymeet.ai, а в Cursor класть готовые расшифровки. Для зачёта М4 этого достаточно.

## Параметры в `.env`

```bash
# Минимум один. Можно все три.
ASSEMBLYAI_API_KEY=
OPENROUTER_API_KEY=
OPENROUTER_STT_MODEL=openai/whisper-large-v3
MYMEET_API_KEY=
```

## Раз в полгода — проверь рынок

STT-индустрия медленнее LLM, но обновляется:

1. Зайди на [assemblyai.com](https://www.assemblyai.com/) и [openrouter.ai/models?modality=audio](https://openrouter.ai/models?modality=audio) — посмотри новые STT-модели.
2. Прогони одну контрольную встречу через всех трёх провайдеров.
3. Если кто-то заметно лучше — обнови `OPENROUTER_STT_MODEL` или замени AssemblyAI на Deepgram (там $200 free кредитов).

15 минут в полгода. Окупается в первый же месяц на больших объёмах.

## TL;DR

- **Встречи / совещания / переговоры со спикерами** → AssemblyAI (автомат)
- **Голосовые / монологи / заметки** → OpenRouter Whisper (автомат)
- **Хочется проще / нет карты для зарубежной оплаты** → MyMeet (через веб-кабинет, без скрипта)
- **Override** → `python transcribe.py file.mp3 --provider {assembly,openrouter,mymeet}`
- **Смыслы из транскрипта** → Cursor с агентами из М2/М3 + промпты из `ПРОМПТЫ_РАЗБОРА.md`
