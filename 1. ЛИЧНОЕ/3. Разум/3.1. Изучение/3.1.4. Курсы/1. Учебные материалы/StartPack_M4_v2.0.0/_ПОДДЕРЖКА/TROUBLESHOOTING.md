# Troubleshooting

> Иди по симптомам сверху вниз. Если ничего не подошло — пиши Лине @LinaRam18, приложи терминал-лог и `.env` (без значений ключей).

## §1 · Скрипт не запускается

### 1.1 `python: command not found`

**Симптом:** в терминале Cursor: `python: command not found` или `python3: command not found`.

**Что делать:**
- **Mac:** `brew install python3` (если есть Homebrew) или скачай с [python.org/downloads](https://www.python.org/downloads/).
- **Windows:** скачай с [python.org/downloads](https://www.python.org/downloads/), при установке **поставь галочку «Add Python to PATH»**.
- После установки перезапусти Cursor.

Cursor использует системный Python — если поставил, но всё ещё ошибка, скажи Cursor «настрой Python interpreter в Cursor».

### 1.2 `ModuleNotFoundError: No module named 'requests'`

**Симптом:** при запуске скрипта.

**Что делать:**
```bash
pip install requests
```
или
```bash
pip3 install requests
```

Если выдаёт ошибку про права — добавь `--user`: `pip install --user requests`.

### 1.3 Скрипт запускается, но ничего не пишет / зависает

**Симптом:** запустили, терминал замер.

**Что делать:**
- AssemblyAI: первый прогон — загрузка файла. Большой файл (>50 МБ) грузится 30-60 сек, потом ещё 1-3 мин на транскрипцию. **Терпение, не Ctrl+C.**
- OpenRouter Whisper: загрузка быстрая, но если файл >25 МБ → ошибка размера.
- MyMeet: см. их статус-страницу.

Если ждёшь >5 минут на коротком файле — Ctrl+C, перезапусти.

## §2 · Ключи и API-ошибки

### 2.1 AssemblyAI: `401 Unauthorized`

**Что делать:**
- Проверь `.env` — ключ должен быть БЕЗ слова `Bearer`, просто строка ~32 символа.
- Зайди в [assemblyai.com/dashboard](https://www.assemblyai.com/dashboard) → API Keys → перегенерируй ключ.
- Перезапусти терминал в Cursor чтобы `.env` перечитался.

### 2.2 AssemblyAI: `402 Payment Required`

**Симптом:** баланс закончился.

**Что делать:**
- [assemblyai.com/dashboard](https://www.assemblyai.com/dashboard) → Billing → пополни.
- На старте даётся $50 free — это ~135 часов аудио. Если кончилось быстро — проверь не зациклил ли скрипт.

### 2.3 OpenRouter: `401 No auth credentials`

**Что делать:**
- Ключ должен начинаться с `sk-or-v1-`. Если нет — пересоздай в [openrouter.ai/keys](https://openrouter.ai/keys).
- В коде используется `Authorization: Bearer sk-or-...` — это уже в скрипте, ты ничего не настраиваешь.

### 2.4 OpenRouter: `402 Insufficient credits`

**Что делать:** пополни баланс на [openrouter.ai/credits](https://openrouter.ai/credits). Минимум $5.

### 2.5 РФ-карта не принимается AssemblyAI / OpenRouter

**Что делать:**
- **Вариант 1:** виртуальная карта через [pdpai.ru](https://pdpai.ru/register?ref=REFCC6VM7YT) — реф-ссылка Дениса, проверенная.
- **Вариант 2:** [WantToPayBot](https://t.me/WantToPayBot?start=w17851188--DTBZM) — выпуск виртуальной карты прямо в TG.
- **Вариант 3:** переключись на MyMeet — он принимает РФ-карту напрямую.
- **Временно:** попроси у Лины тестовый ключ Дениса на 1 прогон, чтобы сдать ДЗ.

## §3 · Файл и формат

### 3.1 `Файл не найден`

**Что делать:** проверь путь. Используй абсолютный путь или путь относительно папки где запускаешь.

Лучший способ — в Cursor правой кнопкой по файлу → Copy Path → вставить в команду.

### 3.2 Транскрипт пустой / в `.md` только шапка

**Симптом:** файл создался, но текста нет.

**Что делать:**
- Проверь что у аудио есть звуковая дорожка (открой в плеере).
- Если видео без звука — это редкий кейс, проверь оригинал.
- Whisper иногда отдаёт пустой результат на слишком тихих/шумных аудио — попробуй AssemblyAI: `--provider assembly`.

### 3.3 Диаризация не работает (один Speaker A на встрече 2+ людей)

**Симптом:** двое говорят, в `.md` всё подписано как Speaker A.

**Причины:**
- Файл слишком короткий (<30 сек) — AssemblyAI не успевает «расслышать» голоса.
- Голоса слишком похожи, или один говорит >90% времени.
- Используешь Whisper (OpenRouter) — он **не умеет** диаризацию. Переключись: `--provider assembly`.

**Что делать:**
- На двухголосном файле — всегда AssemblyAI или MyMeet.
- Если AssemblyAI всё равно не разделил — пиши Лине, разбираем кейс.

### 3.4 Файл больше лимита OpenRouter (25 МБ)

**Симптом:** ошибка `413 Payload Too Large`.

**Что делать:**
- Скрипт должен сам выбрать AssemblyAI на больших файлах (>10 МБ). Если не выбрал — `--provider assembly`.
- Или разбей файл на части любым видеоредактором / `ffmpeg`.

## §4 · Cursor и интеграция

### 4.1 Cursor не находит `transcribe.py`

**Симптом:** говоришь «запусти transcribe.py», а Cursor «такого файла нет».

**Что делать:**
- Скажи: «открой папку StartPack_M4 в моём проекте». Cursor найдёт.
- Если не находит — проверь, что папка `StartPack_M4/` лежит **внутри** твоего бизнес-проекта Cursor, а не где-то отдельно.

### 4.2 Cursor запускает скрипт, но не видит `.env`

**Симптом:** ошибка «API_KEY не задан» хотя ключ есть.

**Что делать:**
- Файл должен называться **именно `.env`** (не `.env.example` и не `env.txt`). Точка в начале обязательна.
- Файл должен лежать **в той же папке что и `transcribe.py`** (т.е. `StartPack_M4/.env`).
- Скажи Cursor: «покажи содержимое `.env`» — если файла нет, попроси создать из `.env.example`.

### 4.3 Cursor разобрал транскрипт, но обновил не те файлы

**Симптом:** попросил пополнить `_КЛИЕНТЫ/<имя>.md`, а он перезаписал что-то другое.

**Что делать:**
- Всегда давай Cursor **точный путь файла**, который надо обновить.
- Проверь diff перед `Accept` — Cursor всегда показывает изменения.
- Если уже принял неудачное изменение — `git restore <file>` (если в git) или Cmd+Z в открытом редакторе.

## §5 · MyMeet (опционально)

### 5.1 MyMeet API возвращает ошибки

**Что делать:**
- MyMeet API на момент написания М4 — не всегда стабильно. Если упирается в API → используй веб-кабинет mymeet.ai напрямую. Залил файл — скачал `.md` → положил в категорию `_ТРАНСКРИПТЫ/<…>/`. Это **полноценный путь сдачи ДЗ**.
- Если хочется автоматизации — пиши Лине, посмотрим вместе.

## §6 · Бонус-трек (TG-бот на VPS)

### 6.1 Бот молчит после старта

См. `StartPack_M4/BOT_NA_VPS.md` § «Дебаг». Базовые проверки:
- `systemctl status m4-transcriber-bot` — active?
- `journalctl -u m4-transcriber-bot -f` — что в логах?
- TG-токен правильный? `curl https://api.telegram.org/bot<TOKEN>/getMe` отвечает 200?

## §7 · Когда ничего не помогает

1. Скопируй последние 10–20 строк терминала.
2. Покажи Cursor: «вот ошибка моего скрипта, разбери и предложи фикс».
3. Если Cursor не разобрался — пиши Лине @LinaRam18, приложи скриншот + `.env` без значений ключей.
4. Красная зона (ничего не работает 48ч+) → созвон с Вебстражем по записи через @catalystosbot.
