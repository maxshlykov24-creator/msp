# Что скрипт принимает на вход

> Один Cursor-скрипт `transcribe.py` + 3 STT-провайдера. Каждый по-своему работает с форматами. Ниже — что куда.

## Сводная таблица

| Тип файла | AssemblyAI | OpenRouter Whisper | MyMeet |
|---|---|---|---|
| **mp3 / m4a / wav / ogg** | ✅ напрямую | ✅ напрямую | ✅ напрямую |
| **mp4 / mov / webm (видео)** | ✅ извлекает аудио сам | ❌ нужен `ffmpeg`-извлечение | ✅ извлекает сам |
| **Голосовое из Telegram (.ogg)** | ✅ | ✅ | ✅ |
| **Длинные файлы (>1 час)** | ✅ до 5 ГБ | ⚠️ до 25 МБ за запрос | ✅ есть тариф |
| **YouTube-ссылка** | ❌ нужен `yt-dlp` локально | ❌ | ❌ |
| **Google Drive ссылка** | ❌ скачивается локально | ❌ | ⚠️ зависит от тарифа |
| **Zoom Cloud Recording (по API)** | ❌ скачивается локально | ❌ | ✅ автоматическая интеграция |

## Главное правило

**Положи файл в `_ТРАНСКРИПТЫ/_INBOX/` локально.** Скрипт работает с локальными файлами. Если файл в облаке — скачай его в `_INBOX/` любым способом (drag-n-drop из Drive, скачивание Zoom-записи, экспорт MyMeet).

Это сделано осознанно: **локальные файлы = у тебя в руках**. Если что-то пойдёт не так — у тебя оригинал, всегда можно перезапустить.

## Размеры и лимиты

| Провайдер | Лимит размера | Лимит длительности | Когда упрёшься |
|---|---|---|---|
| AssemblyAI | 5 ГБ | без лимита | гигантские записи лекций |
| OpenRouter Whisper | 25 МБ за запрос | ~25 мин аудио | длинная встреча — раздели на куски или используй AssemblyAI |
| MyMeet | по тарифу | по тарифу | смотри ЛК mymeet.ai |

⚠️ **Если файл слишком большой для Whisper** — скрипт авто-выберет AssemblyAI (см. [ВЫБОР_МОДЕЛИ.md](../ВЫБОР_МОДЕЛИ.md)). Или вручную: `python transcribe.py file.mp4 --provider assembly`.

## Откуда брать аудио в твоём бизнесе

### 1. Митапы и конференции
- Если ты выступаешь — записывай экран встречи через Zoom / Meet / Telemost. На выходе mp4.
- Если ты участник — спроси у организаторов запись, или используй [Otter.ai](https://otter.ai/) / [tl;dv](https://tldv.io/) как наблюдателя.
- Бесплатный вариант — диктофон смартфона прямо в зале (рядом со спикером).

### 2. Созвоны с подрядчиками
- **Zoom:** Cloud Recording (Pro+ план) → mp4 в облако → скачай в `_INBOX/`.
- **Google Meet:** Recording (Workspace) → Drive → скачай.
- **Telemost (Яндекс):** Pro — есть запись.
- **Telegram-звонки:** записывай экран на телефоне / Mac (нужно разрешение собеседника).
- **WhatsApp / Viber звонки:** запись экрана + системный микрофон.

### 3. Видеовстречи с клиентами
- Тот же Zoom Cloud Recording. **Договорись заранее** — у клиента видна красная точка «идёт запись». Это нормально, юридически чисто.
- Если клиент не хочет видео — запиши только аудио (на телефон рядом). Часто этого достаточно.

### 4. Эксперты / консультанты / тренеры / сопровождение
- **Zoom-разборы:** Cloud Recording обязательно — теряются деньги, если не записал.
- **Встречи вживую:** диктофон смартфона. Лучше — TG-голосовое для надёжной синхронизации (TG не теряет файлы).
- **Мастермайнды и групповые сессии:** проси у организаторов запись. Обычно дают.

### 5. Голосовые себе, разговор с другом
- Просто записывай голосовое в Telegram → Saved Messages → 3 точки → Save File.
- Или диктофон смартфона. Файл потом перекидываешь в `_INBOX/`.

## Готовые сторонние сервисы (могут заменить скрипт)

Если ты не хочешь возиться со скриптом — есть полностью готовые сервисы. **Это валидный путь сдачи М4**: подключаешь сервис, получаешь `.md` (или `.txt`), кладёшь в правильную категорию, Cursor разбирает.

| Сервис | Что | Когда брать |
|---|---|---|
| **[MyMeet](https://mymeet.ai/)** | RU. Запись + расшифровка встреч. Веб-кабинет, бот для Telegram | Если хочется без скрипта вообще, или нет международной карты |
| **[Otter.ai](https://otter.ai/)** | EN. Лучшая диаризация на английском, плагин Zoom | Если у тебя много встреч на английском |
| **[tl;dv](https://tldv.io/)** | EN/RU. Встроенный наблюдатель в Zoom/Meet | Если команда на западных созвонах |
| **[Descript](https://www.descript.com/)** | EN/RU. Видеоредактор + транскрипция | Если планируешь монтировать подкасты/видео |

Все эти сервисы выгружают `.txt` / `.docx` / `.md`. Превращай в `.md`, клади в `_ТРАНСКРИПТЫ/<категория>/` — Cursor разбирает тем же промптом.

## Главное

Скрипт — это **контроль и кастомизация**. Сервисы — это **скорость и UI**. Цель модуля не «настроить скрипт», а **наполнять контекст компании регулярно**. Если сервис помогает фиксировать чаще — пользуйся сервисом.
