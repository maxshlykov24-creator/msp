# Старт здесь

> Привычка предпринимателя: **всё, что про твой бизнес — фиксируем.** Встреча с клиентом, созвон с подрядчиком, разбор с консультантом, идея в голосовом другу — закидываем файл → через минуту в `_ТРАНСКРИПТЫ/` готовый `.md` → Cursor пополняет контекст компании.

Без этого взгляды экспертов уходят с экспертом, возражения клиентов забываются к следующей встрече, идеи на ходу пропадают. **Твой бизнес теряет память.**

## Что ты получишь

1. **Готовый Cursor-скрипт `transcribe.py`** — кладёшь в свою бизнес-папку. Закидываешь файл, говоришь Cursor «обработай» — получаешь `.md`-транскрипт с разделением на спикеров.
2. **3 STT-провайдера на выбор** — AssemblyAI (для встреч с 2+ людьми), OpenRouter Whisper (дёшево для голосовых), MyMeet (российский, с РФ-картой напрямую).
3. **Папочная структура `_ТРАНСКРИПТЫ/`** — 5 категорий (митапы / созвоны-подрядчики / клиенты / эксперты-консультанты / личное) + `_INBOX/` для новых.
4. **5 готовых промптов разбора в Cursor** — под каждый тип разговора. Прочти `.md` → скопируй промпт → Cursor разбирает на смыслы и пополняет твой контекст.
5. **Бонус-трек:** как обернуть скрипт в TG-бота на VPS из М3, чтобы транскрибировать на ходу с телефона 24/7.

⏱ **Время:** 50 минут видео + ~30 минут активной работы → **1.5 часа** на первый прогон.
💰 **Стоимость:** 0 ₽ инфры (скрипт локально / VPS из М3) + ~$5–10/мес на STT (AssemblyAI free $50 на старте).

## 3 шага · что делаешь по порядку

```
[1] Получить 1–3 ключа          (~10 мин)  →  _ПОДДЕРЖКА/ИНСТРУКЦИЯ_ДОСТУПЫ.md
        ↓
[2] Скопировать StartPack_M4    (~5 мин)   →  StartPack_M4/ → твоя бизнес-папка
    в свою бизнес-папку Cursor                                из М1/М2
        ↓
[3] Прогнать 3 файла + сдать ДЗ (~15 мин)  →  ДОМАШКА.md
```

Всего активной работы — **~30 минут**, остальное смотришь в видео урока.

## Что нужно перед началом

- ✅ Бизнес-папка из М1/М2 (там уже `_КОНТЕКСТ/`, `_БИЗНЕС/`, `_КЛИЕНТЫ/` и т.д.).
- ✅ Cursor с подпиской Pro+ (как в М1).
- ✅ Карта РФ для оплаты STT (~$5–10 на старт). Альтернативы — [pdpai.ru](https://pdpai.ru/register?ref=REFCC6VM7YT) или [WantToPayBot](https://t.me/WantToPayBot?start=w17851188--DTBZM).
- ✅ Python 3 (он уже стоит на Mac/Linux; на Windows — `python.org` или Cursor сам поставит).
- ✅ Любое тестовое аудио — голосовое в TG, mp3 с диктофона или короткое Zoom-mp4. Можно реальную встречу обезличенную.

**VPS из М3 НЕ нужна** для базового трека М4. Понадобится только если решишь сделать бонус — свой TG-бот 24/7.

## Главный сдвиг этого модуля

> **Ты собираешь систему памяти своей компании.** Не для отдела продаж, не для команды — для самого факта существования компании.

В М1 ты собрал рабочее место CEO. В М2 — оцифровал организацию. В М3 — собрал AI-сотрудника для лидов. В М4 — **закрываешь дыру утечки контекста.** Каждый разговор, который раньше пропадал, теперь остаётся в твоей системе.

Это **первый AI-сотрудник, которым ты пользуешься каждый день лично.** Остальные — в фоне. Этот — твой ассистент.

## После сдачи

1. Открывается **Модуль 5** (Слушатель звонков — ОКК). Там твой Транскрибатор учится **оценивать** звонки менеджеров по чек-листу — добавится LLM-аудит и Sheets-дашборд. Тот же STT, та же папочная структура — но уже для команды, не лично для тебя.
2. **Транскрибатор остаётся работать.** Каждую встречу, каждое голосовое — в `_ТРАНСКРИПТЫ/`. К Модулю 6 у тебя 30–50 расшифровок — это уже корпус для контента и аналитики.
3. **Раз в неделю** — Cursor + промпт «дайджест за неделю» из `ПРОМПТЫ_РАЗБОРА.md`. Это **главная управленческая практика после курса.**
