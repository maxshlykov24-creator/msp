# Посудомойка, мастер

Копия переписки из личного Telegram, чат «Мастер посудомойка», с 6 по 23 сентября 2026. Снята 23.09.2026 в 11:07 МСК, чтобы тексты, фото и голосовые можно было отдать юристу.

- `переписка.md` — сообщения по времени, московское время, id Telegram
- `переписка.json` — те же сообщения полями
- `файлы/` — 3 голосовых (ogg) и 3 фото: смета деталей, квитанция 10 000, скрин смс
- `SHA256.txt` — контрольные суммы json, md и файлов

В этом чате нет рукописной расписки и фото паспорта. Файлы не переписывать: после правки суммы в `SHA256.txt` перестанут сходиться.
