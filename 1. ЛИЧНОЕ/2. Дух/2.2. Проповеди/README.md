# Проповеди

**Просмотр и прослушивание** проповедей (чужих): кто, когда, ссылка/сервис, краткий конспект, цитаты, что откликнулось.

**Структура:** тематические подпапки с нумерацией `2.2.N.` (как в остальном профиле): `2.2.1. Благодать/` … `2.2.10. Прочее/`. Описание границ тем — в `.cursor/ПРОПОВЕДИ_ПОДПАПКИ_СМЫСЛ.md` (корень репозитория Cursor). Новые сырые файлы по умолчанию — в [`Входящее/Проповеди`](../../Входящее/Проповеди).

**Граница с `Изучение/`:** если после просмотра начинаешь **углубленно** разбирать текст или тему — основная работа в `Изучение/` (например `Вопросы/` или конспект по книге Библии), а здесь оставь ссылку на просмотр или одну строку «продолжение там».

Имена файлов: `YYYY-MM-DD_Спикер_тема` или как удобно для поиска.

Канон — [СТРУКТУРА_И_ПРИНЦИПЫ.md](../../СТРУКТУРА_И_ПРИНЦИПЫ.md).
