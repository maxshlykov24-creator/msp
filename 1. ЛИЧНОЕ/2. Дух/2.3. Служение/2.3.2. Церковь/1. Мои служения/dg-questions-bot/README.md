# dg-questions-bot

Telegram-бот для вечеров вопросов с лидерами домашних групп.

**Два телефона:**
- 🎯 **Модератор** — управляет темпом, отмечает ответы, видит прогресс
- 📺 **Экран для стола** — показывает вопрос, передаётся по кругу

**Гарантии:**
- Вопросы не повторяются между встречами: ответ сразу пишется в колоду
- Пропуск не сжигает вопрос: он может вернуться в другой раз
- Порядок: сначала лёгкие → тёплые → чуть глубже
- Состояние переживает перезапуск бота

---

## Быстрый старт

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Настройка
cp .env.example .env
# вставь BOT_TOKEN в .env

# 3. Сгенерировать questions.json из колоды
python build_questions.py

# 4. Запуск локально (для теста)
python -m app.main
```

## Игровой цикл

```
/start → выбор роли
Модератор: создаёт сессию → получает код
Экран: вводит код → связываются

Модератор: выбирает Продолжить (сначала — только с подтверждением) → лёгкие+тёплые / вся колода

Экран: [▶ Мой вопрос] → вопрос показывается обоим
  → [↺ Другой вопрос] — заменить вопрос один раз за ход
  → ожидает модератора

Модератор: [✅ Ответил] / [⏭ Пропустить] / [↩ Не тот человек]
  → экран снова: передай телефон

Модератор: [🏁 Завершить встречу] → итог; отвеченные уже в колоде
```

- **pydantic-settings** — конфиг из .env
- **Docker** — деплой на VPS DKAcademy `194.87.226.234` (см. `deploy/DEPLOY.md`)
